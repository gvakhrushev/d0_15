# D0 Theory Closure Contract

This file fixes the **definition of done** for the research programme.  Its purpose is
to prevent frontier inflation: decomposing one vague obstruction into several precise
lemmas must not be counted as making the theory less complete.

## 1. Completion is classification, not absence of possible questions

A D0 question is terminal when it is in one of four states:

1. **CORE** — internally derived and machine-owned.
2. **NO-GO** — internally proved not derivable from the frozen present core.
3. **BRIDGE / PASSPORT** — the exact external mathematical or physical input is named,
   typed, and separated from the core.
4. **EMPIRICAL TEST** — the internal observable is frozen and only comparison with data
   remains.

A terminal NO-GO or passport is **not an open core debt**.

The theory is not required to eliminate every conceivable external bridge, derive every
Standard-Model/cosmological number, or formalize every mathematical framework that can
be connected to D0.

## 2. What counts as a load-bearing blocker

A new target may enter the active closure frontier only if at least one is true:

- it can change a frozen internal observable/readout;
- it is needed to type or prove an existing CORE claim;
- it reveals status inflation: the registry says CORE/CERT but the implementation proves
  materially less;
- without it an existing residual cannot be classified as CORE, NO-GO, bridge/passport,
  or empirical.

Interesting extensions that do not satisfy these conditions are parked as **OPTIONAL
EXTENSIONS**, not counted against closure.

## 3. Progress metric: independent blocking entropy

Do **not** count:
- theorem count;
- issue count;
- named proof-target count;
- downstream consumers of one missing primitive.

Count instead the number of **independent unclassified choices** that can alter a core
result.

When one broad question is decomposed into five precise consequences of the same missing
map, blocker count remains one.  When a NO-GO proves that a whole family of candidates
cannot work, blocker count decreases even if the registry gains several explanatory
theorems.

## 4. Current representation example

The finite-generation grading frontier illustrates the rule.

The graph-derived degree operator is `diag(24,22,20)`.  A compatible involution is now
classified into exactly eight diagonal sign patterns.  The two scalar cases `±I` give
the scalar branch; all six non-scalar cases give the same neutral-current readout
`nc = 8`.  Direct scene/address parity is `-I`, so that route is closed-negative.

Therefore the load-bearing representation residual is **not** “find a grading”, “choose
which generation is negative”, or “choose a Q8-rank pairing”.  Those are already
collapsed.  The residual is the single provenance statement connecting the owned
terminal Fourier orientation sector algebra to the intrinsic generation observable
algebra.  All downstream variants of that one statement count as one blocker.

## 6. Stop rule

Research on a lane stops when its load-bearing ambiguity is terminally classified.
Further mathematics may continue as an extension, but it must not silently move the
definition of a completed D0 theory.

The global closure target is therefore:

> **zero unclassified load-bearing internal ambiguities, with every remaining interface
> explicitly CORE, NO-GO, BRIDGE/PASSPORT, or EMPIRICAL.**

This target is intended to decrease monotonically even while the explanatory theorem
graph grows.
