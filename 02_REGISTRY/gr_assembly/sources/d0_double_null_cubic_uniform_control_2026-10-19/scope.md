# Exact cubic uniform-correction control

For the orthogonal crossed-null profile `H=a x`, `J=b y`, the exact `a*b` Cartan correction from the pinned #334 theorem makes all 40 field Euler coefficients vanish. This control expands the full continuum-Levi-Civita links with that correction in the exact ring `Q[a,b]/(a^3,b^3)` at `h=1`, using the original six plaquettes and independent 24 link plus 16 coframe variations.

At each cubic order `[a^2 b]` and `[a b^2]`, the flat homogeneous 24x24 Cartan Hessian has determinant 256. A spatially uniform cubic connection correction chosen to cancel all 24 link rows at the origin does so at that node, but leaves two nonzero coframe rows there. The same correction also leaves nonzero link rows at the adjacent node `(x,y)=(1,0)`. Thus the constant-correction chart does not close the cubic 40-row system.

This is a scoped negative control. It does not exclude spatially varying link corrections, permitted lower-order coframe modes, a coupled lattice solve, a full all-order root, or physical D0-to-GR closure.
