# D0 to GR assembly

This is the composition layer for the current gravity route. Claims and proof
owners remain in their existing registries; the work manifest remains the queue
and GitHub remains the live execution plane. An application records exactly
which result discharges which premise, with its hypotheses and interface map.

The integration in this PR adds typed obligations, scoped prior attempts,
provenance, task dispatch checks and a generated overview. Imported research
keeps its original scope and pending acceptance. A no-go removes only its
declared route; it never supplies an existence premise.

The command reference and acceptance rules are completed in this same PR.
