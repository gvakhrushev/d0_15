# Кандидат: Role-индукция coordinate coframe на одном невакуумном джете

Статус: **candidate**. Это один оператор и сравнение коэффициентов. Полная native-цена не отождествлена с геометрическим действием. Строка `claims.csv` не заводится. ОТО этим сертификатом не выводится.

Pin реконструкции, только чтение: `e92d4714183aec5b8838906be1dfd23844178042`. Blob `check_reconstruction.py`: `0b11d34f2f982a62616722feeb110f10fa55f2e6`. Ветка #334 не меняется и не вливается.

## Утверждение

На семействе

```text
N[0,0]=N[0,3]=1/2, N[3,0]=N[3,3]=-1/2, N^2=0,
e=I+H N, F=I-H N, g=e^T eta e=eta+H k k^T, k=(1,0,0,1),
```

симметричная матрица `V` с индексами `0..3` индуцирует вариацию coordinate coframe

```text
delta e = e g^{-1} V / 2.
```

Это формула (14) pin. Строки `e` не являются native legs `v_r = eta F_r^T`: при `H=1` эти два столбца различны.

Для профильной вариации `V=k k^T` подъём равен `N` и занимает только строки 0 и 3. Строки 1 и 2 у `F` от `H` не зависят.

Источник считается дважды, отдельно:

- из torsion → absorb → curvature этого coframe;
- из координатных символов Кристоффеля метрики `g`, со знаком MTW `R_{σν}=R^ρ_{σρν}`.

Coframe-кривизна на общем 2-джете и Christoffel на квадратичном профиле `H = p x^2/2 + q y^2/2 + r x y` дают один коэффициент. Отдельный Christoffel на `H=x^3` даёт `Ric=3x k k^T`, то есть `(Hxx) k k^T / 2` при непостоянной второй производной. На `H=x^2+1/4` Christoffel даёт `Ric=k k^T`, и probe `E_00` равен 1 тождественно, не только в нуле.

```text
Ric=(Hxx+Hyy) k k^T / 2,    R(g) vol = 0.
```

След нулевой на всём семействе, в том числе вне vacuum. Это геометрическое свойство данного источника. Оно не есть архивный anomaly-stress: тот на своём носителе равен нулевой матрице, а здесь `Ric` при `Hxx+Hyy≠0` нулевой матрицей не является.

Невакуумный джет `H=x^2+1/4` в точке `x=y=0`:

```text
H=1/4, Hx=Hy=Hxy=Hyy=0, Hxx=2,
Ric=k k^T,
trace(g^{-1} Ric g^{-1} E_00)=1,
delta e(E_00)=E_00*(7/16)+E_30*(1/16).
```

Подъём probe снова сидит на строках 0 и 3. Профильный probe `trace(Gup k k^T)` равен 0: вариация одного только `H` этот источник не видит.

## Что сюда не входит

Равенство (20) pin, `d S_native ?= c d∫(L_cmp+L_T)+d S_matter+r`, не доказано. Коэффициент `c` и материальный функционал `S_m` не выбираются. `2c G=T` не записывается. Dressing не объявляется каноническим выбором coframe: левое лоренцево `P` с `P_00=P_33=5/4`, `P_03=P_30=3/4` сохраняет `g` и меняет `e`. Правое действие тем же `P`, как в регулярной карте pin, координатную метрику меняет; оно не используется как сохранение метрики.

## Отрицательные контроли

Все четыре способны отвергнуть отождествление, и все его отвергают.

| Объект | Значение на этом джете | Совпадает с probe 1 |
| --- | --- | --- |
| heat-зазор `2(Hx^2+Hy^2)` в нуле профиля `H=x^2` | 0 | нет |
| row-wave, `a=1/4`, `b=1/125`, второй вклад `-gamma/4` | ненулевой и не 1 | нет |
| `endpoint_factor(4,1)` | 2 | нет |
| нулевая архивная матрица | 0 | нет |

`gamma` на этой карте равен

```text
40443990906472/5471020515625 - 19682707537316 sqrt(2)/5471020515625.
```

Постоянный row-wave frame имеет нулевой координатный Ricci. Скалярный вес этого pp-wave заморожен: `det e=1`. Гармонический вакуум `Hyy=-Hxx` имеет `Ric=0` и ненулевой тензор кривизны.

## Предусмотренная атака

1. Подставить `Ric` формулой вместо вычисления. Проверка сравнивает кривизну coframe с отдельным Christoffel.
2. Назвать probe материальным модулем. Модули `matter_response` и `weighted_source` в этот probe не отображаются; это записано контролями, а не опущено.
3. Считать след-нуль архивной anomaly-свободой. Носители разные, матрицы разные.
4. Распространить один джет на все материи или на native-цену. Класс здесь один: это семейство и этот джет.
5. Прочитать источник по вариации `H`. Этот probe равен 0 при ненулевом `Ric`.
