## Проверка и воспроизведение

Пять точных встроенных Python-блоков §7fy были независимо выполнены в обычном
и `-O` режимах на Python 3.9.6 / SymPy 1.14.0, с `-Werror`: десять кодов 0,
пустой stderr и совпадение каждой stdout SHA-256 с owner. В [results](results/)
сохранена одна полная stdout каждого скрипта, так как обычная и
оптимизированная выдача совпали. [independent_replay.json](independent_replay.json)
фиксирует оба запуска. Это те же owner-программы; проверки конечного `k=2` и
малого Q8-контроля не доказывают асимптотические AR1–AR6 или физический C.

Проверить сохранённые файлы; при наличии исходных Git-объектов — весь diff,
оба source blobs, точные смещения и закреплённый native input:

```sh
python3 -B 02_REGISTRY/research/sources/d0_334_7fy_first_repeat_2026-11-06/verify_intake.py --verify-source-objects
```

Свежий replay извлекает пять проверенных блоков и вход только во временный
каталог под `/tmp`, проверяет их хеши перед каждым вызовом и запускает обе
версии с `-Werror`. Нужен установленный SymPy; owner использует 1.14.0.

```sh
python3 -B 02_REGISTRY/research/sources/d0_334_7fy_first_repeat_2026-11-06/replay_bounded.py --verify-source-objects
```

Вариант без `--verify-source-objects` сверяет локальные пины, но не
подтверждает их происхождение из Git. Проверка требует совпадения stdout
с хешами владельца; отличающаяся версия среды может не пройти этот строгий
тест. Replay доверяет своим входам, интерпретатору и среде; он не является
песочницей или защитой от параллельной подмены файлов.
