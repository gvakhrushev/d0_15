## 1. Карта и регулярность

Эффект `E = (E_0, E_1)` эрмитов на старых блоках. Ветви `Φ_E` — те же, что в стационарном мемо, формулы (1)–(2): для типа `j`

```text
w_0² = p³,  w_1² = p²,  v_0² = p⁴,  v_1² = p³,
(m_0, m_1) = (3, 2) для j = 0 и (2, 1) для j = 1,
A_+ = w R + B/√2,  A_- = w R - B/√2,
ещё (m_0 - 2) копий w R и m_1 копий v R,
R = √(I - E),  B = √E.
```

`f_j` — скалярная условная цена (2), на матрицу продолжается непрерывным функциональным исчислением. Минус-ветвь обращается в нуль при

```text
e_{*,0} = 2p³ / (1 + 2p³),   e_{*,1} = 2p² / (1 + 2p²).
```

Объявленный безопасный интервал — тот же куб якобиана, переписанный в собственных значениях `e = p²(1+u)`:

```text
δ = p³ / (2(1 + 2p²)),
I_safe = [p²(1 - δ), p²(1 + δ)].
```

На `I_safe` выполнены четыре условия источника.

1. `I_safe ⊂ (0, 1)`, и расстояние до `{0, 1, e_{*,0}, e_{*,1}}` больше `0.02555`. Интервальная оценка даёт концы около `0.356406652216057` и `0.407525370284153`, корни около `0.320714913182` и `0.433084729318`.
2. Каждая вероятность ветви не меньше `P_min > 5.912×10^{-4}`. Плюс-ветвь отдельно не меньше `0.659`. Поэтому `f_j` класса `C^∞` на `I_safe`: квадратные корни гладки на компакте внутри `(0, 1)`, а `q log q` гладок, пока `q` отделено от нуля.
3. `φ_j = exp(-ℓ f_j)` тоже `C^∞`. Первая разделённая разность `(φ')^{[1]}(λ, μ)` продолжается по непрерывности значением `φ''(λ)`. Это интегральный остаток Тейлора, не полюс. Совпадение собственных значений не является сингулярностью.
4. Для гессиана остатка нужно отдельное coarse-условие: все собственные значения `σ` и `σ*` не меньше объявленного `s_♭ > 0`. Тогда положительные углы выхода имеют собственные значения не меньше `m = s_♭ P_min`. Структурные нули дополнения полного fine-оператора в логарифм не входят. Направление, которое выводит массу на эти нули, лежит вне карты.

Вне `I_safe`, при `P_min = 0` или при `s_♭ = 0`, ограниченный гессиан не заявляется.

Постоянный кодовый сдвиг `k` не входит во вторую производную: на SOURCE он сдвигает цену на константу. Если `k` зависит от параметра, его вклад надо добавить отдельно; здесь его нет.

## 2. Кандидатная формула second jet

Пусть `μ_j = p^{n+1+j}`, `Z(E) = Σ_j μ_j Tr exp(-ℓ f_j(E_j))`, `σ*_j = μ_j exp(-ℓ f_j(E_j)) / Z`, и `s_{j,a}` — собственные значения `σ*_j` в собственном базисе `E_j`. `Z` внутри разделённой разности заморожен: его движение сидит только в члене ранга один.

Для эрмитовых направлений `H, L`

```text
α(H) = Σ_{j,a} s_{j,a} f_j'(λ_{j,a}) H_{j,aa},

K_j(λ, μ) = (s_j(λ) f_j'(λ) - s_j(μ) f_j'(μ)) / (λ - μ),   λ ≠ μ,
K_j(λ, λ) = s_j(λ) f_j''(λ) - ℓ s_j(λ) (f_j'(λ))²,

D²A*(H, L) = Σ_{j,a,b} K_j(λ_{j,a}, λ_{j,b}) H_{j,ab} L_{j,ba}
             + ℓ α(H) α(L).
```

Если путь имеет ускорение `Ë`, то `d²A*/dt² = D²A*(Ė, Ė) + α(Ë)`. Первая вариация (12) видит только диагональ `H_{aa}`. Вторая видит и внедиагональные пары, в том числе при `λ_a = λ_b`.

Аргумент, не численный. Производная следа `d/dt Tr g(E) = Tr(g'(E) Ė)` верна и при `[E, Ė] ≠ 0`: в собственном базисе след берёт только диагональ, где разделённая разность равна `g'`. Вторая производная при `Ë = 0` равна `Σ_{a,b} (g')^{[1]}(λ_a, λ_b) |Ė_{ab}|²`. Подстановка `g = φ_j` и тождества `dA* = -dZ / (ℓ Z)` даёт формулу выше. На скалярных адресах она совпадает с уже опубликованным (14), включая смешанный член `ℓ a_i a_j ψ'_i ψ'_j`; это символическое тождество, не подгонка.

На `spec(E_j) ⊂ I_safe` промежуточная точка теоремы о среднем остаётся в `I_safe`, и

```text
|D²A*(H, L)| ≤ 22.53 Σ_j ||H_j||_HS ||L_j||_HS
              + ℓ (2.12)² ||H||_∞ ||L||_∞.
```

Здесь `||H||_∞ = max_j ||H_j||_op`. Коэффициент `22.53` — наружная оценка `exp(ℓ(f_max - f_min)) sup |f'' - ℓ(f')²|`: `C_1 < 2.12`, `C_2 < 19.52`, `sup |f'' - ℓ(f')²| < 20.41`, `exp(ℓ Δf) < 1.104`. Множитель больше единицы потому, что замороженный вес `μ_j φ(ξ) / Z` между собственными значениями может превысить единицу, хотя сами `s_{j,a} ≤ 1`.

Эти потолки проверяет интервальное исчисление на 512 подинтервалах. Это оценки, не точные экстремумы.

## 3. Смешанная производная и гессиан остатка

Остаток `R(E, σ) = D(Φ_E σ || Φ_E σ*)`. На сечении `σ = σ*` он нулевой, и его градиент по `σ` нулевой.

Производная плотности, `Tr η = 0`:

```text
(Dσ*_j(H))_{ab} = s_j^{[1]}(λ_a, λ_b) H_{j,ab} + δ_{ab} ℓ α(H) s_{j,a}.
```

При `λ_a = λ_b` предел `s'` равен `-ℓ f'(λ) s`. Второй член — движение `Z`. Без него след `Dσ*` равен `-ℓ α(H)` и уходит с симплекса состояний.

Смешанная производная на сечении:

```text
D_{E,σ} R(H, η) = - Hess_σ R(Dσ*(H), η).
```

Гессиан настоящего остатка при faithful выходе `τ = Φ_E σ*` с собственными значениями `τ_α > 0`:

```text
Hess_σ R(η, η) = Σ_{α,β} log^{[1]}(τ_α, τ_β) |(Φ_E η)_{αβ}|²,
log^{[1]}(x, y) = (log x - log y) / (x - y) → 1/x.
```

Если все `τ_α` лежат в `[m, M] ⊂ (0, ∞)`, то `1/M ≤ log^{[1]} ≤ 1/m`. На положительных углах канала при `s ≥ s_♭` и спектре в `I_safe` можно взять `m = s_♭ P_min` и `M ≤ 1`. У типа 0 пять углов, у типа 1 три, и `||A η A*||_HS ≤ ||η||_HS`, потому что `||A||_op²` равен вероятности ветви и не больше единицы. Поэтому

```text
Hess_σ R(η, η) ≤ (5 ||η_0||_HS² + 3 ||η_1||_HS²) / (s_♭ P_min).
```

Снизу `Hess_σ R(η, η) ≥ ||Φ_E η||_HS²`, и одна плюс-ветвь даёт ещё `≥ (0.659)² ||η_j||_HS²`. Это положительность на faithful-карте, не принцип выбора физического минимума: стационарный мемо прямо говорит, что устойчивость плотности не есть принцип выбора (`:176–177`).

Полная цена `F(E, σ) = 6 + ℓ^{-1} D(Φ_E σ || μ_f)`. Частная вторая производная по `E` при замороженной `σ = σ*` не равна `D²A*`. Кандидатное тождество огибающей, комплемент Шура:

```text
D²A*(H, H) = ∂²_E F(H, H) - ℓ^{-1} Hess_σ R(Dσ*(H), Dσ*(H)).
```

Аналитически это цепное правило вдоль `σ*(E)`: градиент по `σ` на сечении нулевой, поэтому ускорение `σ*` выпадает, а смешанный член сокращается с гессианом остатка.

## 4. Некоммутирующий пример

Уровень `n = 2`: блоки `M_3 ⊕ M_2`, потому что `counts(2) = (3, 2)`. Это первый уровень, где ready-блок может нести и совпадение собственных значений, и ненулевой коммутатор. Массы `μ_0 = p³`, `μ_1 = p⁴`, и `3p³ + 2p⁴ = 1`.

Спектр внутри `I_safe`, не на границе:

```text
E_0 = diag(p², p², p²(1 + δ/2)),
E_1 = diag(p²(1 - δ/2), p²).
```

Направление в этом собственном базисе:

```text
H_0 = [[1/2, 1, 1 + 3i/10],
       [1,  -1/2, 0],
       [1 - 3i/10, 0, 1/3]],
H_1 = [[1/4, 1/2 - i/5],
       [1/2 + i/5, -1/5]].
```

`[E_0, H_0] ≠ 0`, и первые два собственных значения `E_0` совпадают точно.

Кандидатное значение:

```text
α(H)        =  0.058467147188139926293
D²A*(H, H)  = -10.465078493541355195
вне диагонали, λ_a ≠ λ_b:  -5.1530285532708278901
пары с λ_a = λ_b, a ≠ b:    -3.9308438918005241307
член ℓ α²:                   0.0016449780157838755568
```

Независимая конечная разность по собственным значениям `E ± εH`, экстраполяция Ричардсона, отличается на `1.5×10^{-12}`. Это диагностика. Тождество раздела 2 аналитическое.

Та же цифра получается из Шура: частичный `∂²_E F` при замороженной подготовке не равен `-10.465...`, а после вычитания `ℓ^{-1} Hess R` остаток диагностики `3.6×10^{-10}`. На этом направлении `Hess R > 0` и не превосходит потолок раздела 3 при `s_♭`, равном минимальному собственному значению этой `σ*` (`около 0.1386129209534986`); грубый пол выхода `s_♭ P_min` около `8.19×10^{-5}`.

Нормировочное тождество канала на этом примере: `D(Φσ* || μ_f) + log Z` имеет остаток около `10^{-45}`. Углы и вес `p^{n+4+v}` согласованы с (3) и (7), а не с диагональным сокращением.

Золотые наклоны, как якорь к уже опубликованному окну, а не как новый результат: `f_0'(p²) = 0.58484529751693897635` попадает в `(0.58484, 0.58485)`, `f_1'(p²) = 1.7812023151481134057` попадает в `(1.7812, 1.7813)`. Это `A4D_NATIVE_JACOBIAN_CONTROLLED_RECORD_SOURCE.md:199–201`.

## 5. Контроли, которые обязаны ломать вывод

Каждый контроль ниже обязан разойтись с конечной разностью. Иначе формула раздела 2 не отличалась бы от запрещённого сокращения.

1. Коммутирующий shortcut. Оставить только диагональ собственного базиса, то есть выбросить пары `a ≠ b`. На примере пропадает и внедиагональный кусок `-5.153...`, и вклад столкновения `-3.931...`. Остаток не равен конечной разности. Скалярный адрес (14) этот контроль не ловит: там нечему не коммутировать.
2. Игнорирование `Z`. Выбросить `ℓ α²`. На скалярном адресе символическая разница с (14) равна `ℓ a² (ψ')²`, не нулю. На примере числовая дыра `0.001644...`. Тот же пропуск в `Dσ*` уводит след с симплекса: без члена `ℓ α s` след касательной равен `-ℓ α ≠ 0`.
3. Столкновение как сингулярность. Наивный частный `(s f'(λ) - s f'(λ)) / (λ - λ)` не определён. Предел `(f'(λ+ε) - f'(λ)) / ε` при `ε = 10^{-9}` совпадает с `f''(λ)` точнее `10^{-6}`, а `1/ε` уходит в бесконечность. Полюс по зазору собственных значений не есть гессиан.
4. Рождение ранга как гладкий гессиан. Формула (11) стационарного мемо, `:221–227`: при `ε = t²` отношение цены к `ε` на `ε = 10^{-4}, 10^{-8}, 10^{-12}` равно примерно `-17.69`, `-36.83`, `-55.97`. Один конечный квадратичный коэффициент не садится на два масштаба. Критическая амплитудная ветвь ранга один не называется минимумом. Первая производная по `t` нулевая, вторая по `t` не ограничена.

Отдельно: частичная заморозка подготовки, то есть выдача `∂²_E F` вместо `D²A*`, на примере тоже не совпадает с огибающей. Это тот же Шур, не пятый независимый механизм.

## 6. Что этой формулой не является

Рождение ранга остаётся отдельным спуском (11), не квадратичной формой. Уникальность faithful-минимума плотности не удаляет критические амплитудные ветви и не выбирает физический минимум.

Условный гиперболический кандидат стационарного мемо, `:322–346`, здесь не пересчитывается и не усиливается. Там уже сказано, что `ρ² > 24` не попадает в режим компилятора `ρ ≤ 1/2`, и что это не запрет критической геометрии точного спектрального action. Стабильная подготовка и гиперболичность гравитации не отождествляются.

Нулевые моды полного fine-оператора не получают ограниченного логарифмического гессиана. Регулярность остатка — только на положительных углах faithful coarse-выхода.
