# D0: внутренние часы и конечные исходные программы

Продолжение существующего PR #334. Исходный коммит:
`c7708742bea04684ffd6aed16774cfdf1b94b129`.

- `PROOF.md`: полные доказательства, условия применения и входные источники.
- `SYNTHESIS_RU.md`: объяснение результата на русском языке.
- `check_internal_clock_bridge.py`: точные матричные тождества и полная сцена.
- `check_finite_golden_secants.py`: исходные Golden/SourceI-слова и оценки.
- `result*.json`, `golden_secants_result*.json`: реальные результаты запусков.
- `inputs/`: неизменённое доказательство из последнего локального архива
  и его повторно исполненная проверка.
- `MANIFEST.json`: хеши файлов и сведения о выполнении.

Запуск:

```bash
python -m pip install numpy scipy sympy mpmath
OPENBLAS_NUM_THREADS=1 python check_internal_clock_bridge.py
OPENBLAS_NUM_THREADS=1 python check_finite_golden_secants.py
```

Второй скрипт ищет конкретные степени Golden-оператора в явно ограниченном
диапазоне до 30 миллионов. Развёрнутое исполнение 66 миллионов ворот не
заявлено: повторяющиеся слова проверяются по формулам произведения, а
ошибки — интервально.

Пакет сохранён локально. GitHub в этом проходе не изменялся. Предыдущий
локальный архив также не объявляется опубликованным в репозитории.

Это не сертификат полного вывода ОТО, не Lean-сборка, не запуск общей
сеточной задачи и не независимая приёмка. Точный результат относится к
описанному отражательному исполнению с одинаковыми воротами на всех
узлах фиксированной сцены и фиксированным оплаченным временем.
