# Сквозной ансамбль источников D0

См. `PROOF_RU.md` — одна связанная теорема: разные внутренние запросы, полная цена, собственный коэффициент, точные нелинейные корни прежнего полного 42-компонентного семейства и контролируемый smooth-source предел.

Не является безусловным доказательством D0→ОТО. В частности, обязательность данного каталога/активного cut для исходных книг 0–1 и общая recovery всех решений не доказаны. Исходный lambda_0 не подменяется новым lambda_*: это разные вычисленные коэффициенты разных явно определённых аппаратов.

## Воспроизведение

```bash
python -m pip install -r requirements.txt
python check_closed_source_cone.py
python -O check_closed_source_cone.py
```

Скрипт сам создаёт `result.json`. Текущие `result_normal.json` и `result_optimized.json` побайтно одинаковы. Их хэши и хэш проверенного файла находятся в `MANIFEST.json`.

Не требуется интернет или доступ к GitHub для запуска. Сведения о прежних теоремах, которые проверка НЕ повторяет, перечислены в доказательстве. `run_stdout.txt` — фактический нормальный вывод; это не подстановка ожидаемых чисел.

## Главный результат

Для каталога m=0,...,M с исходными Golden-весами p^(m+2), полной неудачей и разными материальными откликами p^m q истинный источник на common-null носителе равен

`D B = Gamma_M (D F + lambda_M D Q)`, `Gamma_M>0`.

При явно описанной общей растущей фабрике lambda_M стремится к lambda_0/(2p), без задания значения по целевому полю. Точные конечные Einstein–CAR корни используют lambda_M, а не заранее поставленный предел. Общая теория источника сохраняет all-grade heat/return и не делает историю бесплатной.
