# Сквозная проверка последнего перехода D0 → ОТО

- `PROOF_RU.md`: точная теорема о полиномиальном источнике и её логическая область.
- `check_root_source_universality.py`: воспроизводимая проверка на прежнем интерфейсе 2+8 знаков.
- `result.json`: фактический результат запуска.
- `result_optimized.json`: фактический результат `python -O`, совпадает с обычным.
- `execution_manifest.json`: версии среды и SHA256 исполняемого кода/результатов.

Запуск при установленных SymPy и mpmath:

```bash
python check_root_source_universality.py > new_result.json
python -O check_root_source_universality.py > new_result_optimized.json
```

Результат — не опровержение D0 и не полное закрытие ОТО. Он отделяет реализацию выбранного действия от его вывода из исходной физической динамики. На данном интерфейсе реализация является универсальной: это математически доказывается, а не заключено из отсутствия найденного доказательства.
