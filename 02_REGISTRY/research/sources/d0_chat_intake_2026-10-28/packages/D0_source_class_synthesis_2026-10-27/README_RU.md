# D0 — синтез через класс полного источника

## Полученный результат

Не нужно доказывать единственность компилятора ради одинаковых классических
уравнений. Для одного исходного глобального отчёта r(y), сохранённых
неудач подготовки и когерентно завершённого внутреннего исполнения:

    B_m(y)=H_m+Phi_alpha_m(r(y)),
    Phi'_alpha_m(r)>0,
    D B_m=0 <=> D r=0.

Документ `PROOF_RU.md` содержит доказательство с полным набором условий,
точный исходный 1024-строчный Golden-декодер и конструктивный подъём
конечнокодовых входных моментов. `thresholds.json` — реальные целые пороги
для обеих таблиц, а не присвоенные вероятности.

## Проверка

    python check_source_class.py > reproduced.json
    python -O check_source_class.py > reproduced_optimized.json

Требуются SymPy и mpmath. Файл `thresholds.json` воспроизводится при запуске.
Все тесты используют исключения, а не удаляемые при `-O` assert.

Для подготовки монет исходной таблицы найдено 94 условно честных бита
и 6 Golden-монет: 194 прямых G-вызова только монетного слоя.
Его готовность (2p^3)^94 ≈ 2.3031e-31. Полные расходы Boolean-логики,
исходных банков и обратных операций этим числом НЕ покрываются.
Неудачи не удалены: они включены в цену и в доказательство источника.

Нормированная оценка источника равномерна даже при такой малой готовности.
Это не утверждение эффективности или доступной экспериментальной точности.

конкретных ресурсных банков и общие точные решёточные корни не доказаны.
`unconditional_GR_closed=false`. Пакет не заменяет исходный raw216-контракт.
