# D0: геометрический источник на общих голономиях

Содержимое: полное доказательство на русском, фактически исполненный проверочный
скрипт, его результаты в обычном и оптимизированном режимах, ссылки на публикацию
в существующем PR #334 и контрольные суммы.

Основной результат: геометрическая плакетная плотность ТОЧНО представлена
нечётным внешним CAR-следом для всех P∈SL(4), B∈sl(4). Сохраняются все
индуцированные вариации. Для старого невзвешенного следа доказана гладкая C1
оценка O(h^4) после суммирования по четырёхмерному объёму.

Запуск (требуются sympy и mpmath):

```sh
python check_parity_bridge.py
python -O check_parity_bridge.py
```

Скрипт не изменяет файлы и не требует интернета. Вызов печатает JSON.
Доказательство лежит в PROOF_RU.md. Англоязычная версия опубликована в GitHub;
REMOTE.json связывает её с данным пакетом. Скрипт и receipt побайтно совпадают
с проверенными Git blobs; русский документ является отдельной полной версией.

Границы: полная нативная физическая цена не отождествлена с геометрической
плотностью. Большое исходное исполнение, общая сеточная система, Lean и CI
в данном проходе не запускались. Универсальная ОТО не объявлена закрытой.
