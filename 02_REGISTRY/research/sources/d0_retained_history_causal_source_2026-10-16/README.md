# Retained-history causal source: bounded evidence

Consumer: [the actual history/source proof](../../A4D_RETAINED_HISTORY_CAUSAL_SOURCE.md).

`check_retained_history.py` exports `run(repo=None)` and deterministic JSON
on its command line. It executes only pinned creator/order definitions,
not any earlier checker or spectrum/root replay.

The exact checks cover the same32 Julia/Walsh labels, both golden ports,
all128 outcome completeness, a noncommuting incoming-event order, no-reset
first-exit composition, moving preparation normalizer, the clock factor1/256,
and full16 all-angle cone identities. The scalar EH comparison is only on
the named cone family; scale variation also differentiates its coefficient.

`RESULTS.json` is the ordinary-run stdout. `VALIDATION.json` records the
normal/optimized stdout hashes, byte comparison, runtimes and source pins.
The smooth-stencil C1 matrix-element estimate is the linked analytical
proof, not a numerical continuum experiment. No action term, reference
pointer, physical Julia-gate admission, all10 Einstein equation or original
fixed-source terminal is added.
