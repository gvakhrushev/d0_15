## Работа и научные границы
Составить таблицу ТОЛЬКО совместимых ошибок одного declared interface: auxiliary gap epsH/epsJ, return tail z^(k+1), operator approximation, coframe/observer conditioning, spatial quadrature и источник после actual right inverse. Для каждой величины указать domain, норма и предикат, при котором её вообще можно складывать с другими. v8 и central-terminal AF — разные программы: два отдельных бюджета, пока ведущий не докажет их связь; не суммировать bound от разных цен.

Получить машинно проверяемые неравенства выбора глубин/допусков как функций h и ВХОДНЫХ физических scales. В 4D точечное O(h^6) после h^-2 raw sum даёт O(1), не o(1). Учесть trace-norm/HS conversion, lambda^-1 central compiler при использовании того маршрута, beta,M,z dependence, conditioning h_x и fixed calibrated source. Не выбирать beta(h), t(h) или α(h) как физический закон для спасения ответа. Для endogenous weights использовать N08 при полном source; fixed calibrations ограничение unfolding сохраняется.

Выход — один parametrized bound и минимум два численных бюджета с явно ASSUMED input rates. При несовместимых гипотезах программа должна отказать с названием карты, не выдавать ложный PASS. Это достаточные оценки, не доказательство существования native refining solutions.
