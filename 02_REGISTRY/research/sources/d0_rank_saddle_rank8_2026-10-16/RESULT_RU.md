## Пространство

В базисе, где проектор занятости `Pi` диагонален ранга `k` на оболочке ранга `r`,

```text
V_k = { S = S*,  Tr S = 0,  (I - Pi) S (I - Pi) = 0 },
dim_R V_k = 2 r k - k^2 - 1.
```

При `r = 128`, `k = 8` размерность равна `1983`. Полный бесследовый ориентир `k = 128` даёт `16383` и этой проверкой отвергается: пустой-пустой блок в `V_k` не входит. Бесследовая матрица только на пустом дополнении лежит вне `V_k`, и `T_k` сжимает её в нуль.

## Оператор T_k

Формула (16), `X = X_v`:

```text
T_k(X) = Pi X Pi - Tr(Pi X) Pi / k + (I - Pi) X Pi + Pi X (I - Pi).
```

По индексам, `tr = Tr(Pi X)`:

```text
i, j < k, i = j:   X_ii - tr/k
i, j < k, i ≠ j:   X_ij
ровно один индекс < k:  X_ij
оба индекса ≥ k:   0
```

След `T_k` равен нулю, `T_k` эрмитов, пустой-пустой блок нулевой. Для `S ∈ V_k` спаривание точное: `Tr(S T_k(X)) = Tr(S X)`. Пустой-пустой кусок `X` в `T_k` не входит.

Это сверено двумя реализациями: покомпонентной формулой и буквальными произведениями проекторов. На общем эрмитовом `10×10` при `k = 8` разность тождественно нулевая, и спаривание с общим `S ∈ V_k` сокращается. На рациональной эрмитовой `128×128` с ненулевыми занятым, прямоугольным и пустым блоками реализации совпадают; линейность и однородность `T_k` сохраняются. На `η = E_00 - E_11` и на вещественной занято-пустой матрице `E_0,8 + E_8,0` оператор `T_k` действует как тождество, спаривание совпадает со следом.

## Седло

Кандидатная функция на `V_field ⊕ V_k`, без квадратичного члена по оболочке:

```text
L(v, S) = (1/2) H_rho(v, v) + Tr(S T_k(X_v)).
```

Её гессиан есть (18):

```text
[ H_rho   T_k* ] [v]
[ T_k       0  ] [S]
```

Независимый гессиан SymPy на общем `H_rho` размера `2×2` и общем прямоугольном `T` размера `3×2` даёт верхний блок `H_rho`, внедиагональные блоки `T` и `T*`, нижний блок — нулевая `3×3`.

На координатном пространстве `R^1983` та же линейная по `S` функция просканирована полностью. Независимых пар `1983×1984/2 = 1967136`. Все значения гессиана равны нулю, включая диагональ. Линейные коэффициенты ненулевые и сокращаются. Вторая разность `S ↦ Tr(S M)` на явных `128×128` матрицах из `V_k` тоже нулевая.

## Отрицательный контроль

Подстановка обязана сломать проверку формы. Исключение арифметики контролем не считается.

1. Положительный координатный auxiliary Hessian `(k/2) ||s||^2` при `k = 8` на том же `R^1983`. Тот же сканер находит `1983` ненулевые диагональные элементы, каждый равен `8`; вне диагонали нуль. Предикат «нижний блок нулевой» ложен.
2. Тепловой/AF-гессиан `k Tr(S^2)` при равномерном `ρ = I_k/k`. На `η = E_01 + E_10` вторая производная `Tr((ρ + t η) log(ρ + t η))` в нуле равна `16`, и `k Tr(η^2) = 16`. На `η = E_00 - E_11` седло даёт `0`, тепловая форма даёт `16`. На прямоугольном `E_0,8 + E_8,0 ∈ V_k` те же `0` и `16`. Проверка формы отвергает отчёт с этим значением.
3. Замена самого `T_k` положительной тепловой матрицей `U(S) = k S`. На `η` спаривание становится `16` вместо `2`. Это не (16). Отчёт с такой заменой отвергается.
4. Разделённая разность логарифма между собственным значением `1/8` и пустым `ε → 0+` расходится. Конечный положительный блок на этом направлении не есть тепловой гессиан сингулярного состояния; обращение такого блока не используется.

Положительность бесследной диагональной части `sum d_i^2 + (sum d_i)^2` видна по ведущим минорам `1+m` для `m = 1,…,7`: это `2, 3, …, 8`, все больше нуля. Вместе с `2|S_ij|^2` форма `k Tr(S^2)` положительно определена на `V_k`. Именно поэтому она не может стоять на месте нулевого блока.

Полноранговая размерность `16383` в том же предикате тоже отвергается.
