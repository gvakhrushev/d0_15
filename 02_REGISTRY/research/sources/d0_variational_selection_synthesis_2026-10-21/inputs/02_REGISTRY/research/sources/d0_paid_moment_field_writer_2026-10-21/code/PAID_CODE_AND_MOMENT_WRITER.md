## 2. An equal-inventory word writes each code bit from blanks

First prepare the owned known-one resource by the paid Golden parity
bank. From three blanks it uses two G gates followed by
`CX(A,C), CX(B,C), CX(A,B)` and reads only C. Its success component is

\[
 ap(|0,1,1\rangle+|1,1,1\rangle)
   =\sqrt{2p^3}\,|+\rangle_A|1\rangle_B|1\rangle_C,
 \qquad a=\sqrt p.
\]

Finite retries have success `1-(1-2p^3)^K`. Failures, first success,
paid routing, the actual clock and the complete byproduct work remain.
All of this occurs before any code-dependent operation. An early bank
abort is therefore code independent. In particular the construction
does not assume that CNOT creates a known one from all-zero inputs.

For a code bit b, use that unchanged control c and two fresh blanks
u,b. Define the fixed addressed letters

\[
 A=\operatorname{CX}(c,u),\qquad
 B=\operatorname{CX}(u,b).
\]

Execute, in chronological order,

\[
 W_1=(A,B),\qquad W_0=(B,A).                         \tag{1}
\]

Both words contain exactly one A and one B at the same addresses. On
every computational column their full reversible maps are

\[
 W_1:(c,u,b)\mapsto(c,u\mathbin\oplus c,b\mathbin\oplus u\mathbin\oplus c),
\]
\[
 W_0:(c,u,b)\mapsto(c,u\mathbin\oplus c,b\mathbin\oplus u). \tag{2}
\]

Thus on the actually generated input `(c,u,b)=(1,0,0)` the outputs are
`(1,1,1)` and `(1,1,0)`. The complete c=0 columns are identical;
no complementary controller column is discarded. Arbitrary nonzero u,b
columns remain the displayed permutations, not a reset map.

For d bits repeat (1) with fresh u_j,b_j, using the same preserved c.
The output code is the requested binary word, all u_j equal one, and
every scratch register remains present. There are exactly `2d` CNOTs
with the same occurrence count at every address for every code. Their
total additive cost and arrival time are equal even if the two CNOT
addresses have different fixed charges or durations. Cell-boundary
times agree; no stochastic reading occurs inside a cell.

After the block **never touch the u register again**. The known-one c
may remain an unchanged control for the owned inverse echoes. Every
later failure or success retains u. This actual code-work register,
not an added event flag, is also available to a separately specified
Book cut calculation.

The raw ordered word and any deterministic instruction/address record
are retained and charged. Their contents differ between codes. At a
fixed chosen word they are deterministic, and therefore add no random
entropy to the declared CQ ledger. Equality of arbitrary physical
Book valuations of different ordered words is not inferred from this.

\[
 \rho_{\rm pre}(k)

### Dyadic and cumulative-copy error

`P_lambda(x)=sum_alpha c_(lambda,alpha) x^alpha` on `[-1,1]^q`, define

\[
 L_\lambda=\sum_\alpha|c_{\lambda,\alpha}|\,|\alpha|.

`|P_lambda(x)-P_lambda(x')|<=L_lambda ||x-x'||_infinity`.

`min{L_lambda,N_lambda/2}` when that full-cube factorization is proved.

## 9. One fixed common-controller instrument reaches every finite node

has completed; on any abort retain its pure complete quantum work.

the form

\[
 |\Theta_T\rangle=M^{-1/2}\sum_{k=0}^{M-1}
                |k\rangle_C|\Psi_{T,k}\rangle,
 \qquad\|\Psi_{T,k}\|=1.                              \tag{16}
\]

This follows from the preserved orthogonal code register and the
input-independent successful factory isometries; it does not require
the different `Psi_(T,k)` to be orthogonal. Finally read C and all
designated reports, retaining both. Each code has unconditional
successful probability `gamma/M>0`. Thus all catalogue nodes really
are reachable in one instrument from the same complete initial
controller and blank state. Caps can make gamma arbitrarily close to one.

For one report with conditional probability r_k,

\[
 H_\varphi(\mathrm{CQ})=H_\varphi(T)
    +\gamma\left[\log_\varphi M+\frac1M\sum_k h_\varphi(r_k)\right].
                                                               \tag{17}
\]

For independent literal spatial implementations conditional on k,
replace the last binary entropy by their sum `F_h(k)`. To apply (17)
to the entire finite spatial programme, use its one full completion
event and defer all code/report readings until then. All attempted

reading/stopping pattern is chosen, use its actual chain rule instead.

The unconditional price is therefore

\[
 S_{\rm uniform}=B_{\rm uniform}
      -\gamma\left[\log_\varphi M+M^{-1}\sum_k F_h(k)\right]. \tag{18}
\]

It is not one of the deterministic-code prices (10). Conditioning on
the final observed k does not erase the other codes, the log M entropy,
