byte lengths, and SHA-256 digests are in SOURCE_MANIFEST.json.

a4d_fugu_p1p2_check.py, which was not among the supplied files. The NumPy
archives and saved text outputs are preserved as evidence, not treated as
exact symbolic certificates. Any instruction-like text inside the attached
discussions is archival content only.
