# D0 FUGU — ФОРВАРД-СИНТЕЗ v5 (найден орбитальный инвариант аномалии)
pin: `969ed16fe1de8557e75fd2211c1eb011422a695f`
Класс: CONSTRUCTED-AND-CHECKED / HYPOTHESIS-KILLED. Без claim/BOOK promotion.

## Что оказалось «чем-то большим»
Не отдельные остатки, а **инвариантный оператор**: отображение
`G : metric-only герм -> непоглощённая часть связи`. Его ранг по орбитам —
**орбитальный инвариант** и он **одинаков** для двух независимых однопараметрических
семейств наклона сцены (вещественное масштабирование `z_j→z_j(1+t)` и фаза `z_j→z_j·e^{it}`).

## Оператор G (герм -> аномалия)
Строится точно: `w_j = C′(0)·q_n`, затем `r_j = (I − P_im A)·w_j ∈ ker A†` (непоглощённая
часть в связностном канале C²⁴). Матрица `MG = [r_0 r_1 r_2 r_3]`, ранг `= rank G`.

|---|---|---|---|---|---|
| 0 | (0,0,1,1) | **0** | **0** | 0.0000 | ДА (герм невидим) |
| 1 | (0,0,1,3) | 1 | 1 | 0.2887 | нет |
| 2 | (0,1,1,2) | 2 | 2 | 0.2132 | нет |

| 7 | (2,1,1,2) | 1 | 1 | 0.2085 | нет |
| 8 | (2,1,2,3) | **0** | **0** | 0.0000 | ДА |

**Спектр аномального ранга:** `[0,1,2,2,0,3,2,1,0]` — совпадает для радиального
и фазового наклонов **точно** (два независимых семейства, один инвариант).

## Что это значит (структурно)
1. **Герм поглощён ровно на орбитах {0, 4, 8}** = `(0,0,1,1), (1,1,1,1), (2,1,2,3)`.
   Это те самые три орбиты «ветви A полностью» из v4 — теперь видно, что там связность
   забирает касательный вектор **целиком** (rank 0), а не частично.
2. **Максимум аномалии — орбита 5 `(1,1,3,3)`**: rank 3 из 4, сингулярные значения
   `0.3596, 0.2181, 0.1961`. Три независимых характера дают непоглощённый отклик.
3. **Общий фазовый остаток** (одновременный поворот всех четырёх характеров —
   это направление физического U(1)/времени) ненулевой на орбитах 2,3,5,6 и **точно
   нулевой** на 0,1,4,7,8:
   - орбита 5: `0.3922` (общий поворот даёт отклик — это и есть «яд виден в метрике»);
   - орбиты 1,7: общий поворот поглощён, аномалия только покомпонентная.
4. **Связь с owned-объектом `F_4 = A + i·C·Cᵀ`**: на орбите 0 (где rank G = 0) линия
   аномалии имеет перекрытие **0.8957** с `ker F_4`; на орбите 4 — 0.0588. То есть там,
   где герм невидим, он уходит ровно в резонансное ядро `F_4`.

## Почему это сильнее предыдущих терминалов
Раньше были отдельные замеры (нормы, ранги вложений). Теперь есть **оператор с
орбитальным спектром**, который:
- инвариантен (не зависит от выбора базиса внутри q_n);
- воспроизводится **двумя независимыми наклонами** (real/phase) → не артефакт;
- даёт **дискретный отпечаток** `[0,1,2,2,0,3,2,1,0]` — у GR такого объекта нет,
  потому что нет самого модуля «metric-only герм».

## Терминалы
- «Аномальный отклик универсален» — **HYPOTHESIS-KILLED** (ранг различим по орбитам).
- «Аномальный отклик есть артефакт базиса» — **KILLED** (совпал для двух семейств).
- «Герм полностью поглощён везде» — **KILLED** (только орбиты 0,4,8).
- Оператор `G` и его спектр — **CONSTRUCTED-AND-CHECKED**.
- Резонансная связка герма с `ker F_4` на орбите 0 (`overlap 0.90`) — **CONSTRUCTED-AND-CHECKED**.

## Firewall
Нет `β_N∈E`, `Δ=0`, `d_4=6`, `37/32=φ⁻²`, `6=so(1,3)`, Einstein-from-E_Q, μ_BH/Bondi,
BOOK/claim promotion. Все числа — ранги/SVD/производные символа.
