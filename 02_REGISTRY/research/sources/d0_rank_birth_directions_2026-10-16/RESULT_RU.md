## 1. Носитель и сфера

Оболочка `H` имеет комплексную размерность `r = 128`. Опора `F` имеет комплексную размерность `ref = 128`. Занятый проектор `Pi` имеет ранг `k = 8`. Равномерная плотность занятого носителя — `rho0 = Pi/k`.

Амплитуда `C` — комплексная матрица `128 × 128`: строки вдоль `H`, столбцы вдоль `F`. Плотность

```text
rho(C) = C C†.
```

Полная нормированная сфера амплитуд — вещественная сфера Гильберта–Шмидта

```text
S = { C : Tr(C† C) = 1 },
dim_R S = 2·128·128 − 1 = 32767.
```

В ортонормированном разложении `H = im Pi ⊕ (im Pi)^⊥` и `F = (ker C0)^⊥ ⊕ ker C0` точка меморандума записывается блоками

```text
C0 = [ I_k/√k    0 ]
     [ 0         0 ].
```

Тогда `C0 C0† = Pi/k` и `Tr(C0† C0) = 1`, так что `C0` лежит на `S`. Четыре блока амплитуды относительно этого разложения обозначаются `oa`, `ob`, `ea`, `eb`. При `k=8` их размеры `8×8`, `8×120`, `120×8` и `120×120`. Здесь `a` — оси `(ker C0)^⊥`, `b` — оси `ker C0`, `o` — оси `im Pi`, `e` — оси `(im Pi)^⊥`.

Касательное пространство сферы в `C0`:

```text
T = { Z : Re Tr(C0† Z) = 0 }.
```

Первая производная плотности:

```text
D rho(C0)[Z] = Z C0† + C0 Z†.
```

## 2. Подъём (15) и образ

Формула (15) меморандума для эрмитовой `S` с нулевым блоком `(P−Pi) S (P−Pi)` задаёт амплитуду `L(S)` только в занятых столбцах опоры:

```text
L(S)_oa = √k S_oo / 2,
L(S)_ea = √k S_eo,
L(S)_ob = L(S)_eb = 0.
```

Прямое умножение блоков даёт `D rho(C0)[L(S)] = S`. Если дополнительно `Tr S = 0`, то

```text
Re Tr(C0† L(S)) = Tr(S)/2 = 0,
```

поэтому `L(S)` касается `S`. Такие `S` составляют пространство `V_k` формулы (13):

```text
dim_R V_k = 2·r·k − k² − 1 = 2·128·8 − 64 − 1 = 1983.
```

Обратно, у любой амплитуды `Z` матрица `D rho(C0)[Z]` эрмитова и её блок `ee` нулевой. На `T` её след равен `2 Re Tr(C0† Z) = 0`. Значит образ `D rho(C0)` на `T` лежит в `V_k`. Вместе с подъёмом (15) образ равен всему `V_k`.

Поэтому ядро первой производной плотности на полной сфере имеет размерность

```text
dim_R ker(D rho(C0)|_T) = 32767 − 1983 = 30784.
```

То же ядро получается и без ограничения на сферу: если `D rho(C0)[Z] = 0`, то условие касания выполняется само.

## 3. Прямая сумма 1984 + 28800

Блочный вид производной, при `C0_oa = I_k/√k` и остальных блоках `C0` нулевых:

```text
(D rho)_oo = (Z_oa + Z_oa†)/√k,
(D rho)_eo = Z_ea/√k,
(D rho)_oe = Z_ea†/√k,
(D rho)_ee = 0.
```

Следовательно `D rho(C0)[Z] = 0` тогда и только тогда, когда `Z_ea = 0` и `Z_oa` косоэрмитова. Блоки `Z_ob` и `Z_eb` в первую производную не входят. След косоэрмитовой `Z_oa` чисто мнимый, поэтому всякое такое `Z` уже лежит в `T`.

Это ядро есть прямая сумма двух вещественных подпространств.

Правые унитарные направления — касательное пространство правой орбиты `C ↦ C U`, `U ∈ U(F)`, в точке `C0`:

```text
T_right = { C0 K : K† = −K }.
```

В блоках это ровно те `Z`, у которых `Z_ea = 0`, `Z_eb = 0`, `Z_oa` косоэрмитова и `Z_ob` произвольна. Ядро отображения `K ↦ C0 K` состоит из косоэрмитовых операторов, сохраняющих `ker C0` и нулевых на `(ker C0)^⊥` в направлении этой плоскости; его вещественная размерность `(ref−k)²`. Поэтому

```text
dim_R T_right = ref² − (ref−k)² = 128² − 120² = 1984.
```

Та же размерность читается по свободным блокам: `k² + 2·k·(ref−k) = 64 + 1920 = 1984`.

Направления рождения ранга — дополнительное слагаемое:

```text
T_birth = { Z : Z_oa = 0, Z_ob = 0, Z_ea = 0 },
Z_eb = A произвольна в ℂ^{(r−k)×(ref−k)}.
```

Иначе говоря, `T_birth` есть пространство всех комплексных линейных отображений `ker C0 → (im Pi)^⊥`, продолженных нулём на `(ker C0)^⊥`. Вещественная размерность

```text
dim_R T_birth = 2·(128−8)·(128−8) = 2·120·120 = 28800.
```

Пересечение с `T_right` нулевое: у правого унитарного вектора блок `eb` нулевой, а у ненулевого вектора `T_birth` он единственный ненулевой. Сумма исчерпывает ядро, потому что произвольный вектор ядра имеет свободный `eb` и остаток в `T_right`. Поэтому

```text
ker(D rho(C0)|_T) = T_right ⊕ T_birth,
30784 = 1984 + 28800.
```

Все три слагаемых лежат в `T`, а сумма их размерностей равна `dim T`. Значит сумма прямая и совпадает с `T`:

```text
T = L(V_k) ⊕ T_right ⊕ T_birth,
1983 + 1984 + 28800 = 32767.
```

У каждого `Z ∈ T_birth` первая производная плотности равна нулю. Это и есть точное описание 28800 направлений. Физический подсчёт не производится.

Направления с ненулевым `ea` или с эрмитовой частью `oa` в это слагаемое не входят: их первая производная плотности ненулевая. Они лежат в `L(V_k)`, а не среди 28800.

## 4. Вторая производная плотности

Квантор «как правило» из абзаца меморандума про `k=8` в сертификат не переносится. Для описанного пространства `T_birth` верно более сильное утверждение, и только для него.

Пусть `Z ∈ T_birth` отвечает матрице `A`, и пусть `γ` — любая кривая класса `C²` в объемлющем пространстве матриц, в частности любая такая кривая на `S`, с `γ(0) = C0` и `γ'(0) = Z`. Запись `γ(t) = C0 + t Z + t² W/2 + O(t³)` даёт

```text
d² rho(γ)/dt² |_{0} = D rho(C0)[W] + 2 Z Z†.
```

Блок `ee` первого слагаемого нулевой при любом ускорении `W`. Блок `ee` второго слагаемого равен `2 A A†`. Значит блок `ee` второй производной не зависит от ускорения и равен `2 A A†`. Далее

```text
Tr(A A†) = ||A||_HS²,
```

поэтому `A A† = 0` тогда и только тогда, когда `A = 0`. У каждого ненулевого направления из этих 28800 вторая производная плотности отлична от нуля вдоль любой такой кривой.

Это не утверждение о другой трансверсали к `T_right` и не утверждение о гессиане цены. Смешанный вектор `Z_right + Z_birth` остаётся в ядре первой производной, но его вторая производная здесь не объявляется отдельным инвариантом трансверсали: сертификат описывает само линейное пространство `T_birth`.

Для отделения слагаемых: если `K† = −K`, кривая `γ(t) = C0 exp(t K)` лежит на `S` и `rho(γ(t))` постоянна, так что все производные плотности вдоль неё нулевые. Эта кривая касается `T_right`, а не `T_birth`.

## 5. Что остаётся вне сертификата

Полевое ядро, седловой оператор (16)–(18) и нелинейные условия (19)–(23) не решаются. Совместное условие второй материальной струи на векторах `T_birth` не проверяется. Искривлённая ветвь не строится.
