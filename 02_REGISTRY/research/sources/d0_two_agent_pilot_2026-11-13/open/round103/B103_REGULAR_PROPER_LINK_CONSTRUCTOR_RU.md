# B103. Общий proper-link Julia32 для рационального открытого chart

**Результат.** Для шести точных `Fraction` centre offsets в исходном B42 `GEN` и каждого четырёхзначного CODE sector построен конечный интервальный target и ленивый native G/CX/SourceI emitter исходного B25 `J(Λ(U)/2)` на всех 32 колонках. Он не использует ни деление на boost, ни точное определение максимального pivot; нулевой boost и равные pivots допустимы. Для `target_bits=3460` полный один proper-link sector имеет исходно-операторную ошибку `<2^-3451`, при потреблении прежних certificates B91/B93/B42. [Код](regular_link_julia.py), [проверка](check_regular_link_julia.py), [receipt](B103_REGULAR_LINK_CHECK.json). Это SOURCEI-profile один sector/variable-bank upper, а не готовый новый global SOURCE, paid clock или physical admission. `physical_C_closed=false`, `GR_closed=false`.

## 1. Typed input и связка с A53

`offsets` — ровно шесть экземпляров Python `Fraction`, каждый строго `|offset|<2^-32`, порядок

    GEN=((0,1),(0,2),(0,3),(1,2),(1,3),(2,3)).

`digits` — ровно шесть целых `0..3`, `σ=2^-80`, `p²=(3−√5)/2`. Настоящая локальная координата

    θ_j = offset_j + σ(digit_j−3p²).

`xy` — исходный B25 baseline `None,(1,1),(1,2),(2,1),(2,2)`. Тогда `U=exp(Θ)U₀(xy)` с исходным null-frame генератором `Θ=Σθ_j η(E_ij−E_ji)`; правый порядок и baseline B42/B25 не изменяются. `digits=None` дополнительно реализует точный центр для проверки/возможного явно объявленного center consumer; это не CODE-pattern и он не подменяется нулевыми digits.

На предложенном chart строго

    |offset|+3σ < (3/8)·2^-30 < min(p²,1−p²)·2^-30.

Последнее следует из `2<√5<9/4`. Поэтому каждая координата входит в исходный **асимметричный** B21 cube, и B91 strict Julia defect gap `I−CCᵀ,I−CᵀC > I/16` применим. Это chart рациональных имен; вывод для произвольного real field требует отдельно передать допустимое имя/приближение и заплатить B91 исходный Lipschitz и source budget.

Для одного B93 variable f-group вызывающая сторона связывает chart и адрес:

```python
ids = group['indices_by_generator']              # 6 независимых B21 coordinates, GEN order
offsets = field.selected(ids)                    # 6 Fraction из одного A53 FieldCentre
entry = variable_entry(group, digits)            # address, 12 CODE wires и их literal pattern
certificate, angles = native_rotations(offsets, digits, group['xy'])
assert certificate['input']['offsets_fraction']  # точные имена центра и digits
forward = sector_blocks(layout, entry, angles, reverse=False)
reverse = sector_blocks(layout, entry, angles, reverse=True)
```

`variable_entry` точно сохраняет B93 low/high wiring `ids+[2688+j for j in ids]` и pattern `[digit&1]+[digit>>1]`. Прочие fixed/reference sectors остаются за исходным B93; нельзя присваивать им новые смещения по имени банка. Один вызов связывает один адрес и один CODE pattern. Для полного f-bank нужно пройти **все** его variable groups и все 4096 digit assignments, выбирая собственные шесть offsets для каждого group; заменять offsets одного site другим или считать этот sector полной таблицей нельзя. `variable_bank_entries(field,reverse)` и `variable_bank_blocks(field,layout,reverse)` реализуют этот полный ленивый проход для переменной части: на обратном ходе инвертируются порядок всех sectors и каждое actual слово. Fixed/reference sectors по-прежнему отдельно оплачивает caller.

## 2. Прямая Julia без сингулярного SVD

Для original CAR order `(0,2,3,1)` строятся все minors `Λ(U)` по классам grade `0,1,2,3,4`. Для `C=Λ(U)/2` сохраняется исходный B25 знак и расположение

    J(C)=[[C, sqrt(I−CCᵀ)], [sqrt(I−CᵀC), −Cᵀ]].

Матрицы дефекта grade-block diagonal с размерами `1,4,6,4,1`, благодаря чему не нужна диагонализация с вырожденными eigenvectors. Для каждого положительного блока D:

    Z₀=I,
    Zₙ₊₁=½ Zₙ(3I−D Zₙ²),       Sₙ=D Zₙ.

Это конечный полином в D. У собственных `d∈[1/16,1]` остаток `e₀=1−d≤15/16`, `eₙ₊₁=eₙ²(3+eₙ)/4≤eₙ²`, и `|sqrt(d)−d Zₙ(d)|≤eₙ`. Число шагов выбирается точной integer-проверкой `(15/16)^(2^n)<2^(-target_bits−16)`; для 3460 бит `n=16`. Все 4×4 экспоненты, minors и матричные операции считаются outward dyadic, факториальный хвост exp и остаток корня включены в интервалы. Входящее B91 gap — явная предпосылка, не численный SVD check.

На `||C||<1` Julia непрерывна по C, ортогональна и принадлежит `SO(32)`: при `C=0` она меняет местами два 16-мерных блока, детерминант `(+1)`, а path `tC` сохраняет ортогональность. По интервалам строится **точная dyadic** матрица A; измеренный radius и оценка `||A−J||op≤32 max_entry_error` сертификатно дают `≤2^-3460`.

## 3. Все 32 columns и остановка при ties

В каждом столбце interval QR выбирает **первую** строку с доказанным `|entry|>1/8`; равенство двух кандидатов не решается. Для A, находящейся на `<2^-3460` от ортогональной J, `σ_min(A)≥1−2^-3460`. После предыдущих устраняющих вращений нижний остаток текущей колонки имеет норму не меньше этой величины: он равен расстоянию до span предыдущих колонок, а соответствующий вектор коэффициентов имеет норму ≥1. В ≤32 оставшихся строках существует entry по модулю ≥`(1−ε)/√32>1/8`. Значит всегда существует **строго** сертифицируемый кандидат; exact tie не мешает выбрать первый подходящий. Все дальнейшие радиусы при устранении столбца не меньше выбранного.

496 двухстрочных Givens в SO дают `G₄₉₆…G₁ A=R`. Устранённые элементы заменяются точным нулём только после алгебраической формулы `s=−b/sqrt(a²+b²)`; каждый denominator отделён от нуля. QR выбирает положительные первые 31 pivot; `det A>0` из `||A−J||<1`, поэтому и последний diagonal положителен. При увеличении bits матрица A стремится не к J, а к fixed полиномиальному приближению `J_n`; точная ошибка двух off-diagonal root-блоков имеет норму не больше `e=2^(-target_bits−16)`. Следовательно на достаточно высокой precision `δ=||A−J||≤2e=2^(-target_bits−15)`. Каждая диагональ `r_jj` лежит в `[1−δ,1+δ]`, поскольку это расстояние j-й колонки A до span предыдущих. Для верхней части `r_<j,j` выполнено `R_<jᵀ r_<j,j=A_<jᵀ A_j`; `||R_<j⁻¹||≤1/(1−δ)` и `||AᵀA−I||≤2δ+δ²`, откуда `||r_<j,j||≤(2δ+δ²)/(1−δ)<3δ`. Таким образом `32 max|R−I|<96·2^(-target_bits−15)<2^-target_bits`: фиксированный остаток sqrt имеет явный строгий запас, а не объявляется стремящимся к нулю. Программа увеличивает dyadic precision до этой posterior проверки; она и `||A−J||` дают target-ошибку `≤2·2^-3460`. Число возможных последовательностей pivots конечно, все выбранные радиусы >1/8, и интервалы на каждой допустимой ветви сходятся равномерно; поэтому поиск действительно завершается.

Angles для обратного QR выводятся в хронологически правильном порядке. B93 grid выбирает конкретный `1≤k≤Q` с ошибкой `<2^-3460` на каждый полный all-column rotation; интервалы angle при необходимости пересчитываются с удвоенной точностью. Точное равенство угла границе сеточной ячейки не требуется: принимается ограничение ширины, после которого соседняя клетка имеет достаточную uniform error. Итого

    ||Ĵ−J|| ≤ (2+496)·2^-3460 <2^-3451.

Это uniform bound одного выбранного address/CODE sector, не max-ошибка целой последовательности нескольких SOURCE copies. Off-sector identity точна: все незадействованные Givens маски возвращаются исходной Walsh-грамматикой B42; conjugating CX-перестановки попарно отменяются. У sector имеется 12 address + 12 CODE + branch + 4 остальных Julia bits = 29 контролей; Julia flag и четыре modes образуют 5-bit DATA. Старый RIGHT, phase-rebit и comparator scratch не адресуются. Forward/reverse использует действительные literal inverses SourceI/G/CX, а не бесплатное сокращение или очищение aux/port/Spin.

## 4. Бюджет, стоимость и проверка

`certificate` сохраняет точные имена offsets/digits/xy и SHA-256 всех 496 адресованных k; это привязка вычисленного сектора, а не учёт его исполнения.

Один полный вариант на ненулевых offsets с заданными `digits=(0,1,2,3,1,0)` и `xy=(1,2)` действительно построил все 496 целых native grid k на 3588 бит без precision retry. Все 1024 первоначальные Julia entry интервалы содержат более точный 3844-битный replay; Все 496 G powers этой точки независимым ball-пересчётом на 7168 бит проверены `<2^-3456`. Глобальная `<2^-3460` оценка для произвольной точки опирается на B93 uniform-grid theorem, а не на один replay. Exact rational fixtures проверили identity/нулевой boost и 4×4 Hadamard с равными pivot; все 496 пар из пяти бит проверены на корректное преобразование индексов и знак с произвольной остальной DATA. Четыре случая, включая смещённые поля, сопоставлены всем 32 столбцам независимой численной B25 Julia: max расхождение около `1.2e-15`; это **диагностика**, строгую target-оценку дают интервалы и residual выше. Полные маски `2^29` или огромные степени G не выполнялись.

При **неизменных** остальных A48 prefix/coframe/CAR/SITE contracts достаточно заменить в его recurrence

    select=max(26·2^-3456, 498·2^-3460).

Точный рациональный пересчёт с `3^9`, 1440 Choi, 128 CAR и SITE по-прежнему даёт full SOURCE error `<2^-3423`. Это не доказывает, что новые A53 coframe/CAR уже удовлетворяют тем же contracts; их требуется проверить отдельно.

`sector_cost` вычисляет exact compressed inventory одного выбранного sector по реально выбранным k, а обратный inventory совпадает с буквальной инверсией. `variable_bank_cost_upper(group_count,reverse)` даёт безопасный componentwise upper на `4096·group_count` sectors, k≤Q, 496 rotations и до 8 перестановочных CX на rotation. Для 256 исходных f-groups `SourceI` и `CX` reverse upper имеют длину 3535 бит, `G_port` — 3533 бита. Это **upper**, не число реально оплаченных букв; fixed sectors, Choi adapter, другие компоненты, G/CX replacement для SourceI, полная цена и новый growing clock не включены. Их нужно пересчитать на одной общей A53 истории прежде чем переносить A49 bounds.
