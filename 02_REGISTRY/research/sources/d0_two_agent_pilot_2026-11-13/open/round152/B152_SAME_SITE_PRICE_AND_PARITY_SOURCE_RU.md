# B152. Цена повторного чтения того же SITE

На исходной геометрической вариации A75 любое фиксированное число полных проходов по восьми SITE-битам сохраняет положительный остаток в объявленных ценах A76 на всех глубинах от 1 до 8192. Повтор одного фиксированного паритета на том же входе даёт отрицательный отклик буквальной средней цены, около $-7.49754\cdot10^{-6}$ за чтение. Производные Info и двух проверенных подтверждений ограничены независимо от числа чтений. Семь указателей уже дают полный ранг 128 на рассмотренных вариациях кофрейма.

## Одна подготовка, одна Julia, много свежих указателей

Пусть $Y=y$ — записанный исход прежнего указателя, $Z_y$ — ненормированное состояние DATA и RIGHT, $\Pi_x$ — диагональный SITE-проектор и $q_{yx}=\|\Pi_xZ_y\|^2$. Прежний указатель исполняется один раз. Для каждого фиксированного паритета $f_j(x)$ применяем положительные CX от его SITE-битов к свежему указателю $(\sqrt p,p)$, $p=\varphi^{-1}$, и записываем сырой исход $m_j$. Kraus-операторы диагональны на SITE. При $r_0=p^2$ и $\kappa=p^3=p-p^2$
$$
 T_j(1\mid x)=r_0+\kappa f_j(x),\qquad
 P(y,\mathbf m)=\sum_x q_{yx}T_x(\mathbf m),\qquad
 T_x(\mathbf m)=\prod_{j=1}^K T_j(m_j\mid x).
$$
Переменная $X$ здесь представляет вероятности без отдельного резкого измерения. После каждого тонкого журнала состояние DATA+RIGHT чистое. Энтропия полной классически-квантовой записи равна энтропии $(Y,M)$, а $H_\varphi(M\mid Y)=K h_\varphi(r_0)+I_\varphi(X:M\mid Y)$. Для среза со скрытым DATA остаётся $H(M\mid YR)=H(M\mid Y)-I(M:R\mid Y)$. Оценка работы через Info ниже использует полный срез. [Исходный прибор A76](../../direct/round76/record/DATA_GEOMETRY_RU.md) · [Ценовые конвенции A76](../../direct/round76/record/NOISY_SITE_PRICE_RU.md).

После усреднения новых печатей старый SITE-блок $x,x'$ умножается на $(2p^{3/2})^{d(x,x')}$, где $d$ — число чтений, на которых паритеты этих адресов различаются. Это скалярное произведение указателей $(\sqrt p,p)$ и $(p,\sqrt p)$ на каждом таком чтении. Повтор одного паритета сохраняет когерентность внутри его секторов и подавляет её между секторами. В знаковом подъёме B149 добавленные положительные буквы имеют единичный относительный класс. Применение к реальной памяти требует доказать этот подъём для рождений, CX и печатей. Если старый проектор класса существует и коммутирует с новым прибором, полнота Kraus-операторов сохраняет его Born-маргиналь после суммирования по новым исходам. [Условия маркированного возврата B149](../round149/B149_FULL_BOOK_MEMORY_RETURN_RU.md).

## Производные Info и подтверждений при любой фиксированной длине

Пусть $Q_y=\sum_x(q_{yx}/q_y)T_x$ и $K_{yx}=D_{\mathrm{KL},\varphi}(T_x\Vert Q_y)$. При дифференцировании по $q_{yx}$ слагаемые от нормировки каналов сокращаются. Из $Q_y\ge(q_{yx}/q_y)T_x$ следует
$$
 D I_\varphi(X:M\mid Y)=\sum_{yx}(Dq_{yx})K_{yx},\qquad
 0\le K_{yx}\le -\log_\varphi(q_{yx}/q_y).
$$

На префиксе $u=(y,m_1,\ldots,m_{j-1})$ положим $r_u=P(m_j=1\mid u)$ и $r_x=T_j(1\mid x)$. Цена подтверждения A76 равна $L(r_u)$, где $L_{\rm reg}(r)=1+2r(1-r)$ для зарегистрированной работы и $L_{\rm coh}(r)=F(s)$, $F(s)=\sqrt{1+2s}[1+(\sqrt3-1)s]$, $s=\sqrt{r(1-r)}$, для указанного чистого когерентного подтверждения. Последняя формула использует допуск когерентной операции из A76. Производная премии сверх постоянной $K L(r_0)$ по $q_{yx}$ имеет вид
$$
 G_{yx}=\sum_{j,u\mid y}P(u\mid x,y)\,B_{-L}(r_x,r_u),\qquad
 B_F(a,b)=F(a)-F(b)-F'(b)(a-b).
$$
Действительно, производная $P(u)[L(r_u)-L(r_0)]$ равна $P(u\mid x,y)[L(r_u)-L(r_0)+L'(r_u)(r_x-r_u)]$. На обеих границах $L(r_x)=L(r_0)$. Цепное разложение KL даёт ту же сумму для $K_{yx}$ с $B_{-h_\varphi}$.

На $[p^2,p]$ отношение кривизн $(-L'')/(-h_\varphi'')$ лежит между $0.44$ и $0.54$ для обеих цен. Оно равно $4\ln\varphi\,r(1-r)$ для зарегистрированной цены и $(\ln\varphi)[F'(s)/s-(1-4s^2)F''(s)]/4$ для когерентной. Интегрирование второй производной переносит границы на $B$, поэтому $0.44 K_{yx}\le G_{yx}\le0.54 K_{yx}$. [Интервальная проверка](check_same_site_price.py).

На исходной двухузловой касательной $D=\partial_A/a-\partial_B/b$ получаем $S_+<0.008386$, $S_-<0.008903$, где $S_\pm=\sum_{yx}(Dq_{yx})_\pm[-\log_\varphi(q_{yx}/q_y)]$ и обе части неотрицательны. Поэтому
$$
 -a_\nu S_+-b_\nu S_-
 \le\sum_{yx}(Dq_{yx})(\lambda G_{yx}-\nu K_{yx})
 \le b_\nu S_++a_\nu S_-,\qquad
 a_\nu=(\nu-0.44\lambda)_+,\quad b_\nu=(0.54\lambda-\nu)_+.
$$
Границы применены к фиксированному расписанию. При предсказуемой остановке константы за чтение умножаются на $\mathbb E K$ и её производная входит в цену.

## Фактический ценовой остаток

По A75 $DR=0$ и $DG_n>0.02204$ для $G_n=H_n+J_n$, $1\le n\le8192$. Старый порт сам даёт нулевую строку. Для любого фиксированного полного старого кода A76 имеем $DC_{\rm old}>-0.004344153$ и $DH_\varphi(Y)<0.000245225$. Цена буквального слова $1+m_j$ даёт $\kappa D\mathbb E f_j(X)$. Печать всех восьми битов за один проход даёт от $1.13174652\cdot10^{-5}$ до $1.13174657\cdot10^{-5}$. Фиксированные полевые константы этой модели имеют нулевую производную. У паритета $x_4\oplus x_6\oplus x_7$, маска 208 при нумерации с нуля, печатный отклик лежит в $(-7.49753930,-7.49753925)\cdot10^{-6}$ за чтение. Это самая отрицательная строка среди всех 255 ненулевых фиксированных паритетов с положительными CX. Его можно читать тремя CX на указатель либо один раз применить $4\to7,6\to7$, читать бит 7 и обратить две начальные операции. Второй способ добавляет собственные стадии в часы. Бит 1 уже даёт отрицательную строку с одним CX на чтение. Для паритетного повторения
$$
 D(C_{\rm new}+\lambda W-\nu H_\varphi(M\mid Y))=K DC_1+O(1).
$$
Для некоторого конечного фиксированного $K$ отрицательный отклик этого слагаемого превосходит по модулю положительные старые строки всех 8192 глубин объявленной модели.

Длинная серия с этим тарифом в конечном счёте нарушает положительность реализованной Info по (BORN)+(GAIN). Возьмём старую метку с ненулевыми массами обоих паритетов. После первой печати posterior паритета $u_1>u_0$. Разность ожидаемых будущих буквальных цен равна $(K-1)\kappa(u_1-u_0)$. Разность будущих энтропий ограничена через $\log_\varphi2$. Премия подтверждений над постоянной также ограничена сверху через $0.54\lambda\log_\varphi2$. Для последней оценки можно применить границу кривизн к вогнутому прогибу между $r_0$ и $p$ и затем сложить условные энтропийные премии. Разность будущих потенциалов $f_1-f_0$ при $f_i=2H_i-\mathbb E C_i$ тогда уходит линейно в минус. В начислении для первого исхода 0 эта разность входит с положительным множителем $P(m_1=1\mid y)$. Остальные слагаемые данного начисления ограничены. Иной полный тариф, фактическая оплата стадий и абсолютный класс возврата требуют собственных проверок.

## Семь указателей для 128 вариаций

Функции $x_0\oplus x_6,\ x_2\oplus x_6$ и $x_1,x_3,x_4,x_5,x_7$ имеют общее ядро из масок 0 и 69. Их чтение использует семь свежих Golden-указателей и девять положительных CX. Строки якобиана A76 по 128 вариациям суммируются по парам $x,x\oplus69$ и проходят через шумную матрицу $T^{\otimes7}$. Для каждой из двух старых портовых меток пустого Fourier-исхода интервальная невязка обратной матрицы меньше $0.006<1$. Поэтому 128 **совместных вероятностей** при одной такой метке имеют ранг 128. Шесть бинарных печатей при одной фиксированной старой метке дают не более 64 строк. Нормировка внутри одной старой метки с семью печатями оставляет не более 127 независимых строк. [Проверка семи считываний](check_seven_site_readers.py) · [Сертификат](SEVEN_READERS_RESULT.json).
