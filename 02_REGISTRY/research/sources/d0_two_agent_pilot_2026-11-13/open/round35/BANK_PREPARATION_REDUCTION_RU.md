# B35. Сведение полных source-bank maps к определённым подготовкам векторов

## Результат и оставшийся parent

Для всех семи B25 bank targets получено точное операторное сведение полного `O_b`/RAW-frame и полного site-controlled CAR map к отражениям относительно **заданных нормированных векторов**. Fixed-anchor отражения выпущены как исполняемая конечная G/CX/SourceI grammar с буквальным обратным проходом. Невыполненным named parent остаётся **физическая когерентная подготовка этих конкретных векторов** со строгой равномерной ошибкой, заданной ниже. Это количественная редукция, а не готовая подготовка bank или полный H.1 writer.

Утверждение охватывает все `2^22` Choi input columns и все CAR grades на входах с заявленной чистой *private* рабочей областью. SAM и внешний SITE сохраняются как read-only controls; unknown oldRIGHT, другие source copies, общий native aux, port и Spin могут быть произвольными и запутанными с внешним состоянием. Глобальные births, исходный vacuum/Fourier prefix, внешний SITE loader, все marks/clock и фактическая Cost−Info не выведены. `physical_C_closed=false`, `GR_closed=false`.

## 1. Полный Choi: точное равенство двух отражений

Для действительного B25 `j,b` обозначим нормированный исходный вектор `Omega=Omega_j(Y_b)`, `r=|a=0,i=0,j=0>` и

```
A = 2049,  Omega[a,i,j] = J_a[j,i]/sqrt(32 A),
c = <r,Omega> = 1/sqrt(32 A) = 1/sqrt(65568),
u = (r+Omega)/sqrt(2(1+c)),   R_v = I - 2 |v><v|.
```

Каждая полная `J_a` ортогональна, включая `J_0=I_32`; поэтому `||Omega||²=(A·32)/(32A)=1`. Дополнение до `2^22` содержит нули, но в нормировку не входит. Постоянство `c` верно для каждого полного SAM label, не только в центре. Вектор `u` тоже нормирован. Непосредственное раскрытие даёт точное равенство на **всех** входных колонках:

```
O_b = R_u R_r = I+K+K²/(1+c),  K=|Omega><r|−|r><Omega|.
```

Для истинных 22 RAW births требуется полный map

```
O_b (G†)^⊗22 = R_u R_r (G†)^⊗22.
```

`O_b` фиксирует padding, но `(G†)^⊗22` смешивает padded и active inputs; поэтому padding полного RAW-frame нельзя считать identity. Порядок записи математический: RAW inverse применяется первым. `G†=ZGZ` точно; при выделенном distinct port его 22 маршрутизированных применения стоят 22 G + 132 CX + 88 SourceI, плюс реальные births/marks.

Нельзя заменить `u` непосредственно на `Omega`: `R_Omega R_r r=2c Omega−r`, и расстояние до `Omega` равно `sqrt(2(1-c))≈1.41145` для настоящего `A`. `REDUCTION_HOSTILES_CHECK.json` содержит также точный рациональный пример.

## 2. CAR: два отражения и сокращение anchor

Пусть `e=|grade 1>`, `gamma=sqrt(p)` и `m_x` — полный B25 нормированный grade-16 вектор на внутреннем site. `m_* = gamma|1> + p|14>`. Для любого site и SAM label

```
<e,m_x> = <e,m_*> = gamma,
u_x = (e+m_x)/sqrt(2(1+gamma)),
u_* = (e+m_*)/sqrt(2(1+gamma)).
O_m = R_(u_x) R_e,      O_* = R_(u_*) R_e,
M_x = O_m O_*^T = R_(u_x) R_(u_*).
M = Σ_x |x><x|_internal-site ⊗ M_x ⊗ I_RIGHT ⊗ I_oldRIGHT.
```

Одинаковые `R_e R_e` сокращаются как полные unitary, не после измерения и не только на исходной подготовке. `u_*` — одна фиксированная целевая подготовка; `u_x` может зависеть от SAM и внутреннего site. На семействе `f,0,x+,x−` B25 имеет `Psi=0`, так что `m_x=m_*` и **target M=I**; исходный baseline/vacuum/Fourier и его физические стадии при этом не исчезают. CAR reference `y±` имеет фиксированную site-зависимость, `q` — настоящую SAM/site-зависимость.

В Choi части `y+,y−,0` используют одну и ту же reference family `(u_ref,I links)`; `x+` и `x−` дают ещё две фиксированные. Только `f` и `q` в этой конкретизации требуют SAM-dependent Choi family. Повторно используемое имя target не является копированием квантового состояния: все реальные copy births всё равно отдельны. Центр `Y0` отдельно от любого SAM vertex, в частности от all-zero `b`.

## 3. Минимальная достаточная физическая предпосылка

Для Choi и двух CAR половин нужны реальные finite native unitaries `U`, содержащие свои отдельные `w` private wires, и буквальные оплаченные `U†`. Пусть `F` — **все** внешние факторы, включая SAM, невыбранные banks, site/RIGHT, произвольные native aux/port/Spin и oldRIGHT; для CAR нужный внутренний site находится среди read-only controls F. Требуется для каждой family равномерный isometry contract

```
|| U ( |r,0^w> ⊗ I_F ) − V_u || <= eps,
V_u |b,x,xi> = |u_(b,x),0^w> ⊗ |b,x,xi>.
```

Для fixed family индексы `b,x` могут не использоваться. Порядок tensor factors схематичен; физический SAM должен оставаться control-only на требуемых стадиях, oldRIGHT и прочие защищённые факторы не должны адресоваться. `F` может быть в любой суперпозиции и запутан; **shared aux/port/Spin не предполагаются нулевыми**. Если у реализации остаётся garbage, который зависит от входа или не возвращён к `0^w` на этой изометрии, указанный контракт не выполнен. Private wires конкретного U, private wires другого U и отдельный чистый workspace компилятора отражения должны быть разведены.

Определим joint anchor `R_(r,0^w)=I−2|r,0^w><r,0^w|⊗I_F`. Реальная последовательность для Choi —

```
U R_(r,0^w) U† R_(r,0^w) (G†)^⊗22.
```

При exact isometry она на **любой** source DATA column с исходным `0^w` даёт нужный `O_b(G†)^⊗22` и возвращает private work к нулю. При указанном `eps` разность двух subspace projectors не более `2 eps`, поэтому при точных anchor reflections вся полноколоночная ошибка не превосходит `4 eps`. Если каждое физическое anchor reflection имеет clean-work error `zeta`, hybrid bound становится `4 eps+2 zeta`. Ошибка одного фактически исполненного `U` учитывается через указанную изометрию; второй отдельно приближённый inverse не предполагается: используется literal inverse **самого** U.

Для CAR последовательно исполняются такие joint reflections для `u_*` и `u_x` на раздельных private registers; получаем `4 eps_* + 4 eps_x + zeta_* + zeta_x`. На идеальной исходной подпространственной области оба private work возвращены в ноль. Дополнительный чистый predicate workspace при каждом отражении аналогично должен быть чист в target schedule; фактический остаток поглощается в `zeta` через hybrid argument.

Одной проверки `U|r,0_work>` при **одном** состоянии внешнего oldRIGHT недостаточно. Также нельзя просто отражать `|r><r|⊗I_private-work`: `REDUCTION_HOSTILES_CHECK.json` даёт точный конечный пример, где подготовленная единственная private-clean column правильна, но такое отражение даёт неверный результат на другой source column. Там же пример одной плохой SAM ветви: средняя squared error `2^-2688`, а worst-case controlled operator error равна единице. Поэтому ни centre-only тест, ни средняя по SAM не заменяют вышеуказанную равномерную изометрию.

## 4. Реальная grammar anchor reflections и количественный бюджет

[anchor_reflection.py](anchor_reflection.py) строит фиксированный адресованный native DAG: вычисляет предикат в отдельный clean flag через A13 X/CX/CCX, исполняет точный routed `Z`, затем буквальный native inverse **фактического** вычисления. Гейт не использует SAM или oldRIGHT как target. Реальные адреса, port, Spin, arbitrary aux, все private и predicate scratch должен выделить владелец графа; доступность RAW births и marks не предполагается. Подстановка A14 использует принадлежащую владельцу Walsh/parity конструкцию контролируемых native rotations из [phase compiler](../../../d0_native_readiness_amplification_2026-10-24/PHASE_COMPILER.md); приблизительные Boolean слова и их actual adjoints берутся из A14/A16. В grammar не добавляется идеальный произвольный angle gate или бесплатный heralded phase. Существование этого phase compiler само по себе не строит оставшийся U.

Для joint anchor с `N` controls, где `N=22+w` у Choi и `N=4+w` у CAR, логическая прямая половина предиката имеет

| Anchor | X | CX | CCX | Approximate X/CCX в полном reflection |
|---|---:|---:|---:|---:|
| Choi `0^N` | 2 | `2N−1` | `2N−3` | `4N−2 = 86+4w` |
| CAR `grade 1, work 0` | 0 | `2N−3` | `2N−3` | `4N−6 = 10+4w` |

Для `N=22,4` построенные native DAG, фактический paid inverse и counts проверены в [REFLECTION_REDUCTION_CHECK.json](REFLECTION_REDUCTION_CHECK.json); все 16 чистых CAR input columns и 132 Choi примера прошли logical gate interpreter. A14 даёт при своих условиях all-column error каждого approximate X/CCX `<2^-4096`; чистая comparator reflection тогда имеет `zeta` не больше указанного числа таких вхождений, умноженного на `2^-4096`. Точные CX/Z/native primitives всё равно оплачиваются в clock.

На семь report B25 выделяет до `1260=7·180` Choi и `112=7·16` CAR copies. Для трёх семейств private ширин `w_C,w_m,w_*` консервативное число reflection approximate macros

```
N_ref = 218960 + 10080 w_C + 448(w_m+w_*).
eta_banks <= 1260·4 eps_C + 112·4(eps_m+eps_*) + N_ref·2^-4096.
```

Если **каждый** из ещё не построенных isometry U удовлетворяет `eps≤2^-3224` и каждая private ширина `w≤32768`, то рационально `eta_banks<2^-3210`. Это условный budget без экономии на identity CAR, без выводов о стоимости U и без SITE/Fourier/births/reader/marks. При других widths нужно использовать формулу, а не вставлять 32768 как обнаруженный факт.

При дополнительных предпосылках B29 — full `alpha_target≥1/2`, установленная exact структурная T6 и `g s>2^-3158` — только этот bank-вклад даёт `e_B≤2 eta_banks` и `e_B/(g s)<2^-51` на единицу нормы генератора. Полная `alpha_target≥1/2` **не** следует из одного preprocessor: у семи независимых checkpoints `Q_pre^7≈0.1223`. Это число тоже не является нижней границей полной `alpha_target` без остальных READY компонентов. Остальные реальные источники ошибки и вся правая часть T10 остаются отдельными.

Для пересчёта при иной доказанной границе полной `alpha_target≥a>0` используем B29 coefficient до подстановки alpha: `g s > 2^-3156 a²`. При `eps_C,eps_m,eps_*≤2^-t` и `w≤32768` получаем

```
eta_banks <= 5936·2^-t + N_ref·2^-4096,
e_B/(g s) < 2^3157 a^-2 · (5936·2^-t + N_ref·2^-4096).
```

При указанных widths `N_ref<2^29`. Без учёта остальных частей writer достаточно консервативных значений:

| Точность U: `t` | `eta_banks` | Bank-вклад в `e_B/(g s)` |
|---:|---:|---:|
| 3224 | `<2^-3210` | `<2^-53/a²` |
| 3228 | `<2^-3214` | `<2^-57/a²` |
| 3230 | `<2^-3216` | `<2^-59/a²` |

Это лишь параметрический bank-резерв при доказанном `a`; он не утверждает, что какая-либо из этих точностей уже достигнута, и не заменяет B29 structural/mark gates. При очень малом `a` отражательный член `N_ref·2^-4096` тоже необходимо пересчитать и, если требуется, повысить точность фактических A14 replacements.

## 5. Производные и абсолютная нормировка

B25 strict Julia/material margins обеспечивают гладкость соответствующих target formulas по заявленной непрерывной chart области. Для направления `D`, поскольку `A` и `c` фиксированы,

```
||D Omega||² = (1/(32 A)) Σ_(a=0..A−1) ||D J_a||_F²,   D J_0=0,
||D O_b|| = sqrt(2/(1+c)) ||D Omega||,
||D[O_b (G†)^⊗22]|| = ||D O_b||.
```

Здесь нормы операторов берутся на полном Choi carrier; равенство следует из `u⊥Du` и собственных значений `±2||Du||` rank-two производной отражения. Для CAR при `psi=(Psi_0,Psi_15)`, `z=sqrt(1−p−||psi||²)` и фиксированном p:

```
||D m_x||² = ||D psi_x||² + (psi_x·D psi_x)²/z²,
||D M_x|| = sqrt(2/(1+sqrt(p))) ||D m_x||.
```

Для site-controlled CAR полная норма — максимум по внутренним sites; RIGHT и oldRIGHT остаются identity. Диагностики этих тождеств для 1 792 фактических centre CAR matrices сохранены в [SOURCE_DERIVATIVE_CHECK.json](SOURCE_DERIVATIVE_CHECK.json); точное утверждение выше следует из алгебры, не из float sample.

Равномерная ошибка на конечных SAM vertices **не доказывает производную native compiler как гладкой функции**. Она, однако, контролирует конечную разность нужных исходных эффектов: при фиксированном observable `||H||≤K`, абсолютной ошибке последовательности подготовки не более `eta` на каждом конце и шаге `s=2^-30`, отличие соответствующих разностных отношений не более `4 K eta/s`. Для A11 отдельных leaf `K=16A=32784`, `32A=65568` или `1`; для нормализованного bounded source effect можно использовать его доказанный `K≤1`. Это отдельная оценка, не автоматическая идентификация физического source/derivative и не замена B29 T6, lift и marks.

## 6. Проверки и следующий конкретный шаг

[B25_REFLECTION_TARGETS_CHECK.json](B25_REFLECTION_TARGETS_CHECK.json) сверяет полные `2^22` centre vectors всех семи банков, их абсолютный anchor, случайный полный входной вектор для каждого Choi и все `7·256` CAR maps; дополнительно проверены `4·256` q-CAR maps на четырёх реальных SAM labels. Числа — float diagnostics (максимум CAR `2.3e−16`); алгебраическое равенство действует для всей exact family, а не извлекается из этого выборочного расчёта.

Нужный следующий оператор указан точно: SAM/site-controlled, reversible, native-owned `U_C,j` и `U_m,q`, а также fixed-reference `U_*`/reference U, удовлетворяющие isometry contract пункта 3 и фактически оплачиваемые вместе с literal inverse. Вычислимое численное имя B25 или матрица одного центра не являются такой физической подготовкой. До реализации U, глобального SAME-SITE/disjoint allocation, actual prefix/seal и проверки B29 structural gates нельзя утверждать полный writer, полную alpha, физический C или вывод ОТО.
