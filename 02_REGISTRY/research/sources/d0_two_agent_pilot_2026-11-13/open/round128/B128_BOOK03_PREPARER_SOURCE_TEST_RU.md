## 2. Что сокращается в исходной формуле

В Book03 с указанным учётом вершины стыка \(S(\alpha\gamma)=S_{\mathrm{pre}}(\alpha)+S_{\mathrm{tail}}(\gamma\mid\alpha)\) для полной фиксированной предыстории \(\alpha\). Из разности \(DS(\alpha\gamma_1)-DS(\alpha\gamma_0)\) префикс сокращается буквально. То же верно для логарифма отношения положительных сумм по двум хвостам при одном фиксированном \(\alpha\). Хвост включает свои маршрутизацию, терминал, комплементы и Info, каковы бы ни были их действительные значения. При суммировании разных \(\alpha\) их веса остаются внутри сумм. [Book03 §03.3.0–a и §03.10(d)](../../../../../../01_BOOKS/BOOK_03_FINITE_ACTION_OPERATORS_AND_SCENE_DYNAMICS.md)

Если \(\alpha\) уже классически записана и \(M_j=\sum_\alpha a_\alpha m_j(\alpha)\), доли \(\pi_j(\alpha)=a_\alpha m_j(\alpha)/M_j\) задают точный остаток \(\sum_\alpha(\pi_1-\pi_0)(\alpha)D\log a_\alpha\). Все независимые скалярные строки подготовки исчезают тогда и только тогда, когда эти две условные доли совпадают, то есть \(m_1(\alpha)/m_0(\alpha)\) постоянно на общей положительной поддержке. У когерентных неразличённых префиксов такой формулы с вероятностями нет.

Для оригинального веса пути \(\varphi^{-S}\) общий множитель \(e^{-\ln\varphi\,h(Y)}\) во всех завершённых путях не виден ни в нормированных полных записях, ни в перекрёстных отношениях. При общей амплитудной нормировке в квадрате массы он даёт \(e^{-2\ln\varphi\,h(Y)}\), столь же невидимый. Абсолютное \(D[-\log_\varphi Z]\) меняется на \(Dh\) для суммы весов. Это ядро данных сравнения. Доказательство не назначает новый тариф \(h\). В первичном источнике тот же дефект сформулирован как остаточный корневой член после переноса цены по рёбрам и терминалу. RI4 исключает его производную по доказанно независимому **позднему** управлению, поскольку ранний эталон реально завершается до его выбора. У поля, прочитанного приготовителем, этого аргумента нет. [Исходная RI4 и корневой остаток, строки 160067–160125](https://github.com/gvakhrushev/d0_15/blob/076d5d5a7b366c0dd0970f388df7a9e6895498c4/02_REGISTRY/research/A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md#L160067-L160125) · [Критерий абсолютной калибровки](../round125/B125_ABSOLUTE_SOURCE_ANCHOR_RU.md)

## 3. Точный способ проверить оставшееся движение приготовленного состояния

Зафиксируем программную отметку и пусть общая нормированная подготовка \(\rho>0\) на достижимой подложке имеет уже сохранённое пассивное очищение. Пусть физический перенос полных положительных масс даёт эффекты \(E_j\) на этой подложке, \(m_j=\operatorname{Tr}(\rho E_j)>0\). Эффекты включают полный терминал для соответствующего хвоста. Скаляр \(a_b(Y)\), общий двум назначениям на данной отметке, вынесен из \(m_j\). Транспонирование ниже фиксировано базисом пассивной ссылки. Её нормированная маргиналь и префиксная строка равны
\[
R_j=\frac{(\sqrt\rho E_j\sqrt\rho)^{\mathsf T}}{m_j},\qquad
B=(\rho^{-1/2}D\rho\,\rho^{-1/2})^{\mathsf T},\qquad
D_\rho\log\frac{m_1}{m_0}=\operatorname{Tr}[B(R_1-R_0)] .
\]
Последнее равенство следует из цикличности следа при фиксированных \(E_j\). Условие \(R_1=R_0\) на **одном** верном очищении эквивалентно \(E_1/m_1=E_0/m_0\) и устраняет любой префиксный касательный \(D\rho\) на подложке. Для отклика только данного поля достаточно нуля одного записанного спаривания.

Если эффекты различаются, \(\delta=\|R_1-R_0\|_1\) даёт острую границу:
\[
\left|D_\rho\log\frac{m_1}{m_0}\right|\le \tfrac12\,\operatorname{osc}(B)\,\delta .
\]
Здесь \(\operatorname{osc}\) есть разность крайних собственных значений. Вычитаем середину спектра \(B\), поскольку разность маргиналей бесследова. Для \(\operatorname{osc}(B)\le2\) равенство достигается подходящим знаком \(R_1-R_0\), со скалярной поправкой для \(\operatorname{Tr}D\rho=0\). При независимом движении каждой \(\rho_b\) полный вклад приготовления в перекрёстном контрасте \(\tfrac12 D\log(R_A/R_B)\), где \(R_A,R_B\) суть шансы двух программных меток, есть полусумма этих строк по программным отметкам. Проверка символьного равенства восстанавливает известный остаток для \(E_1=A^2 I+4d^2P_+\) и \(E_0=b^2 I\), включая строго ненулевой случай \(D_\rho\log(m_1/m_0)=4d^2 Du/(A^2+4d^2u)\), где \(u=\operatorname{Tr}(\rho P_+)\). На закреплённой нечётной Spin-подложке эта конкретная чётная строка исчезает. Для других подготовительных касательных проверяются действительные эффекты, а не геометрическое равенство их штатных конечных матриц.

Эта формула переводит проверку движения приготовленного состояния в измеримое равенство для уже существующей ссылки, когда физический перенос доказан. В исходном сертификате Book03 нет такого совместного измерения для данной пары и нет абсолютной массы общей подготовительной ветви. Поэтому получен точный относительный результат с критерием остатка. Абсолютная полная Cost−Info на исходном устройстве и \(\mathrm{GR\_closed}\) остаются открыты.
