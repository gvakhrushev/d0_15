## 1. Независимая проверка M3–M4 и M6

Для точного эффекта `K_γ* K_γ=π_γ I` и одного фиксированного целевого `V_γ`, `V_γ*V_γ=I`, положим `R_γ=E_γ/sqrt(π_γ)` и `Ṽ_γ=V_γ+R_γ`. Тогда `Ṽ_γ` — изометрия и действительно

```text
||dP̃_γ|| <= 2 ||dR_γ||,
||dR_γ|| <= ||dE_γ||/sqrt(π_γ)
             + ||E_γ|| |dπ_γ|/(2 π_γ^(3/2)).
```

На ортогональной сумме истинных фиксированных листьев норма производной projectors — максимум по ветвям. При общем фиксированном `B,g,z` и неизменной поддержке, `D=(1-z)I+zh >=(1-z)I`, поэтому `(2zr/(1-z)) max ||dR_γ||` действительно ограничивает `|dJ|`. Если `B`, `g`, цель `V_γ`, cut, z или ранг меняются, соответствующие настоящие слагаемые нельзя занулить.

Для двух фактически исполненных конечных слов `+,-`, при общей поддержке, том же layout, reference и последнем gate и **одних и тех же** целях `V_γ`, имеем

```text
||P̃_γ,±-V_γ V_γ*|| <= 2 ||E_γ,±||/sqrt(π_γ,±),
|J_+-J_-|/(2|t| Γ)
 <= zr [alpha_+ + alpha_-] / [(1-z)|t| Γ],
alpha_±=max_γ ||E_γ,±||/sqrt(π_γ,±).             (M6)
```

Оценка logdet получается интегрированием по положительному отрезку матриц, не по предполагаемой непрерывной native-траектории. Для исходного CD13 дополнительно сохраняется действительная `||R_h||`. Множитель `π_γ^-1/2` необходим: при сколь угодно малой `π` две ортогональные нормированные ветви могут иметь сколь угодно малую абсолютную разницу `K` и при этом различающиеся projectors. Проверяющий код содержит этот отрицательный контроль.

Для наших **точных исходных** девяти fine-ветвей каждого фиксированного `i=0,1` выполнено `π_γ>=p^16`: нижняя граница учитывает `q_b>=p²`, возможные две code0-tail вероятности `>=p^6` и положительную flag-вероятность `>=p²`. Отсюда формально `alpha_±<=p^-8 max_γ ||E_γ,±||`. Для **новой** конечной реализации, меняющей условное квантовое состояние или fine-effects, эту границу надо заново доказать; один сохранённый coarse-эффект не устанавливает всех девяти `π_γ`. На краю исчезающей ветви rank и само RC3-выражение могут измениться.

M6 применима к `+/-` сравнениям **одного и того же** выбранного слова/семейства, если реально построена общая цель. Два различных слова `i=0,1` из round3 имеют разные хвосты; нельзя считать их цели одинаковыми без действительного оплаченного транспорта и его ошибки. Само наличие полярного представителя не даёт этого транспорта для обеих новых тонких записей.

## 2. Сравнение исходных полярных масс с двумя архивами

Для идеального исходного coarse 0/10 блока LC2/LC4 верны

```text
mu_0=p, mu_1=p³, mu_invalid=p⁴,
f(q)=sqrt(p)sqrt(1-q)+sqrt(p³)sqrt(q).
```

При собственно доказанных полярных conditional ranges, требуемой исходной reference-карте и подходящем фактическом g подстановка в RC3 двух **coarse** положительных ветвей даёт `L=2r`, `h=(p+p³)I_r` и описанное в M2 нулевое чисто вероятностное производное. Самих чисел `p,p³` недостаточно для такого равенства: они являются массами проекций born-вложения; нужны также реальные нормированные `V_b` и их совпадающие операторные overlap с reference после g. Например, нормированный вектор внутри `r=0` с хвостом `(p,-a)` ортогонален `v=(a,p)` и имеет нулевой overlap, хотя массовый проектор `P_0` сохраняет ту же born-массу `p`. Это математический отрицательный контроль, а не новая физическая модель H.1.

В нашей дальнейшей реально уточнённой задаче каждая coarse-ветвь проходит через кодовые хвосты, два шестимаркерных born-архива и оплаченный заключительный `CX`. При указанных временах записи для фиксированного старого адреса

```text
r=4, L=36, L-r=32,
mu_fine,0 = p^8+p^12,  mu_fine,1=p^12,
h_i=H_(i,0) A_0 A_0*+H_1 A_1 A_1*,
A_b=X_b/sqrt(q_b),  i=0,1.
```

Коэффициенты `H_(0,0)≈4.0562251824e-4`, `H_(1,0)≈4.3613852866e-4`, `H_1≈4.1985756322e-6` учитывают настоящий условный хвост, обе fine-записи и реальный последний gate. Первая зарегистрированная ветвь `b=1` при этом несёт reference-бра `a<0|`, а не `<v|`. Полярные массы `p,p³` не разрешено вставить вместо этих новых коэффициентов: это другая система cuts, физический носитель и история. Также нельзя сравнивать её абсолютный `J` со старым M2 без правильного переноса рангов, clock, B и g.

## 3. Более узкая конечная оценка для вычисленного h

Зафиксируем одно из наших двух слов `i`, его реальную последовательность рождений/регистраций и все операторные reference-факторы. В обоих конечных сравнениях `+/-` пусть исходные scalar effects точны и q лежит в исходном диапазоне. Матрицы

```text
A_b,± = X_b,± / sqrt(q_b,±)
```

являются сжатием нормированной условной изометрии, поэтому `||A_b,±||<=1`. Из точной формулы round3, а не из подстановки распределения меток,

```text
||h_+-h_-|| <= 2 sum_b H_(i,b) ||A_b,+-A_b,-||,
|J_+-J_-|/(2|t|Γ)
 <= zr sum_b H_(i,b)||A_b,+-A_b,-||
       / [(1-z)|t|Γ],        H_(i,1)=H_1.           (O4)
```

Доказательство — `AA*−BB*=(A−B)A*+B(A−B)*`, затем тот же положительный logdet, что в M6. При `r=4` для CD13 весь правый член умножается на `||R_h||` в истинной физической норме. Эта оценка позволяет проверить меньший **root-видимый** остаток, чем максимум разностей всех leaf-изометрий, потому что исходная последовательность round3 уже даёт точную факторизацию девяти ветвей. Она не доказывает, что остальные квантовые будущие наблюдения или полная физическая цена эквивалентны.

Если доказан общий root target `A_b^*` и реальные конечные ошибки

```text
||X_b,± - sqrt(q_b,±) A_b^*|| <= epsilon_b,±,
```

то в (O4) разрешена подстановка

```text
||A_b,+-A_b,-|| <= epsilon_b,+/sqrt(q_b,+)
                    +epsilon_b,-/sqrt(q_b,-)
                  <= p^-1 (epsilon_b,++epsilon_b,-).
```

Это отдельная физическая задача на исходный H.1 writer, а не уже вычисленная ошибка. Она сильнее простой регистрации вероятности; но для данного специально доказанного h ей не нужна общая оценка девяти полных `V_γ`. Если conditional recovery, новый reader или настоящий cut меняют использованную факторизацию, (O4) предварительно нужно снова вывести; в общем случае сохраняется более широкая M6 и её реальные fine-вероятности. Значения ошибок на конечных словах делятся на настоящий шаг и gain — их малость сама по себе не устанавливает source-предел.

В частности, если нормированные `A_b` действительно постоянны по одной разрешённой физической вариации, а исходные H, B, g и ranks фиксированы, то (O4) и его дифференциальная версия дают нулевой **marked J** по этой вариации. Для физической ОТО-цепи остаются другие реальные источники, полный heat, adjoints и оригинальное Cost−Info binding; ни M6, ни O4 не подменяют их когерентным gain.
