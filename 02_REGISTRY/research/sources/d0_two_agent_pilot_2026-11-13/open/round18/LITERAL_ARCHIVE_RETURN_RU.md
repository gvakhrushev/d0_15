# B18: полный возврат буквального NPS/нулевого хвоста/архива

**Результат.** Для исходного NPS, E0, точного 36-call inverse echo и настоящих шести архивных копий получена полная операторная компрессия на **исходный** cut. Если `X0,X1` — настоящие банковские corner-операторы двух NPS ветвей, полный когерентный GROWING-возврат равен

```
C = p^4 X0 + p^6 X1,
J = −log det[(1−z)I+z C* C].
```

Здесь уже учтены оба первоначальных провода `r,t`, все шесть канонических рождений архива и их фактическая подготовка в ноль. `q` сам по себе не определяет `X0,X1` и не определяет этот возврат. На исходном matched scalar NPS corner получена конкретная непогашенная строка по углу яркого хвоста: при нулевых информационных коэффициентах `bQ=bC=0` и `theta=0`, `D_theta C=p^6 X0`, а `D_theta J<0` на всём исходном воротнике. Следовательно, нулевая строка рассмотренной в A8 parsed/CQ цены **не** является стационарностью полного когерентного `H+J`.

При буквальном unitary execution физический архив остаётся в полном когерентном carrier; чтение его вероятностей правилом Born само по себе не добавляет физическую измерительную стадию. Для реально зарегистрированного/dephased канала и для отдельного marked-tree clock ниже получены иные формулы; их связь с конкретным Book03 clock требует реального измерения/маршрутизатора и правильного incidence. Никакое из различий не закрывает physical C. `GR_closed=false`.

## 1. Носитель, марки и действительный clock

Обозначим `p=phi^-1`, `alpha=√p`, `v=(alpha,p)`, `u=(alpha+p)/2`, `d=(alpha-p)/2`. Буква `alpha` здесь обозначает амплитуду рождения, а не информационный коэффициент A8. Пусть `j:H0→B` — настоящая canonical bank embedding на исходном cut, включая все прежние births и любые пассивные reference. В прямой нотации owner NPS11–13 положим

```
W=A_b* Z_e A_f,        V=A_b* A_f,
K0=(u W+d V)j,         K1=(u W−d V)j,
X0=j* K0,              X1=j* K1.
```

Это операторы на всех исходных колонках, а не корни вероятностей. `K0,K1` отображают истинный вход в полный конечный bank; `j*` означает **пассивную** canonical компрессию всех его банков, а не trace, postselection либо переименование неизвестного старого входа. Для исходного matched writer `V=I`; четыре `A_f,A_b` и их независимо допустимые variations не отождествляются вне этого сечения.

NPS рождает `r,t` в `v`; `t` не трогается до настоящего E0. После E0 и проверенного обратного эха состояние точно равно

```
|0>_r |0>_t K0|psi> + |1>_r |0>_t K1|psi>.
```

Шесть архивных `v` проходят реальные 17-call inverse-подготовки; копировщик §7fy сохраняет полные шесть битов `(r,t,r,t,t,r)`. Для живого `t=0` получаются взаимно ортогональные архивы `000000` и `101001`. На полном carrier все другие сектора и их true thermal modes остаются; запись `report_bits` в [исходном native_execution](../inputs/native_execution.py) — readout metadata, не физическая measurement/reset инструкция.

При конкретной букве schedule **после E0**: 36 echo calls, затем шесть отдельных births, затем 102 calls их zero-prep и 30 calls copy/port-restore. Это `174` дополнительные стадии. Если carrier до echo имеет размер `D0`, добавка к сумме pre-stage размеров точно

```
36 D0 + (1+2+4+8+16+32)D0 + 132·64 D0 = 8547 D0;
final dimension = 64 D0.
```

При отсутствии последующих рождений и настоящем последнем deliver-CX как `g` minimum birth age равен 132. Это число относится к конкретному **unitary** schedule; оно не описывает внешний dephasing или остановленное first-repeat дерево. Для исходной сцены и `beta=2p²` CL7–12 дают `A_132 < 10^-414`, конкретнее `log10(A_132 upper bound)≈−414.3493`, умноженное на настоящую норму endpoint variation. Истинный нормированный source-budget ещё делится на действительные gain и comparison step и умножается на right-lift/occurrence факторы; значения сами по себе не доказывают C.

## 2. Exact полный unitary cold, без предположения о `q`

Обозначим `M_0=000000`, `M_1=101001`. Пассивная born-бра даёт

```
lambda_0=<v_r v_t v^6|0,0,M_0>=alpha^8=p^4,
lambda_1=<v_r v_t v^6|1,0,M_1>=alpha^4 p^4=p^6.
```

Обе цифры входят в полном 8-wire cut; дополнительные нормированные нетронутые born helpers дают множитель один. GROWING G7–G10 теперь дают на прежнем input rank, для настоящего полного literal word,

```
C = p^4 X0+p^6 X1
  = u(p^4+p^6) C_W+d(p^4−p^6) C_V,
C_W=j* W j,    C_V=j* V j,
G_unit=C* C,
D J=−z Tr{[(1−z)I+z C* C]^-1[(D C)*C+C*D C]}.
```

Все старые марки и возможные `Dj` стоят на своём месте в `D C`; `X0*X1` в полной Gram сохранён. Значения `q` и born массы не вычисляют `C_W`, `C_V`, их относительную фазу или четыре независимые подготовки. Эта формула относится к полномерному unitary clock и его рождённым complement-секторам; она не использует предположения о состоянии `rho`, тонком измерении или единственной успешной ветви.

Для произвольной допустимой идеальной яркой настройки `w(theta)=(cos theta,sin theta)`, `r=1` tail остаётся `0`. Шестикопийный реальный word даёт уже **другой** фиксированный исход `010110` при `(r,t)=(0,1)` с passive overlap `p^6`. На той же исходной bank embedding:

```
C(theta) = [p^4 cos(theta)+p^6 sin(theta)] X0 + p^6 X1,
D_theta C|_0 = p^6 X0.
```

Это алгебра фактического reader на полной когерентной памяти; для `theta≠0` непрерывный target может требовать native approximation и общего физического layout. `theta=0` достигается точным 36-call echo из B17. Формула не предполагает LC4 polar bank recovery.

### Исходный matched scalar NPS: ненулевая nuisance-строка

На настоящем matched scalar сечении `C_W=(1−2Q)I`, `C_V=I`, `q=p²+p³Q`, `0≤Q≤1/2`. Положим

```
x0=u(1−2Q)+d,      x1=u(1−2Q)−d,
c0=p^4 x0+p^6 x1.
```

Тогда `Xb=xb I`, `x0≥d>0`, `c0≥d(p^4−p^6)>0`; при исходном input rank `r` и `0<z<1` точно

```
D_theta J|_0 = −2 r z c0 p^6 x0 / (1−z+z c0²) < 0.
```

В частности, на фиксированном unitary clock с одинаковой chart/layout и идеальным единственным theta-вращением `||D_theta W_final||≤1`, поэтому CL7 отдельно даёт `|D_theta H|≤A_132`; отсюда полная строка `D_theta(H+J)` строго отрицательна, если

```
2 r z p^6 d² (p^4−p^6) > A_132.
```

Это условный аналитический вывод для гладкого unitary target в данной fixed-layout сцене. Не утверждается, что этот гладкий pulse является native primitive: для физического finite contrast необходимы разрешённые секторные слова, одинаковый реальный layout/clock или доказанный транспорт, их ошибки делённые на шаг, actual `z`, gain и право варьировать хвост. Дополнительный физический ledger или другой source может его компенсировать. Однако сама A8 code-price при `bQ=bC=0` имеет `D_theta P=0`, и это не сокращает явно вычисленную строку `J`.

## 3. Dephased channel и фактически оплаченный born test

Если внешний допустимый механизм действительно измеряет полный архив и удерживает классические исходы, его channel имеет ветви `K0 rho K0*`, `K1 rho K1*`. При **отдельно заданной** полной born-проверке всей финальной canonical bank/pointer/tail/archive проекции результирующая CP-карта на входном cut равна

```
T_born(rho)=p^8 X0 rho X0* + p^12 X1 rho X1*,
Pr_born=Tr[rho (p^8 X0*X0+p^12 X1*X1)].
```

Это та же реальная canonical компрессия, применённая после внешнего разветвления: cross terms потеряны благодаря регистрации. Формула является точным conditional-channel потребителем, но native_execution сам не исполняет этот channel или дополнительный born-test. Если тестировать только две payload wires `r,t` и не требовать возврата bank/archive, результат на scalar coarse effects — `p²(1−q)+p³q`. Если дополнительно сравнить все шесть архивов с их born states, но не сравнивать bank, результат — `p^8(1−q)+p^12 q`. Нельзя смешивать эти числа с предыдущей bank-sensitive CP-картой.

## 4. Отдельный отмеченный clock RC1–RC3

Если **физически задан** надлежащий measured router на сохранённых archive flags, его fixed projectors, конечные leaf spaces, данные `J_v/B_root`, действительный последний gate на каждой ветви и генерация cut, то результат владельца RC3 имеет

```
h=P0 B_root* g P_L g* B_root P0,
det=(1−z)^(L−r) det_root[(1−z)I+z h].
```

Для конкретного fixed-projector чтения полных шести архивных flags после последней записи, при branch-independent оставшихся port-restore calls и canonical reference transport, `g P_L g*` есть прямая сумма **нормализованных диапазонов** двух финальных branch maps. В этом определённом интерфейсе при `E_b=K_b* K_b` имеем точную формулу на исходном cut

```
h = p^8 X0 E_0^+ X0* + p^12 X1 E_1^+ X1*.
```

`+` — псевдообратный оператор на истинной поддержке; физически недостижимые ветви не включаются в `P_L`. На strict scalar collar `E0=(1−q)I`, `E1=qI`, `0<q<1`, и это упрощается к

```
h = p^8/(1−q) X0 X0* + p^12/q X1 X1*.
```

Здесь диапазонные projectors и `L−r` принадлежат именно измеренному дереву, а не unitary G10. Эта формула не исходит из подстановки probabilities в projector и не совпадает с trace-preserving channel или born CP effect; порядок `X X*` тоже нельзя произвольно заменить на `X* X`. Если timing измерения/последнего gate или canonical reference отличается, необходимо построить настоящее `B_root` и rederive; один декларативный «mark» не исполняет RC1 router.

На matched scalar NPS сечении из п. 2 этот условный marked-clock коэффициент вычисляется полностью:

```
h(Q)=p^8 x0(Q)^2/(1−q(Q)) + p^12 x1(Q)^2/q(Q).
```

При фиксированных остальных данных его производная **строго отрицательна** на `0≤Q≤1/2`; это пример того, что проекторы ранга могут менять ориентацию при изменении поля, даже если вероятности не входят в них напрямую. Доказательство знака: `q∈[p²,1/2]`, `d≤x0≤alpha`, `x1≥−d` и

```
dh/dQ = p^8[-4u x0/(1−q)+p³ x0²/(1−q)²]
       +p^12[-4u x1/q−p³ x1²/q²].
```

Первый член строго отрицателен, так как `4u(1−q)≥2u=alpha+p>p³ alpha≥p³x0`. При `x1≥0` второй неположителен. При `x1<0` сумма не больше

```
−4 p^8 d (u/p−p³ alpha) + 4 p^10 u d
=−4 p^9 d (2u−p² alpha) < 0,
```

где использованы `q≥p²`, `1−q∈[1/2,p]` и `1/p−p²=2p`. При fixed rank и `z>0` соответствующий `D_Q J_marked` положителен. Это строгое свойство указанного marked-clock интерфейса и matched NPS corner, а не выполненное доказательство, что исходная программа реализует такой router или что вся цена источника совпадает с ним.

Для контраста: если отдельная условная polar recovery помещает `K_b/√q_b` прямо в пассивный bank subspace, тогда `X0=√(1−q)I`, `X1=√q I` и `h=(p^8+p^12)I` действительно независимо от `q`. Эта **дополнительная** полярная гипотеза не верна автоматически для исходного NPS без recovery. Таким образом ни «RC3 всегда зависит от q», ни «RC3 всегда постоянен» не следует только из двух scalar effects.

## 5. Фазы, проверка и границы

На matched scalar NPS при `Q=1/4` численно `q≈0.440983`, а `(C*C, born CP, h)≈(0.00614024,0.00425121,0.00771079)`. При `Q=1/2` получается `(0.00005745,0.00017235,0.00034470)`. Во втором случае `x1<0`, и когерентный cross term **отрицателен**: нельзя объявить `C*C` больше dephased результата без известной относительной фазы. Эти значения используют разные математические consumers и даны для различения формул, не как три одновременно измеренные цены.

[check_literal_return.py](check_literal_return.py) независимо повторяет все 512 Boolean-входов copy-word, проверяет две точные NPS fixtures, исходные born amplitude `p^4,p^6`, знак изменения cross term и 101 численную проверку derivative. Проверки B17 воспроизводят настоящий 36-call echo на всех колонках. Исполнение полного гигантского H.1, физического измерительного router, всех ранее существующих readers и 425D heat не заявлено.

Главный остающийся вопрос physical C теперь конкретнее: показать, какой **фактический** полный execution и retained/registered cut выбирает исходный Book03 `F=P U* Q U P`, вычислить или bound его настоящий source и все weights на той же истории, и включить оставшиеся физические Cost/Info/boundary/ledger terms. Нельзя заменить это `q`, независимой CP price или отмеченным `h` другого непостроенного clock.
