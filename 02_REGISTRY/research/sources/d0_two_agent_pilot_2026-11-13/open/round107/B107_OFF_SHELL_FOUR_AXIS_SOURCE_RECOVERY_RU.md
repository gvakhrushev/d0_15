# B107. Off-shell восстановление четырёх source-строк на A54/B105

**Результат: условный конечный recovery, не off-shell zero.** Для каждого точного рационального имени поля `y`, `|y_j|<2^-32`, рассматриваем B105 с одним и тем же `y` и одним actual `M(y)`-dependent post во всех `+/-` сравнениях. На исходных 2688 MG2 axes четырёхслотовая координатная строка исходного reader `H+J`, делённая на свою actual `Γ(y)`, отличается от

    (DIτ(Y), −DIτ(Y)/2, DIτ(Y)/2, 0)                (1)

по компонентам Pf/Qf/Qb менее чем на `2^-108`, Pb — менее чем на `2^-189`; евклидова норма всей ошибки в `4×2688` координатах меньше `2^-102`. Здесь `Y=Y₀+y`, `DIτ(Y)` — градиент **исходного** B25 скаляра при фиксированных reference/SITE, а не производная дискретного выбора native grid. Это не утверждение малости или нуля `DIτ(Y)` вне центра.

Область: выбранный A23/B25 SOURCE с canonical RAW source-private fibre, исходный born-product CODE, пустой начальный carrier `H₀=C`, тот же reader и gain, оплаченные B105 control/core/post/probe/padding/retention. Результат наследует явно закреплённые B65/B91/B95/B97/A50/A54/B106 контракты. [Проверка](check_regular_source_recovery.py) выполняет точный рациональный пересчёт, проверяет SHA и геометрию middle; [receipt](B107_REGULAR_SOURCE_RECOVERY_CHECK.json). Гигантские path sum и производственное слово не исполнялись. `physical_C_closed=false`, `GR_closed=false`.

## 1. Геометрия middle и одна фиксированная задача на поле

A54 использует namespace, physical wire map и A29 compiler A48. Все не-SOURCE stages передаются прежнему provider; между Q marks стоят обратный resource frame, восемь REPORT, PORT_ZERO, SC6 и центральный знак. Проверены исходные affine REPORT private intervals и shared endpoints, 34112 resource wires, SC6, port/spin/aux и compiler helper: они не пересекают 5376 CODE wires. На actual A54 dispatch независимо проверены все middle stages и depths 0/1/2. Transducer закрыт на обоих исходных cuts согласно унаследованному A29/B82 contract.

Следовательно actual middle `S` не использует CODE **даже как controls** и `[S,X]=0` для CODE-only X. Диагональность `M` следовала бы уже из более слабого CODE-control-only условия; для перестановки Q она сама по себе недостаточна. Actual return `C` не объявляется равным `Bᵀ`, а actual `S` — симметричным. Проверочный отрицательный пример показывает, что CODE-control-only middle может не коммутировать со skew X.

К каждому `y` привязан отдельный `GlobalSource(y)`; post строится из действительного path-sum `M(y)`, а не из старого `M(0)` или идеальной таблицы. Post один и тот же в сравниваемых slot/sign/axis histories **при данном y**. При смене поля post может меняться. Поэтому эта работа восстанавливает control covector при фиксированном поле; она не отбрасывает `dU_post/dY` в полной полевой производной физической задачи. Pb стоит непосредственно перед post и отличается от post-probe.

Равенство Qf/Qb с обратными знаками для полных конечных сравнений использует именно CODE-disjoint `S`, одинаковые control lengths, исходную stage-gauge сопряжённость и один новый paid clock A43/A50. Оно не устанавливает равенства всех закреплённых intermediate CODE marks. При `+/-` используются отдельно скомпилированные controls, ошибки которых оплачены в следующих оценках.

## 2. Новая равномерная оценка вне центра

B65 даёт на всём исходном выпуклом raw cube `||D²Iτ||<2^25` и в выбранном центре `||DIτ(Y₀)||<2^-3083`. Поскольку `sqrt(2688)<52`, на новом chart

    a(y) := 2^-3083 + 2^25·52·2^-32,
    ||DIτ(Y)|| < a(y) < 1/2.                         (2)

Этот грубый uniform bound лишь обеспечивает kernel estimate; в (1) сохраняется точный `DIτ(Y)`. Все CODE sample points остаются в старом B21 cube по A53 chart margin. С `σ=2^-80`, `||V||<104`, `||DIτ||≤a(y)`, `||D²Iτ||<2^25`, `gσ>2^-3208` и новым A54 `e_M<2^-3421` для

    μ(y)=c_ref−2g Iτ(Y),     τ(y)=||M(y)−μ(y)I||

получаем, без добавления μ как физического контрчлена,

    τ(y)/(gσ) ≤ 2·a(y)·104 + 2^25 σ·104² + e_M/(gσ) < 85.    (3)

Старая оценка `<2^-41` использует малый **центральный** градиент и здесь не переносится. Обозначая `e_prefix` uniform A54 SOURCE-fibre bound, B91 `||DB||≤1748` и расстояние всех label offsets дают

    δ = 156·1748·σ + 2e_prefix,   2^-62 < δ < 2^-61.       (4)

Это сравнение полных SOURCE outputs с оставленным fresh remainder, не частичный след. Степень `2^-116` относится к следующему квадратичному kernel, а не к δ.

## 3. Q kernel и Pf sampling

Для исходного reflected SourceI profile `B₀ᵀS₀B₀` используем A44/A50 all-insertion identity с `V e_b=e_b⊗B₀,bω`, постоянным reference `J`, `Δ=V−J` и `A=Δᵀ(I⊗S₀)Δ`:

    Φ₀(X)−(DX+XD)/2 = Δᵀ(X⊗S₀)Δ−(AX+XA)/2.

Линейные по Δ слагаемые сокращаются. Для skew `||X||≤1` это даёт dimension-free `2δ²`; A29 G/CX replacement добавляет `e_W<2^-15800` на полную insertion map, а не только на её endpoint. В skew остатке вычитается скаляр μ. При `c_ref>2/3` отсюда для actual M и одного target post

    |d_Qb − d_red,Pf/2|
      ≤ (3/4)[(τ/(gσ))(2δ²+2e_W)+e_W/(gσ)] + e_U/(gσ),
    первый квадратный член <2^-116,   e_U/(gσ)<2^-6039.      (5)

Последнее строго посчитано точными дробями с (3)–(4); это равномерная ошибка, не попытка подставить центральный `τ/(gσ)<2^-41`. Qf имеет противоположный знак на основании раздела 1.

Для Pf B95 product identities применяются при **любом** сдвинутом центре: постоянное слагаемое коммутирует, линейное даёт `∂j Iτ(Y)`, quadratic expectation сокращается. В проверке также вычислен точный ненулевой рациональный пример сдвига на одном четырёхуровневом блоке. Для общего поля доказательство использует исходную product identity, а не численную выборку. B97 uniform `||D³Iτ||<2^31` даёт

    |Dσ Iτ−∂j Iτ(Y)| ≤ (2^31/3) σ² 104³ <2^-109.

Fixed actual post содержит реальную весовую поправку, которая не выбрасывается:

    d_red,Pf = Dσ Iτ − (g/c_ref)Dσ(Iτ²)
               − <χ,[M²−M₀²,X]χ>/(4 c_ref gσ),
    M₀=diag_b(c_ref−2g Iτ(Y_b)).

Uniform B97 `|Iτ|<2^15`, `||DIτ||<2^20` и исходное `g<2^-3061` дают weight error `<2^-3021`; A54 `e_M` даёт corner error `<2^-212`. Эти оценки не делят общую full-vector SOURCE error на g.

Для Pb именно **до** post `ξ=Mχ/||Mχ||` и target `U*ᵀχ=ξ`; следовательно `ξᵀXξ=0` для real skew X, а target corner curve чётна. Actual post error, отдельно компилированные controls и heat сохраняются в остатке: target symmetry не делает фактическую finite row точно нулевой.

## 4. Новый clock и точная сумма ошибок

B105 проверяет все физические CODE addresses и строит новое одинаковое оплачиваемое padding. Для данного uniform A54 upper использованы **новые точные** `Lbase`, `Nbase` и их SHA в receipt; `Nbase.bit_length=30833`, `K=175604`, но сами длины отличаются от A49. Часы принадлежат фактически padded истории:

    N=Nbase+2K,
    D=2^n(Lbase−2+3·2^K)−1,   n=11893774624.

При B105 `M_b(y)>669/1000`, post-ошибка даёт `c₀(y)>2/3`; actual `c₀≤1`. Поэтому для фактического

    Γ(y)=4 z p^K c_ref gσ / (1−z+z p^K c₀(y)²)

используется нижняя нормировка без `p^K`: `(8/3) z gσ`. Это actual полевая `Γ(y)`, фиксированная в данном сравнении, не производная отношения и не центральная Γ, подставленная в другую задачу.

При `t=2^-1700`, `z=2^-20`, actual new `Nbase/K` и исходных A42/A47 hypotheses получены каждый раз: finite-J Taylor `<2^-192`, две независимые control errors `<2^-190`, новый heat каждой оплаченной строки `<2^-8139`, post `<2^-6039`. Рациональная сумма в коде не округляет слагаемые до указанных верхних степеней. Она даёт по каждой оси errors Pf `<2^-108`, Qf/Qb `<2^-108`, Pb `<2^-189`, и непосредственно проверяет

    2688·(E_Pf²+2 E_Q²+E_Pb²) < 2^-204.

Дополнительно оплаченная finite `|Qb−Pf/2|<2^-115`; это более слабая off-shell оценка, чем центральная A50. Это bound **ошибки восстановления** (1), а не bound самой объединённой строки. В центре дополнительно действует отдельная B65 малость `DIτ(Y₀)<2^-3083`.

## 5. Открытые границы

Здесь нет полного dual по произвольным CODE/old/WORK/preparation directions и не идентифицирована физическая норма `V_h`. A23 выбрал полную vacuum/Fourier extension; её совпадение со всеми колонками, marks и оплаченной историей фактического owner descriptor или допустимый marked transport, включая `Dν`, не установлены. Исходный fine instrument/suffix, physical carrier/action/gate, независимые WORK/scene/record/Info rows, физическая same-execution Cost−Info и GR refinement остаются самостоятельными обязательствами. Никакая точность скомпилированного конечного семейства не доказывает off-shell stationary source или GR closure.
