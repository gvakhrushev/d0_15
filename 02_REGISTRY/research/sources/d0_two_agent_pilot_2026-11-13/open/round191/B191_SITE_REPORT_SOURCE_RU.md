# B191. Два оплаченных способа адресовать SITE в отчёте #334

Один общий абсолютный центр и независимые сдвиги для каждого знака восстанавливают разные физические статистики. Для исходного локального отчёта важна корреляция восьми знаков через один центр. Для отчёта на глобальных средних нужна доказанная условная факторизация знаков. [Исходное различие в #334](https://github.com/gvakhrushev/d0_15/blob/2c98a0c0a/02_REGISTRY/research/sources/d0_gr_2026-11-18/followups/2026-11-19/metric/INDEPENDENT_SHIFT_SHARED_SITE_RU.md#4-почему-усреднение-не-равно-исходному-локальному-отчёту).

| Исполнение | Точный результат | Проверка |
|---|---|---|
| [Один общий абсолютный центр](centre/COMMON_COHERENT_CENTRE_RU.md) | Локальное нелинейное среднее сохраняется на равномерном условном SITE. Старые провода вообще не адресуются. На одной настоящей паре дескрипторов вычислена потерянная независимая первая строка SITE и нижняя граница различимости полных архивов. | [Полный адресный тест, 4256 CX и 1120 Toffoli](centre/RESULT.json) |
| [Четыре минимальных сдвига на каждый знак](small_shift/MINIMAL_CATALOGUE_SHIFT_RU.md) | Для конкретного каталога \(L=4\) две честные монеты на знак дают скалярное среднее эффекта. Меньше четырёх точек в распределении недостаточно. Полный архив с реальным ключом может различать старый SITE. | [Характеры, минимальность и 5856 CX и 1120 Toffoli](small_shift/RESULT.json) |

Первый вариант точно переносит \(D r_{\mathbf h}\) только на тех направлениях, на которых \(\sum_x D\mu_{\mathbf h,x}r_{\mathbf h,x}=0\). Второй вариант даёт проверяемый вход для условного глобального расчёта [B189](../round189/B189_ABSOLUTE_INTERFERENCE_RU.md). Цены подготовок, контроллеров и полных отказов, операторное продолжение до полного sign и перенос всех вариаций H.1 остаются открытыми. \(\mathrm{GR}_{\mathrm{closed}}=\mathrm{false}\).
