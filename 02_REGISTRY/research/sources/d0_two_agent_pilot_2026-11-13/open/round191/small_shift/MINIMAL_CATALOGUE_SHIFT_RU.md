# Четыре минимальных сдвига для знаков каталога \(L=4\)

Для фактических двухполевых дескрипторов #334 достаточно двух свежих честных битов на знак. Четыре сдвига дают постоянный усреднённый эффект на старом SITE при заявленном операторном интерфейсе локального знака. Меньшая положительная поддержка этого для всего каталога дать не может. При новом буквальном сравнителе нет Toffoli для сложения адресов. ## Локальные характеры и минимальность

Пусть \(d=(u_d,v_d)\) и \(e=(u_e,v_e)\) — два дескриптора, \(u,v\in\{0,1\}\). На собственном сечении \(e_{\rm coframe}=4I,\ U=I,\ \rho=1\) нормированная локальная билинейная квадратура равна

\[
 F_{de}(x)=(-1+u_du_e-v_dv_e)
    \cos\!\left(\frac{\pi}{2}[(u_d-u_e)x_0+(v_d-v_e)x_2]\right).
\]

Знак \(-1\) приходит от общего шага \(x_1\). Шаги \(x_0,x_2\) дают вклад лишь когда обе копии имеют этот шаг, со знаками \(+1,-1\) соответственно. При каждой такой общей разности внутреннее скалярное произведение пропорционально косинусу разности исходных фаз. Четвёртое направление не даёт вклада. Проверка отдельно вычисляет исходные разности во всех 256 ячейках для всех 16 упорядоченных пар.

Возьмём \(\tau=2s_0 e_0+2s_2 e_2\) с двумя равномерными независимыми \(s_0,s_2\). Каждый ненулевой характер в формуле меняет знак хотя бы при одном из этих сдвигов. Поэтому \(\mathbb E_\tau F_{de}(x+\tau)\) равна глобальной средней для **каждого** \(x\), а диагональные пары сохраняют свои постоянные значения.

Для любой положительной меры сдвигов, скаляризующей все пары, должны исчезнуть комплексные коэффициенты Фурье на частотах \((1,0),(0,1),(1,1),(1,-1)\) и противоположных. Эти четыре направления реально встречаются с ненулевым коэффициентом у пар \(00/10,\ 00/01,\ 00/11,\ 01/10\). Постоянство вещественного косинуса после усреднения по сдвигу на всём SITE обнуляет обе координаты соответствующего комплексного коэффициента, поскольку на SITE аргумент меняется в том числе на четверть оборота. Тогда четыре функции \(1,\chi_0,\chi_2,\chi_0\chi_2\), где \(\chi_j(\tau)=i^{\tau_j}\), ортонормальны в \(L^2\) этой меры. Следовательно, её поддержка содержит не менее четырёх точек. Предложенный равномерный закон достигает границы.

## Оплаченное сравнение и область переноса

Регистр сдвига содержит два новых \(|+\rangle\) для каждого знака. Он может оставаться когерентным. На прямом участке восьмью CX копируем старый \(X\) в восемь чистых адресных битов, двумя CX добавляем сдвиг только на старших битах координат \(0,2\). Для \(r=e_j\) исходные два CX прибавляют обычный соседний шаг по модулю 4. Далее исходные 24 CX вычисляют пословные совпадения и семь отмечаемых Toffoli собирают флаг. Штатный NC1 регистрирует флаг с новым хвостом, затем вычислительная часть обращается. На успехе старые \(X,Y\), ключ, \(h=1\) и scratch возвращаются. Грязные регистры и все фактические остановы фабрик сохраняются.

Один сравнитель, включая CX из NC1, требует **14 Toffoli и 70 CX** при \(r=0\), **14 Toffoli и 74 CX** на соседе. Для восьми знаков, двух центральных и восьми соседних сравнений на знак получается **1120 Toffoli, 5856 CX и 16 новых плюс-ресурсов**, сверх подготовок scratch, хвостов, адресации и собственно CAR/Choi-приборов. При тех же условных независимых скалярных фабриках, что у #334, вклад этих ресурсов в готовность равен \(b_1b_2^{16}(b_2^6b_3)^{1120}\). Отдельное начало каждый раз не оплачивается повторно, если общий \(h\) уже включён в другой участок. [Точные исходные пределы фабрик и сравнения](https://github.com/gvakhrushev/d0_15/blob/2c98a0c0a/02_REGISTRY/research/sources/d0_gr_2026-11-18/followups/2026-11-19/metric/INDEPENDENT_SHIFT_SHARED_SITE_RU.md#L24-L59)

Внутри каждого знака один ключ удерживается для всех его действительных сравнений. **Разные знаки получают разные независимые ключи.** При локальном контракте \(E_{j,t\mid\tau}(x)=(1+t\,m_j(x+\tau))/2\) на всей прежней арене и \(m_j\), составленном из указанных каталоговых моментов, усреднённый эффект каждого знака скалярен. Если независимая готовность и условный инструмент доказаны и для каждого сохраняемого предшествующего журнала, это даёт произведение знаковых вероятностей для B189. Сумма модулей B189 тогда применима к уже действительно зарегистрированным \((\mathbf H,R)\), пока ключ не читается и дополнительные реальные фабричные квитанции имеют требуемый условный закон. Метод вычисляет полином на глобальных средних каждого знака. Один общий абсолютный центр для всех восьми знаков сохраняет другую величину, среднее нелинейного локального отчёта. На него это утверждение о независимой факторизации не распространяется.
