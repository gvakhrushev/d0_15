# B87: глобальный source radius и all-skew feedback A44

**Результат: PASS при закреплённых исходных bounds.** На одном фиксированном центре A30/A41 для любого вещественного SAM skew `Y`, `||Y||op≤1`, аналитическая actual Q-feedback строка отличается от половины идеальной fixed-post P_f строки меньше чем на `2^-32` в actual `Γ_native`. Обратная Q_f строка равна ей с противоположным знаком. Оценка не содержит `sqrt(dim SAM)` и не предполагает точную самосопряжённость actual compiled S. Это утверждение об аналитических feedback functional и любой их допущенной подобласти, не о конечных оплаченных сравнениях по всем направлениям, полной H+J цене, stationarity или full task admission. `physical_C_closed=false`, `GR_closed=false`.

## Один глобальный радиус вместо соседних рёбер

Пусть `u_b=B⁰_b|ω>` — исходный старый SourceI/profile prefix на canonical WORK, `b₀` — любой зафиксированный SAM label и

    V|b> = |b>⊗u_b,   J|b> = |b>⊗u_b₀,   Δ=V−J,
    δ=||Δ||=sup_b ||u_b−u_b₀||.

Это операторная норма одновременно по всем `2^2688` меткам, не сумма по всем меткам. Для двух произвольных labels могут измениться 256 coframe columns (по 4 coordinates), 256 links (по 6), 64 matter sites (по 2). Эти counts и единственность каждого Choi address проверены по B21/B24; геометрические диапазоны действуют на всём кубе и соединяющем labels отрезке.

В нормированном Choi source изменённые Julia blocks различных адресов ортогональны в Frobenius-скалярном произведении. При exact Julia defect `>1/16`, нормировке `sqrt(32·2049)>256` и B84 source inequality:

* coframe: каждая из 4 координат сдвигается не более s, поэтому `||ΔC||≤2s`, одно изменение адреса даёт `<3s/16`. Для 360 f/q копий сумма квадратов `<360·256·(3/16)²s²=3240s²`;
* link: разность шести generator coefficients имеет норму суммы ≤6s. B65 `||U||<17/16`, Duhamel и exterior lift дают `||ΔC||<54s`; один Choi address даёт `<81s/16`. Для 180 f копий сумма квадратов `<1180980s²`;
* matter: `||D m||²≤(1−p)/L<6/5<(11/10)²`. На каждом из 64 sites две компоненты меняются не более s и site mass равна 1/256. Для 16 q-CAR копий сумма квадратов `<8(11/10)²s²<20s²`.

SITE и остальные банки не зависят от рассматриваемых coordinates. У нормированных вещественных идеальных source factors при неотрицательных overlaps `||⊗v_i−⊗w_i||²≤Σ||v_i−w_i||²`; здесь изменения каждой копии много меньше 1, поэтому overlaps положительны. Две old-profile prefix ошибки `<2^-3232` учитываются отдельно. Рационально:

    ||u_b−u_b₀|| < sqrt(3240+1180980+20) s + 2·2^-3232 < 1100s.

Более свободный CAR budget A44 `16(11/10)²` также проверен; его полная константа `29605984/25<1089²`, после двух prefix ошибок она тоже даёт δ `<1100s`. Справедливость отсюда **не** означает, что весь старый профиль буквально равен ideal product.

## Размерностно независимое тождество

В исходном точном reflected профиле средний оператор `S⁰` самосопряжён, `||S⁰||≤1`; положим

    Φ₀(Y)=Vᵀ(Y⊗S⁰)V,   D=Φ₀(I),   A=Δᵀ(I⊗S⁰)Δ.

D и A диагональны по SAM label. Раскрывая `V=J+Δ`, линейные по Δ слагаемые в `Φ₀(Y)` точно сокращаются с соответствующими частями `{D,Y}/2`. Для любого Y:

    E₀(Y) := Φ₀(Y) − (DY+YD)/2
           = Δᵀ(Y⊗S⁰)Δ − (AY+YA)/2,
    ||E₀(Y)|| ≤ 2δ² ||Y||.

При real skew Y оператор E₀ также skew. Это матричное тождество на всём SAM, а не сумма оценок отдельных элементов: размер пространства не появляется. Checker воспроизводит его символически для общего skew и самосопряжённого S. Отрицательный контроль показывает, что для несимметричного S переносить это равенство напрямую нельзя.

Actual A30 cuts имеют `pending=0`; A30/B58 telescoping all-column replacement error `e_W<2^-3244` сохраняется при вставке любой SAM-contraction `||Y||≤1`. В частности, для actual Φ и actual диагонального M,

    E(Y)=Φ(Y)−(MY+YM)/2,
    ||E(Y)|| ≤ 2δ²+2e_W,
    ||(E(Y)+E(Y)ᵀ)/2|| ≤ e_W.

Второй bound отдельно платит за возможную асимметрию actual compiled kernel; она не объявляется нулевой.

## Сравнение при фиксированном actual centre

Обозначим `a=c_ref>2/3`, `gs>2^-3158`, `μ=c_ref−2g I_τ(Y₀)` и `τ=||M−μI||`. `|μ|≤1` следует из идеального нормированного comparator на допустимом центре. B65 даёт `||DI_τ(Y₀)||<2^-3083`, `||D²I_τ||<2^25` на всём кубе; `||Y_b−Y₀||<52s` и её квадрат `<2704s²`. Добавив actual diagonal error `e_B<2^-3231`, получаем

    τ/(gs) < 104·2^-3083 + 2^25·2704s + e_B/(gs) <85.

Это оценка **разброса от одного центрального скаляра**, а не старого грубого `σ/(gs)<2^144`.

Для ideal fixed output U* и любого реального skew Y, при `||χ||=1`, normal form B82 даёт

    d_Qb − ½ d_Pf = −χᵀ M E(Y) χ/(2a gs).

Вклад `χᵀ M Y M χ=0` точно вследствие skew Y. Разложение `M=μI+(M−μI)` и симметричная часть E дают bound; перенос к одному A41 `Uhat₀` и его actual gain добавляет `e_U/(gs)`, `e_U<2^-14623`:

    |d_Qb,actual(Y)−½d_Pf,ideal(Y)|
       ≤(3/4)[(τ/(gs))(2δ²+2e_W)+e_W/(gs)] + e_U/(gs)
       <2^-32.

`d_Qf,actual(Y)=−d_Qb,actual(Y)` точно из `[Y,S]=0` на actual supports. Норма здесь — supremum по `||Y||op≤1`, а не сумма по плоскостям. Если admitted directions — лишь подмножество, оценка автоматически верна и на нём; обратное включение всей SO tangent domain не доказано.

При формальном выделении s-зависимости в этой **одной** оценке произведение содержит геометрический член порядка `s³`, reference-centre defect порядка `2^-3083 s²` и отдельные compile/gain terms. Это не является чистой `O(s³)` теоремой при фиксированном ненулевом дефекте и не доказывает uniform refinement или существования нового recompiled семейства при меняющемся s.

## Проверка и ограничения

`check_global_source_reduction.py` независимо проверяет все 2688 label coordinates и фактическое число source copies, нормы и рациональные константы A44, source-prefix/replacement errors и B65 Hessian receipt; символически проверяет operator identity, skew cancellation и negative control с non-selfadjoint S. Он не материализует производство, все SAM states или гигантский kernel. Проверка исходит из оценок и содержательных сертификатов A27/A30/B21/B58/B65/B84 и их фиксированных SHA, а не заменяет их одним числовым тестом.

Полученный bound слишком велик сам по себе для вывода exact совместной stationary формы или универсального положительного/отрицательного знака каждой внутренней строки. Для finite all-plane H+J нужны независимо допущенные paid words, общие clocks, full heat и конечные comparison budgets. Для physical conclusion остаются исходный marked-map/unsplit transport B86, полный original task/FN admission, исходный Cost−Info binding и refinement.
