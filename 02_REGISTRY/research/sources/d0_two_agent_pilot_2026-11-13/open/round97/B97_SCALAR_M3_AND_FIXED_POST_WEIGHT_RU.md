# B97: исходный `Iτ`, третья производная и вес фактического поста

**Результат.** Для исходного B25 `Iτ` на том же B21 raw cube получена проверяемая uniform оценка смешанной третьей производной `||D³Iτ||<2^31`. С точным MG2 quadratic cancellation на born product это даёт scalar sampling bias `<2^-109` при `σ=2^-80`. Для заявленной A49 истории с `H₀=C` и одним fixed actual post отдельно вычислена весовая поправка: она не равна нулю по общему тождеству, но при исходном g меньше `2^-3021`. С оплаченной конечной A49 Pf-сравнительной строкой, corner и heat общий нормированный остаток к `∂j Iτ(Y₀)` меньше `2^-108` для каждой из 2688 координат.

Это утверждение для конкретного typed SOURCE, declared canonical RAW fibre, born-product CODE, исходного same-reader Book `H+J` и пустого initial carrier A49. Независимые Qf/Qb/Pb, произвольный correlated old input, original `Dν` marks, физическое Cost−Info/admission и ОТО здесь не закрываются. `physical_C_closed=false`, `GR_closed=false`.

## 1. Uniform M3 исходного scalar instrument

Используется исходная физическая Lorentz-диаграмма B21 и B65, без изменения `Iτ`, reference fields, `ρ_x`, SITE, action или selector. Во всех оценках направления в полной raw-диаграмме имеют евклидову норму не более 1; третья производная — смешанная трёхлинейная operator norm, не только производная вдоль одной оси.

B65 даёт `||U||,||U⁻¹||<17/16` и `||DΘ[h]||≤√6<5/2`. Duhamel и четырёхфакторное правило Лейбница дают для plaquette `P`:

    ||P||<4/3, ||DP||<14, ||D²P||<128,
    ||D³P|| < (4·5/2)^3 (17/16)^4 <2^11.

Для `∧^kP`, `0≤k≤4`, три отмеченных направления распределяются по одному, двум или трём факторам. Поэтому

    ||D³∧^k P||
      ≤4(4/3)^3·2048 +36(4/3)^2·128·14
        +24(4/3)·14³ <2^18.

Исходный A11 creator commutator квадратичен по coframe, с B65 bounds `A₀<2, A₁<4, A₂<4, A₃=0`. Шесть граней и неизменная trace-нормировка `(400/9)·16/8` дают `||D³f_x||<2^29`. Исходный `q_x` имеет два линейных coframe и два линейных matter-difference множителя. Применяя B65 базовую константу 12 и относительные bounds `(1/2,1/2,16,16)`:

    ||D³q_x|| ≤12·3!·(256+8)=19008 <2^15.

Оба результата используют именно поля в физическом chart. Например, polynomial `R₂` в A11 становится U на нём, потому что исходная SO/null-ортогональность выполняется тождественно вдоль chart; произвольные off-chart матрицы не охватываются.

Исходный B25 reporter polynomial дифференцируется точно по `Q[p,x,y,z]`: `r_xxx=0`, сумма модулей коэффициентов `r_yyy` равна `5 097 600<2^23`. B65 уже даёт `ρ_x>1/2`, `ε=2^-1531`, положительные `r_x(0,0)>2^-26`, `r_y(0,0)>2^-22`, `k₀<24`, `a_y<1` и нормированные первые производные reporter меньше 2. Следовательно `|r_yyy/r_y(0,0)|<2^45`, а полная цепочка на фиксированных исходных reference и SITE после одной общей суммы даёт

    ||D³Iτ|| < 2·2^29 + 48·2^15
                  + 3(2ε)2^47·2^18·2^23
                  + 24·3(2ε)2^43·2^9·2^13
                  + 24(2ε)²2^45·(2^9)^3
               < 2^31.

Тот же источник и gradient/value bounds B65 дают `|Iτ|<2^15`, `||DIτ||<2^20`. Exact polynomial coefficients и все рациональные inequalities воспроизводятся [certify_scalar_third_derivative.py](certify_scalar_third_derivative.py); ранее установленный M2 не переименован в M3.

## 2. Quadratic lift — с продуктовой предпосылкой

Для `Φ=φ^⊗2688`, `φ` и `X_j` исходных MG2–MG3, B95 точно проверил `H_jφ=φ`, `H_j=[V_j,X_j]`, `⟨φ,V_jφ⟩=0`. Поэтому expectation коммутатора всех quadratic monomials в `Y₀+σV` даёт ноль, кроме нужной линейной строки:

    D_σF := ⟨Φ,[F(Y₀+σV),X_j]Φ⟩/σ,
    D_σ Iτ = ∂j Iτ(Y₀) + R₃,
    |R₃| ≤ (2^31/3) σ²·104³ ||X_j|| < 2^-109.

Оценка следует из трёхмерного Taylor remainder на всём convex cube, `R_v<104` и `||[R,X]||≤2||R||||X||`. Она относится к исходному born-product Φ; для произвольного entangled CODE state B95 предъявил контрпример quadratic cancellation. Норму полного подготовленного SOURCE jet `<2^-44` здесь не делят на малый g.

## 3. Настоящий вес fixed positive post

A49 рассматривает `H₀=C`, так что chronological old Gram и `ρ` исходного determinant на этой начальной границе скалярны. Но post фиксирован на фактическом `Mhat`: пусть

    r=||Mhat Φ||,  ξ=Mhat Φ/r,  U*ξ=Φ,
    M₀=diag_b(c_ref−2g Iτ(Y_b)),   E=Mhat−M₀.

При идеальном fixed post и исходном собственном `Γ=4 z p^K c_ref gσ/(1−z+z p^K c₀²)` независимая аналитическая Pf feedback строка точно равна

    d_Pf = −⟨Φ,[Mhat²,X_j]Φ⟩/(4 c_ref gσ)
         = D_σ Iτ − (g/c_ref) D_σ(Iτ²)
           − ⟨Φ,[Mhat²−M₀²,X_j]Φ⟩/(4 c_ref gσ).

Второй член — действительная весовая поправка fixed post: её нельзя удалить, объявив продуктовую лемму справедливой для произвольного `ρ`. [check_fixed_post_weight.py](check_fixed_post_weight.py) независимо проверяет алгебру с произвольными диагональными error entries в точном рационально-символьном fixture и затем подставляет исходные bounds.

Из исходной B29 формулы

    g=2κ₉p^7 d_h ε² α² r_x(0,0)r_y(0,0)

и `0<κ₉,p,d_h,α,r_x,r_y≤1` следует `g<2^-3061`; здесь α — исходная полная вероятность READY, а не новый коэффициент. На одном двухбитном coordinate block расстояние между любыми `Iτ` values не больше `3σ·2^20`, а сумма шести MG2 plane coefficients `<3/2`. Следовательно

    ||[Iτ,X_j]|| < (9/2)σ·2^20,
    |(g/c_ref)D_σ(Iτ²)| < 2^-3021.

B96 даёт `||E||=e_M<2^-3421`, `Mhat,M₀` contractions и `c_ref>2/3`; поэтому `||Mhat²−M₀²||≤2e_M`, а реальный нормированный corner remainder `<2^-212` при `gσ>2^-3208`. A49 post error `<2^-9247` добавляет `<2^-6039` в той же нормировке. Это bounds, а не предположение, что actual compiled corner точно равен идеальному.

Для общего ненулевого старого carrier этот вывод применять без новой проверки нельзя: исходная матрица `ρ` может содержать old/CODE correlations или другие effect-changing условия. Если владелец отдельно докажет, что исходный scalar source действует как I на весь соответствующий old fibre и CODE state остаётся этим независимым born product, формула может быть поднята по тождеству; сама A49 пустая начальная история такого расширения не доказывает.

## 4. Конечная оплаченная Pf price row

A49 исполняет один и тот же actual core и post в обоих сравнениях; остальные три независимых control slots стоят в exact identity padding. Для real skew `||X_j||<1` и contraction M имеем `|c^(k)(t)|≤1`; исходная A42 оценка третьей производной J при `z=2^-20`, `t=2^-1700`, `gσ>2^-3208` даёт finite-J Taylor `<2^-192`. Независимо скомпилированные `P̂_+`, `P̂_−` несут A47 operator errors `<2^-5099`; их вклад после деления на t и gain `<2^-190`. Они не объявляются точными inverse. Настоящий A49 common growing clock и все paid padding/retention stages дают для этой отдельной строки heat `<2^-8139`.

Сумма всех положительных rational bounds:

    |FD_Pf(H+J)/Γ − ∂j Iτ(Y₀)|
      < 2^-109 + 2^-3021 + 2^-212 + 2^-6039
        + 2^-192 + 2^-190 + 2^-8139
      < 2^-108.

B65 также даёт `||DIτ(Y₀)||₂<2^-3083` для данного finite reference slice; значит каждая указанная нормированная Pf строка имеет модуль `<2^-108`. Это оценка на **математически заданные конечные native words**, включающая heat и отдельный actual post; гигантский path-sum/clock физически не исполнялся. Никакой вывод о нулевой точной строке, всей dual-норме четырёх slots или исходном physical Cost−Info из неё не следует. При необходимости контроль конечного 2688-component covector следует проводить в его собственном норме/lift: простое умножение на `√2688<52` даёт `<2^-102` до дополнительных `C_h`.
