# B72 — какие marks и выходы сохраняет backward-пара A36

**Результат.** Два backward-исполнения имеют побуквенно одинаковый полный prefix до конца A30 core. На терминальном carrier они отличаются только локальной операцией на одном SAM wire: все observables на остальных проводах и полный reduced-channel после удаления **этого одного** wire совпадают точно, в том числе при внешней запутанной reference. При этом terminal `Z` этого SAM wire различает исполнения. Совпадение reduced выхода не является равенством полных raw histories и само по себе не устанавливает same-task admission.

## 1. Точное разложение фактических слов

Обозначим выбранный SAM wire через `j`, остальной terminal carrier через `C` (включая остальные 2687 SAM wires, весь WORK, поздние born wires и любые нетронутые внешние факторы). В A36 backward `+` и `−` имеют один pre `G^n0` с одной padding, одну и ту же последовательность A30 core и один и тот же конец, кроме степени post на j:

\[
 V_+=(G_j^{n_-}\otimes I_C)V_{common},\qquad
 V_-=(G_j^{n_+}\otimes I_C)V_{common}.
\]

Это **точное равенство полных конечных операторов/isometries**, не аппроксимация малым углом. Оно следует из того, что post padding — буквальная последовательность 2- и 5-CX полноколоночных identity, `K=66076` поздних born/G операций действуют на новые провода и коммутируют с G на j, а физический последний G на j завершает соответствующую степень. Для вывода endpoint-оператора можно переставить действия на разных факторах; в реально оплачиваемом clock они сохраняют первоначальные ordinals и состояния. Это не идентификация clock или цен.

Для любого ограниченного `O_C` и внешней reference `R`, которую не адресует новое слово:

\[
 V_+^*(I_j\otimes O_{CR})V_+
 =V_-^*(I_j\otimes O_{CR})V_-,\qquad
 \operatorname{Tr}_j(V_+\rho V_+^*)
 =\operatorname{Tr}_j(V_-\rho V_-^*).
\]

Второе тождество действует для произвольной density, включая entanglement с R, на объявленной области общего input. Это алгебраическое утверждение о канале; конкретный A36 выполнен с `H0=C` и сам по себе не создаёт дополнительный физический input/reference. Tracing **всего** SAM является более грубым следствием, если такой quotient допускается задачей. Удаление только j уже достаточно. Сохранены все комплементарные выходы, в том числе исходы failure и существующие WORK/record регистры; новые reader или record от этого не исполняются.

## 2. Что реально зарегистрировано

A30 [source mark registry](../../direct/round30/SOURCE_RAW_MARK_REGISTRY.json) задаёт 1372 source slots и API для 282×256=72192 исходных leaf bindings; для них указан один `COMMON_SOURCE_RAW_FRAME_BEFORE_ANY_REPORT`, индекс стадии 1380. `leaf_mark` возвращает bounded оператор на DATA данного слота с тождеством на остальных регистрах; оно не выполняет detector или совместное измерение. Граница входа — canonical свежий WORK и произвольные coherent SAM⊗old, а не все dirty-WORK columns.

Поскольку A36 backward `+` и `−` до конца core имеют **один и тот же реальный prefix**, их любые фактически заданные observables на этом prefix равны как pulled-back операторы, не только как средние зарегистрированных leaf marks. Это включает и допустимый SAM-conditioned оператор на ранней отметке и любую reference entanglement. Pre-sign comparator event также расположен внутри общего core; само это структурное равенство двух A36 слов не доказывает, что все исходные owner pre-sign maps уже перенесены в новый descriptor A30/A32.

Список A30 registry **не назначает marks внутри последующих post-power/padding/retention** и явно не заявляет исполненного reader/record. По нему нельзя доказать, что более широкий task не требует таких marks. Разные промежуточные states, адресованные операции, clock и native raw memory остаются частью обеих полных историй даже там, где terminal subsystem совпадает.

## 3. Один реально различающий terminal observable

`Z_j=|0><0|-|1><1|` на **одном** SAM wire j различает terminal состояния двух построенных программ. Для `j=2` при прежних A27/B54 ideal law, A30 compressed error и B58 exact SAM-controlled структуре:

\[
 \langle Z_j\rangle_+ - \langle Z_j\rangle_- > t/151>0,
 \qquad t=2^{-1618}.
\]

Это не наблюдение, которое объявлено исполненным, и не предположение, что именно его требует H.1 descriptor. Доказательство использует только старые константы:

* Для идеального comparator `c_b=1-2 kappa p^7(4+sum_x w_x Xi_bx)`, `0<=kappa<=1` и `sum w_x=1`. Точные полиномиальные коэффициентные оценки `|r_x|,|r_y|<2^21`, исходные `k0<24`, `delta_ref<2^-1543`, а также `0<=P_bank<=1` дают `|Xi_bx|<2^27 delta_ref`. Из `p<618034/10^6`, `p^7=13p−8` следует `c_b>0.71` с запасом и после actual A30 ошибки `<2^-3231`, равномерно по b.
* B58/A30 structure даёт `W_actual=sum_b |b><b| tensor U_b` с реальными унитарными `U_b` на полном WORK. Для любых двух b, различающихся только битом j, векторы `U_b|omega_WORK>` имеют overlap с одной born-ссылкой больше 0.71; их взаимный действительный overlap больше `2·0.71²−1=41/5000`.
* Общий pre `G^n0` отличается от I меньше `2delta_angle`, `delta_angle=2^-4852`. У born `v=(sqrt(p),p)` исходная X-coherence `2p sqrt(p)>1/2`; после pre и полного controlled core она строго больше `1/300`. Усложнение остальными SAM bits лишь даёт положительное взвешенное среднее указанных overlaps.
* A36 backward `+` заканчивает `G^nminus≈R(-t)`, а `−` — `G^nplus≈R(+t)`. Разность идеальных ожиданий Z равна `2 sin(2t) <X>`. При `sin(2t)>t` и двух actual angle errors суммарное отклонение не превышает `4delta_angle`; строго `t/150−4delta_angle>t/151`.

Проверка [check_backward_output.py](check_backward_output.py) независимо воспроизводит source pins, реальное расположение частей, exact CX identity, символическую алгебру и рациональные неравенства. Знак и строгость используют **перечисленные владельческие оценки**, не исполнение огромной матрицы или новый root/calibration.

## 4. Точная граница same-task

Исходный §7eh.H.1 задаёт free incoming SAM, полный исходный подготовительный writer и исходные bank/pre-sign marks; §7eo.G FA1 и §7fo.A отдельно говорят, что из этого списка **автоматически не следует** требование полного terminal prepared isometry `WJ`. На прочитанном A30 registry найден общий checkpoint, но не найдено правило, требующее terminal `Z_j`, полный joint SAM output либо marks внутри нового post/padding. Это ограниченная проверка заявленных источников, не доказательство отсутствия такого требования в любой физической задаче.

Следовательно:

* Если зарегистрированный конкретный task требует одинаковую **полную terminal joint map** или terminal `Z_j`, наша конкретная пара эти выходы не сохраняет; полный FN fixed-payload fibre к ней без иных условий неприменим.
* Если task действительно допускает quotient, в котором j отбрасывается, и требует только перечисленные комплементарные terminal effects вместе с совпадающими ранними marks, указанные конечные эффекты сохраняются точно. Но это **ещё не same-task admission**: нужно предъявить descriptor и допустимость quotient, его фактические retained histories/records, проверку промежуточных marks, native legality и полную цену одного и того же execution. В частности, H+J двух полных растущих clocks различается по A36/B71, хотя reduced output совпадает.

Тот же точный факт о complement действует для **любого** unitary `U_*` на SAM, включая рассматриваемое аналитическое устранение post-preparation. Но сохранение complement само по себе не сохраняет joint SAM/return task: для конкретной пары различие показано terminal `Z_j`, а для произвольного `U_*` нужна своя проверка joint payload. Исходная H.1 могла допускать такую независимую `P_b`-подготовку на указанных supports; это не делает её допустимой в полном FN fixed-payload fibre. Аналитическое `U_*` здесь не объявлено уже построенным оплаченным native word.

Это различие не назначает Cost, Info, вероятностный закон task selection или новый physical reader. `physical_C_closed=false`, `GR_closed=false`.
