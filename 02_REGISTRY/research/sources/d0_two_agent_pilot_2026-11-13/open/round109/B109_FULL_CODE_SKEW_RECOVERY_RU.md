# B109. Полный CODE-skew feedback-source в неquotient-норме

**Результат.** На фиксированном рациональном поле `Y=Y₀+y`, `|y_j|<2^-32`, для выбранного A54/B105 graph с born-product CODE, canonical source-private fibre и `H₀=C` аналитический feedback-covector по **всем четырём независимым real CODE-skew slots**, включая нелокальные CODE correlations, приближает

    DIτ(Y) ∘ L,
    L(X)=ell(X_Pf)−ell(X_Qf)/2+ell(X_Qb)/2,                 (1)

в явно заданной ниже неquotient dual norm с равномерной ошибкой `<2^-34`. Pb входит в пространство и его kernel, но не удаляется. Это конкретная подстановка A54/B105/A44/B107 в принцип исходного §7eh.I.2–I.3, а не новая теорема о норме или геометрии. Здесь source — **аналитическая производная feedback J**; полный finite `H+J` dual по всем skew и физический Cost−Info этим не установлены.

[Точный проверяющий код](check_full_skew_recovery.py) и [receipt](B109_FULL_SKEW_RECOVERY_CHECK.json) закрепляют owner и зависимости. Оценки условны на ранее проверенные A54/B105/B106/B107, B65/B91 и A44/A50 contracts; гигантское слово не развёрнуто. `physical_C_closed=false`, `GR_closed=false`.

## 1. Полный raw control space, kernel и right lift

Для `m=2688`, двухбитного born product `χ=φ^⊗m` и

    V_j=diag(b_low,j+2b_high,j−3p²),
    ell_j(X)=<χ,[V_j,X]χ>,

каждый slot допускается в **математическом** сравнении как произвольный real skew оператор на всём CODE. Это больше пространства реализованных пока native controls. На прямой сумме четырёх таких пространств определим

    ||X||raw=max{ ||L(X)||₂, max_a ||X_a||op/52 }.          (2)

Это конечная норма на полном пространстве: для любого ненулевого X второе слагаемое положительно, включая `ker L` и Pb. Она не отождествляет разные kernel directions и не утверждает их нулевой фактической реакции. По `R_v<104`, для любого направления `u` с `||u||₂≤1` имеем `||Σu_j V_j||≤104`, поэтому `||ell(X)||₂≤208||X||op`; первая часть (2) конечна даже для нелокального skew.

Исходная точная MG2 identity A47 даёт `[V_j,X_j]χ=χ`, а `X_j` действует на своей двухбитной паре и `||X_j||op<1`. Для `j≠k` они коммутируют с `V_k`, следовательно `ell(X_j)=e_j`. Это же проверено в точном поле Q(√p), с `||X_j||F<1`. Для любого `v∈R^2688` положим

    R(v)=(Σ_j v_j X_j, 0, 0, 0),
    L R(v)=v,
    ||Σ_j v_j X_j||op ≤ Σ_j |v_j| < 52||v||₂,
    ||R(v)||raw=||v||₂.                                    (3)

Следовательно pullback `f↦f∘L` сохраняет **точно** dual norm для любого raw covector f. Нижняя оценка тестирует R(v), верхняя следует из первого слагаемого (2). Оставление положительной norm на kernel при этом существенно; quotient не вводится.

Проверка строит и явный ненулевой kernel: на двух **исходных** четырёхуровневых blocks выбран skew K с `ell_1(K)=ell_2(K)=0`, `||K||F<1`, но `<χ,[V_1V_2,K]χ>=1/500`. Остальные координаты — spectators. Так даже на исходном born product линейный decoder не устраняет общий quadratic response. Этот контрпример запрещает переносить B95/B97 специальное осевое quadratic cancellation на произвольный X; он не утверждает, что конкретная реальная физическая kernel reaction равна данной игрушечной величине.

## 2. Калибровка и пределы физического lift

При записи `Y_b=Y+σV(b)`, `σ=2^-80`, первая кинематическая вариация координат в отдельном CODE slot равна `σ ell(X)`. Поэтому взвешенная source-комбинация (1) калибруется как `σ L`, а right lift единичного **raw** поля — `R/σ`, с bound `52/σ` в опорной operator оценке. В норме (2) его точная норма `||v||₂/σ`. Масштаб σ оплачивается в actual `Γ(Y)`; ограниченный inverse при `σ→0` не заявляется.

Исходный §7eh.I.2 строит аналогичный неquotient norm уже через физическую `iota_h:V_h→R^m` и supremum по допустимым protected states. Норма (2) — конкретная **raw Euclidean** версия при данном rank-one `H₀=C`, а не переименование её в физическую `V_h`-норму. Для действительного физического lift необходимо отдельно предъявить тип, norm и допустимость `iota_h`, а также условие попадания координатных изменений в её образ. Условно, если физический v отображается в `iota_h v`, то `R(iota_h v)/σ` даёт координатное изменение `iota_h v` и имеет raw norm `||iota_h v||₂/σ`; это само по себе не доказывает physical admission или bounded physical `C_h`.

## 3. Все-skew scalar remainder без ложного quadratic cancellation

Зафиксируем поле и один actual post от `M(Y)` для всех четырёх вариаций. B65 даёт `H:=sup ||D²Iτ||<2^25`; весь CODE sampler находится в прежнем выпуклом B21 cube, `R_v<104`, `σ=2^-80`. Диагонально на всех CODE labels

    Iτ(Y+σV)=Iτ(Y)I+σ Σ_j ∂_j Iτ(Y)V_j+R,
    ||R|| ≤ (H/2) σ² R_v².

Для любого skew `||X||op≤1` из `||[R,X]||≤2||R||` следует

    | <χ,[Iτ(Y+σV),X]χ>/σ − DIτ(Y)·ell(X) |
       ≤ H σ R_v² <2^-41.                                  (4)

В отличие от B107 на конкретных MG2 axes здесь остаток **первого порядка по σ**. Равномерная оценка `||DIτ(Y)||<a=2^-3083+2^25·52·2^-32<1/2` используется только в контроле разброса; в target остаётся полный `DIτ(Y)`, не нуль и не центральное значение.

## 4. Actual M², post и четыре slot-остатка

В идеальном исходном reporter

    M₀=diag_b(c_ref−2g Iτ(Y_b)),
    ||M−M₀||≤e_M<2^-3421,   gσ>2^-3208,

а actual G/CX compression `M` имеет CODE-diagonal real structure и `||M||≤1`. B105 строит post из **actual** `M`, поэтому reduced Pf источник действительно содержит `M²`. Для любого skew X сохраняется B97 identity

    d_red,Pf(X)=Dσ Iτ(X)−(g/c_ref)Dσ(Iτ²)(X)
                   −<χ,[M²−M₀²,X]χ>/(4 c_ref gσ).

Здесь `Dσ F(X)=<χ,[F(Y+σV),X]χ>/σ`. На всём поле `|Iτ|<2^15`, `g<2^-3061`, `c_ref>2/3`. С положим

    osc=aσR_v+(H/2)σ²R_v².

Тогда `||Iτ(Y+σV)−Iτ(Y)I||≤osc` и, без локальной осевой оценки,

    |Dσ(Iτ²)(X)| ≤ 4·2^15·osc·||X||op/σ,
    e_weight=(3/2)·2^-3061·4·2^15·osc/σ <2^-3021,
    e_corner=(3/2)e_M/(gσ) <2^-212.

Таким образом `r:=HσR_v²+e_weight+e_corner` ограничивает разницу reduced Pf и `DIτ·ell` на единичном operator ball. Actual native fixed post отличается от target не более `e_U<2^-9247`; соответствующий аналитический остаток каждого slot не больше `e_post=e_U/(gσ)<2^-6039`. Для Pb target-corner `ξᵀXξ=0`, но его post remainder не удаляется.

Из B107/A44 на том же field-bound SOURCE, с полным retained remainder и точным CODE-disjoint middle,

    δ=156·1748·σ+2e_prefix,       2^-62<δ<2^-61,
    τ/(gσ)<85,
    k=(3/4)[(τ/(gσ))(2δ²+2e_W)+e_W/(gσ)] <2^-116,
    e_W<2^-15800.

Эта оценка all-insertion map действует на **любой** skew, без суммы по огромному числу CODE planes. Actual return не отождествляется с обратным forward, actual middle — с симметричным; для Qf/Qb используется его доказанное отсутствие CODE даже в controls. Их target signs дают −1/2 и +1/2 Pf; их kernel остатки сохраняются отдельно.

Обозначая через `T_Y` четыре аналитические derivative исходного feedback J, делённые на одну actual положительную `Γ(Y)`, получаем точную рациональную верхнюю оценку

    || T_Y − DIτ(Y)∘L ||raw* ≤
      52 [2r + 2k + 4e_post] < 2^-34.                       (5)

Коэффициент 52 нужен потому, что (2) допускает `||X_a||op≤52` на единичном raw ball; нет неявного отбрасывания kernel. Внутри скобок по очереди учтены Pf и две половины Q для r, два Q kernel и четыре post-остатка. Равенство (3) даёт полезное, но условное следствие:

    | ||T_Y||raw* − ||DIτ(Y)||₂ | <2^-34.                     (6)

Это равномерная **аналитическая** оценка на всём rational chart и полном raw skew space. Она не доказывает малости исходного `DIτ(Y)` или точной стационарности; если отдельно известна малость одной из двух норм, (6) переносит её на другую с явной ошибкой. Никакая физическая полевая норма не подставлена вместо `||·||₂`.

## 5. Что уже оплачено и что ещё требуется

B105/A55 действительно содержат конечные сравнения для 2688 осей в каждом из четырёх slots, matched arms и отдельные post probes; для этих осей B107 сохранил более сильное `O(σ²)` product cancellation и полные finite `H+J` bounds. Указанные axes и post probes **не являются** полным базисом произвольных skew на `2^5376` CODE labels, тем более четырёх независимых slot spaces. Их существование не оплачивает native `±` слова любого X, единый новый clock и нормированный finite dual для этой расширенной семьи.

Для physical finite-dual source дополнительно нужны допустимость полного пространства или точного требуемого подпространства, actual native компиляция/control accuracy, оплаченные births/padding/retention и heat на одном task, правильные исходные marks/instrument, physical `iota_h`, `V_h`, `C_h`, а также реакции old/input/WORK/scene/record/Info и same-execution Cost−Info. Нельзя считать отсутствующие строки нулевыми или автоматически переносить на них (5). Действие и history выбранного A23 vacuum continuation ещё требуется связать со всеми исходными owner columns/marks или провести допустимый marked transport. GR refinement также остаётся открытым.
