# B75. Независимая проверка A38

**Статус: PASS для семи численных сертификатов углов, алгебры макросов, обратного порядка на малом DAG и формул бюджета.** Все семь исходных показателей независимо перепроверены при 61000 битах; `B75_INDEPENDENT_ANGLE_AUDIT.json` имеет статус `PASS_ALL_SEVEN_INDEPENDENT_INTEGER_INTERVALS`. Реальное выполнение всего controlled-W и полное расписание post-SAM данной проверкой не подтверждаются. Физические source/admission и `GR_closed` не закрыты.

## Радиус и целевые углы

В A38 `ball_mul` применим при следующем инварианте: центры c,d с радиусами r,u содержат точные комплексные числа z,w единичной нормы. Из |c|≤1+r и |w|=1 следует |cd−zw|≤r+u+ru. После деления на масштаб каждая из двух координат округлена вниз менее чем на 1, поэтому прибавка `+2` строго покрывает евклидову ошибку округления. Начальный радиус как сумма ширин интервалов обеих координат тоже достаточен. При бинарном возведении инвариант сохраняется на каждом произведении; роль численной фазы и continued fraction ограничена предложением кандидата. Прямые интервалы отдельно нужны для фактических семи степеней.

Положим p=(√5−1)/2, cos θ=√p, sin θ=p. Цели A38 соответствуют положительным корням для π/8, π/6, θ/2; для β используются c_ref=1−8 sin²(512θ)p⁷ и (cos β,sin β)=(√(c_ref/(1+c_ref)), √(1/(1+c_ref))). Отрицательные цели получают сменой знака sin. Этим установлена алгебра целевых координат, а не точность предлагаемых показателей.

`verify_post_angles_independent.py` проверяет каждую готовую степень прямоугольными интервалами с 61000 двоичными разрядами, используя отдельное точное GMP integer-вычисление; float не применяется. Целевые радикалы и c_ref вычисляются с outward округлением, sin(512θ) — через владельческий `native_phase._rotation_intervals`. Для сложения/вычитания берутся крайние суммы, для умножения — минимум и максимум четырёх точных произведений с floor/ceil. Комплексное произведение получает интервалы для ac−bd и ad+bc; пересечение с [−1,1] допустимо, поскольку каждая точная степень G унитарна. Индукция по binary powering сохраняет точное значение в каждом прямоугольнике. Максимальные абсолютные разности исходного и целевого прямоугольников дают L1 верхнюю границу нормы разности вращений; целочисленное сравнение с 2^-20000 является строгим. Малые примеры проверяются на точное совпадение с функцией владельца. Использована `gmpy2==2.3.2` (CPython 3.9, macOS arm64); она служит только backend-ом точных целых чисел. Каталог `.deps` не включён в коммит. Восстановление из каталога round75: `python3 -m pip install --target .deps gmpy2==2.3.2`.

## All-column макросы и счёт

Для Z оба CX переворачивают произвольный helper только при установленном q. Ветвь q=0 получает R(2π)=I, q=1 — R(π)=−I, следовательно получается Z на q тензорно с I на полном helper, без требования чистоты helper. Для CCZ сумма знаков восьми parity равна 8 только на 111 и нулю иначе; итог — −I или I на произвольном helper. В фактических DAG проверены 16 и 18 единиц δ для Z/H, 64 для CCZ и 100 для CCX; последний содержит 100 k8 гейтов G и 28 CX. Здесь δ — доказанная ошибка одной соответствующей базовой степени, а не глобальная ошибка задачи.

Хронология controlled-G: R(θ/2), CX, R(−θ/2), CX. На control=0 это I, на control=1 — R(θ). При обратном знаке первый и второй углы меняются местами. Controlled-G± оплачивается как 2δ; controlled-π/3± — 12δ, поскольку отрицательный угол реализован 11-кратной положительной степенью π/6. Это операторные оценки на всех столбцах при условии индивидуального сертификата углов и несовпадения адресов.

`verify_gcx_post_macros.py` независимо проверяет фактическую структуру DAG, оба направления, все восемь классических комбинаций CCZ с произвольным helper, матричные равенства H и X, обратный порядок на тестовом DAG, крайние адреса копии и формулу бюджета относительно census A30. Дополнительно первые три физических блока фактического W проходят lowering и подсчёт сначала с тестовыми, затем с реальными показателями A38; полный оплаченный поток не запускался. Для реальных показателей суммарное число гейтов controlled-W имеет 31725 двоичных разрядов. Для anchor проверены фактические counts и error units при N=3..7, на обоих направлениях и в режимах phase/reflection. Обобщение полиномиальных формул следует из линейных счётчиков B74; очищенные flag и N−2 scratch, а также непересечение диапазонов должны быть предоставлены вызывающим.

По census A30 число единиц ошибки одной controlled-W равно 2G+100CX и имеет длину 11648 бит. При δ<2^-20000 получается ошибка одного блока <2^-8352; сумма 39366 таких блоков по телескопической оценке <2^-8336. Это условная оценка без остальных частей пост-схемы.

Reverse-provider A38 явно конечен и повторяет исходный поток в обратном порядке с O(B²) replay; его полное производственное исполнение не продемонстрировано. Компонентные сертификаты не являются доказательством готовой единой схемы post-SAM, её общей цены, общего clock/K или физического source.
