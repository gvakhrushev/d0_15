# B118. Независимая проверка области A60 и CODE/банк

**Результат: PASS в объявленном классе decoder.** Оценка A60 действительно даёт ограничение на output-носители любой точной изометрии, которая на **всей заявленной свободной CODE области** сохраняет вероятность заданного общего проектора банка. Оценка не становится безусловным требованием к физическому декодеру одной подготовленной Born-суперпозиции, не доказывает обязательность такого bank-preserving контракта и не закрывает physical Cost−Info. `physical_C_closed=false`, `GR_closed=false`.

[Проверка](audit_source_capacity.py) сверяет SHA замороженных входов, исполняет A60 с перехватом записи, побайтно сопоставляет его receipt, отдельно проверяет радиус, степени, целочисленную ёмкость и два точных конечных контроля. [Receipt](B118_SOURCE_CAPACITY_AUDIT_CHECK.json) фиксирует фактические хеши A60, A53–A55, A59, B91/B108 и B117. Гигантский SOURCE не исполнялся; прежние аналитические и численные certificates потребляются в их области.

## 1. Исходная область и константы

A53 указывает `d_j=b_low+2b_high∈{0,1,2,3}`, `Y_j=Y0_j+y_j+2^-80(d_j−3p²)` и сохраняет весь отрезок в сертифицированном chart. Из `p²+p=1`, `1/3<p²<2/3` следует `|d_j−3p²|<2`; поскольку `4·2688=10752<104²`, полный евклидов радиус строго меньше 104. Порядок 5376 CODE bits и 2688 координат сохраняется, fixed PF/collar не превращается в подвижную физическую область.

B91/A47 дают для выбранной полной ideal source extension `||DB||≤1748`; A54 и B108 дают uniform actual error `<2^-3423` на полном SOURCE DATA/CODE fibre с canonical private inputs и допустимым reference. Значит при одном field name и canonical pure bank b

    ||U_y(|x>⊗b)−|x>⊗B(Y)b|| ≤ δ,
    δ < 1748·104·2^-80 + 2^-3423 < 2^-62.

Тот же bound для произвольной суперпозиции CODE следует **из полной uniform operator error A54 и direct-sum ideal target**, а не из одного набора поточечных column estimates. Вектор-якорь определяется ideal SOURCE, а реальная output isometry может содержать control mixing. Old/reference можно фиксировать в одном разрешённом чистом состоянии; перенос на дополнительные независимые физические inputs отдельно не утверждается. Canonical WORK/private сохраняется; dirty input не навязывается.

## 2. Вместимость и условие о декодере

Входы `|x>⊗b` и потому actual `ψ_x` ортонормированы. Для `P=|Φ_y><Φ_y|` проектирование разности на `I⊗(I−P)` даёт `<ψ_x,I⊗P ψ_x>≥1−δ²`. Если **заданный** точный encoder T является изометрией на всём их span и на каждом x теряет от этой конкретной вероятности не больше η, то для N=`2^5376`

    N(1−δ²−η) ≤ Σ_x <Tψ_x,I_R⊗P Tψ_x> ≤ dim R.

Верхняя граница — trace rank-one проектора по BANK и единицы по **всем** не-BANK носителям. Все реально изменяемые/коррелированные среды и garbage входят в общий R, даже если пользовательский decoder не может к ним обратиться. Незадействованный spectator сам по себе не даёт свободного хранилища. При `η+δ²<1/2`, если R состоит только из b двоичных wires, необходимо b≥5376. Условный `d=9` даёт b≥5373 и не является измеренной размерностью физического clock.

Это необходимое условие, а не цена или нижняя оценка числа операций. Оно не исключает точный decoder, который может менять bank и позже его восстанавливать, использует фактическую side memory, либо обязан действовать только на одной конкретной исходной state. Независимый SWAP-контроль показывает, что сохранение общего bank projector на одном input не переносится на вторую CODE-колонку. В частности, FV7 сам по себе не объявляет весь all-CODE интерфейс обязательным для каждого physical decoder. A59 различает выбранный writer, его canonical H.1 domain и другие возможные descriptor.

Для **идеальных** чистых `|x>⊗Φ_x`, если точно сохраняется вся чистая bank density, output factorizes и попарная ненулевая близость `Re<Φ_x,Φ_z>≥1−2δ²>0` принуждает все output code vectors быть ортогональными; тогда dim R≥N точно. Это отдельное усиление, не довод о редких условных actual states или division на Born-амплитуды.

## 3. Энтропия и source

Для одной чистой CODE superposition общий actual SOURCE output чист; Schmidt rank даёт `rank ρ_B≤N`. Общий projector bound даёт `λ_max(ρ_B)≥<Φ_y,ρ_B Φ_y>≥1−δ²` по Rayleigh **без** требования, чтобы якорь находился в support. При `q=1−λ_max`, максимуме энтропии на остальных `N−1` собственных значениях и `q<2^-124` получаем

    S₂(ρ_B) ≤ h₂(q)+q log₂(N−1)
             < (124+2+5376)·2^-124 < 2^-111 bits.

Речь о сведённом банке указанного чистого состояния до нового измерения. Это не полная CQ entropy истории и не first-source certificate: ни значение, ни его малость не контролируют `D S`, finite differences после деления на шаг/actual gain или произвольный physical `V_h` pullback.

## 4. Дальнейшее применение к Cost−Info

B117 и A60 предметно ограничивают **один** exact bank/projector-preserving codec-interface и сохраняют предоставленную CQ величину под полной isometry. Это не устанавливает same-object semantic decoder, а тем более равенство Book vertex Info и CQ entropy. Существующие FV7 и CD13 по-прежнему требуют стоимость и full source реально выполненных encoder/decoder, clock и сохранённого environment, физический weighted continuation/terminal и истинные gain/right lift. A60 не даёт значений этих operands и не даёт нормированной source-error оценки.

По доступным входам дальнейшее построение очередной абстрактной code/entropy оценки не восполняет этот конкретный пробел. Coding route имеет смысл возобновить при предъявлении реально допустимого same-history semantic decoder вместе с его cost intertwiner и полным Book binding; до этого следующий предметный шаг — искать actual weighted Cost−Info/terminal operand или иной доказанный полный source-equivalent residual, сохраняя возможность одно-input и меняющих банк декодеров. Это вывод о текущих свидетельствах, а не общий запрет на кодирование или физическое закрытие D0→GR.
