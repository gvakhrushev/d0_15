# B73 — независимая проверка reduced feedback A37

**Вывод: условно подтверждено для аналитической секции [A37](../../direct/round37/ACTUAL_POST_SAM_STATIONARY_REDUCTION_RU.md).** Оптимизация действительного post-SAM поворота исходного A30 даёт feedback с `q=<psi,M² psi>` и сохраняет нетривиальный входной источник. При унаследованных фиксированных коэффициентах разница нормированных входных строк с прежним matched feedback меньше `2^-2870` на unit SAM generator и `2^-2864` для исправленного A31 вектора. Это не построение оплаченного native `U*` и не стационарность полного H+J/Cost−Info.

## 1. Задача и область

Для canonical WORK и пустого old cut A32 берём реальное диагональное сжатие `M=diag(c_b)` A30 с `2/3 I<M<=I`, нормированные действительные `psi` и born-вектор `chi`. Разрешим пока **математический** post-SAM unitary U. По Cauchy–Schwarz

\[
 |\chi^T U M\psi|\le\|M\psi\|,\qquad
 q=\|M\psi\|^2=\langle\psi,M^2\psi\rangle.
\]

На достижимой положительной ветви post-SAM first rows исходного determinant-feedback равны нулю при `U M psi=sqrt(q) chi`; это отдельная rank-one постановка actual A30. Предыдущий A2 использует иные fine-reader weights и двухветвевую матрицу; его коэффициенты и цену нельзя автоматически переносить сюда.

В локальном chart положим `xi=M psi/sqrt(q)`, `d=chi^T xi`, `K=chi xi^T−xi chi^T`. Тогда

\[
 U_*=I+K+\frac{K^2}{1+d},\qquad U_*\xi=\chi,\quad U_*^TU_*=I,\quad\det U_*=1.
\]

Независимая символическая проверка подтверждает это на произвольной нормированной двумерной плоскости двух векторов; на ортогональном дополнении U равен I. Точнее, при `||psi−chi||<1/6`, `M>2/3 I`, `||M||<=1` имеем `chi^T M psi>2/3−1/6=1/2`, `2/3<||M psi||<=1`, следовательно `d>1/2`. Для **произвольного** нормированного psi `d>0` не следует: на противоположной точке `xi=−chi` имеем `d=−1`, и данная формула делит на ноль. Общему максимуму там нужна другая вращательная карта. Более общий old-DATA/entangled input не заменяется без отдельного анализа этой rank-one секцией.

## 2. Источники с настоящими разными gains

Пусть `d0=1-z>0`, `eta=z p^K>0`, `c=<psi,M psi>`, а `c_ref=1−8 lambda_vis` — исходная константа reporter. При одной и той же входной вариации сравниваются

\[
 J_{old}=-\log(d_0+\eta c^2),\quad
 J_{red}=-\log(d_0+\eta q),
\]
\[
 \Gamma_{old}=\frac{4\eta cgs}{d_0+\eta c^2},\qquad
 \Gamma_{red}=\frac{4\eta c_{ref}gs}{d_0+\eta q}.
\]

С их собственными знаменателями и `D=D_psi` точно

\[
 \frac{DJ_{red}}{\Gamma_{red}}-\frac{DJ_{old}}{\Gamma_{old}}
 =-\frac{D\langle(M-c_{ref}I)^2\rangle}{4c_{ref}gs}.
\]

Проверка выводит тождество независимо для общей вещественной симметричной `3×3` M и общего skew X, а не только для двух численных диагоналей. Здесь устранение U используется как аналитическая огибающая исходного feedback; движение U учтено через stationary condition. Равенство не приписывается произвольной полной цене с heat/records.

## 3. Численные оценки без новых параметров

Используются фактические B25/B65/A33 значения и исходное выражение `I_tau=a_y sum h⁴f−k0 sum h⁴q+R`. На всём прежнем кубе `0<a_y<1`, `k0<24`, `sum h⁴=1`, `|f|<2^13`, `|q|<16`, `|R|<2^-1457`; поэтому `|I_tau|<2^14`.

Исходный `g=2 lambda_vis delta_ref epsilon alpha² r_x r_y` при `lambda_vis,alpha<=1`, `delta_ref<2^-1543`, `epsilon=2^-1531` и `|r_x|,|r_y|<2^21` удовлетворяет даже `g<2^-3031<2^-3030`. Полиномиальные коэффициентные bounds проверены заново. Из `p²+p=1`, `p<618034/10^6`, `p^7=13p−8` и `lambda_vis<=p^7` независимо следует `c_ref>2/3`.

При `M0=c_ref I−2g I_tau`, `||M−M0||<2^-3231` получаем

\[
 \sigma=\|M-c_{ref}I\|
 <2g\,2^{14}+2^{-3231}<2^{-3014}.
\]

Для unit skew X производная квадратичной формы ограничена `2 sigma²`; при исходном `gs>2^-3158` и `c_ref>2/3` разница одной нормированной строки строго меньше `2^-2870`. Учитывая настоящий A31 forward mean-map и его коэффициент `sqrt(2688)/(u(1−2^-23))<55`, норма исправленной разности меньше `55·2^-2870<2^-2864`. Это перенос только на входную SAM/mean-геометрию; post-row не умножается на `J^-T`.

## 4. Потребление предыдущих finite results

A34/B67 даёт верхнюю границу `<2^-17` для полного конечного H+J вектора C, а A33/B66 — нижнюю `>2^-45`. Чтобы получить **аналитический feedback**, отдельно вычитаем принадлежащую A32 полную finite-to-analytic H+J/heat ошибку `<2^-67`; затем учитываем `<2^-2864` reduced-vs-matched изменение. Треугольное неравенство даёт условно

\[
 2^{-46}<\|E_{red}^{J}\|<2^{-16},\qquad
 \|E_{red}^{J}-E_{geom}(\bar Y_{actual})\|<2^{-15}.
\]

Здесь `E_red^J` — **аналитический редуцированный determinant-feedback** в заявленной исправленной forward raw-диаграмме, не полный source оптимизированной физической программы. Предыдущая оценка включает heat только для конкретных A32 finite endpoints; она не оценивает heat нового исполнения `U*`.

## 5. Что остаётся

Точность, конечный оплаченный G/CX synthesis этой гигантской матрицы, его все используемые mark/output maps и влияние на истинный growing clock/heat не построены. После полной конечной реализации её ошибки придётся делить на реальный gain и конечный шаг; аналитическая плотность native words или близость одного target этому не заменяет. Допуск post-SAM изменения к заявленному task, независимые внутренние уравнения, полный `Cost−Info` и физическая выборка истории также остаются открытыми. По B72 произвольный post-SAM U сохраняет комплементарный выходной канал, но может менять совместный SAM-output и return payload.

Воспроизведение: `python3 -B audit_reduced_feedback.py`; [receipt](REDUCED_FEEDBACK_AUDIT.json) фиксирует источники и точные rational/symbolic проверки. `physical_C_closed=false`, `GR_closed=false`.

Дополнительно проверен указанный в A37 **только аналитический** остаток центральной разности для `q(a)=<exp(aX)chi,M² exp(aX)chi>`: `||M||,||X||<=1` дают `|q^(k)|<=2^k`, `Gamma_red>=(8/3)eta gs`, а исходная рациональная формула при `t=2^-1618` меньше `2^-78`. Её bracket ровно в восемь раз меньше использованного A32 более грубого bound. Это не включает цену и ошибку native `U*`, синтез концов, новые marks, layout или полный heat; старое `K=66076` для новой программы автоматически не переносится.
