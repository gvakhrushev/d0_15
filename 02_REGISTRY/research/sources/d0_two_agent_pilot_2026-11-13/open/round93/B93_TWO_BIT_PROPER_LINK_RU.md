# B93: двухбитный proper-link SOURCE, короткая сетка и lazy native provider

**Статус.** Построены полный локальный каталог для карты A47 `σ=2^-80`, строгие интервалы всех его целевых вращений, короткая общая сетка положительных степеней Golden G, конечный lazy G/CX/SourceI provider и отдельные верхние оценки стоимости. Проверены все 20 496 семейств, все 307 416 хранящихся в их описании углов и соответствие 1 055 488 секторам семи банков. Численные степени k вычисляются поставщиком по требованию; они не были материализованы для всего каталога. Числовой точный полный inventory не вычислен: [exact_resource_inventory.py](exact_resource_inventory.py) задаёт его конечный шардируемый алгоритм. Верхние границы не являются фактической ценой без padding или выполнения этого алгоритма.

Это proper-link часть SELECT, а не полная новая SOURCE-подготовка. Новый полный `e_B`, углы coframe/CAR, буквальные обратные prefix, G/CX replacement для SourceI, полный corner `e_M`, clock, heat и admission необходимо собрать и проверить отдельно. `physical_C_closed=false`, `GR_closed=false`.

## Каталог и область действия

Для каждой из шести локальных Lorentz-координат точное значение

    θ_j = 2^-80 (low_j + 2 high_j − 3p²),  p=(√5−1)/2.

В исходной нумерации CODE индекс `low_j=j`, `high_j=2688+j`. Каждая переменная строка содержит шесть low, затем шесть high; такое расположение эквивалентно парам `[j,2688+j]`. Дополнительный source-private scratch не вводится. Фактические адреса проводов предоставляет вызывающая сторона в массиве `all_SAM` длиной 5376; существующая проверка B42 требует их непересечения с address, mode, Julia flag, port, Spin, aux и прочими закреплёнными проводами.

Исходный B42 каталог связывается с 256 переменными адресными шаблонами в f и четырьмя значениями каждой из шести координат: `256·4^6=1 048 576` переменных секторов. Ещё 768 фиксированы, а у других шести банков по 1024 фиксированных сектора. Каталог хранится факторизованно; [proper_link_two_bit_targets.py](proper_link_two_bit_targets.py) перечисляет каждую строку без материализации миллиона слов. Пять вариантов baseline (`identity`, четыре исходных значения площадки) дают `5·4096=20 480` переменных семейств; 16 фиксированных/reference families сохраняют исходные формулы.

Для `exp(Θ)` использован интервальный ряд с `||Θ||∞<18·2^-80<2^-75` и доказанной факториальной оценкой хвоста. Boost в family c identity baseline мал порядка `2^-78`; его строго положительная нижняя граница проверяется интервалами, а не float64. Все source targets, factorization, допустимые frame и максимальные pivot вычислены целочисленной dyadic арифметикой с 4096 бит. Все интервалы целевых sin/cos имеют ширину `<2^-3500`; фактическая максимальная ширина в отсчётах `2^-4096` имеет 170 бит. Прямой полный перечень хешей — [TWO_BIT_FAMILY_RECEIPTS.jsonl.gz](TWO_BIT_FAMILY_RECEIPTS.jsonl.gz), сводка — [FULL_TARGET_CHECK.json](FULL_TARGET_CHECK.json).

## Строгие степени без 20080-битной сетки A47

[certify_short_grid.py](certify_short_grid.py) принимает произвольный поддерживаемый `--controls K`, `--error-bits`, `--min-q-bits`; отдельно выпущены сертификаты для K=15, 24, 29 и 46. Он использует закреплённый независимый B80 интервал `γ=θ/(2π)`, умножает его на `2^K` целочисленно, строит кандидата continued fraction по середине и проверяет точно `gcd(pn,q)=1`, `q·max|q·2^Kγ−pn|<1`, `16/q<2^-3460`. Никакое качество исходного float-кандидата не предполагается.

Для K=29 получено q длиной 3476 бит. Для любого вычислимого target вращения существует вычислимая положительная степень `1≤k≤q`, у которой **целый фактический** `G^(2^29 k)` отличается от target по operator norm строго менее `2^-3460`. Реализация [proper_link_two_bit_native.py](proper_link_two_bit_native.py) строит outward atan2 для целевого интервала, берёт ближайшую rational cell и вычисляет `k` модульным обратным. Если ширина ячейки не разрешена на текущей точности, цель и расчёт повторяются при удвоенной точности. Это конечная конструкция на вычислимых именах: непрерывные интервальные операции сходятся, знаменатель для dominant компонента отделён от нуля, а при достаточно малой ширине явная проверка `2q·width≤1` сработает. G-степень не заменяется оракулом: каждый `repeat(k, G)` — конкретное конечное DAG-описание реальных стадий.

Повторное прямое возведение Golden G в 7168-битных комплексных шарах проверено независимо на 47 эффективных углах трёх различных семейств и controlled-X; это выборочная независимая проверка вычисленных k, не проверка всех k. Глобальная оценка на все семейства следует из полной проверки исходных targets и доказанного uniform-grid алгоритма. X состоит из двух независимо выбранных вращений и имеет error `<2^-3459`.

## Lazy schedule и честный бюджет

B42 Walsh emitter вызывается с `common_controls=29`: максимальный Fock predicate — 12 address + 12 CODE + branch + Julia flag + три mode-контроля. Каждое слово состоит из реальных G/CX/SourceI DAG и содержит буквальную обратную последовательность B42. Все остальные SOURCE DATA, неопределённые aux/port/Spin и внешние системы остаются в области оператора B42; заявляется действие на всём соответствующем DATA fibre при заранее объявленном canonical SOURCE-private input, не на произвольном dirty private. Для банка и каждого выбранного сектора не более 100 обычных поворотов и одного X; потому

    ||Ĵ_proper−J_proper|| ≤ 100·2^-3460 + 2·2^-3460
                            = 102·2^-3460 < 2^-3453.

У каждого адреса и CODE assignment выбран ровно один локальный сектор, остальные точные identity; поэтому coherent superposition не умножает эту оценку на миллион секторов. Это error *только proper-link части одного SELECT*, при точном SourceI, не готовый `e_B`.

[PROPER_LINK_RESOURCE_UPPER.json](PROPER_LINK_RESOURCE_UPPER.json) содержит покомпонентные верхние границы для каждого отдельного bank, его прямого и буквального обратного слова. Они получены заменой всех k на q и верхним ограничением по всем глубинам обращения; положены 96 Fock, две части X и четыре диагональных SELECT даже для identity families. Это заведомо завышенная верхняя оценка, не exact inventory и не фактически оплаченная строка. Максимальная битовая длина bound на число SourceI — 3537 для f, 3527 для остальных. Если в будущем *каждый* SourceI будет заменён G/CX-словом с all-column ошибкой `<2^-8000`, гибридный вклад одного f bank будет `<2^-4463`. Сам replacement, его count и цена здесь не предъявлены.

[exact_resource_inventory.py](exact_resource_inventory.py) группирует все 20 496 family/control-width classes, вычисляет реальные k lazy provider, применяет точный B42 compressed-count recurrence и умножает на число адресов. Параметры `--shard i --shards n` разбивают конечную работу; для всех классов устанавливается равенство обратного inventory буквальной инверсии прямого. Сумма результатов по всем непересекающимся shard — exact числовой inventory, но до запуска и сверки всех shard она не заявляется как полученная. Вся эта цена относится только к proper-link SELECT, а не к четырём полным физическим историям.

## Проверки

`python3 open/round93/full_catalogue_validate.py` пересоздаёт полный family receipt. `python3 open/round93/full_precision_replay.py` повторно проверил все 20 496 семейств и 307 416 углов на 4352 битах: исходные hashes совпали, новые интервалы вложены в 4096-битные, pivot и ориентация сохранились. Это повтор той же исходной алгебры с большей точностью, а не независимое доказательство физического источника. `python3 open/round93/independent_check.py` повторно сверяет все family IDs и все 1 055 488 логических секторов, четыре короткие сетки, фактические первые блоки прямого/обратного provider, максимальные 29 контролей, compressed cost на одном переменном секторе и 47 direct native-angle witnesses. Сеточный сертификат опирается на доказательство B80, а source factorization и Walsh grammar — на закреплённые B42/A14; B93 не выдаёт эти зависимости за заново доказанную исходную физическую admission.
