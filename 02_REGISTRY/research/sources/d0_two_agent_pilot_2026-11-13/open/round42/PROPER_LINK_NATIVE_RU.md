# B42. Source-bound native proper-link Julia SELECT

Построены конечные lazy-программы proper-link части Julia SELECT для каждого из семи исходных bank, с действительными степенями native G, CX и SourceI и буквальными оплачиваемыми обратными ходами. Для каждого фиксированного bank программа на адресах proper-link имеет uniform operator-error меньше \(2^{-3257}\), включая произвольные aux, port, Spin и запутанные внешние системы; при branch=0 она **точно I**. Адреса anchor, coframe и padding эта часть оставляет точно без изменений. Гигантское полное слово не разворачивалось и не выполнялось.

Это **не полный** Julia SELECT или Ω-loader: отдельная coframe-часть и их интеграция с address/Bell prefix, векторным адаптером и общей ценой исполнения требуют отдельной проверки. Выбор одного из семи bank здесь внешний и фиксированный; дополнительное когерентное управление выбором bank и его цена не утверждаются. Физическое C и GR остаются открыты.

## Имена источника и строгие углы

`proper_link_targets.py` восстанавливает 336 семейств по исходным формулам B25, а не по близости float-матриц. Каталог связывает их с 23 296 адресными/локальными SAM-секторами: 17 152 в f и по 1024 в остальных шести bank. Исходные \(p\), \(k_0\), \(\pi\), исходный полином поля, шесть локальных генераторов и reference boost/rotation заданы dyadic-интервалами. \(k_0<24\) проверяется из исходной Golden-формулы, \(\pi<22/7\) — из интервала Machin; десятичная metadata не используется как доказательство. Экспонента каждой шестибитной матрицы вычисляется интервальным рядом, хвост ограничивается нормой \(\|\theta\|_\infty<2^{-27}\) и факториалом.

Для каждого f/reference-boost, где требуется деление на величину boost, интервал даёт строгую положительную нижнюю границу; общий проверенный минимум больше \(2^{-32}\). Identity и reference spatial rotation обрабатываются как точный нулевой boost по типу источника. В каждом столбце SO(4)-исключения выбран максимальный по абсолютной величине элемент: это сравнение подтверждено интервалами, а каждый используемый радиус строго сертифицирован не меньше \(1/\sqrt{4-\mathrm{col}}\). Формула знаков Fock и полный Julia-блок потребляют точную факторизацию B41. Нулевые и отрицательные pivot не округляются численным порогом.

`PROPER_LINK_ANGLE_LIBRARY.json.gz` содержит исходные family/sector bindings, 5018 конкретных положительных \(k\), хеши целевых интервалов и целочисленные границы ошибок. Для каждого вращения сертификат доказывает норму ошибки \(\le2^{-3264}\) у фактического \(G^{2^{23}k}\). Для X используется отдельный сертифицированный \(k\) условной фазы и отдельный \(k\) вращения; их **суммарная** ошибка также \(\le2^{-3264}\), и максимальный множитель обоих равен \(2^{23}\). Вспомогательный aux не предполагается чистым.

Численный candidate-grid предлагает значения \(k\), но не доказывает результат. Основание сертификата — исходные интервалы с 7168-битным масштабом, целочисленное возведение в комплексных шарах и проверка конечного неравенства. `verify_proper_link_angles.py` повторно вычисляет все 5018 степеней на 8448 битах, сверяет хеши и вложенность source-интервалов и проверяет ошибки без candidate-grid. `verify_rectangular_sample.py` использует другой, прямоугольный метод возведения и проверяет по одному углу каждого семейства; это выборочная независимая арифметическая проверка, а не второй полный прогон всех углов. Сопоставление 336 имён с B25 `precision_name` на повышенной точности — дополнительная численная диагностика, не интервальное доказательство.

## Управление и буквальная цена

`proper_link_native.py` раскрывает Walsh-термы лениво: для K контролей он использует степени \(2^{23-K}k\) и выдаёт фактические DAG из G/CX/SourceI по одному, не обозначая их неизвестным фазовым oracle. Управления address/SAM/branch остаются read-only. Для каждой Fock-пары два CX переводят два occupation-состояния в одну контролируемую ось; нужный знак синуса и обращение фактической последовательности обрабатываются отдельными физическими обратными ходами. Условный X реализует фазу на произвольном aux и поворот Julia flag. Каждая невыбранная ветвь возвращается точно к I, включая исходно произвольные port и Spin.

Полный сектор содержит не более 101 макроса и не более 23 контролей. Поэтому на выбранном секторе
\[
\|\widehat J-J\|\le101\cdot2^{-3264}<2^{-3257}.
\]
У адреса есть ровно один выбранный локальный SAM-шаблон, а все остальные сектора действуют точно как I и не меняют адрес или SAM. Следовательно, та же оценка действует для полного proper-link оператора одного bank без умножения на число секторов, в том числе на когерентных суперпозициях и при произвольной внешней запутанности.

`prefix_compatible_global_layout` связывает 2688 SAM, адрес, Choi input/output, branch, port, Spin и aux с расположением A19. Phase rebit, comparator scratch, Choi input и oldRIGHT не адресуются. Этот layout — конкретный проверенный binding; при иной укладке вызывающая сторона обязана сохранить непересечение и ограничения на провода. `bank_blocks` выдаёт обратный bank в обратном порядке с буквальной инверсией каждого фактического блока. Обратный от уже буквального обратного **не** заменяется бесплатным исходным словом.

`PROPER_LINK_NATIVE_RESOURCES.json` содержит точные стоимости прямого и буквального обратного слова каждого bank по G-port, G-other, CX и SourceI, включая вложенные обращения. Это ресурсы только данной proper-link части; подготовка начальных проводов, prefix и coframe не включены. Размеры цен существенны: отдельные целые счётчики содержат около тысячи десятичных знаков. Эта конечность не означает практической выполнимости полного слова.

## Проверки и воспроизведение

- Exact native проверки: 672 малые колонки Walsh, 768 активных Fock-колонок и их обратные ходы, все состояния port/Spin/aux в проверяемых случаях; 128 проверок X, полный вложенный toy-sector и буквальная inverse-of-inverse. Все 23 296 расписаний проверены на число контролей и недоступные для записи провода.
- Численная проверка полного 32×32 расписания выполнена для всех 336 семейств; наибольшая наблюдаемая разность с B25 около \(2.6\cdot10^{-15}\). Она диагностическая и не является сертифицированной оценкой native error.
- `INDEPENDENT_PROPER_LINK_ANGLES.json`, `RECTANGULAR_SAMPLE_CHECK.json`, `NATIVE_PROPER_LINK_CHECK.json`, `FULL_JULIA_SCHEDULE_CHECK.json`, `SOURCE_NAME_CHECK.json` и `PYTHON_FALLBACK_CHECK.json` фиксируют объём проверок и hashes. Сжатая библиотека читается через `proper_link_native.library()`.

Проверки запускаются из `open/round42`: `python3 verify_proper_link_angles.py`, `python3 verify_rectangular_sample.py`, `python3 check_native_proper_link.py`, `python3 check_full_julia_schedule.py`, `python3 verify_source_names.py`, `python3 build_resource_receipt.py`. При генерации и проверке использованы Python 3.9.6, mpmath 1.3.0 и опционально gmpy2 2.3.2 / GMP 6.3.0. При отсутствии gmpy2 основной расчёт использует точные целые Python и будет значительно медленнее; `PYTHON_FALLBACK_CHECK.json` фиксирует побитовое совпадение на пяти семействах и нескольких полных больших степенях. Сами библиотеки ускорения в результат не включены. Зависимости A14/A18/A19 и B25 нужны в сохранённых путях и проверяются по hashes в receipt/library.

`full_Julia_SELECT_complete=false`, `physical_C_closed=false`, `GR_closed=false`.
