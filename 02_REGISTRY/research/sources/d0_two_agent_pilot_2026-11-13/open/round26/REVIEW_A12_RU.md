# B26. Независимая ограниченная проверка A12

**Результат:** существенного расхождения в точных selector tables, степенях и offsets отдельных копий или заявленной границе готовности **selector/fair-bank компонента** не обнаружено. A12 compiler и verifier выполнены в отдельной временной копии соседних `round11/round12`; все пять восстановленных JSON совпали побайтно с переданными файлами, verifier выдал **39 941** check. Владелец A12 не изменялся. Отдельный [check_a12_exact.py](check_a12_exact.py), не импортирующий арифметический класс compiler, независимо пересчитал исходный DAG, все три palettes, 54 коэффициента report и component caps.

Проверенный вывод — операторная и селекторная **спецификация** при заявленных входах, а не выпущенный native processor. Сохранено исходное `Lambda_h=2^1525`. Полная `alpha_h`, physical stage/readout/seal, физическое `C` и GR остаются открытыми; `GR_closed=false`.

## 1. Palette weights, capacities и один READY на каждый palette

Независимая арифметика в `Q(p)` использует пары рациональных чисел и `p²=1−p`; знак определён точным сравнением рациональных квадратов. Для **каждой** строки файла проверены: точная нормировка input weights, положительность, обе capacity-суммы, неотрицательность целочисленных counts, равенства ready branch `tau·w` и сохранённая abort mass `1−tau`. Получено:

| Palette | Распределений | Fair bits `r` | Golden prefix depth `n` | `tau` |
|---|---:|---:|---:|---|
| internal DAG и dummy | 25 | 1374 | 0 | общий для всех 25, примерно 0.749634 |
| source type × SITE | 512 | 1580 | 1 | общий для всех 512, примерно 0.517690 |
| исходный `sigma × 10-sign mask` | 2048 | 94 | 6 | 1 |

Оригинальные полиномы `r(epsilon s, sigma epsilon t)` независимо перестроены из определения `E,ell,u,B,A,r` в точном кольце; сверены все 27 coefficients для каждой `sigma` и все 2048 итоговых пар `(beta,1−beta)`. Проверена строгая положительность обеих сторон. Точные numerator/denominator и input hashes — в [EXACT_REVIEW.json](EXACT_REVIEW.json); decimal τ выше только для ориентира.

Число prefix типов `n` и `n+1` равно `F_(n+1),F_n`, поэтому вместимость двух корзин `2^r F_(n+1),2^r F_n`. Сумма готовых labels **и abort** равна каждой такой вместимости; исходные фиксированные fair и Golden coins и неиспользованный suffix остаются частью подготовки. Изолированный A12 verifier дополнительно перебрал raw Golden words для `n=0,1,6` и проверил границы всех непустых ранговых интервалов. Это точные целочисленные доказательства по заданным таблицам, не выполнение реверсивного threshold circuit на `2^1374` или `2^1580` колонках.

## 2. Операторная индукция и независимые копии

Для двух разных базисных векторов `a,b` исходная нормированная rank-two часть

```
X_ab=|a><b|+|b><a|,
X_ab=(T_ab − Z_a Z_b T_ab)/2
```

равна среднему **двух Hermitian involutions на всём полном пространстве**, включая complement: `T_ab` есть swap с identity вне пары, `−Z_a Z_b T_ab` меняет на дополнении знак. [Независимая проверка](EXACT_REVIEW.json) точно проверяет 31 различных `(dimension,a,b)` для размерностей 2, 3, 4 и 7; алгебра выше не зависит от dimension. Отдельный hostile-control показывает, что общий δ для двух копий даёт на `|2,2>` единицу, тогда как `X_01⊗X_01` даёт ноль. Поэтому fair δ и selector resources разных **occurrences** должны быть независимы, включая повторное использование одного и того же узла DAG.

Из A11 независимо пересчитаны все **20 402** узла, массы и bidegrees; сверены все **3 618** reachable add-узлов и их 25 общих распределений. При условии, что каждый узел реализован отдельным coherent selector, операторная индукция такова: constant даёт sign(c)·I, leaf — указанное среднее двух involutions, add — сумму с точными весами и identity padding, mul — tensor product на непересекающихся copy-слотах. Линейность равенств операторов не требует product-state входа. Это доказательство математического среднего; оно не выдаёт controlled involution/native implementation.

Для одного report точный независимый layout записан в [EXACT_REVIEW.json](EXACT_REVIEW.json): Choi `[0,82)` для S1, `[82,164)` для S2, затем T1..T8 по два до `[178,180)`; CAR T1..T8 по два от `[0,2)` до `[14,16)`. Внутри любого product node offsets независимо суммируются для Choi и CAR; в add child использует своё начало и identity до максимальной степени. Умножение интервалов для семи report banks даёт отдельно регенерированные ресурсы, а не одни и те же копии в нескольких вызовах.

Для каждого из 512 `(site,source type)` отдельно проверено

```
w=mass_root/(rho_site · 2^1525),
weights=[w,(1−w)/2,(1−w)/2],       0<w<1.
```

Отмена последних двух identity даёт ожидаемый полный оператор `H_root/(rho_site Lambda_h)`. `rho^-1` включён один раз; проверка предполагает правильный A11 raw-u/periodic source binding, а не повторно доказывает этот binding.

## 3. Фиксированные cap и предел готовности

Независимый обход DAG подтвердил 455 максимально посещаемых узлов геометрического root, 18 материального и `2·455+8·18=1054` padded walk slots. Максимальные rank-two leaf selections дают `2·82+8·4=196` независимых δ. На их основании пересчитаны `cap_internal=7`, `cap_top=7`, `cap_fair_bank=28`:

```
selector/fair-bank component:
10 248 262 fair qubits, 76 Golden qubits,
286 951 336 оплачиваемых fair-bank attempts на report.
```

Все фиксированные попытки должны исполняться, включая дальнейшие после первого успеха; dummy slots и failures сохраняются. При принадлежащем owner one-attempt plus-resource `s_F=2p³`, независимых реально подготовленных банках и условных τ таблиц точный union bound на failure этой части равен примерно **0.3208597503**, меньше `1/2`. Следовательно заявленная нижняя граница component READY `>=1/2` верна **в рамках этих указанных логических компонент**. Это не стоимость полного processor и не доказанная полная `alpha_h`.

Общий τ действительно даёт `READY effect = tau·I` на coherent palette-control для заданной целевой карты; этого **самого по себе недостаточно** для равенства retained post-READY окружения и marked maps при разных значениях контроля. Контрольный точный isometry `|0>→|0>|0>`, `|1>→|1>|1>` имеет единичный READY effect, но оставляет разные состояния environment; если последнее трассировать, межконтрольная когерентность теряется. A12 сохраняет raw prefixes и не заявляет такую замену; реальный транспорт и сравнение `A_b,t,O_t` должны быть отдельно проверены после построения полного word.

## 4. Оставшийся физический интерфейс

Проверка не исполняла Boolean rank/threshold/first-success маршруты, multi-controlled signed involutions, H/Toffoli/phase factories, Hadamard test или их `G/CX/SourceI` реализацию. Их входы, сохранение контролей, действительные success/failure labels и последовательность оплаченных births/clock должны быть развернуты. В особенности существующий measurement/feedforward интерфейс H/Toffoli нельзя считать уже перенесённым в coherent H.1 dilation только по совпадению marginals. Нужны действительный all-column/marked-prefix error budget, вся READY-конъюнкция, реальный `alpha_h`, полный reader/seal ledger и физическая Cost−Info связь.

[ISOLATED_REPLAY.json](ISOLATED_REPLAY.json) привязывает исходные файлы и побайтное сравнение пяти восстановленных outputs. Воспроизведение из корня open-checkout:

```
OPENBLAS_NUM_THREADS=1 python3 -B -W error 02_REGISTRY/research/sources/d0_two_agent_pilot_2026-11-13/open/round26/check_a12_exact.py
python3 -B -W error 02_REGISTRY/research/sources/d0_two_agent_pilot_2026-11-13/open/round26/replay_a12_isolated.py
```

Обе проверки читают A11/A12 и пишут только внутри `open/round26`; вторая запускает запись компилятора только во временной копии. Публикации, выбора новой физической Info или закрытия GR здесь нет.
