# B63. Достаточный конечный determinant/heat comparison для canonical start

При исходных условиях retained-source owner получен **один конкретный** конечный same-initial comparison, у которого оценённая сумма determinant finite-difference и полного growing-clock heat даёт `<2^-73` на каждое SAM-направление при нормировке `Gamma_s`. Это условное применение исходного конструктора; оно не устанавливает полную цену всех исходных independent rows или стационарность.

## 1. Какой именно z

Book03 §03.25 записывает `beta,z` как параметры функционала. Владелец §7cq прямо различает внешний feedback `0<zeta<1` и параметр события `2^-20`. Но выбранный retained-source `SOURCE_PROOF_RU.md` §1 **отдельно фиксирует** именно внешний feedback `z=2^-20`, `beta=2p²`, а его исходный reporter — `z0=2^-20`. Значения одинаковы, смысл разный. Ниже используются оба принадлежащих этому owner значения, без нового action coefficient; для общего Book03 `z` дана отдельная параметрическая формула.

## 2. Пустая начальная история и конечные native endpoints

Исходные R1/R2 допускают отдельный canonical-start пример `H0=C`, `Omega0=1`, `P0=I_C`. Старого оплаченного prefix до начала нет, поэтому `C_<=1`, `A_old=1`, `rank(P0)=Tr(A_old)=1`; первые реальные стадии A30 при `m=0` — последовательные RAW births. Это конкретный допустимый начальный tuple, а не утверждение, что иная историческая задача имеет пустое прошлое. Все остальные условия сравнения, marks и независимые ряды сохраняются.

Выбранные заранее

```
t = 2^-1618,       angular error each delta < 2^-4852
```

реализованы **двумя положительными integer G powers**; точные показатели и integer-ball certificate — [здесь](SUFFICIENT_ENDPOINT_G_CERTIFICATE.json). Независимый прямой owner interval replay с точными рациональными bounds для `sin(t),cos(t)` подтвердил каждую ошибку даже `<2^-4873`: [результат](SUFFICIENT_G_INDEPENDENT_CHECK.json). Численный кандидат сам не считается доказательством.

Оба конца имеют общие birth layout и одинаковую оплаченную длину до и после core по B62, включая identity padding на живых WORK; последний настоящий gate обоих — `G_SAM`. Каждое из `m=2688` направлений можно рассматривать отдельной парой слов одного и того же правила. Для конкретных степеней и A30 core их изолированное base stage count меньше `2^11647`. Полная последовательность настолько велика, что не исполнялась плоско; описаны конечные DAG/repeats и их точные counts.

## 3. Два independent bounds на determinant

Используется действительно доказанная для выбранного source family условная нижняя граница `g s>2^-3158`, фактический `c>2/3` и настоящий feedback weight, так что

\[
\Gamma_s\ge\gamma_{under}p^K,\qquad
\gamma_{under}=(8/3)z\operatorname{Tr}(A_{old})2^{-3158}.
\]

Идеальная continuous SAM-пара здесь только цель finite comparison; integer compiler не дифференцируется. Для реального диагонального scalar core `c(t)` имеем `|c^(j)|<=2^j`; для `A_old` contraction третья производная исходного logdet и ранее оплаченная точная retention дают

\[
E_{FD}\le {t^2 2^{3158}\over16}\left[
 {64\over1-z}+{192z\over(1-z)^2}+{128z^2\over(1-z)^3}\right].
\]

Разность finite compiled endpoints относительно идеальной пары при одинаковом `p^(K/2)` return даёт после нормировки на `2|t|Gamma_s`

\[
E_{angle}\le {3\,\operatorname{rank}P_0\over2(1-z)\operatorname{Tr}A_{old}}
 2^{3158}\delta/|t|.
\]

Обе ошибки и сумму проверяет [точный rational budget](certify_determinant_fd_budget.py), [результат](DETERMINANT_FD_BUDGET.json): для указанного empty-start `E_FD+E_angle<2^-74` при `Gamma_s`. В единицах `2^-73` достаточные верхние оценки примерно `0.12500048` и `0.18750018`; строгие проверки выполняются дробями. При нормировке `Gamma_s/s` этот **однострочный** bound становится `<2^-104`.

Для произвольного фиксированного ненулевого old Gram, если известны dyadic bounds `1−z>=2^-Q` и `rank(P0)/Tr(A_old)<=2^H`, можно заранее взять

\[
n=\left\lceil{3237+3Q\over2}\right\rceil,\qquad
t=2^{-n},\qquad \delta<2^{-(n+H+Q+3233)}.
\]

Тогда сумма обоих determinant ошибок `<2^-73` на одну строку при `Gamma_s`. Новые G powers под такие фактические Q,H должны быть отдельно построены и сертифицированы; если old Gram нулевой, положительного gain floor здесь нет.

## 4. Поздний retention и полный растущий heat

После фиксации именно этих конечных endpoints вставляем перед общим последним `G_SAM` ровно `K=66076` отдельных `birth;G` пар. Эти новые биты не участвуют в последнем gate; return множится точно на `p^(K/2)`. Значения для условной исходной R11:

```
q=11647, |t| z Tr(A_old)=2^-1638, Q=1638,
K=4(11647+3158+1638+75+1)=66076.
```

У двух программ одинаковые все birth-stage dimensions и последний gate; каждый отличающийся paid prefix stage включён в `B_prefix<=2 N_base d_base`, не зануляется. Из `(2p)^-1<5/6` и `(5/6)^4<1/2` настоящая полная all-mode thermal error при собственных R11 гипотезах `<2^-76` на строку под `Gamma_s`. Для **полных часов** с K поздними рождениями нельзя подставлять front-loaded формулу размеров исходного A30. При n ранних рождениях и L endpoint gates до добавления retention (включая последний G) точная сумма stage dimensions равна `(L−3)2^n+4·2^(n+K)−1`, а число слоёв — `n+L+2K`; формула независимо проверена прямым суммированием конечных случаев. Конкретная сумма determinant и этой heat оценки `<2^-73` на направление. Требуются перенос всех фактически заданных marks/readers и действительная общая интерпретация старого cut; сами эти условия числовая оценка не доказывает.

Для unit raw physical mean-chart covector нормировка — `Gamma_s/s`. Если `d_j=FD(J_j)/Gamma_s`, после скорректированного A31 decoder получается `(1/u)J_actual^-T d`; `||J_actual^-1||<1/(1−2^-23)` и `sqrt(2688)/[u(1−2^-23)]<55` дают **векторный** finite determinant+heat error `<55·2^-73<2^-67`. Однострочная оценка `<2^-104` не является без дополнительного lift оценкой всего вектора. Native-only ошибка A31, centre shift, `J^-1−I`, `E_tau`, source/Taylor, reader и независимые old/F/B rows остаются отдельными.

`physical_C_closed=false`; `GR_closed=false`.
