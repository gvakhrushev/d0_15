# B41. Структурная полноколоночная факторизация proper-link Julia

Для исходного proper-link оператора B25 \(C=\Lambda(U)/2\) построено точное разложение Julia-блока на идеальные управляемые плоские вращения и X: не более **101 идеального макроса на один адрес/SAM-сектор**. Доказана единая строгая граница defect-корней для всех семи исходных семейств. Полный native word, его конкретные углы и оплата здесь ещё не построены: это следующий parent для фактического Julia SELECT.

## Конструкция L, D, R без численного SVD

Исходные метрика и порядок занятостей — \(\eta\) и `ORDER=(0,2,3,1)` из B25. Матрица \(T\in SO(4)\) из B25 удовлетворяет \(T\,\mathrm{diag}(1,-1,-1,-1)T^T=\eta\). Все исходные \(U\) принадлежат связной с единицей компоненте \(SO^+(\eta)\): текущая базовая связь есть экспонента нильпотентного Lie-генератора, SAM-модификация есть экспонента Lie-генератора, reference boost и rotation заданы явно, остальные связи единичны.

Положим \(A=T^TUT\), запишем его первый столбец \((\gamma,v)^T\), \(h=\|v\|\). При \(h>0\):

1. \(\gamma>0\), \(\gamma^2-h^2=1\), \(n=v/h\). Построим чистый boost \(B\) с блоками \(B_{00}=\gamma\), \(B_{0s}=h n^T\), \(B_{ss}=I+(\gamma-1)nn^T\). Для устойчивого вычисления можно использовать \(\gamma-1=h^2/(\gamma+1)\).
2. \(K=B^{-1}A=\mathrm{diag}(1,Q)\), \(Q\in SO(3)\). Выбрать единичный базисный \(e_j\) с \(|n_j|<3/4\), положить \(v_2=(e_j-n_jn)/\sqrt{1-n_j^2}\), \(v_3=n\times v_2\). Такой \(j\) всегда существует; знаменатель ограничен снизу \(\sqrt7/4\). \(O=\mathrm{diag}(1,[n,v_2,v_3])\in SO(4)\).
3. Пусть \(P\in SO(4)\) — Hadamard в плоскости времени и первой пространственной координаты с дополнительной сменой знака последней координаты. Тогда
\[
P^TO^TBOP=\operatorname{diag}(\gamma+h,\gamma-h,1,1)=D_4,
\quad L_4=TOP,\quad R_4=TK^TOP,\quad U=L_4D_4R_4^T.
\]
Здесь \(\gamma+h=e^r\), \(\gamma-h=e^{-r}\); для вычисления второй величины можно использовать точное \(1/(\gamma+h)\). Все \(L_4,R_4\) имеют определитель +1.

При **точном** \(h=0\) деления на boost нет: \(U\in SO(4)\), можно положить \(D_4=I\), \(L_4=I\), \(R_4=U^T\). В частности, при \(U=I\) оба фактора единичны. Случай нулевого радиуса в любом последующем плоском исключении обрабатывается тождественным поворотом; отрицательный pivot обрабатывается допустимым поворотом на π, а не выкидывается. В конечном интервальном компиляторе выбор ветви и ошибка при возможном неразличении нуля требуют отдельного сертификата. В диагностическом Python-коде порог \(10^{-13}\) является только float-эвристикой, не точным критерием.

## Julia и знаки Fock

Положим \(L=\Lambda(L_4)\), \(R=\Lambda(R_4)\), \(D=\Lambda(D_4)/2\). Благодаря функциональному исчислению для положительных корней на полном пространстве 16 состояний:
\[
J(C)=\begin{pmatrix}L&0\\0&R\end{pmatrix}
 J(D)
 \begin{pmatrix}R^T&0\\0&L^T\end{pmatrix},\qquad
J(D)=\begin{pmatrix}D&\sqrt{I-D^2}\\\sqrt{I-D^2}&-D\end{pmatrix}.
\]
Это равенство всех 32 колонок, включая обе стороны Julia flag \(t\). Диагональное значение
\[
d_m=\tfrac12(\gamma+h)^{m_0}(\gamma-h)^{m_1}
\]
зависит только от двух boost-eigenmode битов \(m_0,m_1\). Поэтому хронология \(J(D)\): \(X_t\), затем четыре вращения \(t\), по одному на каждое значение этих двух битов, с \(\sin=-d_m\), \(\cos=\sqrt{1-d_m^2}\). Точная символическая проверка сопоставляет эту схему со всеми элементами \(J(D)\).

Любой \(Q\in SO(4)\) раскладывается не более чем на шесть плоских вращений: последовательным исключением элементов трёх столбцов, соответственно 3+2+1 исключений. Выбирая радиус \(\sqrt{a^2+b^2}\ge0\), после исключения первые три диагональных элемента положительны, последний также равен +1 по определителю. Два нулевых элемента дают I; отрицательная ненулевая диагональ допускает \(\pi\)-поворот. Для каждого mode-plane \((i,j)\) его внешняя степень действует на четыре пары occupation states. Знак синуса равен \((-1)^{N_{between}}\), где число заполненных промежуточных мод считается по исходному `ORDER`, а не по числовому порядку индексов. Все шесть пар мод проверены независимо точными exterior minors.

В двух диагональных Julia-множителях встречаются четыре управляемых Fock-фактора \(L,R,R^T,L^T\). Следовательно, грубая граница — \(4\cdot6\cdot4+4+1=101\) идеальный двухуровневый/X-макрос. Для сектора с 12 адресными и 6 локальными SAM-битами, общей внешней branch, Julia flag и тремя occupation-условиями достаточно не более 23 контролей в отдельном двухуровневом Fock-макросе; два бита eigenmode достаточны для диагонального Julia-вращения. Это структурный счёт, не число G/CX/SourceI; CNOT-сопряжения, native приближения, адресные предикаты и буквальные обратные ходы ещё нужно построить и оплатить. У единичных или вырожденных факторов число макросов может быть меньше.

## Строгая положительность defect для исходных семейств

Для \(SO^+(1,3)\) сингулярные значения \(U\) равны \((e^r,e^{-r},1,1)\). На внешней алгебре максимальное произведение равно \(e^r=\|U\|\), поэтому \(\|C\|=e^r/2\). Оба Julia defect-корня строго положительны в точности при \(e^r<2\).

Исходная reference boost имеет \(\|U\|=(1+H/2)/(1-H/2)=9/7\), reference rotation и identity имеют норму 1. Для текущего f-bank при \(H=1/4\), \(0\le x,y\le3/4\), \(k_0<24\), \(\pi<22/7\), из точного полинома B25 следуют \(|k_x|,|k_y|<1/50\). Каждая из двух нильпотентных матриц имеет норму 1, поэтому норма их суммы меньше \(1/25\); куб суммы равен нулю, и исходная ссылка \(I+N+N^2/2=\exp N\). Для шести локальных SAM-генераторов \(\|\theta\|\le6\cdot2^{-30}\). Следовательно,
\[
\|U_f\|\le e^{1/25+6\cdot2^{-30}}<e^{1/20}\le20/19<9/7.
\]
Итак, по всем исходным секторам \(\|\Lambda(U)/2\|\le9/14\), а каждый из двух положительных defect-операторов удовлетворяет
\[
I-CC^T\succeq (115/196)I,\qquad I-C^TC\succeq (115/196)I.
\]
Граница относится к исходным идеальным формулам, а не к доказанной ошибке будущего native compiler.

## Проверка и оставшаяся работа

`check_proper_link.py` связывает исходные 23 296 proper-link local sector entries семи bank с каталогом: 17 152 для f и по 1024 для каждого из шести остальных. Полученные 336 различных **float64** матриц сверены с исходным B25: полный 32×32 Julia-блок, LDR, ортогональность, определители и разложение на шесть плоскостей; наибольшая наблюдаемая ошибка Julia — около \(4.4\cdot10^{-15}\). Выборка всех записей и дедупликация float-матриц служат диагностикой, не интервальным доказательством для 23 296 точных целей. Отдельно точными вычислениями проверены знаки всех шести Fock mode-planes, нильпотентность и принадлежность генераторов Lie-алгебре, SO(4) диагонализация одного boost и базовый 32×32 Julia. Сверены четыре полных SAM-присваивания с исходным вычислителем полей. Чистая конструкция при нулевом boost и отрицательных pivot также проверена.

Для продолжения необходимы конкретные интервалы для факторных углов всех нужных локальных секторов, условно управляемые native G/CX/SourceI слова, явные обратные DAG, учёт ресурсов и uniform operator-error всей композиции. Воспроизведение: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -W error check_proper_link.py` из `open/round41`. Итог и хеши исходных данных: `PROPER_LINK_CHECK.json`.

`full_Julia_SELECT_present=false`, `physical_C_closed=false`, `GR_closed=false`.
