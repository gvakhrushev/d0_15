## Точные вероятности и смежные интервалы

Пусть $p=\varphi^{-1}$. Действительное каноническое чтение даёт 0 с вероятностью $p$ и 1 с вероятностью $p^2$. Его кодовые длины равны соответственно 1 и 2. Для активных адресов $j=1,\ldots,8$ нужны массы $n_jp^{36}$, где

$$
 (n_1,\ldots,n_8)=(5644800,4939200,4390400,3087000,
                   1580544,548800,115200,11025).
$$

Неактивный адрес 0 имеет массу $1-20316969p^{36}$. Для любого порядка этих девяти адресов разбиваем $[0,1)$ на смежные интервалы с указанными длинами. Каждое реальное чтение делит текущий цилиндр на младшую часть доли $p$ и старшую часть доли $p^2$. Как только цилиндр целиком лежит в одном адресном интервале, выбираем этот адрес. Неисполненный суффикс не рождается. Внутренняя граница, совпавшая с концом цилиндра, не требует дальнейшего чтения.

Все восемь накопленных границ принадлежат $\mathbb Z[p]$. Относительная координата границы в очередном цилиндре меняется по одному из отображений $x\mapsto x/p$ и $x\mapsto(x-p)/p^2$. При алгебраическом сопряжении $p'=-\varphi$ эти отображения имеют вид $x'\mapsto-px'$ и $x'\mapsto p^2x'+p$. Оба сжимают расстояние до инвариантного интервала $[-p,1]$ с коэффициентом не больше $p$. Как только расстояние меньше $p$, имеем $|x-x'|<1+2p=\sqrt5$. При $x=a+bp\in[0,1]$, $a,b\in\mathbb Z$, это вынуждает $b=0$, то есть $x=0$ или $1$. Следовательно, каждый граничный путь конечен. Все цилиндры и их произведения вероятностей проверяются точно в $\mathbb Z[p]$.

Чтобы оптимизировать порядок, для каждого подмножества $S$ адресов вычисляем глубину $d(S)$ пути границы $\sum_{j\in S}\pi_j$. Максимум по границам данного порядка равен максимальной глубине чтения. Минимум этого максимума находится рекурсией

$$
 D(S)=\max\bigl(d(S),\min_{i\in S}D(S\setminus\{i\})\bigr).
$$

Для среднего числа чтений берём сумму вероятностей всех посещаемых внутренних цилиндров. При добавлении очередной границы из её пути надо вычесть общие префиксы с предыдущей границей. Дело в том, что любой цилиндр, содержащий новую и какую-либо более раннюю границу внутри себя, содержит и ближайшую предыдущую границу. Поэтому добавка зависит лишь от пары смежных подмножеств $S\setminus\{i\},S$. Динамическое программирование на всех 512 подмножествах даёт точный минимум среднего по всем порядкам, а также при требовании минимальной максимальной глубины. Наихудший максимум среди порядков равен 58. Значения округлены наружу в [квитанции](RESULT.json).

## Гибрид с глобально оптимальным максимумом

Пусть конечный диспетчер использует не более $d$ независимых чтений. Для нижней оценки любой его ранний лист можно математически дополнить до длины $d$, сохраняя прежний адрес для всех таких дополнений. Пусть $P_j'$ — сопряжение вероятности адреса. Тогда

$$
 \sum_j|P_j'|\le\sum_{x\in\{0,1\}^d}
     |(p')^{d+|x|_1}|=(\varphi+\varphi^2)^d=\varphi^{3d}.
$$

В заданном законе восемь активных сопряжённых масс положительны, а одна неактивная отрицательна. Следовательно, левая часть равна $2\cdot20316969\varphi^{36}-1$, и она строго больше $\varphi^{72}$. Отсюда $d\ge25$. Оценка охватывает произвольную форму дерева и произвольное использование его реально прочитанной предыстории, пока дополнительная случайность отсутствует.

Для верхней границы используем 22 попарно несовместимых ранних префикса длины 2–8 из словаря `EARLY` в [проверке](check_golden_selector.py). Они сразу выбирают свои адреса. Если ранний префикс не встретился, читаем 25 символов. У неизрасходованного класса с $k$ единицами число доступных слов равно

$$
 A_k=\binom{25}{k}
      -\sum_{h\in\mathrm{EARLY}}
        \binom{25-|h|}{k-|h|_1}.
$$

Таблица `RESIDUAL` задаёт неотрицательные целые количества $N_{jk}$ оставшихся слов для восьми активных адресов. Неактивному адресу принадлежат остальные слова. Диспетчер вычисляет вес и лексикографический ранг **записанного** 25-битного слова в его классе, пропуская потомков ранних префиксов, затем выбирает принадлежащий этому рангу интервал выхода. Счёт возможных продолжений нужен только как целая комбинаторная функция. Он не требует новых выборок. Проверка удостоверяет точно и для каждого адреса

$$
 \sum_jN_{jk}\le A_k,\qquad
 \sum_{h\in\mathrm{EARLY}_j}p^{|h|+|h|_1}
      +\sum_kN_{jk}p^{25+k}=n_jp^{36}.
$$

Проверяются обе границы каждого ненулевого рангового интервала и реальный ранний диспетчер без дополнительных символов. Получаем ровно 5 767 190 положительных сырых листьев, из них 22 ранних. Вероятность достижения лимита 25 лежит между $0.093275563764$ и $0.093275563765$. Среднее число чтений равно $1466-2363p$. Результат достигает минимального максимума. Среднее среди всех произвольных деревьев с этим пределом отдельно не оптимизировано.

При LC1 с одним новым хвостом на одно чтение указанный гибрид использует в среднем $11.171369167996\ldots$ рождений и максимум 50 для своих исходных чтений. У обязательной ленты соответствующее число равно 72. У исходной остановки математическое среднее получено рекурсией $E_c=1+pE_{c-1}+p^2E_{c-2}$ при $E_c=0$ для $c\le0$. Это и есть правильное сравнение с первичным EIGHT_READERS. Оба новых селектора совпадают с ним по девяти выходным массам, сохраняя собственный фактический сырой журнал. В частности, адрес 0 агрегирует исходный отказ. Его новые сырые исходы не обязаны сохранять старую отметку точного неактивного попадания отдельно от перескока.

Для каждого из новых префиксных деревьев вероятность листа равна $p^{L(w)}$. Поэтому средняя буквальная длина совпадает с энтропией всего его сырого архива. Она также равна $(1+p^2)$, умноженному на среднее число чтений: на каждом действительно посещённом внутреннем префиксе условная цена следующего чтения равна $1+p^2$. На гибриде это $7.719226244649\ldots$ золотых единиц. Эти числа относятся к чтениям и их буквальному тарифу. Фактическая адресная машина, передача выбранной настройки, состояние поздних хвостов и полный час имеют собственные расходы.

Оба дерева допускают классический выбор после действительного чтения, если сохраняемый журнал доступен управлению. Формула девяти адресов переносится на настоящий геометрический банк при той же условной реализации каждого тега и одинаковой принятой полевой карте. Селектор в этой постановке не требует собственного отмечаемого Toffoli. Физическая цена классического диспетчера и перенос полного Book03 Cost−Info остаются открытыми. `GR_closed=false`.
