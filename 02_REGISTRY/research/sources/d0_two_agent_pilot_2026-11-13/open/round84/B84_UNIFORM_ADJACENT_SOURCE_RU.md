# B84: равномерная оценка соседних prepared sources

**Результат.** Для исходного prefix `B⁰` из A30, включая именно прежние приближённые SourceI/profile preparations, а не заменяя их идеальным произведением, на всех 2688 координатах B21 и всех остальных SAM labels при `s=2^-30`:

    Λ_coframe < 2s + 2^-3231 < (9/4)s,
    Λ_link    < 12s + 2^-3231 < (25/2)s,
    Λ_matter  < s + 2^-3231,
    max_j Λ_j < 2^-26.

Это равномерные аналитические оценки на всём кубе, а не перебор нескольких состояний. В частности, для j=2 применима первая строка. Они опираются на A25/A27/A30, B21/B25/B65 и границы A37/A41; не являются самостоятельным восстановлением всех их доказательств. Точное рациональное ядро и inventory проверяются `check_uniform_adjacent_sources.py`; сам скрипт не доказывает аналитические леммы ниже и не разворачивает production state.

## Источники и единственная изменённая локальная запись

По B21 здесь 1024 coframe, 1536 proper-link и 128 matter координат. B24 содержит 2049 Choi адресов. Проверка каждого label показывает: изменение одной coframe или link координаты затрагивает ровно один соответствующий Choi адрес. B25 `fields` и фактический inventory A30 дают семь банков по 180 Choi и 16 CAR: coframe меняет только f и q Choi (360 копий), link — только f Choi (180 копий), matter — только q CAR (16 копий). Остальные части, включая SITE и общий `B_R`, одинаковы. Для matter меняется один внутренний site; его вес в CAR равен 1/256.

A27 ideal source есть нормированное вещественное произведение в независимых source arenas. Для нормированных вещественных факторов с неотрицательными попарными перекрытиями:

    ||⊗v_i − ⊗w_i||² ≤ Σ_i ||v_i−w_i||².

Наши однофакторные разности меньше 1, поэтому перекрытия положительны. Общий унитарный `B_R` сохраняет норму. Использование этой оценки не отождествляет идеальное произведение с буквальным старым профилем: последняя поправка ниже учитывается отдельно дважды.

## Choi и геометрия

Julia dilation строится из contraction C и дефектов `(I−CCᵀ)^(1/2)` и `(I−CᵀC)^(1/2)`. Точная верхняя граница B21 для coframe `u*=12985565259/13421772800` удовлетворяет `1−u*²>1/16`; у link есть аналогичный запас. Само по себе более грубое `u*<31/32` этого не доказывает: `1−(31/32)²=63/1024<1/16`.

По уравнению Сильвестра для разности положительных квадратных корней и запасу 1/16,

    ||J(C')−J(C)||_F ≤ sqrt(34) ||C'−C||_F < 24 ||C'−C||_op,

где C имеет размер 16×16. В нормированном Choi source изменён один 32×32 блок из 2049, поэтому норма изменения состояния не превосходит последнего выражения, делённого на `sqrt(32·2049)>256`.

Для coframe `||ΔC||=s`, так что на один Choi source приходится `<3s/32`, а на всё произведение `<sqrt(360)·3s/32<2s`.

Для link, представляя его как `exp(A)U₀`, B65 даёт по всему кубу `||U||<17/16`; также `||A||,||A'||≤6s`, и один генератор имеет норму 1. Формула Дюамеля и `exp(12s)≤1/(1−12s)` дают `||ΔU||<3s`. Телескопирование в `⊕ₖ ∧ᵏ U`, k=0,…,4, даёт для соответствующего C оценку `||ΔC||<6(17/16)³s<9s`. Следовательно один Choi меняется на `<27s/32`, а всё произведение на `<sqrt(180)·27s/32<12s`.

Для matter, из B21 `L>1/3` и `p>3/5`; вдоль ребра тот же нижний запас следует из вогнутости L. Для нормированной локальной CAR-карты `m` имеем `||∂m/∂ψ_A||²=1+ψ_A²/L<6/5<(11/10)²`. С весом site 1/256 изменение каждой из 16 CAR копий меньше `11s/160`, а всего произведения — меньше `11s/40<s`.

A30 inventory отдельно устанавливает для каждой стороны ребра старую prefix-ошибку `<2^-3232` относительно идеального source product. По неравенству треугольника перенос даёт добавку `<2^-3231` к каждой из трёх оценок. Это prefix-ошибка, а не ошибка полного replacement `e_W`; смешивать их нельзя.

## Следствие для независимой Q-feedback строки

При исходном gain `gs>2^-3158`, B65 даёт в центре `||DI_τ(Y₀)||<2^-3083` и по всему непрерывному кубу `||D²I_τ||<2^25`. Поскольку `||Y−Y₀||<sqrt(2688)s<52s`, всякая компонента градиента имеет модуль `<27/16`. Для идеальных scalar targets `M⁰=c_ref−2gI_τ` и фактических A30 диагональных `M`, отличающихся от них на `<e_B=2^-3231`, отсюда на любом ребре

    |M_b−M_c|/(gs) < 27/8 + 2e_B/(gs) < 7/2.

Используем B82 kernel и его независимые строки при одном фиксированном A41 выходе `Uhat`. При `e_W=2^-3244`, `ε_U=2^-14623`, `c_ref>2/3` и сумме весов одного локального генератора `Σχ_bχ_c=p√p<1/2`, B82 reflected identity и приведённая выше оценка дают

    |d_Qb,actual(J_j) − (1/2)d_Pf,ideal(J_j)|
       < (21/32)Λ_j² + (21/8)e_W + (3/4)e_W/(gs) + ε_U/(gs)
       < 2^-53 − 2^-56.

Здесь `d_Pf,ideal` вычисляется с идеальным A37 выходом U*, тогда как Q-строка — с A41 Uhat и actual `Γ_native`. При сравнении с actual Pf добавляется соответственно малая A41 погрешность. Условия A37/A31 дают существование одной из 2688 локальных осей с `|d_Pf,ideal(J_j)|>2^-52`; следовательно на этой пока не вычисленной по индексу оси

    |d_Qb,actual(J_j)| > 2^-56,
    d_Qf,actual(J_j) = −d_Qb,actual(J_j).

Равенство знаков использует точную SAM-disjoint поддержку среднего S. Оно относится к аналитическим независимым feedback rows и предполагает допуск соответствующих Q supports; не установлены оплаченная конечная Q-разность полного H+J, полное same-task admission или физический выбор этой строки. A41 доказывает конечное слово математически, но его production provider/слово не материализованы.

Для отдельной j=2 строка с `<2^-77` на разность с половиной Pf получается **только при дополнительной** pointwise оценке A43 `|ΔM|/(gs)<2^-17`: это условная арифметическая проверка, не доказательство данной оценки в B84.
