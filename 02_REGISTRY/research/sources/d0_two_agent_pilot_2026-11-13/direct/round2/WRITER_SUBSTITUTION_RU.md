# Подстановка настоящего pre-sign writer в marked RC3

13 ноября 2026. Продолжение D0→ОТО, existing #334. Этот расчёт потребляет marked h из `open/round3/ROUND3_RESULT_RU.md` и исходные **NPS11–13**, а не назначает неизвестной компрессии значение sqrt(q).

## 1. Две неизвестные компрессии выражаются через owned операторы

Первичный владелец, строки 145142–145182 на `dc411daf01f697ec85dd22f28bfe124171796645`, задаёт на **независимых** forward/back preparations:

```
W_bf=A_b* Z_e A_f,  V_bf=A_b* A_f,
U_read=W_bf tensor P_+ + V_bf tensor P_-,
K_0=u W_bf+d V_bf,  K_1=u W_bf−d V_bf,
u=(a+p)/2,  d=(a−p)/2,  a=sqrt(p).
```

Вход r действительно родился в v=(a,p). Его пассивная bra даёт множители a,p. Буквальный NPS рождает и r, и t до reader; t остаётся нетронутым до E0. Ниже этот spectator-tensor лишь алгебраически вынесен, без перестановки реального рождения и оплаченных стадий. Если исходный j и B_pre отождествлены ровно с соответствующим полным born-вложением этого writer, то до E0:

```
X_0=a(u C_W+d C_V),
X_1=p(u C_W−d C_V),
C_W=j* W_bf j,  C_V=j* V_bf j.                    (W1)
```

Для общей предыстории W1 остаётся точной с C_W=j_ref* W_bf j_phys и C_V=j_ref* V_bf j_phys: пассивное born-вложение и реально сгенерированный вход могут различаться. Их совпадение нужно доказать для применения скалярной секции ниже. Это полная операторная подстановка: C_W,C_V и их собственные источники сохраняются. Если перед writer есть неприведённая историческая компрессия C_<, её нельзя заменить единицей; W1 применяется с правильными исходными maps либо с отдельно доказанной общей факторизацией. В частности, произвольные старые адреса и их Euler-строки не исчезают из-за выбора одного фиксированного prefix в round3.

## 2. Полный источник в объявленной независимой карте

Положим A=H_(i,0)>0, B=H_1>0 — **вычисленные коэффициенты** двух реальных шестимаркерных readers и последнего CX из round3. Пусть `q_0=1−q`, `q_1=q`, и

```
T_0=u C_W+d C_V,  T_1=u C_W−d C_V,
h=A p T_0 T_0*/(1−q)+B p² T_1 T_1*/q.             (W2)
```

В общем случае дифференцировать нужно ВСЮ W2: обе матрицы, q и, если они действительно меняются, коэффициенты readers/сцены. Эта формула наследует исходный single fixed-old-address cut и девять листьев round3. На этом cut `r=4`, `L=36`,

```
J=−32 log(1−z)−Tr_4 log[(1−z)I+zh].
```

При согласованном реальном scalar corner `C_W=c I`, `C_V=I`, обозначим `α=uc+d`, `β=uc−d`, `s=p³`. Из NPS10 на этом сечении

```
q=(1−s c)/2,  0≤c<1,  p²<q≤1/2,
ν=A p α²/(1−q)+B p² β²/q,  h=νI.
```

Но независимую вариацию нельзя заменить производной только ν(q). Для фиксированных A,B,z:

```
Λ_W=u[A p α/(1−q)+B p² β/q],
Λ_V=d[A p α/(1−q)−B p² β/q],
Λ_q=A p α²/(1−q)²−B p² β²/q²,
dh=Λ_W(dC_W+dC_W*)+Λ_V(dC_V+dC_V*)+Λ_q dq I,
dJ=−z/(1−z+zν) · [2Λ_W ReTr(dC_W)
                    +2Λ_V ReTr(dC_V)+rΛ_q dq].    (W3)
```

Это сохраняет полную подготовительную проблему. У исходного NPS13 q зависит только от A_f, тогда как C_W зависит от A_f и A_b. Реальная matched-unitary вариация C_V имеет нулевую действительную trace в объявленной стандартной карте, но это не разрешает занулить C_W, старые maps, произвольный moving cut или тепловую часть.

## 3. Строго положительный источник на согласованном сечении

Вычисленные coefficients round3 удовлетворяют **A>pB** для обоих слов. Это проверяется точной рациональной изоляцией исходного алгебраического числа a, не только десятичной печатью.

Положим

```
f_+(c)=(uc+d)²/(1+sc),
f_−(c)=(uc−d)²/(1−sc).
```

Тогда

```
ν(c)=2p(A−pB) f_+(c)+2Bp²[f_+(c)+f_−(c)],
f_+'(c)=(uc+d)(2u+usc−sd)/(1+sc)²>0,
(f_++f_−)'(c)=4c(u−sd)²/(1−s²c²)²≥0.            (W4)
```

Следовательно, ν_c>0 на всём исходном интервале. Более того,

```
ν_c ≥ 2p(A−pB)d(2u−sd)/(1+s)² >0,
−ν_q ≥ 4p(A−pB)d(2u−sd)/[s(1+s)²] >0,
dJ/dq=−r z ν_q/(1−z+zν)>0.                       (W5)
```

Получен конкретный положительный scalar source для **буквальной неполярной программы**, при действительной W1 и согласованном сечении. Это не противоречит M1/M2 из MARKED_SOURCE_RU.md: здесь нормированные условные ranges меняются вместе с q, поэтому гипотеза постоянных V_γ не выполнена. Таким образом общий marked-функционал не обязан быть слепым к q; слепым является именно изменение только вероятностей при фиксированных ranges.

## 4. Почему знак ещё не даёт ОТО

W5 — источник вдоль согласованной карты. Полный контракт требует стационарности всех действительных независимых внутренних переменных. Для проверки этого ограничения рассмотрим точный двухмерный **математический** bank-контроль, не объявляя его полной H.1-реализацией:

```
A_f=Rot(θ), A_b=Rot(θ+η), j=|0>, Z=diag(1,−1),
C_W=cos(2θ+η), C_V=cos η,
q=(1−s cos(2θ))/2.
```

При η=0 backward-изменение не меняет q, но

```
∂η C_W=−sin(2θ),  ∂η C_V=0,
∂η J=2zr Λ_W sin(2θ)/(1−z+zν).                   (W6)
```

Условие A>pB также гарантирует Λ_W>0 при 0≤c≤1: после подстановки q,

```
Λ_W=2u{p(A−pB)(uc+d)/(1+sc)
       +Bp²·2c(u−sd)/(1−s²c²)} >0.
```

Поэтому в модели 0<θ≤π/4 matched corner не является внутренней стационарной точкой. Это строгий контроль против ложного вывода «положительный диагональный gain ⇒ полное закрытие». Он не доказывает, что конкретная θ/η-ручка входит в первоначальную H.1 с её полным списком marks; её реальный native/fixed-effect перенос остаётся отдельной обязанностью. Но W3 уже показывает, какую действительную строку обязан решить такой перенос.

Если вместо буквальной программы выполняется настоящий совместимый conditional polar recovery и V_γ становятся фиксированными, источник M1 исчезает. Если новые fine marks не допускают такого recovery, нужно решать их настоящий ограниченный аппаратный stationary problem. Ни произвольное приравнивание A_f=A_b, ни игнорирование цены recovery эти варианты не разрешает.

## 5. Точный вклад в дальнейшую работу

Теперь marked h не является свободным двухматричным предположением: W1–W3 связывают его с уже owned NPS-операторами и сохраняют их независимые строки. На объявленном matched scalar section доказан строгий знак W5. Следующее необходимое действие — применить настоящий stationary-fibre/constraint transport к **этой** fine-recorded программе, с её full heat, старой историей и физическими Cost−Info. Положительный знак не закрывает эти условия. `GR_closed=false`.
