# Обратная подготовка SAM при фиксированном H.1 core

13 ноября 2026. Это уточнение области после STATIONARY_BACKWARD_RU: H.1 T6/T10 разрешает endpoint preparations на SAM/live protected factors, но не превращает весь фиксированный marked геометрический core в свободную подготовку. Здесь решается именно общий backward SAM-фактор на каноническом входе. Положительность marked source и совместимость полного paid fibre остаются разными утверждениями. `GR_closed=false`.

## 1. Сохранённый вычислитель и неизвестный вход

Пусть C — действительное H.1 сжатие fixed core на канонических WORK/SITE входах. На целевом продуктном разделе `C=diag(c_b)` на SAM, tensor I на неизвестном DATA. Обозначим состояние SAM после forward preparation через ψ, после backward через χ; обе нормированы. Действительный r-мерный DATA сохраняется на всех столбцах и может быть запутан с нетронутой ссылкой.

Здесь требуется именно объявленный канонический WORK/SITE checkpoint и указанная факторизация относительно DATA. Произвольная более ранняя cross-компрессия не объявляется единицей. Если она присутствует, данное специальное решение не заменяет её независимые строки. Рождения, reader-tail и последнее CX остаются на своих физических стадиях.

С `u=(sqrt(p)+p)/2`, `d=(sqrt(p)−p)/2`, `s=p³`, реальными `α=p H_(i,0)` и `β=p² H_1` положим

```
m=<ψ,Cψ>, v=<ψ,C²ψ>−m² ≥0,
q=(1−s m)/2,
w0=α/(1−q), w1=β/q,
b0=(um+d), b1=(um−d),
ν=w0 b0²+w1 b1².
```

После той же контракции fine-readers единственная SAM-матрица для backward χ равна

```
M_SAM=w0 |(uC+d)ψ><(uC+d)ψ|
     +w1 |(uC−d)ψ><(uC−d)ψ|,
h=<χ,M_SAM χ> I_DATA.                              (A1)
```

Здесь НЕВЕРНО нормировать `(uC±d)ψ` как полные branch-isometries: C уже сжат по WORK. Действительные эффекты q_b считаются по полному writer до этого сжатия, а потерянные при cold contraction компоненты остаются в реальном носителе и heat. Именно поэтому unrestricted-bank S3 имеет другой спектр.

## 2. Точное stationary-решение разрешённого SAM-вращения

При v>0 в ортонормированном базисе ψ и `(C−m)ψ/sqrt(v)` матрица A1 имеет блок

```
L=w0 b0+w1 b1,
M_SAM = [ ν          u sqrt(v) L     ]
        [ u sqrt(v)L u²(w0+w1)v      ],
T=ν+u²(w0+w1)v,
D=4 w0 w1 u²d² v,
λ_SAM=(T+sqrt(T²−4D))/2.                          (A2)
```

Остальные собственные значения равны нулю. При v=0 имеем M=ν|ψ><ψ| и λ=ν, без деления на sqrt(v). Общая обратная подготовка должна выбрать верхний eigenvector χ*. Так решаются все её SAM-строки. При tensor I_DATA выбирается соответствующий r-мерный верхний projector, и строки смешивания SAM с live DATA также стационарны в математической unitary-области этих факторов. Выполнение ограничений физической реализации этих вращений всё ещё должно быть подтверждено.

Точная цена на этой секции

```
J_SAM=−(L_leaf−r)log(1−z)−r log(1−z+zλ_SAM).
```

На v=0 совпадение χ*=ψ следует из решения, а не накладывается как равенство независимых переменных. При v>0 обычно χ*≠ψ. Нельзя выводить стационарность всей программы из равенства legs только в центре.

## 3. Выигрыш backward-оптимизации квадратичен по разбросу core

Поскольку M_SAM≥0, его Rayleigh на ψ равен ν, а trace равен T, точно

```
0≤λ_SAM−ν≤u²(w0+w1)v.                            (A3)
```

При фиксированном m первая вариация λ по v в v=0 равна

```
∂v λ|0=u² L²/ν≥0,
(w0+w1)ν−4w0w1 d²=L².                            (A4)
```

Для matched цены J_match с h=νI получаем

```
0≤J_match−J_SAM≤[r z/(1−z)]u²(w0+w1)v.            (A5)
```

На исходном H.1 noisy collar q≥p², q<1/2 имеем `w0+w1≤2α+β/p²`. Если `||C−c_*I||≤σ`, то `v≤σ²` для любой нормированной ψ. Это настоящая оценка чувствительности решённого backward-минимума; она не требует выдумывать гладкую зависимость native компилятора.

Для двух реально исполненных finite comparisons +/− на одном layout, с общей нормировкой Γ>0 и шагом t≠0, исправление normalized source относительно matched секции ограничено

```
|[(J_SAM,+−J_SAM,−)−(J_match,+−J_match,−)]/(2tΓ)|
 ≤ r z u² (2α+β/p²)(σ_+²+σ_-²)
     /[2(1−z)|t|Γ].                               (A6)
```

Для κ-потребителя сохраняется фактическая норма right lift. Native ошибки приближения χ* и все оплаченные новые стадии добавляются отдельно. Нельзя подставлять только малость σ, не деля на реальный шаг и gain.

## 4. Подстановка существующей H.1 таблицы

T8 уже даёт `C=c_*I−2g a_s Σ_j D_j I_tau V_j+R` и `||R||≤g L a_s² R_v²+e_B`. Здесь a_s — sampling step (другое число, чем sqrt(p)). Поэтому для именно этой таблицы

```
σ≤2g a_s ||Σ_j D_j I_tau V_j||+g L a_s² R_v²+e_B.
```

Это снимает одну конкретную неопределённость: отклонение оптимальной общей backward-подготовки от matched цены ограничено квадратом реального разброса H.1 core. Здесь matched marked gain равен `Γ=2r z ν_c g a_s/(1−z+zν)>0` при нормировке `Dm=−2g a_s DI_tau[L·]+error`; положительность ν_c доказана W4–W5. Это не старый coherent T9 gain. На фиксированном физическом h и фиксированном collar Γ имеет порядок g a_s. Выбор `e_B=o(g a_s)` и, например, t=sqrt(a_s) делает эту часть A6 стремящейся к нулю при a_s→0. Это асимптотический расчёт **этой** части, а не бесплатная конечная программа: конечные comparison controls, её точность, layout, исходные нормы и прочие остатки ещё должны быть перенесены.

Разрешённые дополнительные effect-preserving local аппараты могут иметь собственные свободные направления, отсутствующие в A1. Их нельзя исключать только потому, что backward SAM-уравнение решено. Full heat, history, Cost−Info и реакции геометрических marks остаются в полном master. Существующий κ-результат потребляется лишь после проверки этих оставшихся источников на том же исполнении.
