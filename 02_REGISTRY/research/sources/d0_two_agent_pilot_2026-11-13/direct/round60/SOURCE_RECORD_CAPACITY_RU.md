# A60. Вместимость записи при сохранении банка текущего SOURCE

**Результат.** Для выбранного SOURCE A54/A55 получена необходимая граница
на точное перекодирование всей области свободных CODE-входов. Если оно
сохраняет банк, включая его private/aux/SITE факторы, почти вся исходная
размерность CODE должна оставаться в остальных сохранённых носителях.
Более слабого сохранения вероятности одного явно заданного проектора банка
уже достаточно. Это конкретный тест одного decoder-интерфейса FV7;
не вывод полной Cost−Info и не запрет любых способов сжатия.

`physical_C_closed=false`, `GR_closed=false`.

Вход: A59 `bdc7d0a619e34772cc153b52ebcd6d837289aeec`; A47, A54/A55
в том же worktree. Партнёрский B117
`7a6977d4597cd031b98569fc6e98ff269eb0495e` даёт общий rank bound CQ-носителя.
Он может быть пустым при rank-one input и большом bank. Здесь используется
дополнительное свойство именно текущего SOURCE: близость всего семейства
CODE-колонок к одному чистому состоянию банка.

## 1. Область и общий якорь

Зафиксируем одно рациональное имя поля y из A53/A55 и допустимый чистый
canonical вход b всех остальных факторов. Никаких dirty private входов
не добавляем. Old/reference, если они нужны в выбранном исполнении,
фиксируются в допустимом чистом состоянии; доказательство требует лишь
этой подобласти исходного свободного CODE/SAM-контракта H.1.

Обозначим m=5376, N=2^m. Идеальный SOURCE имеет вид

    B_s(Y) = sum_x |x><x| tensor B(Y + sigma v_x),
    sigma=2^-80,  ||v_x||<104.

Все bank факторы, кроме CODE, включены в B и b. Выбранная полная extension
A23/A54 сохраняется; тождество произвольному иному writer не предполагается.
По A47/A55 ||DB||<=1748 в исходной Euclidean норме 2688 координат.
Полные отрезки между Y и Y+sigma v_x лежат в сертифицированном chart.
По A54 actual SOURCE U_y имеет error e_B<2^-3423 на нужной initialized
fibre. Пусть

    Phi_y = B(Y)b,  ||Phi_y||=1,
    psi_x = U_y(|x> tensor b),
    delta = 1748 * 104 * 2^-80 + e_B < 2^-62.

Операторная оценка и интеграл DB по отрезку дают одновременно для всех x

    ||psi_x - |x> tensor Phi_y|| <= delta.                    (1)

Векторы psi_x ортонормированы: actual SOURCE состоит из действительных
унитарных gates с одинаковыми canonical births. Доказательство не требует
точной block-diagonal структуры скомпилированного U_y. Оно не делит error
на редкую Born-амплитуду и не заявляет близость каждого нормированного
условного bank-состояния после измерения actual CODE.

Пусть P_y=|Phi_y><Phi_y|. Из (1), проектируя на дополнение, получаем

    <psi_x, (I_CODE tensor P_y) psi_x> >= 1-delta^2.           (2)

## 2. Теорема для реального SOURCE, а не одного подготовленного вектора

Пусть T — точная isometry на span{psi_x}, а полный сохраняемый output
размещён в R tensor BANK. Здесь BANK тот же банк, на котором определён P_y.
В R должны войти все прочие реальные носители: code, decoder workspace,
clock/stop/length, environment и garbage, требуемые для восстановления.
Система, недоступная decoder для записи, не служит дополнительной памятью.

Предположим, что для каждого x encoder сохраняет вероятность P_y с потерей
не более eta>=0. Равенство всей bank density — достаточное, более сильное
условие. При zeta_x=T psi_x имеем

    <zeta_x, (I_R tensor P_y) zeta_x> >= 1-delta^2-eta.

Так как zeta_x ортонормированы, проектор на их span не превосходит I.
Следовательно

    N(1-delta^2-eta)
      <= sum_x <zeta_x,(I_R tensor P_y)zeta_x>
      <= Tr(I_R tensor P_y) = dim R.                         (3)

Это полное доказательство: необъявленной независимости банка и record нет.
При eta=0 и R из b binary wires и side размерности d

    2^b d >= (1-delta^2) 2^5376.                              (4)

Если d=1, целочисленность даёт b>=5376. Если **условно** d=9, b>=5373;
девять состояний не присваиваются clock текущего A54/B105 исполнения.
При eta+delta^2<1/2 результат b>=5376 для d=1 остаётся верным.

Число wires не равно Golden description length, Cost или числу stages.
Теорема требует всего заявленного семейства CODE-входов. Она не выводится
из одной фиксированной Born-суперпозиции и сама по себе не ограничивает
decoder, которому исходный semantic-контракт действительно разрешает
работать только на одном известном состоянии.

## 3. Идеальный чистый банк и контроль возможности переноса записи

Для идеальных входов |x>Phi_x, где ||Phi_x-Phi_y||<=delta,
все парные overlaps ненулевые:

    Re<Phi_x,Phi_z> >= 1-2delta^2 > 0.

При точном сохранении каждой чистой bank density выход чистой isometry
факторизуется как code_x tensor Phi_x. Ортогональность входов тогда даёт
<code_x,code_z><Phi_x,Phi_z>=0, то есть все code_x ортогональны.
Здесь dim R>=N точно. Этот дополнительный идеальный аргумент не подменяет
устойчивую actual оценку (3).

Условие сохранения банка существенно. SWAP на двух N-мерных факторах
переводит |x>_record|0>_bank в |0>_record|x>_bank и имеет точный обратный
decoder. Он обнуляет отдельный record, изменяя банк. B117 даёт другой
пример, где банк уже содержит ортогональную копию метки. Такие интерфейсы
не запрещены (3); их реальные операции, временно занятый банк и цена
восстановления должны потребляться в полном FV7 сравнении.

## 4. Малое значение энтропии банка не является малым источником

Блочная идеальная оценка сильнее (1): actual SOURCE на любом чистом
CODE-входе c близок к c tensor Phi_y с той же delta. Для сведённого банка
rho_B имеем <Phi_y,rho_B Phi_y>>=1-delta^2 и rank(rho_B)<=N по Schmidt
rank. Поэтому lambda_max(rho_B)>=1-delta^2. Обозначив q=1-lambda_max,

    S_2(rho_B) <= h_2(q)+q log_2(N-1),  q<2^-124,
    S_2(rho_B) < (124+2+5376) 2^-124 < 2^-111 bits.           (5)

Для оценки h_2 использованы ln 2>1/2 и -(1-q)ln(1-q)<=q.
Якорь не обязан лежать в support rho_B: достаточно Rayleigh bound для
lambda_max. Формула относится к чистому SOURCE output до добавления
неучтённого измерения/смешивания. Это не энтропия полной CQ-записи FV2.

Оценка значения (5) не контролирует производную, finite-difference quotient
или результат деления на фактический малый gain. Она не отождествляет
Book Info с von Neumann entropy и не выбирает физический тариф.

## 5. Что проверено и что требуется для Cost−Info

`check_source_record_capacity.py` проверяет исходные числа и pins,
строгие рациональные bounds, integer capacity и entropy bound. В отдельной
точной 8x8 модели actual unitary смешивает CODE перед controlled bank:
проверены ортогональность колонок, проекторная оценка и trace inequality.
Отдельно проверены ненулевые Gram overlaps и обратимый SWAP-контроль.
Это конечные проверки доказательства, не исполнение гигантского SOURCE
и не формальная верификация всех предпосылок в Lean.

Снятая неопределённость: при предъявлении FV7 decoder для **этого**
SOURCE можно сразу проверить, где он физически размещает запись. Нельзя
считать её исчезнувшей, одновременно сохраняя банк и всю входную область.
Не снятая обязанность: actual Cost intertwiner с приготовлением, clock,
decoder, terminal и memory valuation. B117 точно переносит предоставленную
полную CQ entropy через isometry; полного Cost−Info источника это не даёт.
Для исходной цели остаётся полный source-equivalent residual по CD13
на той же истории с её фактическим gain и физическим pullback. Новый
постулат, Info-функция или физический закон в A60 не вводится.
