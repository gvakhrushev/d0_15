# Два native G: источник записи без компенсации ценой информации

13 ноября 2026. Продолжение исследования по существующим основаниям D0 после ответа пользователя «Новых материалов нет». Baseline #334: `dc411daf01f697ec85dd22f28bfe124171796645`. Новый результат относится к **изменённому физическому слову** и указанному классу цен; `GR_closed=false`.

Потребитель: physical C / полный источник. Конкретная снимаемая математическая предпосылка — нижняя граница `a=b_Q+b_C>=1` sharp entropy-cone §7ft ES1–12. Одновременно устраняется механизм компенсации ES13–14 на noisy исходных вероятностях. Полная физическая принадлежность Cost−Info этому классу остаётся отдельной задачей.

## 1. Изменённый вход: две реальные операции до регистрации

Пусть `p=φ^-1`, `a0=sqrt(p)`, `u=(a0+p)/2`, `d=(a0-p)/2`. Используется исходный noisy reader NPS с полными унитарными загрузчиками:

```
W=A_b† Z A_f,  V=A_b† A_f,
K0=uW+dV,     K1=uW-dV.
```

Здесь `Z=Z†=Z^-1` — исходное SourceI², указатель r родился в `(a0,p)`, а хвост t до E0 не адресуется. Все unknown input, Spin, старые записи и рабочие дополнения остаются в носителе. Из полного унитарного равенства следует

```
W†V=V†W=A_f† Z A_f,
K0†K1=K1†K0=(u²-d²)I=a0 p I,
E=K1†K1=(I-p³ A_f† Z A_f)/2,
p² I <= E <= p I.
```

Вставим **G_r;G_r** после K0/K1 и до исходного `E0(r,t)`. Это два оплаченных вызова, не свободная смена названий и не приближённый X:

```
G² = [[p³, -2a0p], [2a0p, p³]],
K0_hi=p³ K0-2a0p K1,
K1_hi=2a0p K0+p³ K1.
```

Отсюда точная операторная формула на всех входах:

```
E_hi=K1_hi†K1_hi=A I-k E,
A=4p³+4p⁶=28-12sqrt(5),
k=1-2p⁶=8sqrt(5)-17 > 0.
```

Следовательно, для каждого нормированного входа `q_hi=A-k q`, включая вариацию входа, а при фиксированном носителе `DE_hi=-k DE`. Значения удовлетворяют

```
p <= q_hi <= U=(147-65sqrt(5))/2 < 1,
p≈0.618033989, U≈0.827790731, k≈0.888543820.
```

Весь диапазон строго выше 1/2. Полная реакция загрузчика, поля и входа сохраняется с **ненулевым** множителем `-k`. Никакой равенства `S_amp=S_Book` это не предполагает.

E0 не меняет r и при r=1 переводит честно рождённый хвост в 0. Поэтому invalid 11 по-прежнему невозможен. Pulse действует только на новый r, старые записи не затрагивает. Число рождений не увеличивается. Полная цена этих двух новых G не объявляется нулевой.

## 2. Полные коррелированные записи и квантовая память

Потребим действительный common-CODE интерфейс VCP/BCPR. Требуется, как и у владельца, что последовательные Kraus maps сохраняют один CODE PVM, а их эффекты скалярны внутри его блоков. Линейные комбинации K0/K1 выше сохраняют это свойство. После настоящего born loader его сжатые эффекты `M_theta` могут не коммутировать; `sum M_theta=I`.

Для M новых записей используем **весь** совместный закон:

```
P_theta(omega)=product_j q_hi(theta,j,b_j),
G_omega=sum_theta P_theta(omega) M_theta,
B_omega=sqrt(rho) G_omega sqrt(rho),
P_omega=Tr B_omega, r_theta=Tr(rho M_theta),
I_Q=sum_omega S(B_omega)-S(rho),
H_C=-sum_omega P_omega log P_omega.
```

Как у VCP, theta не измеряется, полные исходы не заменяются произведением сжатых маргиналов, начальная энтропия вычитается ровно один раз. Реальные условные квантовые выходы остаются; это тот же заданный CQ-контракт, а не утверждение о единственном физическом Info.

Для исходного фактического парсера 0/10 **новая** средняя длина равна `C_hi=M+sum_j,theta r_theta q_hi(theta,j)`. Рассмотрим уже используемый класс:

```
P_hi=C_hi-(b_Q I_Q+b_C H_C)/ell,
ell=log(phi), b_Q,b_C>=0 FIXED, a=b_Q+b_C>=0.
```

Теперь ограничение a>=1 не требуется. На любом сохранённом компактном интервале `1/2<q_min<=q_hi<=q_max<1` положим

```
L_min=log(q_min/(1-q_min))/ell > 0,
L_max=log(q_max/(1-q_max))/ell.
```

Исходная operator-log оценка BCPR и условные odds полной классической записи дают, с `u_Q=partial_q I_Q`, `u_C=partial_q H_C`,

```
-L_max r_theta <= u_Q/ell,u_C/ell <= -L_min r_theta.
```

Доказательство знака использует сравнение положительных блоков B1/B0, а не диагональность M_theta. Для H_C условная вероятность исхода1 при остальных фиксированных записях — выпуклая комбинация q_hi; её odds лежат в том же интервале. Это прямая high-probability специализация существующих полных оценок, не новая формула информации.

Поэтому

```
D_q P_hi=sum_theta,j w_theta,j Dq_hi(theta,j),
w_theta,j=r_theta-(b_Q u_Q+b_C u_C)/ell,
(1+a L_min)r_theta <= w_theta,j <= (1+a L_max)r_theta.
```

На точном полном NPS диапазоне можно взять `q_min=p`, то есть `L_min=1`. При q-зависимой или физически меняющейся паре b_Q,b_C остаются её дополнительные строки; теорема относится к фиксированным коэффициентам.

## 3. Тот же полный геометрический источник и настоящий right lift

Потребим существующий common-field конструктор, **только где его реальные гипотезы выполнены**:

```
q_theta,j*=q0,j+g_j I_h(Y), g_j>0,
Dq_theta,j=g_j A_theta,j* E_h, E_h=DI_h,
A_theta,j R_h=I.
```

Новая схема даёт `Dq_hi=-k Dq` и потому

```
Gamma_hi=k sum_theta,j g_j w_theta,j
          >= k(1+a L_min) sum_j g_j > 0,
A_hi=sum_theta,j k g_j w_theta,j A_theta,j/Gamma_hi,
A_hi R_h=I,
F_hi/Gamma_hi=-A_hi* E_h+epsilon_hi.
```

Условные состояния старых записей усредняются после применения той же оценки, а не объявляются независимыми. Нулевой r_theta не делится на себя. Полный covector разных коэффициентов может не быть пропорциональным; сохранение общего right lift даёт faithful recovery всех компонент.

На scalar-profile секции оба информационных функционала равны `sum_j h(q_hi,j*)`, так что полный reduced derivative имеет множитель `-Gamma_hi`. Его вычисляют из всей функции; деление действия на полевой gain перед дифференцированием не производится. При `a=0` остаётся положительный gain от одной **известной цены регистрации**. Это ещё не вся физическая цена истории.

Коэффициентные константы равномерны на **всём a>=0**:

```
(1+a L_max)/(1+a L_min) <= L_max/L_min,
a/(1+a L_min) <= 1/L_min,
(B_C+a B_I)/(1+a L_min) <= max(B_C,B_I/L_min).
```

Следовательно, существующий finite-comparison контроль нелинейных отклонений даёт `C (L_max/L_min) nu/|t|`, с настоящими basis/right-lift факторами. Из `|q-q*|<=C g nu` следует `|q_hi-q_hi*|<=k C g nu`, и k входит и в ошибку, и в настоящий gain. Ранг, подготовка и CODE-базис на endpoints могут меняться по исходному двуместному bound; гладкость логарифма на нулевом собственном значении не предполагается.

## 4. Настоящий новый support и часы

Для noisy **пары** r,t, без sharp cursor, допустимый выход после E0 находится в

```
P_good=|0><0|_r tensor I_t + |10><10|_(r,t).
```

Его масса на исходном born `(a0,p) tensor (a0,p)` равна

```
v† P_good v=p+p³=:rho_good² < 1.
```

Это noisy масса; sharp `p²+p⁴` здесь не используется. Для M свежих пар с точным сохранением предыдущих записей и record-disjoint окончанием

```
P_good,total V_total=V_total,
J_born† P_good,total J_born=(p+p³)^M I_true,
||C_total||=||J_born† V_total|| <= rho_good^M.
```

Два G стоят до E0, поэтому этот bound не меняется. Все неиспользованные born modes остаются в полном carrier/heat. Для `J=-Tr log[(1-z)I+z C†C]` уже доказанные P2/P3 теперь дают

```
||DJ|| <= (2zr/(1-z)) rho_good^M N_total,
0<=-r log(1-z)-J <= (zr/(1-z)) rho_good^(2M).
```

При фиксированном core и точности новый pre-padding count увеличен на **2M**. Если прежняя схема имела `N_b<=C_n M`, новая имеет `N_b'<=(C_n+2)M`; обе конечные каталожные ветви уравниваются до общего реального layout. Далее используются именно `N_b'` оплаченных CX;CX-пар, `N_total=3N_b'`. Полный growing-clock owner CL10–12 применяется только при соблюдении его прежнего clock/cut/mode интерфейса. Его экспоненциальная оценка и новый bound J после деления на `Gamma_hi>=k M g` стремятся к нулю с реальными norm/right-lift множителями.

Таким образом, при сохранённых интерфейсах можно подавить весь выбранный master H+J и фиксированный старый ledger на растущей новой истории, включая a=0. Это перенос исходного P1–P16 доказательства с **новым support и actual count**, не разрешение вычеркнуть текущую физическую работу.

## 5. Что снято и что осталось

Снята математическая необходимость a>=1 и прежняя компенсация положительных entropy-вкладов на noisy collar. Новое слово использует ровно два дополнительных native G; не требуется новый угол, X, новое рождение или настроенный коэффициент Info.

Не сняты: принадлежность **полной** физической цены указанному классу; текущая работа и vertex Info, не входящие в него; независимые изменения коэффициентов, scene/birth/terminal; допуск изменённой постановки сравнения. Новый эффект E_hi отличается от фиксированного эффекта старого H.1: старые A/D нельзя объявить перенесёнными только из исполнимости слова. Из `q=(A-q_hi)/k` следует известная обратимая калибровка среднего результата, но это не равенство инструментов, индивидуальных исходов или полной цены.

Для неизвестной добавочной текущей цены W_M остаётся реальный тест `||R_h|| ||D W_M||/Gamma_hi ->0` либо доказанное вхождение её полного источника в тот же класс. Линейный по M неизвестный вклад сам по себе не исчезает. Два G не объявляются бесплатными на основании постоянства числа вызовов.

Это конкретная новая конструкция и более широкий математический потребитель физического C. Полный вывод ОТО этим не заявлен. Следующий шаг — независимая проверка нового native слова и его truthful task/admission, затем использование **реальной** цены добавленных операций.

### Точный контроль против бесплатного восстановления старого бита

Даже случайная классическая обработка одного нового исхода не возвращает исходный двухисходный эффект. Пусть вероятности выдать старый исход1 из нового0/1 равны `u,v∈[0,1]`. Тогда полученный эффект есть `uI+(v-u)E_hi`. Равенство его старому E на несмещённом полном двухспектральном носителе требует `v-u=-1/k`. Но `0<k<1`, тогда как `|v-u|<=1`: противоречие. Это запрет указанной однобитной обработки, не запрет любых future tests на полном сохранённом банке.

Оценка `(A-b)/k` имеет правильное математическое ожидание q, но её значение при b=0 равно `A/k>1`, поэтому не является вероятностным декодером. Заявленный перенос проверки среднего с точностью epsilon должен использовать реальную точность `k epsilon` нового среднего и оплату всего статистического протокола. Такой перенос не следует из одной алгебраической калибровки.

В точке старой noisy компенсации `q≈0.412469881`, `a=1/L(q)≈1.360261028` прежняя производная равна нулю. У нового слова `q_hi≈0.800686707` и производная той же фиксированной цены по исходному q равна примерно `−4.381269561`. Эти десятичные значения — контроль механизма; аналитический строгий знак доказан выше для всего диапазона и всех a>=0.

### Проверка

`check_high_report_source.py` проверяет точные Golden тождества и отдельно численные производные полной совместной CQ/классической цены для действительно некоммутирующего сжатого POVM, смешанных входов и rank-one scalar-section контролей. Численные проверки не подменяют аналитические неравенства. Native all-column проверка двух добавленных G принадлежит отдельному пакету B `open/round10`; его границы нового AD1 сохраняются. Полный геометрический word и его physical Cost−Info не воспроизводились.
