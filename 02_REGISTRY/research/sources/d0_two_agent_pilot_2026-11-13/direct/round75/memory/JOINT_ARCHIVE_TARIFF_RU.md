# A75. Один зарегистрированный разряд компенсирует пять единиц прежнего тарифа в двух определениях информации

Пусть старый оплаченный архив \(A\) уже измерен. Его частью является ограниченный целый расход \(W(A)\), например длина всех фактически напечатанных символов определённого участка. Для двух определений информации можно **одним последующим прибором** получить одинаковый перепад цены \(-5\) на каждую единицу \(W\). На пяти подлинных приготовлениях это в точности компенсирует их общую среднюю ранее оплаченную величину на всём рассматриваемом полевом семействе. Конструкция требует физической возможности условного выбора между настоящим свежим Golden-исходом и известным детерминированным исходом. [Контракт информационных цен новой записи](../history/JOINT_EQUATIONS_RU.md#обе-цены-за-информацию-дают-один-набор-решений) · [Точная проверка всех выходов](check_joint_tariff.py)

## Две измеряемые цены и один порог

У каждого нового бита фиксирован код \(0,10\) с длиной \(1+b\), эталон \(\mu=(p,p^2)\), \(p=1/\varphi\). Записываем упорядоченную пару новых цен. Первая — длина минус приращение энтропии полного архива с квантовой памятью. Вторая — длина минус приращение относительного выигрыша к согласованному полному эталону, который для новых битов использует \(\mu^{\otimes n}\) условно на прежнем архиве. Тогда для распределения свежего исхода \(P\) эти две величины равны \((D_\varphi(P\Vert\mu),H_\varphi(P))\). Это даёт три точные строки.

| Реальный выход | Длина минус энтропия | Длина минус относительный выигрыш |
|---|---:|---:|
| Всегда 0 | 1 | 0 |
| Всегда 1 | 2 | 0 |
| Свежий Golden, вероятности \(p,p^2\) | 0 | \(h=p+2p^2=2-p\) |

Сохраняем старую метку \(\chi\in\{0,1\}\) и один независимый зарегистрированный выбор \(I\), у которого \(\Pr(I=1)=p\) (достаточно назвать нуль его исходной Golden-записи этим событием). Общая цена и энтропия самого \(I\) постоянны. Записываем все 13 выходов таблицы. Сравниваем условные средние при \(\chi=1\) и \(\chi=0\).

| Количество выходов | При \(\chi=0\) | При \(\chi=1\) |
|---:|---|---|
| 3 | Свежий Golden | 0 |
| 1 | Свежий Golden | 0, если \(I=1\), иначе свежий Golden |
| 8 | 1 | 0 |
| 1 | 1 | 0, если \(I=1\), иначе 1 |

Для первых четырёх выходов разность пары цен равна \((3+p,-(3+p)h)=(3+p,-5)\), поскольку \((3+p)(2-p)=5\). Для остальных девяти она равна \((-8-p,0)\). Итого получается **ровно \((-5,-5)\)**. Никакой отрицательной буквальной платы схема не печатает. Снижаются условные средние реально напечатанных длин за вычетом выбранного информационного приращения.

На смешанном старом RIGHT формулы сохраняются, если при фиксированных реально зарегистрированных \(A,I\) новые состояния независимы от RIGHT и все перечисленные свежие исходы сохранены. Тогда для энтропии действует цепное правило, а для относительной энтропии нужна указанная условная факторизация эталона на каждой старой метке. Сам взаимный выигрыш \(I(R:B_{\rm new}\mid A,I)\) в этой конструкции равен нулю. Смена этого операнда меняет вторую цену.

## Прежняя работа в одном полном протоколе

Положим сначала \(0\le W\le M\), \(W\in\mathbb Z\), и используем \(M\) порогов \(\chi_j=1[W(A)\ge j]\). Если присвоены лишь целые знаковые значения, можно прибавить известную константу. Один и тот же зарегистрированный \(I\) допустимо переиспользовать во всех порогах; условно на \(A,I\) свежие выходы независимы. При обеих информационных конвенциях получаем точное равенство для компоненты ожидаемой цены
\[
 \Delta_{\rm new}(Y)=C-5\,\mathbb E_Y W(A).
\]

В том же полном протоколе запустим пять отдельно действительно приготовленных старых опытов при одном поле \(Y\). Все их подготовители, длительности, отказы, сырые архивы и условные квантовые состояния сохраняются. Если в каждом опыте исходный тариф входит в стоимость с коэффициентом один и имеет один и тот же закон или хотя бы ожидаемое значение, сумма пяти средних прежних тарифов равна \(5\mathbb E_Y W\). Для управления продолжением достаточно \(W\) из **первого** из пяти архивов. Тогда сумма указанной ранее оплаченной части и нового чистого продолжения постоянна в каждой конвенции. Производная исчезает даже при движущейся вероятности каждой старой метки. Равенство относится к средним; на отдельной совместной реализации \(\sum_{j=1}^5 W(A_j)\) обычно отличается от \(5W(A_1)\). Для аддитивности *энтропий самих пяти входов* нужны независимые приготовления: равенство пяти средних расходов само по себе её не даёт.

Если исходная стоимость работ условно зависит от скрытой памяти, но её условное ожидаемое значение при каждом \(A\) равно заранее известному поленезависимому целому \(W(A)\), тот же результат верен для средних. Невидимая вариация цены при одном и том же \(A\), изменение общей готовности без регистрации отказов, нецелая ставка без отдельного механизма и нелинейная общая цена пяти часов требуют своих данных. Предыдущие информационные начисления обеих конвенций не входят в \(W\) автоматически. Для квантового указателя их собственные условия разобраны отдельно. ## Физический допуск переключателя

Условный выбор делается **после** измерения адресов. При разрешённом классическом управлении можно заранее подготовить независимый Golden-провод и отдельный настоящий нулевой провод, затем прочитать один из них по зарегистрированному адресу. Неиспользованный провод остаётся чистым на каждой классической ветви. Подготовка этих проводов, чтение выбранного адреса, вычисление порога, исходная единица для детерминированного выхода, сохранение адреса, прогноз времени и все служебные метки принадлежат действительному расписанию. Если для архитектуры обязателен терминальный замер и второго провода, его дополнительная зависимая информация включается заново. Аналогично оба исхода можно реализовать физическим условным выбором готового прямого слова подготовки. Этот допуск не следует из названия «классическое управление».

Один фиксированный когерентный компилятор с \(n\) контролями пока имеет точную формулу Грея для степени \(G^{k2^n\chi}\). Она не реализует автоматически \(G^{-\chi}\) или условную перестановку двух неизвестных проводов. Одного тождества \(G^{-1}=ZGZ\) для неуправляемого вентиля тоже недостаточно. Для такого требования нужна отдельно доказанная реализация контролируемого считывания либо допустимый нативный предел с ошибкой полного источника. И вычислительные затраты переключателя могут зависеть от поля даже при одинаковом числе выданных битов. ## Почему в этой конечной схеме возникает именно пять

Пусть у конечного писателя каждая случайная условная запись есть либо \((p,p^2)\), либо её перестановка, а остальные записи детерминированы. Все промежуточные случайные результаты сохраняются. При полном эталоне для фиксированного числа новых кодовых слотов (детерминированное заполнение разрешено) вторая цена равна условной энтропии всей последовательности. По цепному правилу она равна \(h\,\mathbb E N_G\), где \(N_G\) — число действительно случайных Golden-записей. На фиксированной старой метке вероятность каждой вершины такого конечного дерева лежит в \(\mathbb Z[p]\), поэтому \(\mathbb E N_G\in\mathbb Z[p]\). Следовательно, для целого перепада \(k\) по старому флагу необходимо
\[
 k/h=k(3+p)/5\in\mathbb Z[p],\qquad 5\mid k .
\]
Последнее следует из линейной независимости \(1,p\) над \(\mathbb Q\) и единственной целой записи элемента кольца. Число 5 — наименьший ненулевой целый перепад в обеих конвенциях внутри указанных ограничений. Произвольные когерентные выходы, неизвестная смешанная память, отбор без сохранения всех исходов или настоящий неограниченный селектор не обязаны давать энтропию вида \(h\mathbb Z[p]\). Полученная компенсация известного тарифа дополняет конструкцию, в которой оплаченная часть имеет минимум на совместных уравнениях. Для самих физических уравнений остаются все прочие источники полной цены. [Критерий оставшегося отклика для корней](../history/JOINT_EQUATIONS_RU.md#что-потребуется-от-полной-цены)
