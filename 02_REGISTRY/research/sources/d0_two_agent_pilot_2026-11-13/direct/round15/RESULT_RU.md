# D0 → ОТО: управление источником и передача квантового ресурса

Продолжение выполнено по текущим основаниям D0, без новых исходных материалов.
В пилоте работали два исследователя: A — направленная сборка источника,
B — независимая конструкция и проверка её совместимости.

**Новый результат:** исходное дерево формулы источника получило конечную
обратимую схему вычисления инструкций. Она выбирает ветви, раздельно ведёт
номера Choi/CAR копий и выдаёт все исходные адреса. Достаточны рабочие стеки
из 11 и 4 записей; число шагов фиксировано, история сохраняется. Логические
операции имеют явную native подстановку A14.

Второй агент построил B31: из 28 фиксированных попыток правильное квантовое
состояние передаётся в выход управляемым обменом, без измерения и без
стирания failure records. Я независимо повторил четыре проверки B31;
шесть выходных файлов совпали побайтно.

Для **одного вычисления инструкций** при указанных входных и физических
условиях доказана идеальная вероятность готовности выше 1/2. Это компонентный
результат; для семи независимых процедур вероятность перемножается.
Суммарная ошибка уже собранных частей семи report вызовов меньше 2^-4058.
Полная схема остаётся крайне дорогой; огромные native слова представлены
конечной грамматикой, не исполнены целиком.

Проверены 496166 вариантов перехода, все 72192 адреса и 76913 размещений
узлов по копиям. Два полных фактических шага исполнены по отдельным
логическим операциям, включая непустые выходные регистры. Независимая
проверка B32 и её точные границы закреплены в `ROOT_REVIEW_B32.json`.

**ОТО пока не выведена.** Дальше требуется исполнить инструкции на самих
квантовых копиях, собрать подготовки семи банков и весь физический
граф с его исходными marks/clock, затем установить связь полного
Cost−Info с геометрическим источником. Подбор Info или новых коэффициентов
не использовался. Полная готовность источника и `GR_closed` остаются false.
