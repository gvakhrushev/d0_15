# Продолжение: полный источник тонкой записи и более простое исполнение

Получен новый промежуточный результат на пути D0→ОТО. Полный вывод пока не завершён.

Теперь в расчёте учтена дополнительная действительно зарегистрированная метка из существующей конструкции §7fy. Вместе с ней учитывается настоящая длина её кода. Для рассматриваемого класса цены найден глобальный минимум по свободной подготовке хвоста и полному сохраняемому квантовому инструменту. После этой минимизации коэффициент геометрического источника строго положителен для всех фиксированных неотрицательных коэффициентов информации. Независимые подготовки и исходные полевые переменные не связывались между собой.

Проверка выявила важную границу: прежняя Golden настройка хвоста стационарна только при прежнем коэффициенте информации. Использовать её без изменений для всех коэффициентов нельзя. Новый минимум учитывает эту строку явно.

Удалось также упростить исполнение: для данного компонента цены полное восстановление большого квантового банка не требуется. Достаточно управлять хвостом настоящего исходного считывателя. При нулевом коэффициенте информации минимум достигается **точным словом из 36 разрешённых операций, без новых рождений**. Оно сохраняет исходные кодовые исходы на всех входных столбцах и не удаляет прежнюю историю. Второй агент независимо проверил это слово; корневой агент воспроизвёл проверку.
