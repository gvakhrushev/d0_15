# A73. Абсолютный отклик суммы историй через возврат к первой записи

У Book II вес истории равен $w_x=\varphi^{-S_x}$, где $S_x$ включает затраты на рёбрах и информацию в посещённых вершинах. В сумме по историям каждый путь входит один раз. Наблюдатель, который запускает прибор и усредняет вес, обычно получает другую величину, поскольку записи возникают с вероятностями $P_x$. Ниже показано, как снять этот множитель на конечной зарегистрированной семье. Можно варьировать одновременно поле, подготовку и закон остановки внутри исходной истории. ## 1. Достаточно воспроизводить исходный прибор и сравнивать полные записи

Фиксируем конечный список $X$ из $d$ различимых исходных историй, положительные $P_x$, гладкую окрестность с тем же списком. Первый реальный запуск даёт запись $X_0=x$. Удерживаем именно её. Повторяем независимые приготовления при том же поле до первого совпадения новой записи с $x$. Обозначим номер совпавшего повтора через $T$, считая с единицы. Повторы могут совпадать между собой до возвращения к $x$. Сравнение должно проверять полное равенство нужной классической истории. Сравнение конечного следа, имеющего несколько неразличимых предысторий, даёт другую сумму.

Для заданного $x$ выполняется `Pr(T>n|x)=(1−P_x)^n`. Пусть $A_0$ — прочитанная величина исходной истории с условным средним $a_x$, условно независимая от свежих повторов. Она может быть вычислена из полных начислений, если они зарегистрированы. Также подходит фактическая бинарная проба веса с условной вероятностью $a_x=\kappa w_x$ при известной постоянной $\kappa>0$. Отсюда

    E[A₀ min(T,N)] = Σₓ aₓ [1−(1−Pₓ)ᴺ],
    E[A₀ T] = Σₓ aₓ,      E[T] = d,
    E[T²] = 2 Σₓ 1/Pₓ − d.

Доказательство следует суммированием вероятностей дожития от 0 до $N-1$. Тождество справедливо покомпонентно для $a_x=w_x[q(x)]$ при известном зарегистрированном классе памяти в конечной алгебре Book II. Это даёт сам элемент алгебры. Логарифм физической наблюдаемой требует выбора обоснованного вещественного положительного сектора. На положительной скалярной сумме абсолютный полевой отклик равен `D log E[A₀T]` для постоянной `κ`. Если калибровка зависит от поля, вычитается `D log κ`.

При $P_x\ge\delta>0$, $|a_x|\le M$, и любом касательном направлении ошибка производной между конечной и полной суммами не превосходит

    (1−δ)ᴺ Σₓ |D aₓ| + N M (1−δ)ᴺ⁻¹ Σₓ |D Pₓ|.

Следовательно, можно заранее задать конечный горизонт, выполнить все приготовления и учесть только действительные совпадения с первой записью до этого горизонта. Для секанты с шагом $t$ нужна ошибка значения $o(|t|)$ относительно физического усиления и нормы переноса. Среднее $E[T]=d$ само по себе не контролирует дисперсию, ошибку производной или затраты на полной растущей сцене.

**Собственная оплата повторов.** Пусть в каждом достигнутом повторе при первой записи $x$ и новой $y$ оплачивается величина с условным средним $c(x,y)$, одинаковым на каждом повторе. Предыдущие неудачи условно не меняют новый прибор. Тогда суммарная средняя оплата до первого совпадения включительно равна $\sum_x\sum_y P_y c(x,y)$. Это следует из независимости нового опыта от события «достигли этого повтора». Если платится одна и та же стоимость приготовления новой записи $c(y)$, формула даёт $d\,E[c(Y)]$; исходное приготовление оплачивается отдельно. При $c(x,y)$, при меняющейся ширине памяти или цене хранения применение множителя $d$ требует самостоятельного вывода. Измерение суммы и тождество для платы самой измеряющей процедуры имеют разные правые части.

## 2. Когда абсолютный отклик можно получить из совпадений ещё проще

Рассмотрим положительные скалярные $w_x$, $Z=\sum_x w_x$. Введём $L=\sum_x P_x^2/w_x$. Одноточечное равенство $w_x=kP_x$ на полном носителе допускает проверку без равномерной подготовки списка. Определитель Грама

    Δ = (Σₓ Pₓ wₓ²)(Σₓ Pₓ³) − (Σₓ Pₓ² wₓ)²

равен нулю тогда и только тогда, когда есть такое $k>0$. Это равенство Коши для двух функций $w,P$ с мерой $P$. При наличии повторяемой условной пробы веса три числа получаются соответственно двумя независимыми пробами веса одной сохранённой полной записи, совпадением трёх независимых полных записей и совпадением двух с одной пробой веса. Масштаб проб учитывается в обоих слагаемых. Аналогично $L$ получается на совпавшей паре взвешиванием времени первого успеха пробы $κ w_x$ и умножением на $κ$. Здесь требуется возможность повторной пробы на том же $x$ со свежими помощниками. Простая повторная подготовка случайного $x'$ имеет другой закон.

Запишем $H(P)=-\sum P_x\log P_x$, $\ell=\log\varphi$ и $\bar S=\sum P_x S_x$. Для $R_x=P_x^2/(w_x L)$ точны формулы

    H(P) + log L − ℓ S̄ = D_KL(P || R),
    ZL − 1 = Σₓ (Pₓ−πₓ)²/πₓ,      πₓ=wₓ/Z.

При $Δ=0$ обе правые части и все их первые производные равны нулю в любой гладкой двусторонней вариации. В частности,

    −D log Z = D log L,
    ℓ D S̄ = D H(P) + D log L.

Для первой строки прямая проверка даёт $DL=(2/k)\sum DP_x-(1/k^2)\sum Dw_x=-DZ/k^2$. Не требуется $Dw_x=D(kP_x)$ в точке. При нескольких исходах, слитых в одну метку, испытание Грама относится только к наблюдаемой метке. Даже при нулевом определителе для меток чувствительность скрытых историй может различаться. Если одноточечное равенство отсутствует, первый метод всё равно измеряет $DZ$.

## 3. Проверка на штатной вероятности с движущимся прошлым

На защищённом скалярном участке SER берём реальную запись $b$ с вероятностями $P=(1-q,q)$. На независимо повторно приготовленном том же семействе есть холодный успех с квадратом возврата $c_0(Y)$, включающим оплаченный прежний возврат. Редкий флаг B134 даёт положительную массу $c(Y)=\Gamma[1-z+z c_0(Y)]$ при фиксированных $Γ>0, z=2^{-20}$. Для каждого удержанного $b$ учитываем совместное событие «новая запись совпала с $b$» и «независимый холодный опыт удался». При независимых доступных приготовлениях его условный вес $w_b=c(Y)P_b$. Для суммы этих двух весов и для цены, определённой через эту пробу, получаем

    Z=c,     L=1/c,     J=−r log(1−z+z c₀),
    ℓ D S̄_пробы = h′(q) Dq + DJ/r.

Здесь $r$ — действительный ранг скалярного корня. При изменении прошлого $Dc_0$ входит полностью. При $c_0=0$ или ненулевом $c_0$ сама формула регулярна вследствие $z<1$. Изменение нескалярного корня требует самостоятельной схемы считывания детерминанта. Отдельный опыт B143 исследует этот вопрос. ## 4. Какие данные различают полные гипотезы

Если прочитаны только полные классические метки и их частоты, семейства $w_x$ и $e^{t}w_x$ имеют при $t=0$ одинаковые базовые веса и одинаковые нормированные относительные веса во всей окрестности. Их $D\log Z$ различаются на единицу. Если допустимая Book-история имеет нулевую наблюдаемую массу во всей окрестности, изменение одного её веса также меняет $DZ$ без единого изменения записей. Тест охватывает заявленную область ровно тогда, когда каждый её путь с положительным весом учитывается и подготовка воспроизводима. Добавление невидимого скрытого класса к $Q_8$-сектору способно изменить и саму алгебраическую сумму. Универсальное отождествление наблюдаемой цены и исходной Cost−Info этими примерами не опровергается. Они устанавливают, каких данных из одних частот получить невозможно.

Для исходной задачи остался конкретный переход. На действительном журнале D0 нужны либо значения платы за рёбра и информацию в посещённых вершинах с учётом приготовления и часов, либо независимый физический тест их абсолютного веса. После этого можно применить первую формулу без предположения, что Born-частоты пропорциональны весам. Для вывода ОТО потребуется сопоставить вычисленный ковектор с геометрическими и материальными строками на том же допустимом семействе и проверить нормированные остатки при уточнении.
