# A34 — полный остаток sampler через структуру исходных f/q

Для неизменённых B25/A30/A32 получена верхняя оценка всего
2688-компонентного математического ковектора конечных сравнений:

    ||C||_2 <2^-17,
    ||C-E_geom(Ybar_actual)||_2 <2^-16.                     (1)

Нормировка C — Gamma0=Gamma_s/s, координаты — исходные raw-u,
экспоненциальные proper links и две Psi при фиксированных PF/collar.
Учитываются actual A31 decoder/Jacobian, конечные reference/report
поправки, native core error и вся A32 finite H+J/heat error. Вместе
с A33 это даёт 2^-45<||C||<2^-17: малый, но доказанно ненулевой
остаток в данной нормировке. Это не точная стационарность и не полный
Cost−Info источник с независимыми controller/reader/old-history rows.

Оценка потребляет тот же точный E_geom(Y0)=0 из B24/B65. В отличие
от грубого T10 cap 4620 используется реальная полиномиальная структура
и независимость исходных SAM bits. Новых коэффициентов или реализации
sampler здесь нет; s остаётся 2^-30.

## 1. Исходная семантика и реальный stencil

На SO-секции R2(U)=U и sharp=U^-1. Исходный f_x — сумма шести
CAR trace terms, билинейная по различным coframe столбцам каждой
грани и линейная по каждому из ЧЕТЫРЁХ exterior-link matrices в
их исходном порядке. Их адреса на L4 попарно различны. Исходный
q_x=nu^-2 sum_(r,t)(u_r^T eta u_t)D_r Psi·D_t Psi.

Фактические B21/B24 каталоги в checker проверяются для ВСЕЙ
диаграммы: 1024 coframe, 1536 link, 128 matter координат. Каждый
free link входит ровно в шесть face instances; каждый matter site —
в пять base stencils. Каждая роль coframe входит в три faces только
на своём base. После одного inverse-rho исходный SITE даёт h^4=1/256.
У произвольных collar coordinates нет независимых SAM bits.

В последующих оценках V=s²p³<s²/4, kappa=1-2p²<1/4.
B21/B65 дают ||u||<2, ||u_r||<1, ||U0^±1||<17/16.
На всём cube ||D Psi||_F<1: центральная норма pi/50, возмущение
меньше 24s. Все числа проверяются рационально с pi<22/7.

Для функции F обозначим вектор её исходных sampling secants

    (T_s F)_j=E_-j[(F(Y_b|bj=1)-F(Y_b|bj=0))/s].

Здесь F_geom=sum_x h^4(f_x-k0 q_x), а DF_geom(Y0)=0.
T_s — действительное линейное усреднение таблицы источника,
не свободное изменение primitive G и не новое действие.

## 2. Геометрические coframe строки

Из билинейности по разным coframe столбцам каждый own coframe
secant равен производной. Остальные coframe variables усредняются
точно до центра. Их независимость от link blocks оставляет только
mean-link errors. A33 доказывает для каждого forward/inverse
exterior factor ошибку <34s², норму <3/2, а для петли <459s².
Та же оценка применима к любой coframe role/component, не только
нулевой строке A33. После трёх faces, trace16 и исходного масштаба:

    |(T_s sum h^4 f)_j - (D sum h^4 f)_j(Y0)| <2^10s².     (2)

Нулевая центральная производная каждой отдельной f-строки не
предполагается: в (2) явно вычитается её истинное значение.

## 3. Геометрические link строки

Для собственного шестибитного link block положим
A=dLambda(Theta), K=dLambda(K_j), ||K||<=4, ||A||<24s.
Усредним остальные пять bits внутри этого block. Ряд exp(A)
до второй степени даёт точно

    E_-j[(exp(A1)-exp(A0))/s]
        = K+(s kappa/2)K²+R_j,
    ||R_j|| <= 4608s²/(1-24s).                            (3)

Линейные cross terms второго порядка сокращаются вследствие
E Theta_other=0. (3) не предполагает коммутирования генераторов.
Остаток оценивается суммой норм двух third-order tails, делённой
на s. Для inverse factor exp(-A) меняется знак K, оценка та же.

После центрального Lambda(U0^±1), норма которого <4/3, отличие
own secant от истинной link derivative меньше

    (8/3)s + [6144/(1-24s)]s² <3s.                       (4)

Нормы own derivative и secant меньше 6. Три остальных независимых
mean-link factors отличаются от центральных на <34s² и имеют
нормы <3/2. Телескопирование даёт для производной петли ошибку

    3s(3/2)^3 +3*34s²*6(3/2)^2 <11s.                    (5)

Остальные coframe пары усредняются точно: в каждой грани их два
различных column blocks. Шесть действительных incidences одного
link, ||creator commutator||<=2, trace16, -1/8, масштаб 400/9
и h^4=1/256 дают на каждую link строку

    |(T_s sum h^4 f)_j-(D sum h^4 f)_j(Y0)|<46s.          (6)

## 4. Материальные coframe строки

Матрица B_rt=D_r Psi·D_t Psi после усреднения получает covariance
поправку. В каждой её entry она по модулю <=4V/h², поэтому норма
одной четырёхэлементной строки <=8V/h². Это учитывает общий base,
collar и совпадение двух направлений; независимость самих разностей
поля не предположена.

Для coframe coordinate u[a,mu] квадратичный own secant добавляет
s kappa eta_aa E|D_mu Psi|²/nu². Сдвиг линейной части из covariance
ограничен 32V/(nu²h²), поскольку ||u||<2. Поэтому локальная разность
с истинной центральной производной удовлетворяет

    |T_s q_x-Dq_x(Y0)|_j
       <= s/(4nu²)+32V/(nu²h²) <s.                       (7)

Эта coframe coordinate участвует только в q своего base. С учётом
k0<24, h^4 и (2) весь геометрический coframe error на строку <s.

## 5. Материальные Psi строки

Для каждого свободного coframe base независимое усреднение даёт
точное равенство, а не неявное закрытие higher moments:

    E[u^T eta u]-u0^T eta u0 = V Tr(eta) I =-2V I.

После nu^-2 обозначим поправку метрики delta_g. Имеем
||delta_g||<2s², ||g0||<12, ||E g||<13. У fixed collar delta_g=0.
Пусть v=partial(D Psi_A)/partial Psi_A(z). Для одного затронутого
base ||v||<=8 (в base это четыре компоненты -1/h, в соседнем — одна).
Квадратичный Psi secant тогда отличается от центральной производной
на

    2 v^T delta_g D Psi_A,0 +s kappa v^T(E g)v.

Его модуль <32s²+208s<209s. Ровно пять base stencils, h^4 и k0<24
дают на каждую из 128 matter строк error <98s. Другой Psi-компонент
не создаёт cross term: исходный q суммирует квадраты двух компонентов.

## 6. Сборка полного вектора и настоящего reporter

Для всех исходных 2688 направлений получено

    ||T_s F_geom-DF_geom(Y0)||²
       < [1024 +1536*46² +128*98²]s²
       =4480512s² <2^24s²,
    ||T_s F_geom||<2^12s=2^-18.                          (8)

Последнее равенство использует прежний точный геометрический root,
а не новый поиск. Исходный finite reference коэффициент 0<a_y<1
остаётся: I_tau=a_y sum h^4 f-k0 sum h^4 q+R.
По B65 1-a_y<2^-3084; по его scalar gradient envelope и (2),(6)
||T_s sum h^4 f||<2^19. Поэтому reference-vector error <2^-3065.

A33 оценил sup|R|<2^-1457 и каждую reporter secant <2^-1426.
Поскольку sqrt(2688)<55, полный reporter error <2^-1420.
Следовательно

    ||T_s I_tau|| <2^-18+2^-3065+2^-1420.                  (9)

## 7. Actual decoder и конечная полная operator-price

Пусть d_j=FD_j/Gamma_s для настоящих A32 пар конечных программ.
Вектор C=(1/u_sampling)J_actual^-T d — именно A31/A32 исправленная
математическая форма при Gamma0=Gamma_s/s. Отдельные actual native-core
и finite H+J/all-mode heat errors уже оценены в этой нормировке
каждая <2^-67. Их сумма не скрыта в (8).

Из ||J_actual-I||<2^-23 и (9):

    ||C|| <(2^-18+2^-3065+2^-1420)/(1-2^-23)+2^-66
           <2^-17.                                     (10)

Никакие actual Jacobian entries не заменены идеальными. B65 с
исходным scalar geometric Lipschitz <2^24 и A31 mean-centre shift
<2^-48 даёт ||E_geom(Ybar_actual)-E_geom(Y0)||<2^-24. С (10):

    ||C-E_geom(Ybar_actual)||<2^-17+2^-24<2^-16.           (11)

Это условное сравнение в одной фиксированной physical raw-диаграмме
L4. Размерность covariance и нормы не переносились из другого all42
short-collar сертификата; его tolerances здесь неприменимы.

## 8. Потреблённая предпосылка и границы

Получен реально малый векторный budget для ранее оставшегося
sampling/Taylor члена; общая оценка 4620 не была самой величиной
ошибки. Одновременно A33 доказывает строго положительную нижнюю
границу 2^-45 для ||C||, так что малость не означает нуль.

C собрана из 2688 отдельных конечных сравнений. Это не совместно
исполненная операция на произвольном вещественном направлении,
не derivative полного padded native centre и не stationary solution.
Сохранены все исходные условия A30 scalar source, A31 mean-map и
A32/R6/R11 operator-price. Непостроенные readers/records, независимые
источники, выбор этой истории исходной Cost−Info и uniform refinement
не входят в (11). physical_C_closed=false, GR_closed=false.
