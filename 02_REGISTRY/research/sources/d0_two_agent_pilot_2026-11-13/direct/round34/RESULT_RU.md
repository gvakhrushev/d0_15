# A34 — контролируемый полный остаток текущего sampler

Для неизменённой конструкции A30/A32, fixed L4 и s=2^-30 доказано
||C||_2<2^-17 и ||C−E_geom(Ybar_actual)||_2<2^-16 при Gamma0=Gamma_s/s.
В C входят 2688 отдельных конечных H+J сравнений с actual A31
mean-map correction. Учтены sampling, finite reference/reporter,
native core, finite-comparison и весь заявленный growing-clock heat.

Это потребляет недостающую малую sampling/Taylor оценку: билинейная
геометрия, независимые link blocks и точные материальные covariance
дают её без чрезмерно грубого Hessian cap 4620. Самопроверка и
независимый B67 подтвердили исходные stencil counts, символические
тождеcтва и точный векторный бюджет. Владельческие source/price
предпосылки сохранены, а не перевыведены из одной численной проверки.

Вместе с A33 имеем 2^-45<||C||<2^-17. Малость не означает нулевую
стационарность. Полный Cost−Info binding, реально независимые
внутренние уравнения, исходный выбор задачи/истории и uniform
refinement остаются открытыми. Чужие all42 root tolerances на эту
2688-мерную диаграмму не переносились.

Результат локальный. physical_C_closed=false, GR_closed=false.
