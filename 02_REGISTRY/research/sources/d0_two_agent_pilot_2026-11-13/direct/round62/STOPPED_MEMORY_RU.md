# Когда память и часы дают тот же предельный полевой отклик

**Результат.** На измеренной истории §7fy, которая останавливается при первом повторе, известную цену напечатанных символов можно уменьшить на прирост спектральной энтропии Реньи всей сохранённой записи любого фиксированного порядка α>1. В нормировке по отклику длительности эти две цены дают одни и те же предельные полевые уравнения при условиях ниже. Сохраняются внутренние изменения приготовления и зависимость момента остановки от поля. Это расширяет класс источников, пригодных для сравнения с ОТО. В исходной формуле Book03 по-прежнему требуется установить физический вес памяти и цену исполнения.

## Исходный опыт

В §7fq LC3 исходная вероятность клика равна q=p²+p³Q, p=1/φ. В §7fy каждая реально прочитанная проба имеет три метки с вероятностями ((1−q)p,(1−q)p²,q) и длинами (2,3,3). Пара проб образует один символ для сравнения, равный единице при двух кликах. Слово содержит k таких символов и один независимый флаг. Для первого повтора сравниваются только символы. Полная запись хранит также исходные метки, флаги, отрицательные сравнения и момент остановки. Конструкция использует оговорённый в §7fy режим свежих запусков. Канонически рождённые рабочие регистры входят в изометрии. Прежнее квантовое состояние ρ может быть смешанным и запутанным с сохраняемой ссылкой. [§7fy, устройство и часы, строки 158794–158904, AR1–AR3, строки 158912–159025](../../../../A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md)

Пусть i обозначает полный исход одного слова с вероятностью μᵢ, x(i) — его k символов для сравнения. В центральной конфигурации слова независимы с одним законом. Для каждого полностью сохранённого листа h с временем τ(h) обозначим его вероятность через πₕ. На разделе скалярных эффектов с полным сохранением выходов Kₕ* Kₕ=πₕ I на защищённом входе. Верные детерминированные копии и номер такта уже входят в h. Если окружающая среда отброшена, нужны её настоящие каналы.

## Полная вариация памяти

Положим Hα(ρ)=log Tr(ρ^α)/(1−α) в натуральных единицах, Γ=⊕ₕ KₕρKₕ*, Eₕ=Kₕ*Kₕ, Zα=Σₕπₕ^α. Из равенства ненулевых спектров KₕρKₕ* и √ρ Eₕ √ρ следует

    Hα(Γ)−Hα(ρ) = log Zα/(1−α),
    D[Hα(Γ)−Hα(ρ)] = α/(1−α) Σₕ (πₕ^α/Zα) Tr(ρα D Eₕ)/πₕ,
    ρα = ρ^α/Tr(ρ^α).

Первое равенство относится к значениям в центре. Второе получено дифференцированием полной матрицы до подстановки скалярного эффекта. Действительно, вклад листа в производную Tr Γ^α равен α πₕ^(α−1) Tr(ρ^α D Eₕ)+πₕ^α D Tr(ρ^α). В разности энтропий последний член точно сокращается, в том числе при изменении старого приготовления. Для α>1 нулевой блок имеет нулевую первую производную следа степени. Первое слагаемое сохраняет поперечные вариации операторов всех ветвей. Математическое взвешивание входа через ρα не требует физического приготовления его копии. [Определение энтропии Реньи](https://digicoll.lib.berkeley.edu/record/112906)

Для α>1 введём a=Σᵢμᵢ^α, wₓ=Σ_{i:x(i)=x}μᵢ^α, B=Σₓ wₓ². Пусть Zα,t — часть Zα при τ=t. Точно Zα,2=B. При τ=t последнее слово совпадает по x с одним из t−1 предыдущих. Снятие условия, что предыдущие слова различны, и суммирование по месту совпадения дают

    Zα,t ≤ (t−1) a^(t−2) B,
    Σₕ τ(h) πₕ^α / Zα ≤ Σ_{t≥2} t(t−1)a^(t−2) = 2/(1−a)^3.

Это оценка на полностью сохранённых листьях. Объединение тонких исходов для получения верхней границы даёт a≤[(1−y)^α+y^α]^k при y=q². Для α≥1+ε и фиксированного ε>0 эта величина экспоненциально мала на рассматриваемом компакте. Пусть для каждого единичного допустимого изменения, каждого достигнутого префикса и входа из этой семьи модуль производной логарифма условной вероятности тонкого слова ограничен Cₕ k. Тогда логарифмическая производная вероятности листа на входе ρα ограничена Cₕ k τ. Это оставляет независимыми изменения разных реально посещаемых приготовлений. На положительном скалярном разделе достаточно ограниченных производных полных эффектов каждой из O(k) меток на посещаемых входах. Изменение условного нормированного состояния в вероятности следующего скалярного эффекта в центре даёт μ Tr Dρ=0. Константы относятся к фактическим вариациям данного масштаба h. Получаем

    ‖D[Hα(Γ)−Hα(ρ)]‖* ≤ [α/(α−1)] 2 Cₕ k/(1−a)^3.

## Сравнение с реально прочитанной ценой и источником поля

Обозначим U=Eτ, L=[y²+(1−y)²]^(−k/2), ℓ=log φ. Средняя длина двух напечатанных токенов на одну пробу равна c=2+(1−q)p²+q. В центре на слово приходится 2kc. Средняя суммарная длина C равна 2kc U. При независимых изменениях в префиксах её ковектор равен **2kc DU+R**, где ‖R‖*≤C′ₕ kU. Это следует суммированием условных ожиданий длины на каждом старте пробы. Производная вероятности старта умножается на одно и то же центральное c, сумма этих вероятностей равна 2kU. В остальных членах дифференцируется средняя длина отдельной пробы, ограниченная вместе с производной на положительном наборе меток. Так в DU остаются и ранние, и поздние остановки.

Из AR1–AR2, U сравнимо с L, а U′(y)≥cₕ kL для больших k. При действительном положительном усилении поля g_y общий масштаб отклика Γ_C=2kc g_y U′ имеет нижнюю границу const·g_y k²L. Вычитание [Hα(Γ)−Hα(ρ)]/ℓ изменяет нормированный ковектор на Oₕ(1/(g_y kL)); собственный остаток напечатанной длины равен Oₕ(1/(g_y k)). Те же пределы после физического правого обратного Rₕ следуют при выборе k(h), для которого эти оценки, умноженные на ‖Rₕ‖, стремятся к нулю, вместе с исходными ошибками LC9 и конечных сравнений. При этих условиях применяются уже выведенные прямое следствие и восстановление решений заявленного класса для источника DU. Цена включает ожидаемую длину напечатанных токенов. Остальные обходы рёбер, считывания часов и подготовка, если они отдельно оплачены, должны войти в действительный остаток CD13.

В пределе Шеннона действует другой механизм §7fz TH4. Полный прирост энтропии содержит h_f DU с h_f=2k[h(q)+(1−q)h(p²)]+h(p²), где последнее слагаемое — флаг. Ошибка независимых условных производных составляет Oₕ(kU). Здесь h — двоичная энтропия в натуральных единицах. Для цены C минус этот прирост в единицах φ коэффициент DU равен 2k[1+2q−h(q)/ℓ]−h(p²)/ℓ ≥2kq−h(p²)/ℓ>0 при больших k. Поэтому тот же вывод сохраняется и для любой фиксированной выпуклой смеси шенноновского прироста и указанных приростов порядка α≥1+ε. Для производной смеси достаточно конечной смеси, либо фиксированной меры и установленной выше равномерной оценки. Меняющиеся физические коэффициенты дают самостоятельные члены. Значения α, смесь и приписывание этих компонент полной Info здесь не выбираются. ## Два конечных исполнения

Для обоих сравниваемых слов одного задания можно проверить положительные операторные границы e^(−η)μᵢI ≤ Eᵢ,префикс ≤ e^η μᵢI на каждом посещаемом входе. При совпадающих метках, точных пустых исходах и правиле остановки композиция даёт e^(−ητ)πₕI ≤ Eₕ ≤ e^(ητ)πₕI. По монотонности *собственных значений* отношение (Tr Γ_end^α/Tr ρ_end^α)/Zα лежит между средними e^(±αητ) с весами πₕ^α/Zα. Для s≥0, ae^s<1, логарифмическая производная наклонённой суммы по s ограничена 2/(1−ae^s)^3: в числителе применяем оценку Zα,t, в знаменателе сохраняем e^(2s)B. При отрицательном s средняя длительность убывает. Поэтому изменение прироста энтропии до каждого конца не превосходит

    [2 αη/(α−1)] /(1−a exp(αη))^3 .

У каждой из трёх законных меток и каждого флага вероятность в центре не меньше p²/2. Ошибка полного эффекта одной метки e≤p²/4 на любом достигнутом входе даёт η≤(2k+1)4e/p² на слово. Поэтому конечная проверка может работать с короткими операциями, сохраняя цену часов и все ветви. После деления разности концов на настоящие 2|t| нужны e=Oₕ(|t|), контроль ae^(αη) и исходный физический перенос. Доказательство не предполагает производную дискретного компилятора и не предоставляет автоматически этих границ для произвольных его слов. Новые положительные исходы вне старого носителя требуют отдельной оценки.

**Что проверяет этот маршрут.** На одной определённой истории широкая семья совместных оценок памяти и цены уже приводит к тем же предельным уравнениям даже с переменной длительностью. Book03 задаёт до считывания сумму амплитуд с упорядоченной памятью. При её свёртке могут сохраниться межветвевые члены, зависимость абсолютной нормы и собственная вариация работы. Не выведено, что их общий остаток на этом устройстве удовлетворяет CD13. Формулы дают проверяемый масштаб и место для сравнения полученного физического источника.
