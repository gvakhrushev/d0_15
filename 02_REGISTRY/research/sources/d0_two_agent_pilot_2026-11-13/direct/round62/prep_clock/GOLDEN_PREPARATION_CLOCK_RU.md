# A62. Сборка исходных часов H.1 из двоичных весов и измеримый тест нормировки

Вход — локальный `bf47f9e66228d0da835c2f3ab64ce6cebb7e6729`. Построена конечная таблица с золотыми весами, из которой одним математическим правилом восстанавливаются все исходные операторы программы с `SourceI`, включая рождения. На том же H.1 получен ненулевой полевой отклик запрещённого исхода, если вместо полярной части этой таблицы применять обычную нормировку состояния. Так две операции различаются на исходной физической подготовке.

## 1. Один обратный перенос на всём алфавите

Положим `p=1/φ, a=√p, p+p²=1`. Функция на цилиндрах будущего переносится к прежнему состоянию. Старая конфигурация задаёт строку таблицы `P`, а лист дерева выбирает конфигурацию будущего и знак памяти. В обычных ортонормированных координатах это `P̃=D_old P D_new⁻¹`, где `D_j` — квадратный корень из исходной меры цилиндров. Для одного бита `D=diag(a,p)`. Такая ориентация позволяет явно обработать рождение.

| Исполненная команда | Обратная таблица и проверка |
|---|---|
| Рождение | Строка `[p,p²]` усредняет два значения. После преобразования координат `[p,p²]D^{-1}=[a,p]=J^*`. Сопряжение даёт исходный канонический приготовленный бит на любой старой памяти. |
| `G` | Возьмём две буквы с весами `p,p²` на каждом разветвлении. Если старый бит 0, равные буквы дают новый 0, различные дают новый 1. Если старый бит 1, первая буква 0 даёт новый 1, первая 1 даёт новый 0 с исходным знаком минус. Все четыре листа учтены в каждой строке. |
| `CX` | Обратное чтение — значения функции на переставленных адресах. Диагональная замена координат даёт мономиальную матрицу с положительными модулями. Полярная часть есть сама обратная перестановка `CX^*`. |
| `SourceI` | На старом порте 0 берётся тождественное чтение, на порте 1 — сопряжённое действие исходной кватернионной единицы. Обе ветви сохраняют меру на рабочем адресе и все координаты Spin. |

Для `G` получаем точно

    P = [[1−2p³, 2p³], [−p², p]],
    P̃ = [[1−2p³, 2ap²], [−ap², p]].

При `G=[[a,−p],[p,a]]` матрица `G P̃` симметрична, поскольку `P̃_{12}−P̃_{21}=3ap²` и `P̃_{11}+P̃_{22}=3p²`. Её старший минор равен `a(p²+p⁴+p³)>0`, определитель `p(p²+p⁴)+2p⁵>0`. Таким образом правая полярная часть `P̃` равна `G^*`. Положительный множитель имеет ненулевой внедиагональный элемент. Для рождения берётся коизометрическая часть прямоугольного переноса, которая уже равна `J^*`.

Сопряжённые частичные изометрии дают буквально исходные `G,CX,SourceI,J` на каждом назначенном проводе. Тензор со старой памятью и произвольным защищённым эталоном сохраняет эти тождества. При подстановке их в **исходные** такты в прежнем порядке получаются прежние префиксы, разрешённые будущие измерения, часы, срез и операторная цена. Два символа в построении — алгебраическая сумма для одной матрицы. Физическая реализация в виде двух новых тактов потребовала бы собственной оплаты, работы и часов.

## 2. Решающий тест на действительном считывателе

В H.1 уже исполняется `E0=CX(r,t);G_t;CX(r,t)`. Для `r=1` его действие на хвост есть `G^{-1}`. Исходное `v=(a,p)^T` переходит точно в `(1,0)^T`, поэтому вероятность 11 и её полевой отклик равны нулю. Эта точность сохраняется в исходном продолжении `E0;L_k`. Тест ниже проводится на самом трёхтактном E0.

Возьмём построенное **до** полярного преобразования `K=P̃^T`, сохраним исходный CX, подготовку и считывание. На `r=1`

    X K X v = (a(p+2p³), p⁵)ᵀ.

Пусть `n_0=‖K v‖², n_1=‖X K X v‖², q=p²+p³Q`. Обе нормы строго положительны. Настоящие ветви r ортогональны, так что после общей скалярной нормировки, даже при корреляции r со старой памятью,

    Pr(11) = q p¹⁰ / [(1−q)n₀ + q n₁],
    D Pr(11) = p¹⁰ n₀ p³ DQ / [(1−q)n₀ + q n₁]².

При фиксированной таблице это ненулевая строка на каждом направлении `DQ≠0`. Для двух реально сопоставляемых конечных программ точный контраст имеет тот же числитель с `ΔQ` и произведение двух конечных норм в знаменателе. Любой общий скаляр амплитуды сокращается. Нормированная таблица с построенной полярной частью даёт точно ноль с исходными часами. Таким образом две процедуры различимы на исходной физической подготовке без доступа к произвольному скрытому входу.

## 3. Почему ориентация и положительный множитель существенны

Для проверки рассмотрена и прямая таблица, в которой вход задаёт столбец. Для входа 0 выходом служит первая буква, для входа 1 неравные буквы дают отрицательный выход 0, равные дают положительный 1. В координатах цилиндров получаем `K_f=[[p,−2p³],[p²,1−2p³]]`. У `D K_f D^{-1}` полярная часть также равна `G`. Подстановка самой матрицы на месте G в E0 дала бы амплитуду 11 на ветви `r=1`, равную `−p⁵`.

Однако ориентированная вперёд модель дерева с полным набором листьев и знаковыми перестановками имеет точный инвариант. Для одной базисной входной координаты все выходные коэффициенты лежат в `R=ℤ[p]`, и их сумма равна 1 по модулю `2R`. Доказательство проходит по дереву от корня. Каждый узел заменяет массу `s` на `ps+p²s=s`, а знак не влияет на вычет по модулю 2. Ранние остановки разрешены, если учтены все их листья. В базисе полного рабочего адреса и вещественного Spin знаковые перестановки также сохраняют сумму по модулю 2. Кольцо `R/2R` является полем из четырёх элементов, поскольку `p²+p+1` неприводим над полем из двух элементов.

Канонический **прямой** RAW-оператор рождения копирует значение в обе дочерние координаты. У любого вектора `w` в его образе координаты попарно одинаковы. Для `w∈R^n` это даёт нулевую сумму по модулю 2. Следовательно ни один ненулевой входной столбец полного конечного дерева из указанного класса в этот образ не попадает. Невырожденная замена координат справа, в частности полярная нормировка матрицы полного столбцового ранга, сохраняет образ. Ранг старой памяти произволен. Эта преграда для прямого пути совместима с точным обратным построением рождения в §1.

Для прямого `G_{raw}=aH, H=[[1,−p],[1,1]]` есть и устойчивая оценка в индуцированной координатной норме ℓ¹. Всякая такая полная знаковая таблица имеет норму ≤1, тогда как `‖aH‖₁=2a`. Расстояние не меньше `2a−1`. В классе произвольной маркировки листьев знаковыми перестановками нижняя грань точна. Действительно, `H/2=I/2+(1−p)X/4+(1+p)J_0/4`, где `X` обменивает две координаты, `J_0=[[0,−1],[1,0]]`. При глубине `m` наибольшая масса листа не превосходит `p^m`. Двумя последовательными порогами кумулятивной массы три группы листьев приближают коэффициенты этой смеси с ошибкой `O`p^m``. Норма `aH−H/2` равна `2a−1`. Это оценка абсолютного прямого переноса в указанной норме. Нормировка, физические тарифы и ковектор Эйнштейна в её утверждение не входят.

Даже на одном такте модели «две золотые ветви на столбец, по одной на каждый выход» произвольные положительные диагональные множители подготовки и терминала оставляют неизменным отношение `|g_{00}g_{11}/(g_{10}g_{01})|`. Для этой модели оно принадлежит `{p²,1,p^{-2}}`, для настоящего G равно `p^{-1}`. Построение §1 использует все четыре листа, сложение амплитуд и несводимый к скаляру положительный множитель.

## 4. Что осталось для физической цены

Таблица §1 использует уже имеющиеся два веса и знаки. Из определения `S(γ)=ΣCost−ΣInfo` пока не выведены именно условная группировка её листьев на данном адресе, их знаковые образы в физической памяти и **физическое применение** полярной части или эквивалентный закон для полного отклика. В частности, сумма представленных операторов не доказывает права стереть или объединить различимые упорядоченные классы историй. Ненулевой результат §2 относится к явно построенной проверочной таблице. Он не измеряет действительный пока неопределённый тариф. Статус `physical_C_closed=false`, `GR_closed=false`.
