# A27: подготовленные product sources и исходный закон семи отчётов

Потребитель — оставшаяся в A25/A26 предпосылка идеального source/report
закона H.1/T3–T5. Здесь рассматривается **идеальный сравнительный оператор**
A25 на объявленном каноническом RAW-входе. Его native error уже учитывается
A25, а physical birth/marked-map/Cost−Info идентификация остаётся открытой.
Новые вероятности, коэффициенты действия или Info не вводятся.
Область — текущий конечный L=4, h=1/4 и m=2688; uniform h→0 theorem
для этой конкретной компиляции здесь не утверждается.

## 1. Состояния, которые реально являются целями подготовки

При каждом фиксированном SAM label b идеальный A22 Choi preparer выдаёт

    |Omega_b> = 1/sqrt(N) sum_(a,i,j) J_b,a[j,i] |a,i,j>,
    N=32 A=65568, A=2049,

с нулевыми амплитудами на padding. Все J — исходные полные Julia32,
включая identity anchor a=0; их контракт и равномерная компиляция
потребляются из A19–A22/B42/B25. Нормировка следует из
`sum_a Tr(J_a^T J_a)=32 A`, а не из размерности padded регистра.

Reflection construction действительно имеет исходную ориентацию.
Если r — anchor, `c=<r,Omega>=1/sqrt(N)` и
`u=(r+Omega)/sqrt(2(1+c))`, то `R_u R_r r=Omega`.
На плоскости r,Omega это та же собственная ортогональная карта
`I+K+K²/(1+c)`, `K=|Omega><r|-|r><Omega|`; на её ортогональном
дополнении обе карты тождественны. Helper-free identity применяется
на идеальном private=0 fibre; произвольные dirty private не подменяются.

Идеальный A24 CAR preparer включает A23 vacuum/Fourier prefix, а затем
исходный A18 frame. Его выход равен

    sum_(z,a,r) m_b,z[a] chi_ref(z,r) |z,a,r>,
    m_b,z = sqrt(p)|1> + Psi_b,z,0|0>
            + sqrt(1-p-||Psi_b,z||²)|14> + Psi_b,z,15|15>.

Внутренний site z равномерный; RIGHT128 сохраняет исходные корреляции.
Для 64 Fourier cos/sin пар коэффициент 1/128 даёт точно
`sum_r chi_ref(z,r)²=64/128²=1/256` на каждом z. Внешний PF SITE —
другой регистр. Идеальный frame `R_um R_ustar` совпадает с
`O_m O_mstar^T`, поскольку `O_m=R_um R_e1`. На mstar он даёт m.
Никакого reset неизвестного RIGHT или старого D не используется.

A25 содержит ровно оригинальные B25 COPY_SLOTS: для каждого bank два
H_f-sign по 82 Choi и восемь H_q-sign по 2 Choi + 2 CAR. Всего
1260 Choi и 112 CAR. В исходном файле тип CAR называется `material`;
это явное переименование роли, а не изменение источника.

## 2. Настоящие исходные leaf moments

Пусть `t=(a,i,j)!=r`, a — queried адрес. Тогда на полном Choi carrier

    H_t=(N/2)(|r><t|+|t><r|),
    <Omega|H_t|Omega>=J_a[j,i].

Это точное алгебраическое равенство: anchor amplitude `1/sqrt(N)`
и queried amplitude `J_a[j,i]/sqrt(N)`. Coframe vacuum-to-grade-one
элементы дают исходные raw u; link grade-one элементы J имеют U/2,
поэтому исходный multiplier 32A (вдвое больше) даёт U.
Нормы остаются 16A и 32A. A15/A25 используют правильную упаковку
`(a<<10)|(i<<5)|j`, независимо проверенную B50 на всех адресах.

Для исходного CAR leaf по внутреннему z и A=0,15,

    X_z,A=(|z,1><z,A|+|z,A><z,1|) tensor I_RIGHT,
    <X_z,A>=2 sqrt(p) Psi_z,A /256.

Равенство использует сохранённую норму строки Fourier; никакой
PF-множитель внутрь CAR-источника не добавляется. Остальные grades
и RIGHT остаются в полном операторе и состоянии.

Эти формулы действуют на всех b, для которых определены прежние
Julia/material targets. Они не выводятся из нескольких численных
образцов B25. Адресный mapping и field/gauge conventions наследуются
из исходных A11/B24/B25, а uniform slack уже обеспечивает существование
всех соответствующих target matrices на полном конечном SAM cube.

## 3. Почему произведение моментов теперь допустимо

В идеальном слове каждый source preparer действует на собственных
DATA/private регистрах и как тождество на общем aux/port/Spin на
соответствующем fibre. При фиксированном b начальные RAW-входы являются
произведением, поэтому подготовленные source copies — произведение
вышеуказанных состояний. Общий внешний SITE не входит ни в один из
этих source-регистров. Это не клонирование неизвестного состояния.

При фиксированном внешнем x каждая logical report circuit действует
лишь на своём report arena, пользуясь x как управляющим адресом;
идеальные вспомогательные native factors возвращаются тождественно.
Поэтому произведение сохраняется между десятью sign groups, а затем
между семью reports при условии (b,x). Между разными b или x
глобальная state может быть когерентной и запутанной. Утверждение
условно по соответствующим блокам, а не требует уничтожить когерентность.

Индукция A11/A12 по source tensor DAG теперь применяется к этим
конкретным product states: constant/add дают линейность, а mul
использует разные copy offsets. Поэтому ожидания H_f и H_q равны
исходным геометрическим f и q именно этих bank fields. Переиспользования
одной физической копии в разных множителях нет; identity padding
не меняет ожидания. B33/A16 сохраняют исходные инструкции и их
rank-two involution effects. Top attenuation вводит ровно один
`1/(rho_x Lambda_h)`.

## 4. Исходный report polynomial и общий PF-average

Пусть F_b,x и Q_b,x — нормированные моменты
`f_b,x/(rho_x Lambda_h)` и `q_b,x/(rho_x Lambda_h)` для выбранного bank.
Два f-sign и восемь q-sign при условии (b,x) независимы благодаря
раздельным source copies и свежим selector resources. Исходная A12
палитра даёт именно

    P_bank(b,x) = alpha · Beta_sigma(F_b,x,Q_b,x),
    E=p²(1+F_b,x/64), u=p+sigma p² Q_b,x/64,
    ell=4E(1-E), B=4u²(1-u²), A=ell+(1-ell)B,
    Beta=1-(1-zB)(1-zA), z=2^-20.

Для sigma=−1 это исходный `r(x_arg,y_arg)` при
`x_arg=epsilon f/rho`, `y_arg=-epsilon q/rho`,
`epsilon=1/(64 Lambda_h)=2^-1531`. Alpha — полная готовность
объявленного идеального reporter из A26, а не alpha^7.

Полный SC6 уже свёрнут B49 по всем control columns к
`G_port^(512 chi) tensor I_Spin`. Его восемь непересекающихся selector
слов имеют ровно две единицы среди пяти RAW-битов, каждое имеет
вес `p³(p²)²=p^7`. Четыре положительных branches проверяют два
события READY&REPORT, четыре отрицательных — их дополнение.
Следовательно при фиксированном (b,x)

    Pr(click | b,x) = kappa9 p^7 [4
       +(P_y+−P_y−)(P_f−P_0)
       +(P_x+−P_x−)(P_q−P_0)].

Общий SITE подготовлен ровно один раз с вероятностями
`w_x=N_x/10946=v_x rho_x`. Сначала берутся указанные произведения
на одном x, и только затем сумма по w_x. В общем случае независимые
PF averages по отдельным calls дают иной ответ (теряется covariance).
На нынешнем фиксированном B25 reference slice значения P_y±, P_x± и P_0
не зависят от x, поэтому здесь отдельное усреднение численно совпало бы
благодаря нулевой covariance. Это частное равенство не меняет фактическую
общую SITE архитектуру и не переносится на независимые reference variations.
Поэтому идеальный canonical corner равен

    sum_b [1−2 kappa9 p^7(4+sum_x w_x Xi_b,x)] Pi_b tensor I_D.

Это совпадение **канонического идеального source/report закона**
на сохранённой finite target family. Настоящий native corner отличается
по норме не более чем 2 eta_input A25. Равенство полных старых
отмеченных prefixes, heat на всех helper columns, физических births,
clock/work/Info и compulsory Cost−Info источника отсюда не следует.
Независимый B54 проверяет исходные reference identities точно:
`H_f/rho=±F_h/36` для x±, а при всех links=I исходный H_f равен нулю
для любого coframe (по точной степени2 и полной поляризации квадратичной
формы). Homogeneous degree2 по matter даёт H_q=0 при Psi=0.
С B49 `H_q(y±)=∓rho d_h`, sigma=−1 и прежними
`d_h=F_h/(36 k0)`, `delta=epsilon d_h` это даёт ровно исходные семь
аргументов H.1, без новой калибровки:

    y+: (0,+delta), y-: (0,-delta),
    f: (epsilon f/rho,0), 0: (0,0),
    x+: (+k0 delta,0), x-: (-k0 delta,0),
    q: (0,-epsilon q/rho).

Геометрические восстановительные теоремы потребляются с их прежними
условиями. B54 также получает строгую положительность: `0<=P_j<=alpha`
влечёт `4+Xi<=4+2 alpha²`; прежние точные rational/interval bounds
дают `c_ideal,b>67/100`. Для фактической скалярной формы A25 отсюда
`c_hat_b>67/100−2^-3231>2/3` на том же каноническом входе.

`physical_C_closed=false`, `GR_closed=false`.
