# A27 — исходный геометрический закон подготовленных источников

Для идеального сравнительного слова A25 на каноническом входе теперь
связаны все этапы: реальные Choi/CAR target states → исходные геометрические
моменты → tensor-DAG → десятизнаковый report → семь исходных reference
аргументов → SC6 и один общий PF-average. Это прежние формулы и
коэффициенты, без назначения новой Info или действия.

Второй исследователь B54 независимо проверил точной арифметикой все
72192 leaf bindings, 2048 строк report, 1372 source slots и исходные
reference identities. В частности H_f при единичных links равен нулю
для любого coframe; для x± точно получено H_f/rho=±F_h/36.

Тем самым снята оставшаяся в A25/A26 предпосылка **идеального
моментного/report закона конкретных подготовленных банков**.
С учётом A25 реальный сжатый результат остаётся скалярным, и его
коэффициент строго больше 2/3 на объявленном каноническом входе.
Прежние условные оценки native approximation теперь потребляют
конкретно проверенный идеальный геометрический report law.

Область: L=4, h=1/4, m=2688. Гигантское слово не исполнялось.
Физический допуск RAW/старого cut, исходные отмеченные префиксы,
readers/seal, растущие часы, heat/work/Info, независимые upstream
вариации и полный Cost−Info source остаются открытыми.
Это не полный вывод ОТО и не uniform refinement theorem.
