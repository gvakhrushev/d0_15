# A31 — исправленный lift именно фактической средней геометрии

Потребитель — H.5/7ar388: при использовании source marks A30 нужно
дифференцировать decoder среднего, а не просто имена sampled vertices.
Здесь задаётся конкретный локальный decoder существующего B25 chart,
проверяются его настоящие координатные операнды и доказывается
обратимость фактического дифференциала. Новые source/action/Info
не вводятся. Реальная большая матрица J численно не вычислялась.

## 1. Исходные координаты и decoder

У B25 имеется 2688 свободных координат на 64 внутренних sites:
1024 raw inverse-coframe u, 1536 proper-link theta и 128 Psi.
PF и collar фиксированы; `s=2^-30`. При vertex b:

    u_b=u0+s(b_u-p²),  Psi_b=Psi0+s(b_Psi-p²),
    U_b=exp(X_b) U0,
    X_b=sum_(a<b) s(b_ab-p²) K_ab,
    K_ab=eta_null (E_ab-E_ba).

Новый файл привязывает каждую координату к настоящим A30 marks и
все 256 link blocks — к полным 16 оригинальным U entries. Для u и
Psi decoder — прямой исходный момент. Для link используется

    theta_dec,ab = [eta_null log(mean_U U0^-1)]_ab, a<b.

Здесь log — локальная главная ветвь. Само среднее mean_U не обязано
быть Lorentz-матрицей. Decoder определён на её открытой окрестности;
на каждом исходном достаточно малом vertex он в точности возвращает
theta, поскольку log(exp X_b)=X_b и
`(eta_null K_cd)_ab=delta_(ab),(cd)`. Все 36 компонент этой последней
идентичности проверены точно; скрытого factor 2 или знака нет.

Это локальный выбор восстановления прежнего chart, не утверждение
о единственном физически выбранном способе читать геометрию.
Если требуются сами coframe e, сохраняется исходная карта
`e=nu eta_null u^-T`, nu=3/5, со своей нормой.

## 2. Фактический Jacobian задан исходными операторами

Пусть V — **фактический** A30 prefix до общей RAW source-точки,
O_i — соответствующий исходный mark из реестра. SAM используется
только как control и O_i не действует на SAM, поэтому точно

    E_i=V* O_i V=sum_b h_i(b) Pi_b tensor I_old

после сжатия канонических WORK. Значения h_i(b) — фактические native
значения, а не подставленные идеальные поля. Конечная программа и
исходные G определяют их вычислимыми числами; полный огромный массив
не разворачивался.

При исходном SAM `v^tensor m` среднее равно
`sum_b Pr(b)h_i(b)`, Pr(b)=p^(m-|b|)p^(2|b|).
Для обычного вещественного генератора J_j на SAM_j,
`u_sampling=2p sqrt(p)`, точно

    D_alpha_j mean_i
      =u_sampling E_(b_except_j)[h_i(b_j=1)-h_i(b_j=0)].

Это равенство следует из диагонального pulled-back E_i, а не из
выбора одной classical branch. Оно сохраняется для произвольного
внешнего old-state/reference. Проверен точный трёхбитный пример с
совместно зависящей от разных SAM координат таблицей.

Определим **настоящую** нормированную матрицу

    J=(u_sampling*s)^-1 D_decoder(mean_actual) D_alpha mean_actual.

Её нельзя заменить I даже при идеальных source states: у log-link
decoder остаётся нелинейная поправка среднего.

## 3. Строгая обратимость и смещение центра

Каждый K_ab имеет operator norm1, следовательно `||X_b||<=r=6s`.
Из центрирования `E X_b=0` и exp-ряда:

    d=||E exp(X_b)-I|| <= r²/(1-r).

Нормированный link chord H_j удовлетворяет
`||H_j-K_j||<=epsilon=r/(1-r)`: это интеграл Dexp по настоящему
отрезку между двумя b_j-значениями, не производная целочисленного
компилятора. Для `||E||<1` log-ряд даёт
`||Dlog_(I+E)||<=1/(1-||E||)` и
`||Dlog_(I+E)-I||<=||E||/(1-||E||)`.

Таким образом ideal link block имеет spectral defect не больше
`6(epsilon+d)/(1-d)<2^-24`; ideal u/Psi blocks точно единичные.
256 идеальных link blocks независимы, поэтому число blocks не
умножает этот block-diagonal norm.

У A30 каждый фактический U-entry отличается по полной входной
operator norm меньше чем `e=2^-3214`. Прежний envelope даёт
`||U0^-1||<2`; значит actual matrix-mean error добавляет не больше
8e. Нормированный SAM-chord error по любой координате не больше
16e/s. Учтена также перемена самого Dlog при сдвиге среднего;
полному native Jacobian нельзя приписывать старую block diagonal
структуру. Консервативная bound каждой его error-entry — 64e/s,
всей матрицы — `2688*64e/s<2^-3166`.

Точные рациональные проверки дают

    ||J-I||_2 < 2^-23,
    J^-1=sum_(n>=0)(I-J)^n,
    ||J^-1||_2 < 1/(1-2^-23).

Для фактического decoded центра получается отдельная оценка
`||Y_decoded-Y0||_2<2^-48`. Центр не отождествляется в точности с Y0.
Его сдвиг должен войти в consistency source через настоящие
derivative bounds, даже если отдельные native mark errors малы.

## 4. Исправленный lift и его область

Для физического смещения y в **объявленном raw-u/theta/Psi chart**
положим

    R(y)=(u_sampling*s)^-1 sum_j (J^-1 y)_j J_j.

Тогда дифференциал фактического mean decoder на R(y) равен ровно y.
Это точный математический right inverse, содержащий настоящую J.
Оценка `||sum a_j J_j||<=sqrt(m)||a||_2`, p>309/500 и
sqrt(p)>39/50 даёт с запасом

    ||R(y)||_op < (55/s)||y||_2.

Для смещения, уже выраженного в единицах s, bound равна 55.
В JSON приведены также количества членов Neumann-ряда для заданной
точности при **точной** J. Вычислительная ошибка приближения самой
J в эти примеры не включена. Гигантская J и control pulse coefficients
фактически не рассчитывались и native actuation не исполнялась.

Если вместо u задана единичная Frobenius-норма изменения coframe e,
нельзя потерять преобразование координат. Из прежних creator column
bounds `||u||_op<2` следует

    ||D u/D e||_(F->F)<20/3,

поэтому для e/theta/Psi в этой смешанной норме достаточно
`1100/(3s)`. Это отдельный множитель к raw-chart bound.

## 5. Что это позволяет сказать о source — и что пока не позволяет

Native-only остаток T10 после raw physical lift при исходной
нормировке Gamma_s меньше 2^-37; после перехода к e/theta/Psi —
2^-34. Это лишь одна составляющая. Сохраняются Taylor remainder,
геометрический/reference error E_tau, actual heat/clock/old-prefix,
reader/finite-comparison error и независимые физические source rows.

Нормировка существенна. В H.4
`Gamma_s=4wgs/c` и `L_rho(sum a_j J_j)=u_sampling a`. Поэтому

    L_rho R(y)=s^-1 J^-1 y,
    DJ[R(y)]/Gamma_s
      ~ s^-1 DI_tau(Y0)[J^-1 y].

Правая часть не равна автоматически `DI_tau(Y_decoded)[y]`.
При нормировке `Gamma_0=Gamma_s/s=4wg/c` ведущий covector становится
`DI_tau(Y0) composed with J^-1`, а **весь** остаток умножается на s.
Выбор нормировки должен следовать тому, какой physical displacement
сравнивается; нельзя убрать s только из знаменателя ошибки.

Например, если исходный geometric covector E_geom имеет настоящую
Lipschitz-bound L_geom на соединяющей окрестности, переход к нему
требует отдельно сохранить слагаемые

    ||DI_tau(Y0)-E_geom(Y0)||/(1-delta),
    delta/(1-delta) * ||E_geom(Y0)||,
    L_geom * ||Y_decoded-Y0||,

где delta=2^-23, а также T10 Taylor/native и полные physical-price
остатки. Первое не становится нулевым по определению decoder;
второе — не ошибка native compiler; третье — не нулевой centre shift.
Здесь нет численного полного source bound или доказанного его нуля.

Следующий необходимый переход — настоящие конечные G/CX comparison
programmes для preparation legs, их общий birth/mark/clock порядок
и полный Book03 source с этими нормами. Дифференциальная обратимость
сама не разрешает свободно варьировать фиксированный угол G.

`physical_C_closed=false`, `GR_closed=false`.
