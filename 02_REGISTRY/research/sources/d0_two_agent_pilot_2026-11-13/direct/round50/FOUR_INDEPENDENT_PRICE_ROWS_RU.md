# A50: четыре независимые строки цены на двухбитной семье A49

На **той же** A49 семье, с тем же fixed post, одним реально оплаченным
clock, исходным reader H+J и собственным gain Γ, получена оценка всех
четырёх независимых сравнений по каждой из 2688 исходных MG2-осей:

    |FD_Pf(H+J)/Γ| < 2^-108,
    |FD_Qf(H+J)/Γ|, |FD_Qb(H+J)/Γ| < 2^-108,
    |FD_Pb(H+J)/Γ| < 2^-189.

Евклидова норма объединённого списка 4×2688 строк меньше `2^-102`.
Это конечные оценки для математически заданных native histories, а не
исполнение огромных слов или доказательство их точной стационарности.
Они относятся к выбранному typed SOURCE, canonical RAW fibre, born-product
CODE и пустому исходному carrier `H₀=C`. Это **не** полный dual по всем
CODE/old/WORK/preparation directions и не исходная физическая норма V_h.
Связывание с original marks, полной Cost−Info и ОТО остаётся открытым:
`physical_C_closed=false`, `GR_closed=false`.

## 1. Какая предпосылка снята

A49 построил actual corner/post/padding/clock, но ещё не вычислял четыре
независимых price rows. B97 снял скалярную предпосылку для Pf: получил
третью производную исходного Iτ, применил exact product quadratic identity
и сохранил реальную поправку веса fixed post. A50 потребляет этот результат,
переносит A44 kernel identity на новый actual split и отдельно оценивает Pb
**перед** fixed post. Старые ненулевые A43/A46 строки на другой таблице,
шаге и clock сюда не переносятся.

Никаких новых действий, коэффициентов Info, source selectors или roots
не вводится. Собирается недостающая часть цены уже построенной A49 семьи.

## 2. Actual split и область all-insertion оценки

До G/CX replacement исходный точный профиль имеет

    W₀ = B₀ᵀ S₀ B₀,    S₀ = D₀ᵀ Z D₀ = S₀ᵀ,

где B₀ заканчивается после первого RAW frame; D₀ начинается с обратного
frame и содержит все восемь REPORT, PORT_ZERO и исходный SC6. В обратном
проходе второй Q-cut стоит после inverse обратного frame, до возврата B₀ᵀ.
Точные literal inverse depths исходного профиля сохраняются. Реальные
G/CX части обозначим `W=C S B`: C не считается равной Bᵀ, S не считается
самосопряжённой.

Проверена новая A48 привязка middle: 34112 resource wires, все восемь
REPORT private intervals и их shared endpoints, SC6, port/spin/aux/helper
не пересекают 5376 CODE wires. REPORT affine map проверяется на своих
диапазонах, без перебора миллиардов адресов. A29 replacement добавляет
только WORK helper/port. Поэтому S не использует CODE **даже как controls**,
и `[S,Y]=0` для любого CODE-only Y точно. Свойства «CODE только controls»,
достаточного для диагональности M, здесь было бы недостаточно.

Все cuts испускаются только при закрытом состоянии SourceI transducer.
Уже принадлежащая B82/A29 грамматика замены имеет all-column operator bound;
A48 даёт новое `e_W<2^-15800` для всего профиля, с componentwise upper на
число оплаченных замен. Вставка Y нормы ≤1 в один такой cut не увеличивает
нормы окружающих операторов. Телескопическая сумма остаётся той же:

    ||Φ(Y)−Φ₀(Y)|| ≤ e_W ||Y||,
    Φ(Y)_cb = Y_cb ⟨ω,C_c S B_b ω⟩,
    Φ₀(Y) = Vᵀ(Y⊗S₀)V,    V e_b=e_b⊗B₀,b ω.

Это полная **insertion replacement** оценка относительно exact SourceI
profile, а не только endpoint M и не SOURCE-to-ideal error. Реальные
identity padding не меняют эти операторы; их вызовы входят в A49 clock.
Огромный stream не перечислялся: применены прежняя структурная теорема,
новая binding-проверка и новая суммарная граница.

## 3. Новая dimension-free Q-оценка

Для всех полных labels, включая корреляции с fresh source remainder:

    δ₀ = sup_(b,c) ||B₀,b ω−B₀,c ω||
       ≤156·1748·σ + 2e_prefix <2^-61,      σ=2^-80.

Использованы B91 uniform M1≤1748, диаметр `3√2688 σ<156σ` и обе ошибки
к ideal typed source. A48 e_prefix консервативно покрывает также исходный
profile до G/CX replacement. Никакой частичный след по fresh remainder
при Q-вставке не производится.

Для `μ=c_ref−2g Iτ(Y₀)` и `τ=||M−μI||` B65 и A49 дают

    τ/(gσ) ≤2·2^-3083·104 + 2^25 σ·104² + e_M/(gσ)
           <2^-41.

μ вычитается только внутри оценки коммутатора; цена не получает нового
контрчлена. A44 identity, с `J e_b=e_b⊗u_ref`, Δ=V−J, имеет вид

    Φ₀(Y)−(D Y+Y D)/2
      = Δᵀ(Y⊗S₀)Δ − (A Y+Y A)/2,
    D=Φ₀(I),       A=Δᵀ(I⊗S₀)Δ.

Линейные члены Δ сокращаются. При skew Y её правая часть skew и имеет
норму ≤2δ₀²||Y||, независимо от числа labels. Для actual Φ разложение
на skew и symmetric части добавляет соответственно ≤2e_W и ≤e_W.

При target post U*, `r=||Mχ||`, `U*ᵀχ=Mχ/r`, reduced Pf и Qb равны

    d_red,Pf(Y) = −χᵀM²Yχ/(2c_ref gσ),
    d_Qb(Y)     = −χᵀMΦ(Y)χ/(2c_ref gσ).

Часть `(M Y+Y M)/2` даёт ровно половину Pf; в skew остатке можно заменить
M на M−μI. Переход к fixed actual post добавляет e_U/(gσ). Поэтому

    |d_Qb−½d_red,Pf|
      ≤(3/4)[(τ/(gσ))(2δ₀²+2e_W)+e_W/(gσ)] + e_U/(gσ)
      <2^-160                                             (1)

для любого CODE skew нормы ≤1. Это аналитический dual identity; лишь
2688 MG2-осей имеют здесь указанные оплаченные конечные control words.
Qf имеет противоположный знак из точного `[S,Y]=0`, а не потому, что
обе строки якобы равны нулю.

## 4. Почему fixed post не удаляет реальную Pf поправку

B97 для исходного Iτ доказал uniform `||D³Iτ||<2^31` на прежнем B21 cube.
При born product Φ=χ и исходных MG2 `[V_j,X_j]Φ=Φ` квадратичные Taylor
члены в expectation коммутатора точно сокращаются. Для
`DσF=⟨Φ,[F(Y₀+σV),X_j]Φ⟩/σ`:

    |Dσ Iτ−∂j Iτ(Y₀)| <2^-109.

Поскольку U* рассчитан для **actual** M, реальная reduced строка содержит
M². При `M₀=c_ref I−2g Iτ` точно

    d_red,Pf = Dσ Iτ − (g/c_ref)Dσ(Iτ²)
               −⟨Φ,[M²−M₀²,X_j]Φ⟩/(4c_ref gσ).

B97 ограничивает weight correction `<2^-3021` исходным `g<2^-3061`,
а actual corner correction `<2^-212`. Вес не объявляется независимым
product и не удаляется. После добавления B65 central defect `<2^-3083`
это даёт нужную малость reduced Pf в (1). Общий SOURCE vector error
`2^-44` не делится на g. Для другого old carrier/коррелированного входа
продуктовая скалярная лемма и эта скаляризация determinant не доказаны.

## 5. Независимый Pb именно перед постом

Для A49 четвертой occurrence угол меняет `U* exp(−tX) Mχ`. Поскольку
`ξ=Mχ/r` и `U*ᵀχ=ξ`, её corner равен

    c_Pb(t)=r ξᵀ exp(−tX) ξ,
    c'_Pb(0)=−r ξᵀXξ=0.

Это верно для любого real skew X и не требует C=Bᵀ. Более того,
target curve чётна. Но fixed native post только приближает U*, а два
native control words компилируются независимо. Их ошибки сохраняются:
actual аналитический Pb остаток ≤e_U/(gσ), конечная строка также включает
control error и heat. Не отождествляется с probe, исполняемым после post.

## 6. Все конечные ошибки и общая норма

Каждое отдельное аналитическое сравнение имеет одно exp(±tX), ||X||≤1,
в окружении contractions. Значит `|c^(k)|≤1`. Исходная A42 Taylor-оценка
для J с `z=2^-20`, `t=2^-1700`, `gσ>2^-3208` даёт `<2^-192`.
Два actual A47 control errors дают `<2^-190`; они не считаются обратными.
A49 growing clock, включая все births/padding/failure/retention, даёт
heat `<2^-8139` на каждую такую строку. Один fixed post даёт `<2^-6039`.

Подстановка этих величин в B97 Pf и (1) даёт начальную таблицу четырёх
строк и, дополнительно,

    |FD_Qb/Γ − ½ FD_Pf/Γ| <2^-159.

Здесь heat обеих сравниваемых строк оплачивается по отдельности. Точные
рациональные суммы, а не только округлённые степени двойки, дают

    2688 (E_Pf² + 2E_Q² + E_Pb²) <2^-204.

Поэтому объявленная координатная Euclidean norm `<2^-102`. Это не
непроверенная замена physical V_h и не перенос допуска `10^-22` из
другого h0/full42 chart.

Для Qf/Qb имеется также точное равенство противоположных **полных H+J
finite contrasts**: одно и то же actual слово переставляется через
CODE-disjoint S, слоты имеют одинаковые оплаченные длины, между ними нет
births. Stage gauge A43/B85 сопрягает полный growing clock, совпадая с I
на концах; все внешние births, padding и последний G одинаковы.
Следовательно `price(Qf+)=price(Qb−)` и наоборот. Это не равенство всех
фиксированных промежуточных marks; их допустимый транспорт остаётся
самостоятельным требованием.

## 7. Что нельзя заключить из малых выбранных осей

Точная product quadratic cancellation использует именно X_j. Для
произвольного CODE skew на тех же 4^2688 labels она неверна. Имеющийся
dimension-free bound даёт только

    ||d_Pf||_all-skew,analytic <2^-40,
    ||d_Qf||_all-skew,analytic, ||d_Qb||_all-skew,analytic <2^-41,
    ||d_Pb||_all-skew,analytic <2^-6039.

Не заявлены их полные native сравнения, физический допуск всех этих
направлений, нормы old/protected correlations или source zero. Тем более
не закрыты WORK/scene/record/Info/preparation equations, actual original
Dν/frontiers, A23-vs-original full vacuum extension и Cost−Info selection.
Требуется следующий перенос в исходный descriptor и его реальные нормы;
ещё один геометрический root или повтор этого census его не заменяет.

## 8. Проверка

`independent_price_rows.py` проверяет новую affine support binding и
вычисляет все rational budgets из закреплённых A47–A49/B97. Checker
проверяет точные малые full controlled matrices как с отражённым
профилем, так и с независимой обратной частью: Pb перед постом, Q swap,
ненулевые противоположные Q и Pf. Отрицательные примеры сохраняют
ошибки approximate post, отдельно скомпилированного отрицательного
control и фиксированной intermediate CODE mark. Проверено также, что
CODE-only-as-control у middle недостаточно для Q commutant.

Root сверил B97 source/artifact hashes и Git blobs и повторил обе его
проверки с побайтным совпадением, запретив запись в B. Полные production
матрицы/слова не исполнялись; machine-checked Lean proof не заявлен.
