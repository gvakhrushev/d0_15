# A48: двухбитный источник и фактический полный векторный отклик

**Закрытая предпосылка.** В A47 двухбитный контроль уже существовал, но
требовал ещё не построенного источника с ошибкой `<2^-3300`. Здесь построены
его конечные генераторы, фактическая привязка регистров и замена SourceI на
G/CX. На объявленной полной SOURCE-DATA fibre получено `<2^-3423`.
Подстановка в A47 теперь относится к конкретным конечным словам:
добавочная ошибка симметричной разности `<2^-1642`, полный axis jet error
`<2^-44`. Это результат для выбранной typed source extension.

**Не закрыто:** тождество всех original marked maps, новая полная
clock/post/corner/price family, полный физический Cost−Info, вывод ОТО.
`physical_C_closed=false`, `GR_closed=false`. Огромные полные слова не
развёрнуты и не исполнены; реализованы конечные ленивые генераторы с
положительными целыми степенями, проверенными погрешностями и ресурсными
оценками. Это не Lean-формализация и не эксперимент на квантовом устройстве.

## 1. Вход и потребление прежнего результата

Новых материалов пользователя не добавлено. Потреблены исходный MG2 lift,
A47, прежние source targets A22/A24/B45 и B93. Значения координаты:

    Y_j = Y0_j + 2^-80 (low_j + 2 high_j − 3p²).

Используются 5376 CODE bits. Порядок глобального CODE — сначала 2688 low,
затем 2688 high. Coframe/CAR используют interleaved local indices
`[j,2688+j,...]`, proper-link использует сначала local low, затем high;
в обоих случаях digit=low+2high. Полнота и согласование масок проверены.
Никакой новый action, Info коэффициент или selector не вводился.

## 2. Полные локальные каталоги

| Блок | Проверенный объём | Макроошибка |
|---|---:|---:|
| Coframe | 1927 families; 4021 angles; 137728 sectors | `≤26·2^-3456` |
| CAR half-vector | 70 vectors; 116 angles | `≤3·2^-3456` |
| SITE | 165 distinct tree angles; 255 nodes; reflection | `≤18·2^-3456` |
| Fourier | новая π/2 power, K=7 | `≤18·2^-3456+15·2^-4096` |
| Joint reflection | новая π power, K=46 | `≤2^-3456` |
| Proper link B93 | 20496 families; 307416 angles; 1055488 sectors | `<2^-3453` |

Coframe max Walsh width вырос с 20 до 24; CAR — с 13 до 15;
proper-link — с 23 до 29. Новых clean scratch только из-за расширения
предикатов не требуется. Все исходные inactive sectors оплачены.

Coframe/CAR и фиксированные углы имеют сохранённые фактические целые k.
Их первичная проверка использует outward target intervals и integer
complex balls; численная догадка k не является доказательством.
B94 независимо повторяет весь набор 4306 фактических степеней прямоугольной
интервальной арифметикой на 9216 битах. Это полный повтор этого набора.

B93 использует другой, строго отделённый способ: доказанную равномерную
короткую сетку для `G^(2^29 k)`, полные проходы target intervals на 4096 и
4352 битах и адаптивный вычислимый выбор фактического k. Полный список k и
его числовой exact inventory не материализованы. Проверка 47 конкретных
степеней B93 — только дополнительный sample; общее утверждение опирается
на grid theorem и полный target pass. Root повторил B93 independent check
без записей в чужую рабочую копию, с побайтным совпадением результата.

## 3. Девятый уровень подготовки

Прежний level8 имеет ideal vector error `<2^-3280`, чего недостаточно для
нового gate. Используется level9. Для `ε0=(1−1/√65568)/2<1/2`:

    ε_(n+1)=ε_n³,
    ε9=ε0^19683<2^-19683,
    ||corrected output−target||²≤2ε9,
    ideal vector error<2^-9841.

Заключительная phase correction зависит от уровня. Старый correction_l
не переносился: вычислена и сертифицирована новая power для
`conj(∏_(j=0..8)(t²+tε_j))/|∏(t²+tε_j)|`, `t=exp(iπ/3)`,
с ошибкой `≤2^-4096`. B94 независимо проверил её на 12288 битах.

Структура рекурсии: `A; good; literal_inverse(A); start; A`.
На level9 имеется 19683 Omega occurrences. Вложенные inverse depths
сохраняются как целые числа; inverse-of-inverse не сокращается по цене.
RAW→zero для Choi private24 и CAR predicate3 включены в генераторы.

## 4. Общий бюджет источника

Пусть `δ=2^-3456`, `ε=2^-4096`, `L=19683`, `e_pre` — прежняя
сертифицированная ошибка Choi address/Bell prefix. Тогда:

    e_select = max(26δ,102·2^-3460),
    e_loader = e_pre+e_select,
    η_half = 2^-9841 + L e_loader + (2L+(2L−2)23+1)ε,
    e_Choi = 4η_half+2δ,
    e_CAR ≤24δ+43ε,
    e_SOURCE ≤1440e_Choi+128e_CAR+18δ <2^-3423.

Максимум для coframe/link допустим из-за непересечения address blocks:
coframe 1..1024, link 1025..2048. До замены SourceI Walsh inactive
sectors являются точными identities. Погрешность их последующей G/CX
замены оплачивается уже общим количеством примитивов.

Область: все исходные DATA22 Choi и DATA+RIGHT19 CAR columns, private на
объявленном canonical RAW fibre, произвольная запутанность с CODE и внешним
reference. Это не all-dirty-private operator theorem. A23 vacuum/Fourier
остаётся явно выбранной полной extension; её равенство непредъявленной
original extension не получено из этой точности.

## 5. Глобальная привязка и конечное G/CX слово

Сохранён восьмибанковый носитель A46. Новые high bits добавлены после всех
старых ресурсов. Физическая пара координаты j:

    (2+j, 11893771936+j), j=0..2687.

Всего RAW births `11893774624`; старый compiler helper остаётся на
physical wire `10407050781`. Не перемещены REPORT/source buffers. SC6
по-прежнему получает исходные семь REPORT; восьмой независимый source/report
сохранён. Все 1568 source slots и все 2688 CODE pairs проверены.

Для SourceI replacement применён прежний точный структурный трансдьюсер
A29 с более точной A38 π/8 power, `δ8=2^-20000`. Один SourceI pair стоит
16 базовых ошибок, CZ — 32 при не менее пяти SourceI. Следовательно
`8·W.SourceI` — безопасная верхняя граница error units. Получено:

    e_replacement <2^-15800,
    e_SOURCE_prefix,G/CX <2^-3423,
    e_canonical compressed core <2^-3421.

Последние две оценки имеют разные области. Первая относится к полному
SOURCE-DATA fibre **до REPORT**; именно её потребляет A47. Вторая — к
канонически сжатому полному comparator core. Одна не подменяет другую.

Proper-link inventory входит как componentwise upper. Поэтому общий
`W_call_count_upper_bit_length=24272` — верхняя граница, не exact price.
Число actual native calls и полная новая clock/heat/post family пока не
вычислены. Старые A46 Q, post, clock, gain bounds не перенесены.

## 6. Применение к полному векторному отклику

`actual_full_vector_source_jet.py` задаёт реальные finite comparison words:
хронология `P_sign; Bhat; P_minus_sign`, где `Bhat` — новый G/CX source
prefix через первый RAW resource frame до REPORT. Контроли берутся из
замороженного A47 сертификата; их привязка и равная оплаченная длина
перепроверены. В двух сравниваемых словах оплачены все четыре вхождения.

Используя A47 `M1≤1748`, `M2≤3233036`, `Rv<104`, `σ=2^-80`, `t=2^-1700`,
`εP<2^-5099`, имеем:

    extra ≤(e_SOURCE_prefix+2εP)/(σt)+(4/3)Rv M1 t² <2^-1642,
    full_axis_jet_error ≤σ Rv² M2+extra <2^-44.

Это норма полного вектора; частичный след или успешный postselection
не используются. Отрицательный actual control не предполагается точным
inverse положительного. Ошибка постоянной части делится на фактический
`σt` и включена в оценку. Дискретный индекс k не дифференцируется.

Так снята конкретная SOURCE precision premise A47. Применимость ко всем
original Dν и физическим вариациям полной цены требует следующего этапа.

## 7. Следующая обязательная работа

1. Построить новую полную corner/post family для actual A48 core и CODE5376;
   пересчитать её target, ошибку, длины и общие дополнения до одной длины.
2. Получить exact price через конечный B93 inventory algorithm либо
   реализовать и оплатить реальное дополнение до заранее доказанной длины;
   upper нельзя переименовывать в actual count.
3. Пересчитать новый clock/heat и четыре независимые price rows, включая
   все SOURCE marks. Прежние A46 оценки служат только структурным образцом.
4. Сопоставить original preparation/Dν/admission и полный Cost−Info source
   на одной истории, сохраняя ненулевые остатки и независимые вариации.

Исходная точная GR-геометрия не пересчитывалась: работа сняла предпосылку
в source route, а не создала ещё один геометрический сертификат.
