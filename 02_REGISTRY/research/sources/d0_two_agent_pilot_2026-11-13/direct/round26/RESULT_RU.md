# A26 — готовность собранной схемы и условный запас точности

Для полного объявленного **идеального** reporter A25 доказано
`alpha=Q_pre>1/2`: детерминированные подготовки SOURCE/SITE/sigma не
добавляют новых условий успеха. Независимый B53 проверил все 2585
palette partitions точной арифметикой и получил целочисленными
интервалами `0.74068<alpha<0.74069`.

Потребление прежнего B29 gain при тех же исходных moment/report и reference
предпосылках даёт для native approximation члена:

* `<2^-73` на единичный generator;
* `<2^-67` после исходного scaled-chart lift;
* `<2^-37` после исходного unit-physical lift.

Эти оценки применяют точную сумму ошибок конкретной A25 сборки,
а не только заранее выбранную желаемую точность. Для реального native
READY B53 отдельно ограничил отклонение эффекта от `alpha I` величиной
`<2^-4060` при канонических свежих report inputs и произвольных внешних
данных. Точная независимость actual READY от поля не утверждается.

Результат — supporting substitution для H.1/B29: устранена недостающая
готовность идеального reporter этой конструкции. Исходный семибанковый
moment/report law, marks/admission, настоящая геометрическая карта,
Taylor и все heat/clock/work/Info вклады ещё требуют общей физической
привязки. Это не полная T10 и не вывод ОТО.
`physical_C_closed=false`, `GR_closed=false`.
