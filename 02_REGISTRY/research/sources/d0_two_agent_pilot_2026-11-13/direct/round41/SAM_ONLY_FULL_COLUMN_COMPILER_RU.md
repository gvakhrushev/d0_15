# A41: конструктивное SAM-only приближение полного оператора A37

**Результат:** по текущим основаниям D0 существует явно определённое конечным алгоритмом слово из положительных `G` и `CX`, действующее только на исходных 2688 SAM-проводах, с

\[
 \|\widehat U-U_*\|_{op}<2^{-14623},\qquad |\widehat U|<2^{25458}.
\]

Здесь `U*` — **вся** матрица A37, построенная из фактической компрессии A30, а не произвольное преобразование одного занятого вектора. Каждое такое слово точно унитарно на SAM и точно тождественно на WORK/внешних проводах. Вспомогательные провода, их рождения, очистки, отражения и непрерывно настраиваемые native-вентили не нужны.

Это конструктивная **математическая теорема** и исполняемая малая reference-реализация. Производственный Python provider, таблица из `2^2688` элементов, выбранные показатели всех производственных блоков и само гигантское слово **не реализованы и не вычислены**. Проверка B81 обнаружила, что первоначальный list/len-интерфейс не может представить эту размерность даже при абстрагировании от RAM: `len` ограничен `PY_SSIZE_T_MAX`. Неподтверждённое обещание production provider удалено; соответствующие функции явно дают `NotImplementedError`. Не следует путать доказанную конечность математического алгоритма с возможностью выполнить его этим Python-кодом.

`physical_C_closed=false`, `GR_closed=false`. Работа относится к native realization и устраняет только узкое препятствие support/unitarity из B78. Полный H.1, четыре независимых слота подготовки, все обязательные марки/операторы, полная оплаченная история и её источник, исходный Cost−Info и уточнение сетки остаются открытыми.

## 1. Потребляемый результат и точная цель

A30 даёт фактическое конечное слово W из G/CX, где SAM (физические провода 2..2689) используется только как управление. При каноническом WORK-векторе v

\[
 M=(I\otimes\langle v|)W(I\otimes|v\rangle)
   =\operatorname{diag}(M_b),\qquad \tfrac23 I<M\le I.
\]

Здесь не заменяется фактическое W на его исходную идеальную reflection-спецификацию. При χ=(√p,p)^⊗m, ψ=Pχ, r=||Mψ||, ξ=Mψ/r положим

\[
 h=(\chi+\xi)/\|\chi+\xi\|,\quad R_v=I-2vv^T,\quad U_*=R_\chi R_h.
\]

Для нормированных χ,ξ с χᵀξ>−1 это ровно A37:

\[
 U_*=I+K+K^2/(1+\chi^T\xi),\quad K=\chi\xi^T-\xi\chi^T.
\]

Обе матрицы равны на span{χ,ξ} и на его ортогональном дополнении; `U*ξ=χ`, det U*=1. Потребляются центр P=I и фактические положительные степени P± из B63/A32, действующие на любом одном SAM-проводе.

Все координаты χ,ψ,ξ,h строго положительны. Действительно p>3/5, √p>3/4; `||P±−I||<2t`, t=2^-1618, поэтому изменённые однобитовые координаты остаются >1/2. Тогда ψ_b>2^-m, r≤1, ξ_b>(2/3)2^-m>2^(-m-1), χ_b>2^-m и h_b>2^(-m-1). Это обеспечивает строго положительные знаменатели и отсутствие вырожденных pivot/ветвей.

## 2. Четыре списка вращений; D не является физической операцией

Для положительного единичного v построим V_v последовательным обнулением координат j=d−1,...,1 плоским вращением R_0j(α_j). Если текущая координата 0 равна x>0, а j равна y=v_j>0, то

\[
 c_j=x/\sqrt{x^2+y^2}>0,\quad s_j=-y/\sqrt{x^2+y^2}<0.
\]

После этого новая координата 0 равна √(x²+y²), а j равна 0. Следовательно V_v v=e₀. Формальный символ D=I−2|0><0| даёт R_v=V_vᵀ D V_v и D R_0j(α) D=R_0j(−α).

Хронологические списки для U*:

1. V_h: j по убыванию, исходный знак s_j.
2. D V_hᵀ D: j по возрастанию, исходный знак s_j.
3. D V_χ D: j по убыванию, противоположный знак s_j.
4. V_χᵀ: j по возрастанию, противоположный знак s_j.

Их матричное произведение

\[
 V_\chi^T(DV_\chi D)(DV_h^TD)V_h
 =V_\chi^TDV_\chi V_h^TDV_h=R_\chi R_h.
\]

Испускаются только `4(d−1)` целевых SO-плоскостей. D алгебраически устранён до native-компиляции. Это сохраняет именно исходную полную матрицу A37, включая действие на незанятых столбцах.

## 3. Точная zero-pattern Walsh-плоскость без ancilla

Для j≠0 выбрать младший установленный бит t. Перестановка F_j, состоящая из CX(t→i) для остальных установленных битов j, переводит 0→0 и j→2^t. Затем на t применяется zero-pattern Walsh-блок:

\[
 \prod_{S\subseteq [m]\setminus\{t\}} X_S G_t^k X_S,
\]

где X_S — последовательность CX(i→t), i∈S. Обратная последовательность после G^k испускается буквально; все коэффициенты для нулевого pattern положительны. На фиксированном состоянии управляющих битов y каждый множитель есть вращение на (−1)^{S·y}kθ. Поэтому сумма углов равна Lkθ при y=0 и ровно 0 при y≠0, L=2^(m−1). После F_j⁻¹ получается **точно** R_0j(Lkθ), тождественное на каждом другом базисном состоянии.

Это тождество верно для любого k и любого состояния SAM, включая суперпозиции. Ни clean-sector, ни коррелированный private, ни постселекция не используются. На одну плоскость приходится Lk операций G и `(m−1)L+2(popcount(j)−1)` операций CX.

## 4. Выбор k без свободного real-angle параметра

Пусть исходная плоскость имеет коэффициенты (c,s), c>0. Применить m−1 раз

\[
 c' =\sqrt{(1+c)/2},\qquad s'=s/(2c').
\]

Это однозначный положительный корень половинного угла. Получается вращение α/L; его cos>0 и |sin/cos|<1 при m≥2. B80 строго доказал для конкретных pn,q, bit_length(q)=20080,

\[
 \gcd(pn,q)=1,\quad |\theta/(2\pi)-pn/q|<1/q^2.
\]

Вычислить интервал τ=atan(s/c)/(2π) шириной ≤1/(2q), взять его середину τ₀, затем ближайшее целое j к qτ₀ и

\[
 k=j\,pn^{-1}\bmod q,\quad 0\mapsto q.
\]

Следует `1≤k≤q`, ошибка рациональной ячейки ≤3/(4q), native орбиты <1/q, поэтому `||G^k−R_(α/L)||op<4π/q<2^-20075`. Для дальнейших оценок достаточно δ=2^-20000.

В reference-коде имеются точные целочисленные интервалы, адаптивная проверка положительности знаменателей, шесть half-angle редукций atan, знакопеременный ряд с остатком, закреплённый B80-интервал π и точное округление через modular inverse. Floating point не участвует. Предел ширины π (<2^-40900 с запасом) существенно меньше требуемого 1/q. Для каждого фиксированного конечного алгебраического входа уточнение остальных интервалов сходится; конечное принятие следует из строго положительных знаменателей и запаса по ширине π.

## 5. Почему параметры вычислимы из actual W

Положим a=√p. Тогда `a^4+a^2−1=0`, cosθ=a, sinθ=a². Все элементы native G/CX, конечного фактического W и его канонического WORK-вектора лежат в Q(a). Каждое M_b есть конечная сумма/произведение этих элементов. Именно этот буквальный алгоритм для малого W реализован в `compressed_entry`: SAM фиксируется значением b, каждый actual leaf и repeat сохраняется, любой target на SAM отвергается; затем вычисляется <v|W_b|v>.

Для производственного математического алгоритма можно не хранить полный вектор. Положить u_b=M_bψ_b, r²=Σu_b² и z_b=rχ_b+u_b. Поскольку V_v однороден по v, для V_h достаточно ненормированного z. Для любого суффикса индексов

\[
 \sum z_i^2=r^2\sum\chi_i^2+2r\sum\chi_i u_i+\sum u_i^2.
\]

Три суммы справа принадлежат Q(a) и определены конечным перебором actual W; r — положительный алгебраический корень. В j-й плоскости требуется только `A_j=z_0²+Σ_(i>j)z_i²`, коэффициенты `c_j=√A_j/√(A_j+z_j²)`, `s_j=−z_j/√(A_j+z_j²)`. Для обратного списка перебор идёт по возрастанию; суммы можно пересчитывать. Это конечная математическая процедура с целыми индексами, а не oracle таблицы/угла и не новая физическая операция для чтения M. Оценка времени/памяти её физического выполнения не заявляется; исходная цена не отождествляется со стоимостью этого математического описания.

## 6. Общая ошибка и число оплачиваемых вентилей

Точный Walsh-блок есть L-я степень выбранного одноплоскостного вращения, поэтому его ошибка ≤Lδ по телескопическому неравенству для унитарных произведений. Для всей матрицы

\[
 \|\widehat U-U_*\|_{op}\le4(d-1)L\delta
 <2d^2\delta=2^{-14623}\quad(m=2688).
\]

Верхняя граница G — `4(d−1)Lq`. Общее число CX точно равно

\[
 4\big((d-1)(m-1)L+2(mL-d+1)\big),
\]

поскольку Σ_(j=1)^(d−1) popcount(j)=mL. Их сумма <2^25458, что проверено точной целочисленной арифметикой с конкретным q. Здесь каждый G внутри G^k оплачен как отдельная операция; никаких бесплатных huge-power gates нет.

## 7. Точная подстановка и незакрытая композиция

B78 требовал доказать отсутствие утечки на private на всех SAM-столбцах для сжатого независимого P_b. Для математически определённого слова A41 это следует непосредственно из support: оно есть \(\widehat U_{SAM}\otimes I_{WORK}\), без новых private. Поэтому унитарность сжатия точная, хотя совпадение с U* приближённое. Прежнюю ошибку A39 на одном занятом векторе нельзя было использовать для такого заключения.

Следующий потребитель — новая полная оплаченная история с этим SAM-only постоператором: сохранить actual A30 prefix/RAW marks, выровнять сравниваемые длины, повторно вычислить clock/heat/gain и независимые источники. Границы A39/A40 нельзя автоматически переносить на изменённую историю или объявлять тем же F_N. Полный H.1, обязательные будущие тесты, независимые upstream/WORK/reader/scene вариации, исходный Cost−Info и уточнение остаются отдельными обязательствами. Здесь не добавляется новая action, Info, source coefficient или selector и не начинается новая геометрическая root-кампания.
