# Эталонный Golden-архив для настоящего остановленного слова full128

На исходном полевом приборе full128 построена конечная проверка каждого напечатанного бита. Пусть Z — вероятность того, что **все** биты архива, до первого STOP включительно, совпали с независимо рождёнными Golden-битами. На действительной касательной §7gb, где DΛ=0 и весь закон портов имеет нулевой первый отклик, получаем

    0,03381657 < Z < 0,03381658,
    −3,6452·10⁻⁶ < D Z < −3,6444·10⁻⁶.

Здесь Z — нормированная частота реального двухисходного теста. Для каждой конкретной зарегистрированной истории Γ её условная вероятность полного совпадения в точности равна φ^(−L(Γ)), где L — полная длина записи семи исходных битов каждого посещения кодом 0/10. Получен физический носитель положительного веса именно для этого архивного кода. Его собственная логарифмическая цена −log Z имеет строго положительную производную. На каждом конечном посещении тесту нужны только семь свежих битов.

## Что приготовлено, что измерено и что оплачено

Работаем с реальным порядком z=2j+b исходного прибора (0≤j<64). У b=0 — STOP, у b=1 — продолжение. Полный исход состоит из шести битов j и одного b. Начальный DATA-маргинал ρ=I₁₆/16 есть значение заданной ρ_Λ=Λ⁻¹/Tr Λ⁻¹ в исходном центре. На выбранной касательной Dρ=0. Состояние любой уже удерживаемой ссылки R может быть запутано с DATA; ни одна из новых операций её не адресует. У исходника §7fh имеется полноразмерное отражение и физический порядок всех 128 колонок. Его приближённая компиляция на произвольной сетке и оплата допуска — отдельные задачи. [Нативная постановка и порог компиляции](../../../../../A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md#L137275) · [Точный исходный full128 и его касательная](../../round69/primary/STOPPED_FINE_RU.md)

Для каждого текущего бита x, пока адрес жив, канонически рождается отдельный указатель v=(√p,p), p=1/φ, и выполняется единственный CX(x,указатель). После этого измеряем исходные семь битов и семь указателей в вычислительной базе. Совместная вероятность нуля на указателе при x=0 равна p, при x=1 равна p². Условно на весь действительный архив показания всех таких свежих указателей независимы. Все ветви, отличные от совпадения, продолжают работу до исходного решения самого порта. Число новых реальных рождений и CX на посещение равно семи каждого вида. Указатели, старый DATA, старые записи, сама метка и все несовпадения сохраняются. Для ответа «все совпали» достаточно объединить уже зарегистрированные строки; печать дополнительного отдельного итога требует собственной работы. [Исходные шесть адресованных указателей в §7gd](https://github.com/gvakhrushev/d0_15/blob/15f5b786ed912a0e91d660e337bf60a7c15c7cfa/02_REGISTRY/research/A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md#L192550)

Обычный код пишет 0 символом 0 и 1 символами 10. Поэтому при h(j) единицах в индексе j длина одной семибитной метки есть l(z)=7+b+h(j), а вероятность нуля сразу на всех указателях есть ν(z)=p^l(z). Исходный портовый код 1+b здесь учтён один раз. Для одного слова Γ произведение даёт ν(Γ)=p^L(Γ). На полном пространстве остановленных семибитных слов Σ_Γ ν(Γ)=1: шесть адресных битов суммируются в (p+p²)⁶=1, а по числу продолжений остаётся Σₙ (p²)ⁿ p=1. Таким образом, ν — также закон самостоятельно приготовимого эталона с остановкой по собственному порту. На каждом достигнутом реальном шаге семь физических указателей реализуют сравнение с этим законом без отбрасывания данных. В каноническом коде для наблюдаемого слова точное число символов L есть −log_φ ν. У полной аппаратной цены остаются стоимость рождения, управления и считывания каждого указателя. Положительный коэффициент сравнения получен без назначения тарифа адресам j. [Существующая физическая запись 0/10](../../round66/clock/FULL_PRINT_CLOCK_RU.md)

## Немедленный STOP на действительном приборе

Пусть B_j=N_j†a для исходного a=N₀, λ=9/640, M_j=N_j N_j†. Для зарегистрированного исхода на одном посещении K_(j,0)=δ_(j0)I−2p²B_j, K_(j,1)=−2p√p B_j. На центре a²=λI; обе тихие производные при j=0 равны нулю. По шести меняющимся цифрам нынешней записи, объединённым **по числу единиц** в фактическом индексе, получаем

    Σ_j t^h(j) D Tr M_j =
      (3/10)t − (9/5)t² + (39/40)t³ + (9/20)t⁴ + (3/40)t⁵.

Уже абсолютное событие «первый порт STOP, все семь указателей равны 0» различает поле. Его вероятность Z₀ и производная на том же исходном приготовлении равны

    Z₀ = (−24789337+11101613√5)/1024000 ≈ 0,0338128202103,
    D Z₀ = 253449/102400−56673√5/51200 ≈ −3,5251727653·10⁻⁶.

Для производной достаточно подставить t=p в полином и умножить на p⁷·4p⁴λ/16. Вероятность немедленного STOP без условия на указатели равна 1−q, q=4p³λ, а её производная нулевая. Поэтому при условлении на немедленный STOP сигнал составляет D Z₀/(1−q). При дополнительном раннем останове **до вызова full128** семибитной метки в журнале ещё нет: пустое слово даёт вероятность совпадения 1; любой реально напечатанный внешний флаг оплачивается отдельно. [Исходные производные тонких строк §7gd](https://github.com/gvakhrushev/d0_15/blob/15f5b786ed912a0e91d660e337bf60a7c15c7cfa/02_REGISTRY/research/A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md#L192509)

## Бесконечный остановленный архив

Положим Φ_b(X)=Σ_j ν(2j+b) K_(j,b) X K_(j,b)†, F=Φ₀†I. По хронологии истинного прибора получаем абсолютно сходящуюся сумму с реальным возвращением DATA

    Z = Σ_(n≥0) Tr[F Φ₁ⁿ(ρ)] = Tr[F (I−Φ₁)⁻¹(ρ)].

На нулевом порядке F=p⁷[(1−4p²λ)I+4p⁴Σ p^h(j) B_j†B_j]; его производная получается из исходных производных каждого N_j и a. Для n=1 строго получено D Tr[F Φ₁ρ]≈−1,1958721552·10⁻⁷; для n=2 — −2,6497570158·10⁻¹¹. Производная инструмента учитывается на каждом месте в произведении, без переинициализации и без скалярной замены Φ₁.

Для явного контроля поздних ветвей имеем нормы F≤u I, ‖Φ₁†‖≤v и ‖DF‖≤u′, ‖DΦ₁†‖≤v′ на самосопряжённых входах, где

    u=1/25,      v=1/2000,      u′=2/25,      v′=1/100.

Здесь p⁷<1/25, p⁸<1/40, q<1/50. Действительные суммы Σ_j ‖D B_j‖²_F<1 проверены на всех 64 исходных строках. Неравенство Коши для двух операторных колонок даёт для производной каждого отмеченного канала оценку 2 max_j ν(2j+b) √(‖Σ K†K‖ · ‖Σ DK†DK‖). Последняя норма меньше 1 по указанной сумме и 4p³<1, 4p⁴<1; у продолжающего канала первая норма q. В окрестности центра сохраняется строгий запас сжатия, поэтому ряд можно дифференцировать. Вклад всех n≥3 в Z не превосходит u v³/(1−v), в DZ — u′ v³/(1−v)+u v′[(1−v)⁻²−1−2v]. Результирующие интервалы в начале записки проверены рациональными неравенствами в ℚ(√5). ## Какой информационный выигрыш различим

Декларируемый здесь наблюдатель читает классический архив Γ, его завершение и значения зарегистрированных указателей. Он может вычислить бинарную частоту полного совпадения. Она строго зависит от поля уже при неизменной статистике портов. Для наблюдателя, который хранит только классический Γ, абсолютный код и эталон дают ещё одно точное равенство в натуральных единицах

    D_KL(P_Γ || ν) = (ln φ) E L(Γ) − H(Γ).

Обе сравниваемые классические подготовки реализованы. Если старая **доступная** запись Y уже прочитана и сохраняется, условленный эталон независимо генерирует ν при том же маргинале Y. Тогда D_KL(P_ΓY || ν P_Y)=(ln φ)E L−H(Γ|Y). На совместной квантовой алгебре (Γ,R) формально и точно D(ρ_ΓR || ν⊗ρ_R)=(ln φ)E L−H(Γ|R); операционное чтение последней относительной энтропии требует тестов на R. Новые указатели к R не обращаются. Когерентная запись, реально измеренная семибитная запись, редукция на DATA и измерение прежней ссылки имеют свои операции и свои информационные цены, как установлено в §7gc–7gf. [Различение доступных алгебр в первичном сравнении](https://github.com/gvakhrushev/d0_15/blob/15f5b786ed912a0e91d660e337bf60a7c15c7cfa/02_REGISTRY/research/A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md#L192160)

Для этой конкретной классической цены известен **полный первый отклик**. В исходном законе, до применения эталонного фильтра, продолжающая карта T даёт Tρ=qρ и (DT)ρ=0 на ρ=I/16. Это следует из a²=λI, D(a a†)=0 и Σ N_j†N_j=I вместе с его производной. После n продолжений ненормированная DATA-масса qⁿρ имеет нулевую производную. У семи обязательных символов и портовой добавки нулевой первый отклик, а сумма h(j) D Tr M_j равна 9/5. Поэтому на всём дереве

    D E L = 9λp²/[20(1−4p³λ)] ≈ 0,0024496572.

Используя на той же касательной строгий предел 0,01636<D H(Γ)<0,01650 для полного классического журнала, получаем **−0,01533 < D D_KL(P_Γ || ν) < −0,01517 нат**. Это цена заданных двух измеримых классических приготовлений в абсолютной нормировке. На том же приборе производная −log Z положительна. Такой знак исключает положительную пропорциональность их ковекторов в данном центре. Вывод о множествах решений или о выборе полного Book-операнда потребовал бы собственных уравнений. [Границы производной всей классической энтропии](../../round69/stopped/FULL_STOPPED_CQ_RU.md#L95)

У наблюдателя, читающего всего один бит «всё совпало», имеется количественно положительная доступная различимость. Его классическая информация Фишера по указанному параметру есть (DZ)²/[Z(1−Z)]>4,06·10⁻¹⁰. Для двух близких полей с шагом t классическая относительная энтропия этого единственного показания равна половине указанного коэффициента, умноженной на t², с остатком o(t²). Обработка полной измеренной записи до этого бита даёт ту же нижнюю границу на различимость полных записей. Это чувствительность данного физического наблюдателя во втором порядке. На том же поле у −log Z первая производная больше 1,077·10⁻⁴.

Положительное совпадение, архивная длина и классическая относительная энтропия являются тремя определёнными величинами одного опыта. Для любого полного входа Ω_DR указатель совпадения даёт ровно ту же вероятность, что и вычисление на его реальном DATA-маргинале, поскольку его эффект есть E⊗I_R. Для приведённых чисел нужны именно ρ=I/16 и Dρ=0; у подвижного маргинала добавляется его собственный вклад. Обязательность такого архивного наблюдателя для исходной §03.3.0a, цена подготовки исходного инструмента и его соответствие all42 из этого результата не вытекают.
