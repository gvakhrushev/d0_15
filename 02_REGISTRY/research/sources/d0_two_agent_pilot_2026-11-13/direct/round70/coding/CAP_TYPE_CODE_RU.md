# Один Golden-код приближает обе первые вариации цены B130

Существует одна последовательность фиксированных, независимо от поля построенных префиксных кодов для всех полных записей CAR16 до третьего вызова. На пяти действительных условных приготовлениях B130 средняя напечатанная длина на один независимый блок приближает классическую энтропию полной записи вместе с обеими производными — по кофрейму v и по общей амплитуде ν четырёх исходных ног. Для исследуемого энтропийного контраста получены проверяемые численные границы. При физической повторной печати можно приближать также множитель 1+1/κ, требуемый при стационарных ранних относительных весах. Точное равенство в каком-либо конечном коде этим пределом не устанавливается.

Основная теорема о классах типов и Golden-коде уже доказана в D0. Здесь осуществлено её применение к двум физическим вариациям B130, с учётом нулевых листьев, реальных условных приготовлений и разных расписаний. ## Полный алфавит и один код

Кодируется фактически зарегистрированная конечная история, включая первую метку. В длинном расписании есть 64 возможных немедленных STOP, 64² исходов второго STOP и 64²·128 вариантов третьего визита, включая оба порта и принудительное окончание. Всего 528448. Добавим 128 помеченных коротких записей с остановкой после первого вызова: K=528576. Детерминированные отметки срока восстанавливаются из слов. Нули вероятности занимают свои места в алфавите. В сравнении префикс 2j+1 фиксирован для j=0,13,29,45,61. Каждое полное длинное условное слово потому содержит один из 8256 допустимых по расписанию хвостовых адресов, а полное короткое слово детерминировано. [Первичный опыт и равные веса четырёх редких состояний](../../../open/round130/B130_SHARED_PREFIX_CAP_SOURCE_RU.md)

Для m целых блоков зададим T=binom(m+K−1,K−1), для каждого вектора количеств τ размер M_τ=m!/∏τ_i!. Каждому из M_τ слов даём рациональную массу μ(w)=1/(TM_τ). Сумма масс равна 1. Отрезки этих масс упорядочиваем один раз для всего алфавита. Внутри отрезка слова берём Golden-цилиндр, содержащий его середину: левый переход сужает интервал в p раз, правый в p² раз, p=1/φ. Останавливаемся сразу после достижения ширины ≤μ/2. Цилиндр целиком внутри нужного отрезка, его ширина строго больше p²μ/2. Для фактических длин F→0, R→10 в натуральных единицах получаем

    −ln μ(w) ≤ L(w) ≤ −ln μ(w)+B,    B=ln2+2lnφ,    Σ exp(−L(w))≤1.

Слова префиксные. Построение не обращается ни к вероятностям прибора, ни к их полевым производным. Чтобы кодировать отдельные слова полного K, реализация вычисляет ранг мультимножества через биномиальные коэффициенты, затем ранг перестановки и адресует середину рационального отрезка. Это позволяет проверить выбранные реальные и тёмные адреса без таблицы из K^m элементов. [Точный исполнимый кодировщик и проверка покрытия](golden_type_code.py)

## Первая производная и открытие тёмных листьев

Пусть P — один из пяти полных условных законов, X состоит из m независимых приготовлений этого закона. На положительном носителе S_m=D log P^m(X) — сумма m центрированных оценок, E S_m²=m I_D. Введём R=L+ln P^m. Верхняя граница R≤ln T+B следует из P^m(w)M_τ=P^m(тип τ)≤1. В нижнем хвосте Pr(R<−u)≤e⁻ᵘ: достаточно E exp(−R)=Σ_{P^m>0}exp(−L)≤1. Следовательно E R₋²≤2. Одновременно 0≤E L−mH(P)≤ln T+B. При дифференцировании фиксированного кода получаем

    D[(E L)/m−H(P)] = E[R S_m]/m,
    |D[(E L)/m−H(P)]| ≤ √I_D · C_m/√m,
    C_m=√[(ln T+B)²+2].

Последняя граница относится именно к производной. У полного B130 каждый регистрируемый лист имеет гладкую векторную амплитуду, также после условления на положительный первый префикс. Для погасшей в центре амплитуды P_x(t)=O(t²), поэтому −P_x(t)ln P_x(t)=O(t²|ln|t||); её первая производная равна нулю. При фиксированном m это верно и на всём конечном произведении, включая смешанные тёмные исходы. Для произвольного абстрактного закона одного конечного Fisher в точке недостаточно. Например, при P₁(t)=|t|/ln(1/|t|) закон имеет нулевую первую производную и нулевой обычный Fisher в центре, тогда как H(t)~|t|. Нужны дифференцируемость энтропии на границе носителя либо доказанное для B130 квадратичное открытие.

## Оплата, подготовка и предел применения

Обычная длина приближает H, а равенство при неподвижных ранних относительных весах требует (1+1/κ)H в контрасте. Для κ=1 реально записываем каждое кодовое слово дважды. Для κ=2 берём две независимые группы по m блоков, к каждой применяем **один и тот же** код: по заранее известному расписанию первое кодовое слово печатаем дважды, второе один раз. Получаем точный множитель 3/2 среднего на один входной блок. Копия детерминирована уже зарегистрированным словом, поэтому её условная Shannon-информация равна нулю. При общей копировальной программе длиновая производная остатка (κ+1)D J−κD(средняя длиновая плата в натах) ограничена (κ+1) соответствующей границей выше. Это устраняет ненулевой **предельный** зазор для указанной компоненты сразу по v,ν.

Требуются m независимо и действительно заново приготовленных запусков. Это можно понимать как условное сравнение в едином полном опыте из m независимых подготовок: на событии, где все m заранее зарегистрированных первых адресов равны конкретному j, последующие слова имеют ровно закон P_j^m. Все остальные журналы тем же кодом разрешены и физически сохраняются. Вероятность такого адреса может быть очень мала. Другой вариант донабора m требуемых префиксов требует оплачивать все неуспешные приготовления и хранить их записи. Один коллективный выбор j, равновесная смесь независимых j для каждого блока и m-кратное использование неизвестного состояния вообще задают разные приборы. Если коррелированы исходные DATA, ссылки или повторные приготовления, нужен действительный закон всего блока.

Код применяется после регистрации всего блока: сама программа арифметики, накопитель, чтения, адресный контроллер, повторная печать и закрытие требуют собственной работы. Фиксированное расписание дополнительной копии не добавляет случайного выбора. При действительно случайном селекторе его закон, память и адрес входят в общую цену. Префиксный код и его счёт напечатанных символов сами не выбирают полную физическую Book-цену. Для перехода к источнику ОТО остаются цена этих операций, изменение масштаба и правого подъёма при физических уточнениях и выбор реально допускаемых вариаций.
