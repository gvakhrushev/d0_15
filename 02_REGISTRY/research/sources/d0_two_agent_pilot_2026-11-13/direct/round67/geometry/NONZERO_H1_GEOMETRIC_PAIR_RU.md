# Два геометрических показания исходного H.1 с ненулевой разностью

Выбран один внутренний узел исходного решения Бринкмана и одна свободная компонента кофрейма. Для малого возмущения уже существующего второго CAR-поля два показания шумного бита H.1 различаются строго. Знак и размер разности получены из исходных семи обращений к геометрическому банку. Дополнительно установлено, как сохранить знак при оплаченном конечном изменении приготовления CODE на фактическом скомпилированном банке EO. Обе постановки сохраняют материальные поля, независимые связи и исходные граничные значения по правилам своего сравнения.

## Геометрия и два конечных входа

Берём `h=1/8`, исходные `a=p/4`, `k₀=r_q/r_f>20` и поля PC4–PC7. На внутреннем узле `z*=0` меняем только значение `Ψ₁₅` с нуля на `b=h·2⁻¹⁰`; в остальных узлах оно равно нулю. Заполнитель компоненты 14 берётся из прежней формулы нормировки `√(1−p−Ψ₀²−Ψ₁₅²)`; запас PC5 остаётся строгим. Независимое поле `Ψ₀=a u` и все исходные лоренцевы связи сохраняются. В качестве допустимой нормированной подготовки SITE берём `ρ_z=1` (`Σh⁴=1`). Границы и калибровка PC13–19 общие. Шаги малы, все кофреймы невырождены, материальные квадратные корни и вероятностные входы лежат в исходной регулярной области с общим положительным запасом при обычном выборе её огибающей до калибровки ε. [Исходный владелец, PC4–PC13, строки 174027–174180, и PC14–19, строки 174182–174277](../../../../../A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md)

Пусть на том же узле `e_N(τ)=I+τE_{uv}` в нулевом репере. Это компонента `e⁺_v`. В двух входах геометрические значения `τ=±2⁻¹²`. Все прочие компоненты на сетке одинаковы. В декартовом репере PC применяется фиксированное `e_C=Q e_N`; в координатах независимого обратного кофрейма направление равно `−E_{uv}Qᵀ` при `τ=0`. Это две матричные компоненты с коэффициентами `−1/√2,+1/√2` (строка `u`, столбцы 0,1). Детерминант в точности один вдоль всего отрезка.

В узле `z*` вклад второго поля имеет градиент `−(b/h)(1,1,1,1)`; его квадрат при `τ=0` равен нулю. Из `g⁻¹(τ)_{uu}=−2τ` и неизменных остальных элементов получаем два **точных** момента:

    f(τ)=−2k₀a²τ,       q_matter(τ)=−2(a²+d)τ,       d=b²/h²=2⁻²⁰.

Для первого равенства исходные две нетривиальные плакетки в данном узле равны `exp(−k₀a²h² N_j)`, j=x,y. Подстановка в полную CAR16-формулу PC8 даёт от каждой `−k₀a²τ` после деления на `h²`; остальные четыре равны единице и дают ноль. Число в геометрической строке соответствует PC11 после перевода `v_role=h e_N`. В других узлах момента, зависящего от τ, нет. В частности, пространственные разности изменённого CAR-поля в соседних узлах присутствуют на обоих концах. Для `I_h=Σh⁴(f−k₀q_matter)` имеем `∂_τ I_h=2h⁴k₀d>0`. ## Считывание Q до знака, затем шумный q на H.1

В (JZ6) исходный холодный возврат равен `c*=1−2Q_event`; на исходном H.1 шумный бит имеет вероятность `q_read=p²+p³Q_event`. Важно, что это предзнаковый проектор после всего исходного процессора, а не один из семи вспомогательных отчётов. Пусть `ε=ε_h≤1/64`, `m=a²+d`, `t₀=2⁻¹²`, `x₊=−2εk₀a²t₀`, `y₊=2εm t₀`, `x₋=−x₊`, `y₋=−y₊`. При обозначениях PC13–20 точная разность **целевой семизапросной программы** равна

    q_read,+ − q_read,− =
      p³ λ_vis a_ready² Δ_y(δ_h) h⁴
      [r(x₊,0)−r(x₋,0)+r(0,y₊)−r(0,y₋)].

Квадратичность `r(x,0)` делает её нечётную разность точно линейной. Для `r(0,y)` на `|y|≤1/64` имеем `|r'''|<200 z₀`, `r_q>z₀/4`; вывод и арифметические границы даны в проверке. Поэтому относительная ошибка по сравнению с линейным ответом не больше `m·200 z₀ y₊²/(6r_q d)<2⁻¹⁸`. Масштаб `γ_h=2λ_vis a_ready² ε r_f Δ_y(δ_h)>0`. Получается положительный и полностью нормированный конечный интервал

    (q_read,+ − q_read,−)/(2t₀ · p³γ_h/2)
       ∈ 2h⁴k₀d · [1−2⁻¹⁸, 1+2⁻¹⁸].

При `τ=0` производная точно равна середине этого интервала после той же нормировки. [JZ6, строки 182719–182753, и буквальная операция считывания NPS10, строки 145097–145121](../../../../../A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md)

## Пара на одном фактическом банке EO

Здесь шаг `t` управляет **приготовлением**, а `s` задаёт масштаб записанной геометрической координаты. Их нельзя подменять числом `t₀` предыдущего сравнения. При центре `τ=0` с уже включённым `Ψ₁₅=b` теорема NG11 строит фактическую самосопряжённую таблицу `M=c_n I+sΣ_j d*_j V_j+E`, где `d*=Dc*`. Для нашего направления `w` выполнено `d*(w)=−γ_h·2h⁴k₀d`. Берём исходный MG2-генератор `X=Σ w_jX_j` в его координатах поля. При дополнительных масштабах карты `χ_h` коэффициенты берутся из `Dχ_h(w)`, а ковектор — в сопряжённых координатах. Разные пары CODE действуют на разных факторах, и их точные целевые экспоненты коммутируют. Оплаченные MG8–MG10 приближают их на всех колонках одинаковыми по инвентарю словами. При фиксированном банке и одном и том же шумном считывателе настоящие вероятности равны

    q_native,±=p²+(p³/2)[1−⟨P̂± φ, M P̂± φ⟩].

Прочие три вхождения приготовления остаются независимыми. Заднее вхождение уже после считывания, внутреннее коммутирует со знаком; исходная геометрическая диагональ даёт тот же предзнаковый результат при таких вхождениях. Постоянная часть таблицы сокращается. По MG3, SER6 и оценке третьей производной сопряжения получаем

    | (2/p³)(q_native,+−q_native,−)/(2t) − S |
       ≤ 2‖X‖‖E‖ + (4/3)‖X‖³t² + 2η_P/|t|,
    S=sγ_h·2h⁴k₀d > 0,       η_P=max_± ‖P̂±−exp(±tX)‖.

Здесь использованы `‖M‖≤1` и `‖ad_X³(M)‖≤8‖X‖³`. Это оценка скалярной вероятности на фактически исполненных концах, не производная дискретной программы. Из NG11 имеем `‖E‖≤2s²R_v²‖d*‖²/a_rad²+2η_N` с действительной ненулевой радиальной восприимчивостью `a_rad`. Сначала уменьшаем `s`, чтобы первая, квадратичная, ошибка дала менее `S/8` после множителя `2‖X‖`; затем выбираем `η_N` с таким же резервом. MG8–11 дают `η_P≤C|t|³+C'η_plane` с конечными эффективными константами данной оси. Выбираем `t>0` так, чтобы квадратичные по `t` остатки дали менее `S/8`, затем `η_plane` так, чтобы его остаток дал менее `S/8`. Получившаяся положительная нижняя граница для `(q_native,+−q_native,−)/(2t)` равна `p³S/4`. Величины выбираются из алгоритмов и положительных запасов существующего владельца. Развёрнутый нативный список степеней для этого нового центра в этой работе не генерировался.
