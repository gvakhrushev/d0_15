# Дополнение A после взаимной проверки

Первый отчёт и его доказательство сохраняются неизменными. Замечания B из `open/REVIEW_A_RU.md` приняты: они уточняют физическое применение, не опровергая доказанную конечномерную евклидову формулировку.

## Явный множитель физического подъёма

Если для полного V построено `L C_I=I_V`, из COV2 следует `||r||≤ε||C_I||`. Подстановка единицы служит только для проверки полноты покрытия. В настоящем CD13 остаётся исходный физический подъём R_h:

```
||R_h|| ||r_h|| / Γ_h
    ≤ ||R_h|| ε_h ||C_I,h|| / Γ_h.
```

Требовать стремления к нулю нужно от всей правой части. Малый полный остаток сам по себе недостаточен при растущем подъёме. В исходном COV4 этот множитель уже был сохранён в альтернативной формуле; здесь он явно выписан и для первого способа.

## Перенос на исходные нормы

Для любых объявленных норм достаточна любая действительная факторизация `LC=R` и операторное неравенство

```
||rR|| ≤ ||rL|| ||C||.
```

Оптимальность евклидовой псевдообратной и корень суммы квадратов относятся именно к гильбертовой прямой сумме из первого доказательства. Для прямой суммы управлений с max-нормой из отдельных `||rL_j||≤ε_j` следует безопасная оценка `||rL||≤Σ ε_j`; для нормы суммы — `||rL||≤max ε_j`. В физических occurrence-нормах нужно вычислять соответствующий фактор C или сохранять доказанные константы сравнения. В уточняющейся семье эти константы могут зависеть от сетки и числа блоков.

Приведённые B контроли `L=(1,2)` и растущий `R_h=(1,t)` корректны. Они не являются физическими моделями H.1, но предотвращают ошибку при интеграции.

## Как использовать открытый результат B

Принята формула B `DΔJ=-F(s_n)Dq` для явно расширенной задачи с дополнительным считывателем. Это источник указанного code/CQ-компонента. Полная физическая цена и перенос остаются открыты.

Нельзя отождествлять рассчитанный градиент наблюдения с картой вмешательства L. При фиксированном reporter семейство этих градиентов пропорционально одному Dq; простое увеличение числа k,n не доказывает покрытие новых физических направлений. Полезный следующий объект — **одно реальное продолжение, один полный оплаченный источник, его перенос и все независимые строки**, с проверкой условия компенсации O2 и границы CD13.

`physical_C_closed=false`, `GR_closed=false`.
