Какой из этих способов оплаты реализует полная Book03, из минимальной длины кода теста не следует.

## Реальное считывание и полная информация

Пусть старый b уже измерен. Произвольные квантовые блоки старой памяти и ссылки ρ₀,ρ₁ имеют следы 1−q и q. Сохраняем их целиком. Берём из A65 только второй тег. Каждое повторение содержит каноническое рождение v=(√p,p), один CX от b, затем действительное G⁻¹=ZGZ на теге и чтение. Это одно рождение и 18 примитивных команд до регистрации, при том же CX/SourceI переносе Z. Адресация, регистрация и остановка требуют своей реализации. При b=0 тег имеет вид |0⟩, при b=1 получаем c|0⟩+p³|1⟩ с c=2p√p, 1−s=c²=4p³, s=p⁶, p=1/φ. [Нативный анализатор и сравнение с буквальной печатью A65](../../round65/RETAINED_PRICE_RU.md)

На m повторениях после сохранения всех меток полный CQ-спектр, с точностью до нулей, есть объединение спектра ρ₀ и спектров ν(u)ρ₁, где ν — произведение m независимых Бернулли(s). Поэтому прибавка энтропии в натуральных единицах **ровно q m h(s)**, при произвольных полевых изменениях ρ₀,ρ₁. Для эффекта H.1 это даёт m h(s)Dq с Dq=gA_pre*D I_h+e. Если все отчёты печатаются одним фиксированным знаком длины за такт с отдельным значением бита, число оплаченных тактов неизменно. Информация всё равно реагирует. Оба плеча читают **тот же** старый b, переприготовления поля в каждом такте нет. Более раннее условное считывание уже давало кратный Dq для классифицированной цены; здесь дополнительно сравниваются односторонний прибор, цены кодов и возможные точные компенсации. Тот же расчёт проверяет необратимую интерпретацию. В исходном **двухтеговом** прочитанном опыте A65 оставим B и все старые данные R. Условная энтропия вторых тегов при сохранении первых, B и R равна q m h(s). Для первых при сохранённых вторых она равна (1−q)m h(s). При b=0 случайны только первые, при b=1 только вторые. ## Почему отдельная цена буквы может остаться неизвестной

Пусть для одного тега две действительные платы за отчёт в единицах длины равны целым n₀,n₁. Изменяется лишь вероятность старого b. С учётом всей информационной прибавки в единицах ln φ получаем

    D ΔC = m s (n₁−n₀−Θ) Dq,     Θ = h(s)/(s ln φ).

Равенство в том же виде верно для конечных разностей q. Введя A(s)=−(1−s)ln(1−s)/s, имеем Θ=6+A(s)/ln φ. Из степенного ряда следует (1−s)(1+s/2)≤A(s)<1. Точные рациональные границы s<57/1000 и 0.48<ln φ<0.482 дают **8.01<Θ<8.1**. Следовательно, независимо от фиксированной целой разности цен абсолютное усиление превышает m s/100. У исходной буквальной печати n₁−n₀=1, у одинаково дорогих регистраций разность нулевая; знаки в обоих случаях отрицательны. Для разности ≥9 знак положительный. При фиксированном масштабе и любом ненулевом знаке стационарные точки добавки совпадают с Dq=0. Для предельного уравнения требуется контроль всех остальных полевых строк относительно фактического усиления.

Более общая конечная проверка допускает индивидуальную цену каждой **полной** зарегистрированной строки, включая зависимость от порядка и числа успехов. Пусть разность средних плат при b=1 и b=0 равна C₁−C₀; эти платы и условные законы фиксированы при данной вариации и алгебраичны. Таковы, например, любые фиксированные целые длины на каждой из 2^m+1 строк с описанным выше законом. С коэффициентом единица перед полной CQ-информацией в золотых единицах наклон равен C₁−C₀−m h(s)/ln φ и **не равен нулю**. Действительно,

    h(s)/ln φ = 6s − (1−s)[2 log_φ 2 − 3].

Число log_φ 2 иррационально: из φ^a=2^b для положительных целых a,b по норме поля Q(√5) получилось бы (−1)^a=4^b. По теореме Гельфонда–Шнейдера оно трансцендентно, иначе степень алгебраического φ с алгебраическим иррациональным показателем была бы одновременно 2 и трансцендентной. Коэффициент при нём отличен от нуля и алгебраичен. Таким образом, ненулевая конечная разность цены следует из арифметики, без выбора таблицы тарифов в доказательстве. Для неконстантного q имеется в виду ненулевая разность при q₊≠q₋. Для разных таблиц отсутствует единая положительная граница: алгебраические числа плотны. На изменяемых внутренних тарифах возникает дополнительный вклад (1−q)DC₀+qDC₁. [А. Бейкер, формулировка теоремы для логарифмов](https://www.cambridge.org/core/journals/mathematika/article/abs/linear-forms-in-the-logarithms-of-algebraic-numbers/55674A9E93007ADD34DCEDC12EA4FB4D)

## Когда код всего журнала допускает компенсацию в пределе

Рассмотрим префиксные кодовые слова, составленные только из токенов `0` и `10` длины 1 и 2. На дереве токенов цилиндр слова длины L имеет вероятность φ⁻ᴸ при последовательном делении интервала на доли p,p². Поэтому оптимальная ожидаемая длина ℓ(ν) для любого конечного положительного закона ν удовлетворяет

    H(ν)/ln φ ≤ ℓ(ν) ≤ H(ν)/ln φ + 2 + log_φ 2.

Нижняя граница следует из неравенства Крафта и неотрицательности относительной энтропии. Для верхней разбиваем [0,1) на последовательные интервалы масс νⱼ. Выбираем первый цилиндр, содержащий середину такого интервала и имеющий массу ≤νⱼ/2; цилиндр лежит внутри интервала, а его масса >p²νⱼ/2. Цилиндры попарно не пересекаются и дают требуемые кодовые слова.

Для полного зарегистрированного журнала (b,теги) при b=0 поддержка одноточечна, при b=1 она имеет закон ν=Bern(s)^m. Обозначим через L₀,L₁ средние длины при фиксированном b в действующем оптимальном совместном словаре. Ограничение на каждый сектор даёт L₀≥0, L₁≥ℓ(ν). Конкатенация адресных токенов и условных кодов даёт (1−q)L₀+q[L₁−ℓ(ν)]≤1+q≤2. Значит, при p²≤q≤1/2 все односторонние наклоны оптимальной ожидаемой цены **минус полная CQ-прибавка** по q удовлетворяют

    −2/(1−q) ≤ L₁−L₀−m h(s)/ln φ ≤ 2/q + 2 + log_φ 2.

При конечной поддержке минимум достигает полное дерево без унарных узлов: сокращение достижимого унарного узла только уменьшает длину. Таких форм деревьев с заданным числом листьев конечно. Значит, границы переходят на конечные разделённые разности. Для отдельного фиксированного полного словаря наклон алгебраической длины за вычетом энтропии ненулевой по предыдущему разделу. Смена минимизирующего словаря может менять знаки, и общая оценка не даёт растущего с m источника. Действительный Book-минимум пути имеет своим носителем физические истории и класс допустимых описаний; равенство с таким совместным кодеком для наблюдаемых выходов в источнике не установлено.

Для полного вывода ОТО требуется перенести одну из действительных оценок на источник исходной Cost−Info, сохранив все изменяемые приготовления, память, плату за часы и допустимый правый подъём. [Проверка источников, состояний, границ и конечного словаря](check_one_tag_price.py).
