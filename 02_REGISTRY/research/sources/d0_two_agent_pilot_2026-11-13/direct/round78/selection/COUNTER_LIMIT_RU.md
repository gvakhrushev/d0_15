# Первая вариация положительного счётчика при закрывающейся спектральной щели

Пусть $T(g)$ — дифференцируемая по операторной норме амплитуда допуска исхода, $\|T\|\le1$, $Y=T^*T$. В частности, $T$ может быть прямоугольным оператором между входом и выходом прибора. Пусть $E_m(Y)$ — эффект двух участков [золотого счётчика](GOLDEN_COUNTER_RU.md) при допуске не более $m$ различий в каждом. При общей готовности классических селекторов имеем

$$
 0\le Y-E_m(Y)\le (m+2)^{-1}I,\qquad
 \|D(Y-E_m(Y))\|\le
 \frac{2(1+2H_{2m+1})}{\sqrt{m+1}}\,\|DT\|.
$$

Здесь $H_n=\sum_{i=1}^n1/i$. Константы одинаковы для всех размерностей, включая различные регуляторы. Размер ядра $Y$ и кратности собственных значений могут меняться. Вторая оценка относится именно к физическому семейству $T^*T$.

**Положительная ошибка.** Пусть $a_k(z)=(z)_k/k!$, $0\le z\le1$. Для билетов $z=p$, $1-z=p^2$ имеем

$$
 E_m(y)=y^2\sum_{n=0}^{2m}c_n(1-y)^n,\qquad
 c_n=\sum_{\substack{i+k=n\\0\le i,k\le m}}a_i(z)a_k(1-z).
$$

При $n\le m$ имеем $c_n=1$ по произведению полных рядов. При $m\le n\le2m$ коэффициенты убывают: теряется первое слагаемое и каждое оставшееся не увеличивается. Положим $c_{2m+1}=0$. Тогда $w_n=c_{n-1}-c_n\ge0$, $\sum_{n=m+1}^{2m+1}w_n=1$ и

$$
 y-E_m(y)=\sum_{n=m+1}^{2m+1} w_n\,y(1-y)^n.
$$

Каждое слагаемое ограничено $1/(n+1)$ для $0\le y\le1$. Функциональное исчисление даёт первую операторную оценку.

**Оценка производной.** Рассмотрим самосопряжённое сжатие $D=\left(\begin{smallmatrix}0&T^*\\T&0\end{smallmatrix}\right)$ и $B=I-D^2$. На входном блоке $D^2=Y$. На выбранной вариации $\|\dot D\|=\|\dot T\|$. Далее точка обозначает дифференцирование по выбранной вариации. Для $S_k=DB^k$ имеем

$$
 \|S_k\|\le (2k+1)^{-1/2},\qquad
 \|\dot S_k\|\le(1+2H_k)\|\dot D\|.
$$

Первая граница следует из $x(1-x)^{2k}\le1/(2k+1)$. Для второй подставляем $\dot B=-(D\dot D+\dot D D)$ в сумму производных $k$ факторов. Первый ряд по $i=0,\ldots,k-1$ ограничен $\sum_i\|D^2B^i\|\le H_k$. Второй ограничивается $\sum_i\|DB^i\|\|DB^{k-1-i}\|\le\sum_i\|DB^i\|^2\le H_k$ по $2uv\le u^2+v^2$. Начальное слагаемое $\dot D B^k$ имеет норму до $\|\dot D\|$. Для $D^2B^n=S_{\lfloor n/2\rfloor}S_{\lceil n/2\rceil}$ правило произведения даёт заявленную оценку, затем усредняем с фиксированными $w_n$. Формула допускает некоммутирующую вариацию. **Что переносится на ряд регуляторов.** Для состояния $\rho_g$ с нормированной положительной трассой положим $q=\mathrm{Tr}(\rho_gY)$ и $q_m=\mathrm{Tr}(\rho_gE_m)$. Обозначим приведённые границы ошибок через $e_0,e_1$. Тогда $|q_m-q|\le e_0$ и $|\dot q_m-\dot q|\le e_1+e_0\|\dot\rho\|_1$. При $q\ge\delta>e_0$ ошибка логарифмического источника в натуральных единицах не превосходит

$$
 \frac{e_1+e_0\|\dot\rho\|_1}{\delta-e_0}
 +\frac{|\dot q|e_0}{\delta(\delta-e_0)} .
$$

Для золотых единиц границу делим на $\ln\varphi$. Одинаково положительная нижняя граница нужна лишь для измеренной массы $q$. Если она убывает при уточнении, можно выбирать $m$ для каждого регулятора по этой формуле, используя его фактические границы источников. При сравнении ненормированных следов и сумм по растущему числу строк необходимо также учесть их множители. Сходимость гессианов из этих оценок не следует: в скалярном примере $T(t)=t$ при любом конечном $m$ эффект $E_m(t^2)$ начинается с $t^4$, тогда как вторая производная $t^2$ в нуле равна 2.

Теорема контролирует наблюдаемый источник при уточнении счётчика. Доказательство физического предела ОТО требует связать этот источник с полной ценой и проверить континуальный переход самих операторов, материи и допустимых вариаций.
