# Полная классическая запись H.1 без внешнего обучения

Пусть один исходный конечный опыт H.1 даёт оплачиваемый бинарный ответ \(T\) и остальной классический архив \(X\), включая признаки неготовности и отказа. Тег \(T\) пишется словами 0 и 1010, длины соответственно 1 и 4. На \(m\) **свежих независимых полных опытах при одном поле** имеется один конечный код, который сохраняет все \(m\) архивов и удовлетворяет
\[
 \frac{\mathbb E\,\ell_m}{m}-H_\varphi(T,X)
  =1+3Q-h_\varphi(Q)+e_m,\qquad Q=\Pr(T=1),\qquad
 e_m\longrightarrow0,\quad D e_m\longrightarrow0 .
 \tag{1}
\]
Не нужны независимый учебный массив, значения полевых вероятностей или постселекция. Внутри каждого из восьмимасштабных опытов остаются его исходные общий SITE, память и зависимости отчётов. Опыт владельца даёт именно \(T\) со всеми отказами при собственных условиях калибровки. [Восемь положительных настроек H.1, первичная сборка](https://github.com/gvakhrushev/d0_15/blob/04931a7a26a9741bba0584c8e1413613ff7a28d5/02_REGISTRY/research/sources/d0_gr_2026-11-18/followups/2026-11-19/metric/EIGHT_READERS_RU.md#L32-L52)

## Три действительно напечатанные части

Сначала передаём все \(m\) тегов \(T\). Обе их кодовые строки префиксно различимы. Размер блока, алфавиты и порядок их символов объявлены один раз. По полученным тегам известны числа \(n_0,n_1\), причём позиции каждой группы сохранены. Пусть внутри \(T=t\) остальные записи имеют конечный алфавит из \(d_t\ge1\) значений. Сложные и непостоянные по длине архивы допускают такое представление, если для них задан конечный полный словарь, включая все допустимые отказы.

Вторая часть — **явный заголовок типов**, частот \(N_{ti}\) каждой записи при каждом теге. Возможны
\[
 M=\prod_{t=0,1}{n_t+d_t-1\choose d_t-1}
\]
пар типов. Третья часть указывает расположение значений по фактическим позициям данного типа. В нём
\[
 A=\prod_{t=0,1} n_t!/\prod_i N_{ti}!
\]
размещений. Кодировщик вычисляет два целых лексикографических номера, от 0 до \(M-1\) и от 0 до \(A-1\).

Каждый равномерный индекс \(j\) из \(s\) возможностей передаётся золотым префиксным словом для интервала \([j/s,(j+1)/s)\). Штатные решения 0 и 10 оставляют доли \(p=\varphi^{-1},p^2\). Кодировщик идёт к середине интервала до первого целиком содержащегося в нём цилиндра. Декодер видит номер, как только полученный цилиндр содержится в одной из равных ячеек. При \(s=1\) слово пустое. Для \(C=2+\log_\varphi2\) практика печати даёт **поточечную** оценку
\[
 0\le \ell_{\rm header}+\ell_{\rm placement}-\log_\varphi(MA)<2C .
\]
Заголовок включён полностью. По первым двум частям известна граница и смысл третьей; вместе они однозначно восстанавливают все старые записи на исходных позициях. ## Первая полевая производная

Пишем \(D_0=d_0+d_1-2\), \(b_m=D_0\ln(m+1)\), так что \(\ln M\le b_m\). Для каждого фиксированного вектора тегов вероятность реального **типа** обозначим \(r\). В силу условной независимости полных опытов все размещения одного типа имеют одинаковую истинную вероятность, поэтому
\[
 \Pr(X^m\mid T^m)=r/A.
\]
Разность фактически напечатанной длины второй и третьей частей и идеальной \(-\log_\varphi\Pr(X^m\mid T^m)\) есть
\[
 V=(\ln M+\ln r)/\ln\varphi+u,\qquad 0\le u<2C .
\]
Среднее \(\ln M+\ln r\) условно на тегах равно \(\ln M-H_{\rm nat}(\text{тип}\mid T^m=t^m)\) и лежит между нулём и \(\ln M\). В частности \(0\le e_m\le(b_m/\ln\varphi+2C)/m\).

Для производной важны редкие типы, которым соответствует очень отрицательное \(\ln r\). Типов не более \(M\), поэтому \(\Pr(\ln M+\ln r<-z\mid T^m)\le e^{-z}\) при \(z\ge0\). Второй момент отрицательной части не больше \(2\int_0^\infty z e^{-z} dz=2\), положительная часть не превосходит \(b_m\). В результате \(\|V\|_2\le\sqrt{b_m^2+2}/\ln\varphi+2C\).

Пусть \(\pi=\operatorname{law}(T,X)\) дифференцируема по полю на фиксированной положительной опоре, \(I_\pi=\sum_z(D\pi_z)^2/\pi_z\). При дифференцировании \(V\) явная производная \(\log_\varphi\Pr(X^m\mid T^m)\) имеет нулевое условное среднее. Остаётся ковариация \(V\) с суммой \(m\) действительных полевых логарифмических производных, чья дисперсия есть \(m I_\pi\). Таким образом
\[
 |D e_m|\le
 \left(\frac{\sqrt{b_m^2+2}}{\ln\varphi}+2C\right)\sqrt{I_\pi/m}.
 \tag{2}
\]
Обе оценки при фиксированном конечном алфавите дают (1), в том числе когда одновременно двигаются \(Q\), архивы успехов и архивы отказов. Необязательные нулевые структурные метки остаются в полном словаре. При уточнении сетки, росте числа полных архивов или изменении опоры требуются собственные оценки \(D_0,I_\pi,m\).

## Память и реальная цена

Формула (1) считает полную энтропию **новой классической** записи на срезе до поступления свежих архивов. Если они уже сохранены, детерминированное перекодирование добавляет нулевую энтропию. При удержанном квантовом RIGHT, неизменном безусловном старом состоянии и чисто классическом выводе \(Z=(T,X)\) приращение относительно одной прежней RIGHT равно \(H_\varphi(Z)-I_\varphi(Z:{\rm RIGHT})\). Соответственно к правой части (1) прибавляется **положительный по значению** член \(I_\varphi(Z:{\rm RIGHT})\) на один независимый опыт; знак его полевой производной требует отдельного вычисления. Иные новые квантовые блоки и корреляции между полными запусками также требуют собственного совместного учёта.

Штатный писатель §7y печатает 0 или 10 из доставленного ведущего бита в настоящем подготовленном контейнере; слово 1010 — два вывода удержанной единицы. Заголовок и размещение вычисляются детерминированно из архива, возможен конечный табличный контроллер при заранее ограниченном блоке. Физическая доставка адресов, реализация сравнения и счётчиков, старые буферы, приготовления и завершение остаются платными. Одна классическая длина не определяет стоимость этих операций.
