# Сохранённые high-записи, исходный последний report и полный источник

13 ноября 2026. Потребитель — physical C / same-execution source в существующем #334, baseline `dc411daf01f697ec85dd22f28bfe124171796645`. `GR_closed=false`.

Новый шаг относительно round6: вместо изменения единственного обязательного report выполнить M дополнительных high-блоков, сохранив их выходы, затем **исходный неизменённый** последний блок. Между блоками потребляется настоящий paid archive handoff §7fq AD2–AD4. Это устраняет необходимость общего недемолируемого CODE-проектора **для приведённой ниже последовательной scalar-инструментальной теоремы**. Само расширение задачи и её полная физическая цена из этого не следуют.

## 1. Точный интерфейс, без сброса памяти

У каждого блока j весь истинный живой вход — Spin с произвольным запутанным старым reference. Source a и новый WORK имеют действительное canonical embedding. Для каждого полного сохраняемого бинарного исхода b требуется

```
K_(j,b)† K_(j,b) = q_(j,b) I_Spin,
q_(j,1)=q_j, q_(j,0)=1-q_j.
```

K включает весь условный квантовый выход; code0 tail остаётся unread WORK. После предыдущего блока: birth z=v; CX(a,z);CX(z,a);CX(a,z); затем seal z. Это четыре стадии, включая birth. Старый source перенесён в z вместе со всей запутанностью; живой a вновь имеет v. Все прошлые WORK/r/t и z сохранены. Следующий блок тождественен на архиве и не выбирает свои q по прошлому исходу. Его независимо заявленные поля/подготовки фиксированы заранее для данного эксперимента.

Это именно true-input scalar identity, не скалярное среднее на одной плотности и не равенство на полном позднем CODE. §7fq AD5 указывает структурный scalar-интерфейс single-SourceI. B13 теперь вывел его из замкнутости реальной span{I,L_i} алгебры для любого конечного слова разрешённого профиля и real WORK-проектора при независимом выборе четырёх native подготовок. Неизвестный Spin/reference может быть комплексным. Граница сохраняется для дополнительно заявленных complex ambient variations и Spin/future tests; исполнение всего геометрического H.1 и его marked-reader транспорта этим не заменено. Ни A_b=A_f, ни совместность event projectors, ни неизвестная плотность не добавлены как предпосылки.

Пусть T_omega — хронологическая композиция всех выбранных K, действующих на живой Spin и новых факторах. По обратной индукции с последнего блока,

```
T_omega† T_omega = P_omega I,
P_omega = product_j q_(j,b_j).
```

Тензорное присоединение произвольного reference сохраняет равенство. Следовательно, joint law новых labels — указанное произведение, а последняя old-вероятность равна q_0 независимо от предыдущих backactions. Это равенство вероятностей, **не** факторизация полного квантового состояния, не стирание предыдущих исходов и не восстановление их индивидуальных old counterparts.

При P_omega>0 карта T_omega/sqrt(P_omega) изометрична. Для любой нормированной, в том числе смешанной, запутанной или рангово-вырожденной входной rho:

```
S(T_omega rho T_omega†)
  = P_omega S(rho) - P_omega log P_omega,
I_Q := sum_omega S(T_omega rho T_omega†)-S(rho)
     = H_C := -sum_omega P_omega log P_omega
     = sum_j h(q_j).
```

S применяется также к субнормированным положительным операторам. Формула непрерывно включает нулевые ветви. Старую энтропию вычитают один раз. Для уже зарегистрированного старого CQ prefix равенство применяется к каждому его действительному conditional input и усредняется; получается I_complete=I_old+sum h(q_j), без повторной оплаты старой записи. При fixed effects источник нового указанного функционала по неизвестной rho и по всем efficient conditional output isometries равен нулю **точно**, а не после выбора одного polar optimizer.

### Независимые fine labels

Бинарная формула относится к настоящему полному инструменту с labels b и всем сохранённым квантовым WORK. Если в том же block уже зарегистрирован дополнительный alpha, его нельзя снова считать когерентным unread WORK. При полном scalar refinement q_(b,alpha)=q_b lambda_(alpha|b) та же теорема даёт

```
H(b,alpha)=h(q)+sum_b q_b H(lambda_(.|b)).
```

Даже постоянные H(lambda_(.|0)) и H(lambda_(.|1)) могут дать дополнительный source, если они различны. Для нескалярных refined effects нужна полная conditional CQ формула, а не этот scalar shortcut. Все такие дополнительные регистрации/marks имеют отдельный реальный вклад R_fine до доказанного включения в расчёт. Исходный descriptor c нельзя ослабить их исключением.

### Почти скалярные эффекты: не нужен общий CODE даже для ошибок

Для последовательности настоящих retained **бинарных** instruments достаточно более слабого и проверяемого операторами условия. В каждом reached узле eta текущего блока j, на его полном истинном живом входе,

```
(q_j-delta_j) I <= E_(j,1|eta) <= (q_j+delta_j) I,
E_(j,0|eta)=I-E_(j,1|eta),
0<q_j-delta_j<=q_j+delta_j<1.
```

Здесь q_j — заранее выбранный scalar профиль; actual effect может зависеть от eta, сохранять backaction и не коммутировать ни с одним прежним effect. Пределы должны быть равномерны по **всем** реально reached inputs/узлам, а не только по среднему состоянию. Всё условное quantum output остаётся, отсутствуют скрытый trace-out и незачтённые labels.

Для любого истинного conditional rho и его purification R положим B_b=sqrt(rho) E_b sqrt(rho). При полном efficient output спектры K_b rho K_b† и B_b совпадают вне нуля. Поэтому локальный CQ entropy gain точно равен H(B|R). Спектральное разложение E_1=sum_theta lambda_theta P_theta даёт состояния sigma_theta=sqrt(rho)P_theta sqrt(rho), r_theta=Tr sigma_theta и ensemble с классическим theta. Канал theta -> sigma_theta/r_theta переводит этот ensemble в R. Data processing взаимной информации даёт

```
sum_theta r_theta h(lambda_theta)
    <= H(B|R) <= H(B)=h(Tr rho E_1).
```

Нулевые r_theta не делятся на себя; берутся только положительные. Это вспомогательный спектральный индекс, **не** физически измеренный theta и не общий индекс между блоками. Оба края лежат между min и max h на [q_j-delta_j,q_j+delta_j]. При

```
L_j = sup_(x in this interval) |log((1-x)/x)|/ell
```

локальные ошибки CQ и classical entropy не превосходят ell L_j delta_j. Теперь условиться на каждый прежний фактический label eta и телескопировать **все** квантовые энтропии между последовательными узлами. Получаются не зависящие от ранга и размера архива оценки

```
|I_Q-total - sum_j h(q_j)| <= ell sum_j L_j delta_j,
|H_C-total - sum_j h(q_j)| <= ell sum_j L_j delta_j,
|C_code - sum_j(1+q_j)| <= sum_j delta_j.
```

Это не замена настоящего correlated joint law произведением: его расхождение остаётся, но энтропия контролируется последовательно. Предыдущий общий nondemolition CODE не требуется ни для exact scalar case, ни для этой оценки finite implementation errors. Заменять полную физическую Info на этот CQ функционал по-прежнему нельзя.

Следовательно для fixed b_Q,b_C>=0 и a=b_Q+b_C полная рассматриваемая price error не больше sum_j (1+a L_j) delta_j. После high pulse operator error масштабируется delta_hi=k delta_old. На фиксированном расширенном compact collar можно выбрать один L_max>=1 для всех этих интервалов. При M high+1 old, delta_old,j<=C g nu и положительной нормировке Gamma_M из полного scalar профиля §3:

```
|P_actual-P_profile|/Gamma_M
  <= C nu L_max (Mk+1)/(Mk-1),   M>=2.
```

Это равномерно по a>=0, M, input rank и числу прежних labels. Здесь Gamma_M — явно вычисленная reference normalization для сравнения, а не автоматически производная всей perturbed native цены. Для двух native comparison endpoints добавляются их две ошибки и делятся на настоящий 2|t| с выбранной общей положительной нормировкой; bound имеет вид C_n nu/|t| с реальными basis/lift факторами. Гладкость entropy на изменяющемся ранге не предполагается. Производная бесконтрольно осциллирующей ошибки не объявляется малой: утверждение о finite comparisons, либо о source с отдельно доказанным D-error. Дополнительные alpha по-прежнему требуют своих полных intervals/entropy и не входят в эту бинарную оценку молча.

## 2. Новый high prefix и старый terminal

Потребим проверенное all-column тождество round6 / B10, где p=phi^-1, ell=log(phi):

```
k=1-2p^6=8sqrt(5)-17 > 1/2,
A=4p^3+4p^6,
q_hi=x(q)=A-kq.
```

Два реально выполненных G на новом r до E0 дают этот эффект. При исходном q∈[p²,1/2] имеем x∈[A-k/2,A-kp²]⊂[p,1). Последний old block остаётся без двух G и выдаёт исходное q_0.

Для фиксированных b_Q,b_C>=0 положим a=b_Q+b_C. Из предыдущего полного CQ тождества **указанная часть** цены равна

```
P_cur = sum_(j=1..M) [1+x(q_j)-a h(x(q_j))/ell]
        + 1+q_0-a h(q_0)/ell.
```

Здесь 1+q — настоящая средняя длина исходного самоделимитирующегося 0/10 parser. Дополнительные G, source, archive handoff, markers, clock, work не объявлены бесплатными: их полный source должен быть учтён отдельно или доказанно включён в выбранные H/J/old/other terms.

Обозначим

```
L_hi(q)=log[x(q)/(1-x(q))]/ell >=1,
L_lo(q)=log[(1-q)/q]/ell ∈[0,1].
```

По каждому **независимому** входу:

```
D_j P_cur = -k(1+a L_hi(q_j)) Dq_j       (j>=1),
D_0 P_cur = (1-a L_lo(q_0)) Dq_0.
```

Эти строки не получены связыванием q_j или четырёх подготовок до дифференцирования. Если коэффициенты b_Q,b_C физически меняются, их собственные строки также остаются; этот результат о fixed коэффициентах.

## 3. Полный signed source, настоящий gain и right lift

Сначала потребим на выбранной source/recovery секции существующие карты владельца:

```
Dq_j = g_j A_j* E_h + r_j,
E_h = D I_h,  g_j>0,  A_j R_h=I.
```

Это отдельная геометрическая/допусковая предпосылка на полном независимо варьируемом input graph. Скалярность эффекта сама по себе её не доказывает. Каждый r_j сохраняет все необработанные preparation, field, implementation и finite-word строки в исходной норме. Если такое представление на заявленных входах не доказано, нельзя заменять их диагональным Dq(Y).

На секции одинаковых калибровок g_j=g и значений q_j=q_0=q, после вычисления всех независимых строк, положим

```
c_hi=k(1+a L_hi),  c_0=1-a L_lo,
D_M=M c_hi-c_0
   =(Mk-1)+a(Mk L_hi+L_lo),
Gamma_M=g D_M,
A_M=(c_hi sum_(j=1..M) A_j-c_0 A_0)/D_M.
```

Для M>=2 получаем точные неравенства

```
D_M >= (Mk-1)(1+a)>0,
Gamma_M >= g(Mk-1)(1+a),
A_M R_h=I,
DP_cur/Gamma_M = -A_M* E_h
  + [-c_hi sum_j r_j+c_0 r_0]/Gamma_M.
```

A_M — **подписанная**, не обязательно положительная комбинация. Тем не менее её total variation нормированных коэффициентов имеет равномерную оценку:

```
V_M=(M c_hi+|c_0|)/D_M
   =1                          if c_0<=0,
   =1+2c_0/D_M                 if c_0>0,
V_M <= 1+2/(Mk-1).
```

Поэтому при ||r_j||<=g epsilon полный нормированный остаток <=V_M epsilon. Сохраняются все независимые строки и действительные norm/right-lift множители. Даже если A_j различны вне общего lift, его faithfulness остаётся точной. Равенство одного scalar reduced derivative не подменяет это full-covector утверждение.

При разных калибровках достаточен прямо проверяемый margin k sum_(j>=1)g_j>g_0; тогда Gamma=sum_j g_j k(1+a L_hi,j)-g_0(1-a L_lo,0) положителен для всех a>=0. Не требуется одинаковый gate count считать одинаковой калибровкой.

**Почему два high-блока:** один не даёт равномерной гарантии по всем a>=0. При M=1 и любом внутреннем q положительное

```
a_cancel=(1-k)/(k L_hi+L_lo)
```

точно обнуляет gain high+old. При M=2 это невозможно на всём указанном collar. Никакой подгонки a для двухблочной конструкции не производится.

При a=0 источником остаётся известная registration cost: Gamma=g(Mk-1). Это расширяет предыдущий positive-Info consumer до нулевого Info коэффициента в **указанном классе цены**. Не утверждается, что полная физическая работа обязана иметь малую производную из-за её положительного значения: даже положительная W(q)=g-independent constant+(Mk-1)q могла бы компенсировать registration derivative при a=0. Это пример границы критерия, не заявленная физическая W.

## 4. Сохранённый output support и фактические часы

У каждого из M+1 readers после E0 точный support

```
P_good=|0><0|_r tensor I_t + |10><10|_(r,t),
<v,v|P_good|v,v>=p+p³<1.
```

Все прошлые пары затем не адресуются. AD2 действует на source/archive и не меняет их labels. Для полного retained output, с настоящим начальным input cut и canonical spectators,

```
P_good,total V_total=V_total,
||C_total||<=rho_good^(M+1), rho_good=sqrt(p+p³).
```

Это bound на фактический cold compression, не повторная подготовка старого Spin и не прежняя sharp SER масса. Ранг исходного Spin/reference cut, z и все нормы остаются настоящими. Из уже доказанных P2/P3:

```
||DJ|| <= (2 z r/(1-z)) rho_good^(M+1) N_total.
```

Для fixed-core истории без дополнительных условных output-recovery слов, если N_core включает полный первоначальный body с его births/readers, но не handoff, то

```
N_b = N_fixed + (M+1)N_core + 2M + 4M,
```

до возможного оплаченного уравнивания сравнительного каталога. 2M — новые G; 4M — M настоящих handoffs. N_fixed включает первый source/bank, фактический старый prefix и closing согласно выбранному счёту. Различающиеся core lengths суммируются, а не заменяются средним без контроля. После согласования всех birth/mark slots нужно общее N_b=O_n(M) для finite +/- каталога; затем именно N_b реальных CX;CX пар дают N_total=3N_b. Sealed records не используются для padding.

Для этого нового списка стадий применяются CL10–12 только при выполнении исходного growing-clock интерфейса (весь 425D носитель, 359D denominator, все birth complements и actual closing). С x=2/55,

```
||DH||/Gamma_M <= 3 C_CL N_b x^(2N_b)/[g(Mk-1)(1+a)],
||DJ||/Gamma_M <= C_n rho_good^(M+1) N_total/[g(Mk-1)(1+a)].
```

При fixed n, положительном g и указанных реальных norm/basis факторах эти остатки стремятся к нулю. В native finite comparisons сохраняется настоящий nonzero step и применяется CL10, без предполагаемой производной word index.

Фиксированный старый ledger с оценкой B_C+a B_I после нормировки ограничен max(B_C,B_I)/[g(Mk-1)]. Но текущие handoff/G/work/fine-label/scene/terminal источники, если не покрыты выбранной ценой и этими доказательствами, входят в

```
epsilon_other = ||R_h|| ||D W_M + R_fine + R_scene + ...||/Gamma_M.
```

Рост M не делает неизвестный линейный по M source малым автоматически. Полная цена не выбрана одной лишь формулой Bernoulli.

## 5. Что именно изменилось в задаче

Конструкция задаёт расширенный descriptor c_M: M дополнительных truthful high-queries с сохранёнными labels/WORK, paid AD2, затем первоначальный old query с его прежним full input/effect и необходимыми marks. На scalar интерфейсе projection результата c_M на последний old label даёт исходный закон c. Это не равенство X_(N,c_M)=X_(N,c), не та же полная история, не совместимость всех возможных поздних инструментальных тестов автоматически и не стирание дополнительных обязательных fine labels.

Снята конкретная прежняя необходимость общего all-bank nondemolition для scalar fresh-block composition; исходный последний report более не требуется восстанавливать из одного high-бита с недопустимой отрицательной вероятностью. M>=2 даёт source margin, устойчивый ко всем фиксированным b_Q,b_C>=0. Полная native H.1 реализация, admission c_M, независимые source maps, незачтённые fine labels и physical Cost−Info остаются ровно на тех местах, где нужны их реальные доказательства.

## 6. Проверка и владельцы

`check_fresh_prefix_source.py` отдельно проверяет точную Golden/подписанную алгебру и численно полные retained CQ-выходы с произвольными различными conditional isometries, mixed/entangled inputs, отдельными source slots и отрицательным контролем скрытой fine-регистрации. Эти вычисления проверяют заявленный математический интерфейс, не исполняют полный H.1.

Native свидетель B `open/round12` исполняет настоящий fresh-source M=2 word, сохраняет оба displaced source states и все три r/t, проверяет все восемь joint labels и финальный old effect. Его 28 calls +8 births =36 stages не включают исходный source, геометрические H.1 writers и closing; это конкретный toy свидетель, не общий H.1 бюджет.

Основные владельцы: §7fq AD1–AD5 истинного input/admission/archive; §7fy свежие scalar comparisons; round6 high all-column effect; P1–P16 и CL10–12 полных clock/cold источников. B13 независимо подтвердил signed gain/right lift и nodewise entropy bound, воспроизвёл A checker и установил указанную границу native scalar/fine-label интерфейса. Корневая проверка независимо воспроизвела B12 (59 exact) и B13 (78 exact, один численный finite-word diagnostic и 24 численных nodewise контроля), с совпадением сохранённых stdout. A checker: 18 exact и 260 численных контролей. Все выполнены с warnings-as-errors; полная физическая цена и Lean-формализация этого нового результата не проверялись. Вывод ОТО не объявлен.

Стандартный внешний математический вход nodewise доказательства — монотонность quantum mutual information под каналом: [Mark M. Wilde, From Classical to Quantum Shannon Theory, theorem 11.9.4](https://markwilde.com/qit-notes.pdf#page=349). Конкретная спектральная конструкция, последовательное применение и source-normalized bound выведены выше; источник не утверждает D0 physical C.
