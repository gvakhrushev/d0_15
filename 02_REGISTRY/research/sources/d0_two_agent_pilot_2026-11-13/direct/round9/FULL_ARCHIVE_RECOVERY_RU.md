# A9: исходный Book03 feedback после реального fine-архива

Этот результат потребляет точный cold B18, actual clock A9 и прежний whole-instrument LC1–LC15. Он заменяет устаревший короткий `f(q)` новым возвратом **полного шестикопийного архива**. Это условная композиция исходного `H+J`, не новое определение Info и не закрытие physical C. `GR_closed=false`.

## 1. Почему одного нулевого хвоста недостаточно

B18 вычислил для буквального NPS/E0, 36-call inverse echo и 138-stage reader

```
C(0)=p^4 X0+p^6 X1,
C(theta)=(p^4 cos(theta)+p^6 sin(theta))X0+p^6 X1.
```

`X0,X1` — настоящие банковские corner-операторы, не `sqrt(1-q),sqrt(q)`. Поэтому `D_theta C|0=p^6 X0` в общем не ноль. На исходном matched NPS B18 доказал строгий отрицательный `D_theta J|0`. Точный нулевой хвост A8 минимизирует указанную при `a=0` parsed/CQ компоненту, но не весь оригинальный feedback. Это сохраняется как проверенная граница A8.

Теперь возвращаем **реальное conditional bank recovery**, которое A8 не требовалось для одной компоненты цены. Все его прежние условия LC1–LC11 остаются: правильный Spin4 input, paid source handoff, старые регистры пассивны, новая арена действительно рождена, исходные marks и разрешённые будущие tests сохраняются с оплаченным transport. Данное рассуждение не конструирует весь recovery word для полного H.1.

## 2. Реальная поддержка нового архива

Пусть `V_A` — действительное изометрическое кодирование reader: шесть канонических births, их 102-call zero preparation и 30-call copy. На true zero archive оно отправляет `(r,t)` в `(r,t,r,t,r,t,t,r)` и сохраняет неизвестный bank. В конце legal coarse subspaces содержат только согласованные записи:

```
S0: (00,000000), (01,010110),
S1: (10,101001).
```

Полный invalid и все несогласованные архивные колонки остаются в носителе, но имеют нулевую **инициализированную** поддержку данного reader. Произвольные конкуренты здесь сохраняют правильность этого же reader и его нулевые support normals. Нельзя заменить `S0` на всё пространство `r=0` с произвольным мусором в архиве: это другая задача и другие born masses.

У пассивного canonical embedding `j_new`, включающего оба прежних `r,t` и все шесть настоящих born архивов,

```
j_new* S0 j_new = mu0 I,   mu0=p^8+p^12,
j_new* S1 j_new = mu1 I,   mu1=p^12.
```

Амплитуды трёх fine-ветвей именно `(p^4,p^6,p^6)`. Они проверены B18 непосредственно по полным восьми битам. Нормированные дополнительные helpers имеют mass1 при полном canonical target; они не добавляют multiplicity к исходному input rank.

## 3. Полный глобальный текущий минимум J

На прежнем scalar-effect интерфейсе `K0*K0=(1-q)I`, `K1*K1=qI`, `q∈[p²,1/2]`. Рассмотрим весь текущий fixed-coarse-effect instrument, допускающий изменение bright fine split **до записи**. Если реальный task отдельно фиксирует `E00/E01`, такой вариации нет и следующий target нельзя объявлять допустимым.

Для любого реализованного изометрического `K` с компонентами в `S0,S1`:

```
C=j_new* K,
||Cv|| <= ||j_new* S0|| ||S0 K v|| + ||j_new* S1|| ||S1 K v||
       = [sqrt(mu0(1-q))+sqrt(mu1 q)] ||v||.
```

Следовательно на **всех** исходных колонках

```
C*C <= f_arch(q)^2 I,
f_arch(q)=sqrt(p^8+p^12)*sqrt(1-q)+p^6*sqrt(q).
```

Равенство достигается восстановлением conditional bank isometries к настоящим canonical targets и ярким хвостом

```
w_J=(1,p²)/sqrt(1+p^4),
u_J=p^4/(1+p^4)≈0.12732200375003505.
```

Тёмный target — прежний `|10>` с его истинной записью. Восстановление делается **до** архива: нормированные prearchive targets после `V_A` точно равны `S_b j_new/sqrt(mu_b)`. Поэтому этот идеальный optimum не требует вызывать inverse на sealed archive. Условный current compiler LC10–LC11 может использовать свой прежний coarse-sector alphabet и helpers; изменились именно его targets. Реальный determinant+1 completion, допустимые адреса, все intermediate marks и compilation debt сохраняются. Достижимость в этом пакете доказана на прежнем compiler-интерфейсе, а не выдаётся за уже исполненное огромное конечное слово.

Уточнение независимого review B19: для применения именно WORK-only real compiler необходимо исходное доказанное свойство выбранного EO/NPS centre `K_b=w_b tensor I_Spin` с вещественным `w_b` на всех колонках. Одна скалярность `K_b*K_b=q_b I` этого не обеспечивает. Например `( |0> tensor I+|1> tensor L_i )/sqrt(2)` имеет scalar effect, но никакая WORK-only unitary не удаляет ненулевой коэффициент при независимом Spin-операторе `L_i`. Для такого иного центра потребуется отдельно доказанное физически разрешённое Spin-coupled recovery. Верхняя операторная оценка для комплексных конкурентов остаётся верной, но не утверждает их достижимость тем же real compiler.

Для исходного `0<z<1`

```
J=-log det[(1-z)I+z C*C]
```

минимален при `C=f_arch I`: матрица под determinant там максимально допустима в порядке положительных операторов. Каждая настоящая двусторонняя fixed-effect tangent row имеет нулевую первую вариацию в этом target, включая комплексные конкуренты и незадействованные колонки. Это глобальный **текущий** инструментальный минимум; перенос к старому prefix ниже использует отдельную every-competitor факторизацию.

При реальном возмущении произвольного support необходимо сохранять исходные линейные нулевые branch-map constraints. Квадратичное `E_invalid=0` само по себе не заменяет нормали. Дополнительные свободные параметры reader, создающие inconsistent raw copies, не включаются в класс truthful-reader конкурентов без изменения самой задачи.

## 4. Источник имеет нужный знак на исходном воротнике

Оптимум по coarse probability лежит в

```
q_mu = mu1/(mu0+mu1) = p^4/(1+2p^4)≈0.11294200177633239 < p².
```

Следовательно во всём прежнем диапазоне `p²<=q<=1/2`

```
f_arch'(q)<0,
ell_arch(q)=-f_arch'(q)/f_arch(q)>0.
```

Вдобавок `f_arch''<0`, откуда `ell_arch'=-f_arch''/f_arch+(f_arch'/f_arch)^2>0`. Точные определения концов дают

```
ell_min=ell_arch(p²)≈0.34503004226815791,
ell_max=ell_arch(1/2)≈0.47403260536130631.
```

Никакие вероятности или поле не подгоняются. Это тот же исходный `q=p²+p³Q`, его настоящий LC9 source и все четыре независимые подготовки. Normal-multiplier pullback переносит optimum через прежний complete field/effect map; он не приравнивает backward occurrence к forward и не удаляет его возможную собственную effect-changing строку.

## 5. Старые строки, настоящий gain и весь тепловой остаток

Это применение требует **всего** LC5, а не только совпадения в одной точке: после настоящего source handoff каждый current competitor адресует лишь текущие WORK, восстановленный source apparatus и разрешённый Spin; старые регистры пассивны. Тогда для каждого такого конкурента `C_total=C_current C_<`. На owned Spin algebra `C_<*C_<=k_<² I4`, `k_<²>0`. Произвольный mutable DATA или операция, обращающая старый prefix, не получает это свойство автоматически.

Запускаем M независимых freshly executed current blocks с реальными reader copies, handoffs и transport. На каждом complete current optimum их compression `f_i I`, поэтому

```
s=product_i f_arch(q_i)^2,
D0=1-z+z k_<² s,
J=-r log D0,
w=r z k_<² s/D0,
Lambda=sum_i ell_arch(q_i) g_i,
Gamma_J=2w Lambda>0.
```

Каждая current field row имеет положительный вес `2w ell_arch(q_i)`. Карты действуют на полном независимом product input, имеют настоящий diagonal right lift и дают source ровно тем же выводом LC9/LC13–LC15 с новым `f_arch`. Исходный rank `r`, oldRIGHT, поля и норма не перенормированы.

Если настоящий полный старый chart удовлетворяет `||DA||<=C_A ||v||old`, прежняя оценка остаётся

```
||D_old J/Gamma_J|| <= C_A/(2 k_<² Lambda)
                   <= C_A/(2 k_<² M ell_min g_min).
```

Для finite old contrasts сохраняется исходный дополнительный `1/(1-z)` и настоящий basis constant. Экспоненциально малый `s` сокращается **только в этом отношении**; из физического gain он никуда не исчезает. Например checker на одном диагностическом chart получает положительный `Gamma_J≈1.60e-38` при `M=20`, а не gain порядка1.

Тепловая оценка A9 применяется к тому же actual unitary archive. Если между прежним echo и шестью архивными births вставлен recovery длиной `N_rec` на той же уже рождённой арене `d`, а перед последним реальным gate — `m` пар `CX;CX`, то

```
N=N_<+174+N_rec+2m,
D=D_<+(8547+N_rec+128m)d,
L=132+2m.
```

При других births или нескольких query-blocks полный layout пересчитывается по всем стадиям. Все `425D` моды и полная `log Z` сохраняются. Истинная нормированная heat-ошибка — `A_L C_full/Gamma_hat`, где `Gamma_hat` измерен/сертифицирован для действительных approximants с относительной ошибкой меньше1.

Как в LC15: сначала фиксируются actual finite chart, M, support/helper arena и положительный limiting gain; затем применяется owned polylog compiler. При `epsilon_k=exp(-k)`, `m_k=k+m0`, реальная длина polynomial in k, `N_k epsilon_k→0`, а factorial `A_(132+2m_k)` подавляет `C_full/Gamma_hat`. Все finite comparisons делятся на настоящий шаг и gain. Малое значение цены не подменяет C1 source control. Реальные новые work/ledger terms не вычитаются из-за этого контроля heat.

## 6. Согласование с A8 и остающаяся физическая граница

У A8 полная выбранная fine-code/CQ цена

```
P_a=2+q+(1-q)u-a[h(q)+(1-q)h(u)]/log(phi)
```

имеет в новой точке `u_J` строку `∂u P_a=(1-q)(1-4a)`. Она исчезает только при `a=1/4`. Это совпадение двух условных компонентов, **не** вывод физического информационного коэффициента. При другом действительном коэффициенте нельзя объявить полную сумму стационарной в оптимуме одного J; нужно решать её настоящий совместный instrument minimum. В частности, нельзя выбрать `a=1/4`, чтобы искусственно согласовать цены.

Результат снимает конкретную математическую предпосылку: имеется полный архивный feedback с глобальным current optimum, положительным source, правильным old-row gain и настоящей growing-clock оценкой. Он возвращает LC4 recovery как необходимое условие данного пути и не маскирует его отсутствием в точном zero-tail word A8.

По-прежнему требуются действительный task и все mark/reader transports, конкретные native recovery/source receipts, остальные физические price/Info/work rows и доказанная связь полного исходного Cost−Info с выбранным Book03 aggregate либо полная source equivalence. Изученный dephased channel или RC3 marked tree не заменяет эту unitary историю. ОТО не объявлена выведенной.
