# A44 — полный внутренний feedback-источник без потери на размерности SAM

Для того же actual A30 core и одного фиксированного A41 Uhat₀ получена
оценка сразу на всём пространстве вещественных SAM skew-направлений:

    sup_(Yᵀ=−Y, ||Y||op≤1) |d_Qb(Y)−½d_red_Pf(Y)| <2^-32,
    sup_(Yᵀ=−Y, ||Y||op≤1) |d_Qf(Y)+½d_red_Pf(Y)| <2^-32.       (1)

Нормировка — прежняя actual Γ_native центра A43. d_Q — аналитическая
логическая производная исходного feedback J на actual core, d_red_Pf —
fixed-post reduced source A37. Число SAM-состояний 2^2688 не входит в
ошибку. Для конкретной j=2 A43 сохраняет свою гораздо более сильную
оценку <2^-77 и полный конечный H+J знак. (1) не заменяет её.

Новый потребитель — полный независимый внутренний источник после A43:
отдельные оценки соседних entries B82/B84 преобразованы в одну операторную
оценку на произвольном Y, включая нелокальные SAM-направления. Она
ограничивается на любой действительно допущенный поднабор. Сам допуск
всех skew в исходную задачу, native ± слова для них, их clock/heat,
full marked-map first jet и physical Cost−Info здесь не выводятся.
physical_C_closed=false, GR_closed=false.

## 1. Whole-label source distance

Пусть u_b=B⁰_bω — полный старый SourceI/profile prefix на cuts B82,
с RAW frame и всеми source arenas. Он не подменяется ideal product.
Оценим ||u_b−u_c|| для ЛЮБЫХ двух SAM labels на исходном B25 cube.

В B21 ровно 256 свободных coframe columns (по четыре координаты),
256 свободных proper links (по шесть) и 64 свободных matter sites
(по две компоненты). Соответствующие Choi-адреса различны. Потребляются
B84 Julia Frobenius bound <24||ΔC||op и нормировка sqrt(65568)>256.

* Для одного coframe column ||ΔC||≤2s, поэтому изменение соответствующего
  нормированного Choi-блока <3s/16. Всего 360 затронутых copies f/q.
* Для одного link шесть координат отличаются каждая не более s. Сумма
  шести B84 edge bounds даёт ||ΔC||<54s; весь соединяющий путь остаётся
  на исходном кубе. Choi-блок меняется меньше 81s/16. Это 180 f copies.
* В CAR на каждом из 64 sites меняются две компоненты. Каждая частная
  производная нормированного m имеет норму <11/10. Поэтому ||Δm||≤(11/5)s.
  Внутренний SITE вес 1/256 и сохранённый RIGHT дают на одну CAR copy
  квадрат нормы ≤64(11s/5)²/256=(11s/10)². Всего 16 q copies.

Разные Julia addresses ортогональны; поэтому их КВАДРАТЫ норм складываются.
В одной f-Choi copy coframe и link addresses также различны. A27 даёт
произведение независимых source copies при фиксированном b. Для реальных
единичных факторов с положительными overlaps квадрат расстояния между
произведениями ≤суммы квадратов расстояний факторов. Здесь positivity
следует из малости каждой разности; общий SITE/RAW frame норму не увеличивает.
Таким образом для ideal source product:

    δ_ideal² ≤[360·256(3/16)²+180·256(81/16)²+16(11/10)²]s²
              =(29605984/25)s² <1089²s².

Каждый старый prefix имеет ошибку <2^-3232 относительно этого product;
для двух концов учитываются обе ошибки. При прежнем s=2^-30:

    δ:=sup_(b,c)||u_b−u_c|| <1089s+2^-3231 <1100s.          (2)

Нет усреднения b и нет удаления branch-dependent correlations или failure.
Исходная ошибка относится к canonical generated WORK, при произвольном
когерентном SAM/old input; dirty WORK на этом шаге не объявляется свободным.

## 2. Центрированная ширина actual M

Общий абсолютный bound ||M−c_ref I||/(gs)<2^144 здесь слишком груб.
В коммутаторе можно вычесть любой скаляр. Возьмём именно

    μ=c_ref−2gI_τ(Y₀), τ=||M−μI||.

B65 на том же непрерывном raw chart даёт ||DI_τ(Y₀)||<a=2^-3083,
||D²I_τ||<2^25; центральный геометрический source нулевой, но малый
reference defect a не объявляется нулём. Радиус всего sampler cube
относительно Y₀ меньше 52s. Taylor с остатком и A30 error e_B дают

    |I_τ(Y_b)−I_τ(Y₀)| ≤52as+½·2^25(52s)²,
    τ/(gs) ≤104a+2^25·2704s+e_B/(gs) <85,                 (3)

где e_B=2^-3231, gs>2^-3158. При фиксированном s основной член равен
84.5. Вычитается скаляр из алгебраической оценки; физическая цена,
reporter, action или Info counterterm не меняются.

## 3. Dimension-free identity для полного kernel

Для точного старого reflected profile S⁰=(S⁰)ᵀ, ||S⁰||=1, определим
контролируемую изометрию V и одну reference изометрию J:

    V e_b=e_b⊗u_b, J e_b=e_b⊗u_ref, Δ=V−J, ||Δ||≤δ,
    Φ₀(Y)=Vᵀ(Y⊗S⁰)V, D=Φ₀(I), A=Δᵀ(I⊗S⁰)Δ.

D,A диагональны. Прямое раскрытие V=J+Δ показывает точное равенство

    E₀(Y):=Φ₀(Y)−½(DY+YD)
          =Δᵀ(Y⊗S⁰)Δ−½(AY+YA),
    ||E₀(Y)||≤2δ²||Y||.                                 (4)

Линейные по Δ слагаемые сокращаются, потому что S⁰ симметричен и
J содержит одно и то же u_ref во всех контролируемых колонках.
При Yᵀ=−Y оператор E₀(Y) также skew. Это оценка отображения в operator
norm, а не покомпонентное суммирование 2^2688×2^2688 entries.

Actual A30 имеет C,S,B, причём C не объявляется Bᵀ и S не объявляется
отражением. Его полная карта вставки Φ(Y) имеет entries

    Φ(Y)_cb=L_cb Y_cb, L_cb=<ω|C_c S B_b|ω>, M=Φ(I).

B82 replacement telescoping применим к произвольному insertion нормы ≤1:
вставка не увеличивает нормы окружающих полных операторов и стоит при
pending=0. Поэтому ||Φ(Y)−Φ₀(Y)||≤e_W||Y||, e_W=2^-3244,
и ||M−D||≤e_W. Разложим

    Φ(Y)=½(MY+YM)+E(Y)+A_s(Y),
    E(Y)ᵀ=−E(Y), A_s(Y)ᵀ=A_s(Y),
    ||E(Y)||≤(2δ²+2e_W)||Y||,
    ||A_s(Y)||≤e_W||Y||.                                 (5)

Здесь A_s — symmetric part actual Φ(Y), не диагональный A из (4).
e_W контролирует полный replacement, e_B — canonical scalar target,
а 2^-3232 — старый prefix. Эти три ошибки не отождествляются.

## 4. Нормированный источник при фиксированном post

При идеальном U* A37, r=||Mχ|| и U*ᵀχ=Mχ/r:

    d_red_Pf(Y)=−χᵀM²Yχ/(2c_ref gs),
    d_Qb(Y)=−χᵀMΦ(Y)χ/(2c_ref gs).

Слагаемое χᵀMYMχ=0, поэтому ½(MY+YM) в (5) даёт ровно половину
d_red_Pf. Кроме того, χᵀE(Y)χ=0, так что в остатке M можно заменить
на M−μI. При ||Y||≤1, ||M||≤1, c_ref>2/3:

    |d_Qb−½d_red_Pf|
      ≤(3/4)[(τ/(gs))(2δ²+2e_W)+e_W/(gs)].

Переход к одному actual Uhat₀ и его фактическому центральному gain
добавляет <e_U/(gs), e_U=2^-14623, как в A42/B82. Оценка использует
норму вставки, поэтому не зависит от числа её ненулевых плоскостей:

    E_all=(3/4)[(104a+2^25·2704s+e_B/(gs))
                   ·(2(1100s)²+2e_W)+e_W/(gs)]+e_U/(gs)
          <2^-32.                                       (6)

Во всех inequalities вычисляются точные рациональные числа. При данном
центре [Y,S]=0 на всех колонках, поэтому аналитические независимые
Q_f,Q_b строки имеют противоположные знаки. Это даёт обе строки (1)
по отдельности; они не складываются и не объявляются одной переменной.

Формула (6) показывает геометрический член, кубический по s, вместе
с a·s² и явными compilation errors. Она не доказывает recompiled family
для произвольного s, не позволяет удерживать e_B/(gs) постоянным при
непроверенном s→0 и не даёт mesh-uniform h→0 theorem. Все актуальные
параметры и исходный finite chart остаются прежними.

## 5. Совместная normal form и защита от ложной стационарности

Для произвольных логических real SAM preparations имеем ТОЧНО

    R=Q_b Q_fᵀ, K(R)=L∘R,
    x=V_bᵀχ, y=P_fχ, ||x||=||y||=1,
    c=xᵀK(R)y.                                         (7)

Здесь ∘ — поэлементное произведение, V_b=P_bᵀ — исполняемая внешняя
операция. (7) получается переносом SAM операций через SAM-disjoint S,
без удаления их оплаченных стадий или marks. Само равенство endpoints
не отождествляет clock или complete marked prefixes.

Если в данной задаче действительно допущены ВСЕ real SAM skew в каждом
из четырёх occurrence и c≠0, совместная feedback стационарность эквивалентна

    K(R)y=cx, K(R)ᵀx=cy,
    Rᵀ[diag(x)Ldiag(y)] symmetric.                       (8)

Первые два условия — независимые сферические производные по x,y;
последнее следует из dc[RY]=Tr((Rᵀdiag(x)Ldiag(y))ᵀY).
Левая inner-вариация эквивалентна симметричности
diag(x)Ldiag(y)Rᵀ, то есть тому же нулевому условию после сопряжения.
Это не отменяет отдельные constraints/marks каждой occurrence.
При c=0 feedback J имеет нулевой первый дифференциал автоматически;
такой branch не имеет используемого положительного gain и не выдаётся
за искомое физическое решение.

При R=I и положительном diagonal M первые два условия означают

    supp(y)⊆{b:M_b=|c|}, x=sign(c)y.

Для внутренних строк дополнительно необходимо и достаточно
y_b y_c(L_bc−L_cb)=0 для каждой пары. Actual kernel лишь почти
симметричен; вырожденный M-eigenspace сам по себе этого не гарантирует.
Если y full-support, первые условия требуют M scalar, что исключает
A43. При R≠I такой вывод незаконен: K(R) уже не diagonal.

Basis y=x=e_b удовлетворяет всем четырём feedback условиям при R=I
даже для nonsymmetric L. Но для прежних diagonal mean observables V_j
и любого skew X имеем e_bᵀ[V_j,X]e_b=0, а b-компонента [V_j,X]e_b
нулевая. Прежний mean/full-vector geometric first jet теряется.
Кроме того, центральный T1 требует исходный Golden χ; all-SO admission
конкретного A43 descriptor не доказан. Поэтому такой математический
стационарный branch не является готовым решением D0→GR.

## 6. Оригинальные marks и дальнейшее применение

Независимый B86 проверяет настоящий исходный mark transport. При P_f
pulled-back maps изменяются сопряжением P_f; фиксировать старые карты
при новом logical p неверно. Для A43 price-swap различаются и исходные
полные pre-sign prepared maps, хотя H+J точно равна. Это разные значения
p с разными M_ν(p), не автоматически запрещённые H.1 истории.

Отдельно B86 подтверждает, что ни один из семи отдельных report banks
не является genuine unsplit current bank. На canonical frontier реальные
f-Choi и q-CAR факторы совместно имеют genuine параметры; но их полный
SAM-correlated остаток R_b надо сохранить. Для потребления исходного
complete bank/fixed processor interface ещё нужен конкретный embedding,
полные D_ν B maps и проверка reuse/retention. Их нельзя заменить одними
coframe/matter moments или незаявленным trace по R_b.

Следующий прямой положительный consumer — такой полный composite-bank
transport, либо отдельная реально оплаченная unsplit preparation, с
исходным функционалом цены и пересчитанными clock, gain и полной ценой
нового слова. (1) предоставляет уже контролируемый
внутренний feedback остаток для будущей совместной source композиции.
Оплата всех новых finite comparisons/heat, physical Cost−Info binding,
original old/input rows и refinement остаются отдельными обязательствами.

check_joint_source_reduction.py проверяет (4),(5),(7),(8) точной рациональной
арифметикой на полных controlled isometries, включая nonsymmetric kernel,
скалярное центрирование, все skew planes малой модели и отрицательные
контроли. Bound (6), фактический inventory B21 и source SHA проверяются
без материализации production kernel. Проверки fixtures не заменяют
общие доказательства и явно не объявлены запуском D0 или выводом ОТО.
