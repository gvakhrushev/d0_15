# Полная тонкая запись до первой остановки исходного full128

Для действительного одноклеточного full128 при `ν=3/5` имеется вариация поля, на которой средняя оплата всех портов имеет нулевую производную, а условная энтропия всей тонкой записи до первой остановки имеет строго положительную производную. Длины произвольны. Изменение стационарного входа, повторное применение действительного канала, тихие исходы и терминальная запись учтены. Уточнение важно для сравнения A68 с ранней остановкой. Даже при известных вероятностях всех времён остановки на данном направлении тонкие записи дают самостоятельный источник.

## Исходный прибор

В обозначениях §7gb `p=(√5−1)/2`, `r=16`, `λ=9/640`, `a=N₀=a†`, `Λ=a†a`. На базовом срезе `Λ=λI`. Берём касательную `DC₀=c₀−c₁`, `Dx₀=iDC₀`; остальные исходные ноги фиксированы. Исходный точный расчёт даёт `DΛ=0` как матрицу и `DρΛ=0` для `ρΛ=Λ⁻¹/Tr(Λ⁻¹)`. Порт 1 продолжает работу, порт 0 завершает её. Каждая из 128 тонких меток содержит порт и индекс `j=0,…,63`. Для работающего прибора считывается классический журнал при неизменённой очищающей ссылке oldRIGHT. Положим `I=H(журнал | oldRIGHT)`. [Первичный источник, исходные формулы и точная однокруговая касательная](https://github.com/gvakhrushev/d0_15/blob/076d5d5a7b366c0dd0970f388df7a9e6895498c4/02_REGISTRY/research/A4D_NONVACUUM_SAME_REPRESENTATIVE_PAID_SOURCE_RESIDUAL_2026_10_20.md#L190658)

## Сколько раз тонкая метка имеет j≠0

Два оператора с j=0 равны скалярам, умноженным на I, и их первые производные равны нулю. Для j≠0 обе портовые реализации пропорциональны одному оператору

    Lⱼ = Nⱼ† a / √[λ(1−λ)].

Знаменатель фиксирован по центру. Там `Σ Lⱼ† Lⱼ=Σ Lⱼ Lⱼ†=I`, а `D Σ Lⱼ† Lⱼ=0`. Первое следует из обеих исходных полнот и `a²=λI`; последнее также получается дифференцированием `Σ (Nⱼ†a)†(Nⱼ†a)=Λ−Λ²` по j≠0. Поэтому последовательность типов по портам и признаку j=0 имеет скалярный эффект и нулевой первый отклик независимо от состояния банка. Вероятности одного посещения в центре равны

| Выполненный ход | j=0 | j≠0 |
|---|---:|---:|
| Порт 1 продолжает | a₀=4p³λ² | a₁=4p³λ(1−λ) |
| Порт 0 завершает | b₀=(1−2p²λ)² | b₁=4p⁴λ(1−λ) |

Пусть N считает все выполненные события j≠0, включая терминальное, если на нём j≠0. Тогда `E zᴺ=(b₀+b₁z)/(1−a₀−a₁z)`. Положим `s=a₁/(1−a₀)`, `w₀=b₀/(1−a₀)`, `w₁=(b₁+a₁w₀)/(1−a₀)`. Точный закон даёт `P(N=0)=w₀`, `P(N=k)=w₁s^(k−1)` и `P(N≥k)=(1−w₀)s^(k−1)` при k≥1. Численно `w₀≈0.978813`, `w₁≈0.020910`, `s≈0.013095`. Даже при N=0 действительно записаны порты и момент остановки.

Для k событий j≠0 обозначим через Iₖ условную энтропию k последовательных букв L относительно той же ссылки, `I₀=0`. В каждой конкретной типовой истории общий множитель выделяется из произведения операторов и его первой производной. Её условный тонкий инструмент совпадает в значении и первой производной с произведением k букв L (если требуется нормировка вне центра, она имеет нулевой первый дифференциал). Цепное правило классико-квантовой энтропии даёт

    D I_stop = w₁ [ D I₁ + Σ_{k≥2} s^(k−1) D Iₖ ].

## Почему бесконечный хвост сохраняет знак

По точной однокруговой формуле §7gb делим `D I_one` на вероятность `a₁+b₁`. Получаем

    D I₁ = (12/631) log(2⁴¹ 3¹⁶ / 5⁴) > 448/631.

Последнее следует из `2⁴¹3¹⁶>2⁵⁶5⁴` и `log 2>2/3`. Для оставшихся k нужен только один новый рациональный коэффициент из всех исходных матриц и их сильвестровых производных

    h² = (1/16) Σⱼ Tr[(D Lⱼ)† D Lⱼ] = 8005/5679 < (6/5)².

Для слова γ из k букв пишем Wγ за произведение и Eγ=Wγ†Wγ. В норме `‖A‖²=Σγ Tr(Aγ†Aγ)/16` каждая из k вставок производной имеет норму h. Буквы перед ней дают I по сохранению единицы, а буквы после неё дают I по сохранению следа. По неравенству треугольника `‖D W‖≤kh`.

Каждому положительному собственному значению e оператора Eγ присвоим массу e/16 с учётом кратности. Сумма масс равна единице. Для `X=−log e` верно `P(X≥k log64 + t)≤exp(−t)` при t≥0, поскольку записано не более 64ᵏ слов по 16 собственных значений. Интегрирование хвоста при `x=k log64` даёт `E X² ≤ x²+2x+2`. Следовая формула дифференцирования и Коши–Шварц дают

    |D Iₖ| ≤ 2 k h √(x²+2x+2) < 2k(6/5)(k·21/5+2).

Нулевые сингулярные значения дают нулевую первую производную, поскольку `u² log(u²)` имеет нулевой дифференциал в нуле. Сумма нормировочных членов исчезает по полноте. Используя `s<1/74` и суммируя k и k² по геометрическому закону, получаем

    Σ_{k≥2} s^(k−1) |D Iₖ| < 6751836/9725425,
    D I_stop / w₁ > 448/631 − 6751836/9725425
                  = 96581884/6136743175 > 0.

**Дифференцирование бесконечного эксперимента.** В окрестности среза для суммы продолжающих операций `T† I≤Q I` с некоторым Q<1. Производная оператора, объединяющего все тонкие исходы одного шага, ограничена H, включая любую ветвь. Для записи с n продолжениями и терминальным нулём нормированная сумма квадратов производных амплитуд по словам имеет корень не больше `(n+1)H Q^((n−1)/2)` при n≥1. Это оценка по местам вставки в произведение продолжающих и завершающего операторов, действующих в прямых суммах. Сумма эффектов уровня не превосходит QⁿI, число ветвей не превосходит 64ⁿ⁺¹. Разделив веса уровня на Qⁿ, тем же подсчётом получаем для логарифмического множителя корень из суммы квадратов не более `Q^(n/2)[n|log Q|+(n+1)log64+2]`. Для меняющегося положительного входа можно включить √ρ в первую амплитуду, использовать ненормированный след и добавить постоянную log16 к счётной оценке. Дополнительная вставка D√ρ ограничена и даёт норму порядка Q^(n/2). Поэтому ряды значений и производных сходятся локально равномерно, а перегруппировка по числу событий законна.

## Ранняя остановка и смысл для ОТО

Есть точная промежуточная проверка с тем же временем остановки. Наблюдатель сохраняет первый полный символ и все последующие порты. Эффект грубого хвоста с n дальнейшими продолжениями равен `(1−q)qⁿI`, `q=4p³λ`, с нулевой первой производной как оператор. Это следует индукцией из `T† I=qI` и `D T† I=0`, включая остаток на любом конечном пределе длины. Условный закон времени после первого порта 1 не зависит в первом порядке от тонкой метки и ссылки. Вероятность самого порта 1 также имеет нулевую производную. Для этого наблюдателя `D I_stop=D I_one=(27p²/25600)log(2⁴¹3¹⁶/5⁴)>0` точно.

Если перед вызовом поставить независимый ранний Golden-флаг из A68, ветвь 0 с вероятностью p завершится до вызова, а ветвь 1 с вероятностью p² получит весь указанный инструмент. С сохранённым флагом условная энтропия равна `H(p)+p² I_stop`; её производная остаётся строго положительной. Это перенос схемы наблюдения A68 на original full128. Для утверждения о самой геометрической паре H.1 нужен физический перенос касательной и выбранного измерения на тот же вход. [Ранний флаг на реальном H.1 в A68](../../round68/returns/ALTERNATING_FIELD_PRICE_RU.md)

На показанной вариации все нативные цены портов для остановленного дерева и одноотражательный Jpre имеют нулевые производные. Поэтому конкретный операнд «портовая цена минус условная энтропия полного тонкого журнала» имеет строгий отрицательный отклик. Для восстановления той же строки уравнений полные цена и Info должны дать компенсирующий вклад на этой касательной либо физическая геометрическая область должна её исключить. Пункт §7ga выделяет точные условия для последующего перехода от физического тензора к aG, в том числе локальность, тождество Уорда вне решений и ненулевой эйнштейновский квадратичный член. Выбранный эксперимент даёт проверку на отбрасывание кандидатов на источник. Физический выбор Book Info, полная цена подготовки, часов и памяти и перенос на всё поле остаются открытыми.
