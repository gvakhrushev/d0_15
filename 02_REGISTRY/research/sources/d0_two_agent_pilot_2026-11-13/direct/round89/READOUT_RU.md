# A89. Два конечных отклика одной H.1-волны и различение цен истории

На одной изготовленной волне и одном фиксированном воротнике две геометрические деформации дают противоположные конечные секущие исходного действия, \(-0.1643305539\) и \(+0.1643305539\). При учёте всего журнала, ранних отказов, материальной подготовки и локальной работы один переставляемый во времени считыватель воспроизводит обе величины с общей положительной шкалой для объявленной средней цены CW1−CQ. Физические энергии двух рёбер узнаются из самой однократной поставки. Геометрический импульс получает оплаченное известное имя. В исследовании A88 для встречного знака требовались две разные материальные подготовки. ## Что говорит абсолютная цена

В отдельной версии прибора каждое действительно зарегистрированное окончание сохранено до суммирования. У полной положительной суммы модулей амплитуд \(\sum_\omega\sqrt{P_\omega}\) получены те же два знака и одинаковый модуль отклика при любом общем конечном бюджете ранних остановов и попарно согласованных тонких успехах. При фиксированном абсолютном весе одной ранней квитанции относительный закон \(P_\omega\propto W_\omega^2\) уже определяет обе секущие цены \(-\log_\varphi\sum W_\omega\). На том же архиве относительный закон \(P_\omega\propto W_\omega\) даёт нуль. Гильбертова норма ортогональных амплитуд также постоянна. Реальная Book03 складывает классы памяти; переход к положительной сумме модулей на этом полном дереве ещё предстоит доказать. [Полная сумма, ранний вес и все окончания](assembly/AMPLITUDE_PRICE_RU.md).

Теперь есть различающая проверка для двух физических концов одного префикса. В центральной настройке при нулевой фазе полная ветвевая разность \((I_1-I_0)-(C_1-C_0)\) должна быть равна \(-1/2\) для амплитудного правила или \(-1\) для вероятностного. При другой фазе знаки меняются. Вычисление исходной Info и всей стоимости окончания по Книге III, с действительным классом памяти, позволило бы исключить как минимум одно из этих правил. Для произвольных положительных Book-весов выведена отдельная нижняя оценка ошибок. Она использует экономическую долю одного реального раннего останова и применима при конечном шаге, без продолжения физической программы по вещественному параметру. [Точный остаток полной цены и граница по одной ранней квитанции](assembly/ABSOLUTE_FISHER_RU.md).
