# A87. Полевой отклик для известного имени и проверка цены исполнения

Четыре участника исследовали одну недостающую связь D0 с уравнениями Эйнштейна. В задаче с оплаченным известным полем удалось убрать предпосылку «нужное геометрическое состояние уже приготовлено». Для одной схемы и одного явно заданного способа оплаты найдены те же нули всех 42 исходных полевых строк на двоичном участке искривлённого семейства. В задаче с *неизвестным* физическим входом проверены адресное считывание, часы и обязательная работа сохранения старых данных. Этот раунд помогает определить, какие исполнения действительно нужно сравнивать для полного вывода ОТО.

**Сопоставление с Open.** B179 начинает с поданного CAR, сразу получает настоящий маркер и вызывает геометрический ресурс только на редкой независимой ветви. A87 строит другой эксперимент для оплаченного известного имени, а также даёт отдельное чтение для неизвестного поданного Choi. Обе схемы позволяют восстановить смешанный геометрически-материальный отклик при своих условиях. B180 сократил редкий селектор до трёх зарегистрированных тестов и показал на явном контрпримере, что одинаковые маргинальные готовности допускают разный условный полевой сигнал. В A87 равенство проверяется на каждом успешном служебном протоколе известного имени. Истинный диспетчер неизвестного входа, конечные регистры и права на поле у этих задач различаются. Подстановка источника из первой схемы в часы второй требует одного фактического исполнения. [Результат B179](../../open/round179/B179_CAR_STOP_AND_LATE_GEOMETRY_RU.md) · [Проверка B180](../../open/round180/B180_MATCHED_READY_AND_FIXED_SERVICE_RU.md).

**Что меняется для вывода ОТО.** На сеточном семействе из известных имён достаточно предъявить две вероятности на строку и проверить возврат, часы и цену одного и того же подготовителя. Точная поставка полного Julia больше не является необходимым промежуточным требованием для этой проверки. Если в исходной задаче доступен только неизвестный полевой экземпляр и сохранённая память, агенту нужен физически допустимый способ связать его с измеряемым источником. Для переноса на ОТО нужно установить отклик первоначальной Cost−Info при независимых изменениях материи, геометрии, подготовки и памяти и затем проконтролировать предел по шагу сетки. Общая нижняя граница вероятности после успеха фабрик не даёт нижней границы общей готовности.

В первичном PR #334 уже получены формула полной локально-аддитивной работы по промежуточным состояниям и отдельный приготовитель известных F5/F6. Для следующей проверки имеет смысл взять одну **исходную** возвращаемую программу и проверить на ней независимую вариацию архива при закреплённых поле и наблюдаемом, включая подготовку, обратный ход и все отказы. Для выбранного семейства ядро полевого отображения известно: если тариф на исторической ленте действительно даёт ненулевой отклик в нём, эта цена не спускается к одному полевому действию. Если отклик сокращается, нужно показать механизм сокращения для допустимых независимых вариаций.
