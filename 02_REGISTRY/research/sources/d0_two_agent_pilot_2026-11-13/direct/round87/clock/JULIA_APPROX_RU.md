# Приближённый полный Julia и Fourier/CAR с общей готовностью

Из оплаченного вычислимого имени поля можно приготовить приближение **всего свежего** исходного вещественного Julia–Choi или Fourier128/CAR, включая дефектные блоки и знаки. На полной Fourier-сетке условная вероятность нужного рабочего исхода равна \(1/64\) независимо от поля, шага сетки и требуемой точности. Для Julia она строго больше \(1/288\), а в приведённом примере также равна \(1/64\). Общий успех физических фабрик и подготовки имени входит отдельным множителем. Результат дополняет [точный полевой регистр и препятствие для точного исходного Julia](../assembly/DYADIC_WRITER_RU.md).

## Нормированный физический выход без сравнения вещественных чисел на равенство

Пусть \(x\in\mathbb R^N,\ \|x\|=1\) — полный нужный вектор, \(M=2^b\). Каждую вычислимую амплитуду заключаем в рациональный интервал \([l_i,r_i]\) ширины не более \(1/M\). Задаём \(m_i=\lfloor M l_i\rfloor\) при \(l_i>0\), \(m_i=-\lfloor-Mr_i\rfloor\) при \(r_i<0\), иначе 0. На двоичной границе допускается соседняя внутренняя клетка. Знак и значение неизвестного точного нуля выяснять не требуется. Для \(w_i=m_i/M\) имеем \(|w_i|\le|x_i|,\ |w_i-x_i|\le2/M\), а для точно нулевой координаты всегда \(w_i=0\). Поэтому при \(K\) ненулевых координатах \(\eta=\|w-x\|\le 2\sqrt K/M\). Можно безопасно взять \(K=N\).

Вычисляем целое \(r=M^2-\sum_i m_i^2\ge0\). Выбираем целые \(d_1,\ldots,d_4\ge0\) с \(\sum d_j^2=r\); конечный поиск с проверкой равенства достаточен. Можно добавить просто четыре помеченных координаты \(d_j/M\). Чтобы сохранить готовность и при большом носителе, до поля выбираем целую степень двойки \(s\ge1\) с \(s\|x\|_\infty\le1\) для всего сравниваемого семейства. В четырёх **отдельных** служебных группах размещаем по \(s^2\) одинаковых координат \(d_j/(Ms)\); физические \(N\) координат прежние. Полученный вектор \(y=(w,v)\) точно нормирован, \(\|v\|^2=r/M^2\). Дополняем адреса нулями до \(P=2^{\lceil\log_2(N+4s^2)\rceil}\). [Формализованная теорема о четырёх квадратах](https://leanprover-community.github.io/mathlib4_docs/Mathlib/NumberTheory/SumFourSquares.html#Nat.sum_four_squares)

Берём прежний конечный пороговый прибор A87. На адресе \(i\) программе даётся целое \(t_i=s m_i\) для физической координаты, \(d_j\) для служебной и ноль для запасного адреса; всегда \(|t_i|\le M\). Отрицательная фаза ставится на \(M-t_i\) из \(2M\) равномерных рабочих слов. После обратного преобразования Адамара амплитуда при нулевом WORK на адресе \(i\) равна \(t_i/(M\sqrt P)\). Поэтому
\[
 \Pr(\mathrm{WORK}=0\mid \text{фабрики готовы})=s^2/P,\qquad
 |\mathrm{выход}\mid\mathrm{WORK}=0\rangle=y .
\]
Полный адрес и все служебные группы сохранены. Дополнительное требование «адрес физический» дало бы полевую вероятность \((s^2/P)\|w\|^2\); общим флагом здесь служит только нулевой WORK. Непринятые слова WORK и отказы фабрик остаются в журнале. Для одинаковой полной готовности требуются одно расписание и постоянный по данным закон фабричных квитанций. На конечном двоичном наборе имён это достижимо, например прямой таблицей фиксированной ширины с обратимым полным просмотром адресов, вычислением порога и очисткой временной арифметики. Выбор \(m,d\), изготовление таблицы, чтение известного имени, ресурсы Адамара, Toffoli, запись и длительность требуют оплаты. Вероятность фактического успеха тогда \(\alpha_{H,b}s^2/P\); нижняя граница на \(\alpha_{H,b}\) при неограниченном уточнении отсюда не следует. [Действительное исходное пороговое слово с его рабочими исходами](../assembly/DYADIC_WRITER_RU.md#от-рождений-к-резкому-полю)

Для исходных Julia32 из \(n\) адресов \(D=32n,\ N=32D,\ |x_i|\le D^{-1/2}\). Берём \(s\le\sqrt D<2s\); тогда \(P<72D\), \(s^2/P>1/288\). Матрицы положительного квадратного корня в Julia вычислимы на \([0,I]\) равномерным полиномиальным приближением даже при нулевых собственных значениях; требуется сертифицированное описание самого поля и его нормировки. Для исходной нормированной вещественной Fourier128-копии \(|x_i|\le1/(8L^2)\), \(N=16\cdot128L^4\), выбираем \(s=8L^2\), \(P=4096L^4\) при dyadic \(L\). Поэтому готовность WORK равна \(1/64\). У примера F5 на \(L=4\) из 524 288 координат ненулевые 49 152. ## Показание, секущая и прежний оператор

Для исходного эффекта \(0\le E\le I\), которому помеченные дополнительные адреса дают нулевой балл, физическое среднее равно \(\langle w,Ew\rangle\). Его ошибка не больше \(2\eta\) по норме \(E\) и \(\|w\|\le1\). Для произвольного эффекта, когерентно смешивающего служебные и физические адреса, допустима другая оценка: \(\|y-(x,0)\|^2=2\langle x,x-w\rangle\le2\eta\), откуда абсолютная ошибка вероятности не выше \(\sqrt{2\eta}\) по следовому расстоянию чистых состояний. Блочно-диагональный служебный эффект может добавить не больше \(\|v\|^2\le2\eta\). При \(k\) действительно независимых копиях и исходном эффекте, продолженном нулём при любом служебном адресе, телескопирование даёт ошибку не больше \(2\sum_i\eta_i\).

На двух именах \(Y\pm hV\) ошибка центральной секущей исходного эффекта не больше \(2\max_\pm\eta_\pm/h\). Эта оценка не дифференцирует ступенчатое округление. Для предела по строкам с gain \(g_H>0\) и нормой переноса \(R_H\) достаточно обеспечить \(R_H\sqrt {K_H}/(2^b h g_H)\to0\) для фиксированного числа независимых копий и ограниченной нормы эффекта. Сюда добавляется истинная ошибка центральной секущей цели; например при ограниченной третьей производной \(O(h^2)\). На реальном неусловном наблюдении учитываются также его фактическая готовность и множители последующего операнда. При \(2^b\ll\sqrt N\) возможен ровно нулевой весь физический вектор даже для равномерной цели; правильная готовность сама по себе не гарантирует точность.

Для Julia старый численный \(32\times32\) блок можно реконструировать из физических амплитуд как \(\widetilde J=\sqrt D\,\mathrm{reshape}(w)\) на его собственном адресе. Получаем \(\|\widetilde J-J\|_{\rm op}\le\|\widetilde J-J\|_{\rm F}\le64\sqrt D/M=:\delta\); та же оценка максимума действует для прямой суммы по фиксированным адресам. Для сжатия \(J^*EJ\) на неизвестной старой колонке численная операторная ошибка не превышает \(2\delta+\delta^2\), в том числе после тензорного расширения тождеством на RIGHT. Это априорная оценка **при условии реального применения указанных операторов**. Пороговая схема готовит свежий нормированный вектор. Её проекция \(w\) не обязана параметризовать унитарную матрицу или изометрию на произвольных входах. Из одной изготовленной Choi-копии и приборов только на новых проводах нельзя исполнить \(J\) на неизвестной закрытой старой памяти: её безусловная маргиналь останется прежней, тогда как, например, \(Z\) переводит \(|+\rangle\) в ортогональное \(|-\rangle\). Доступ к физическому старому порту или допускаемое взаимодействие нужно показывать отдельно. Для исходного свежего Fourier \(F\) также не переназначается ранее запечатанная старая RIGHT.

При \(b=18\) проверены два полных Julia-адреса с честными \(\sqrt{1-C^*C}\), исходная соседняя компактная связь и две точки кофрейма \(t=1/2\pm1/32\). Секущая фиксированного межадресного эффекта до округления равна \(-0.0123269712\), после равна \(-0.0123218858\); точная готовность в обоих опытах \(1/64\). На F5/F6 \(L=4\) с настоящими 712 буквами общей амплитуды и всеми классами Fourier-знаков получена та же готовность, физическая ошибка вектора \(0.0006901121\). Полная квантовая амплитудная ошибка с помеченными дополнительными координатами больше и равна \(0.0335318\). Не вычислены обязательная стоимость поля и весь графовый или экономический отклик аппарата. GR_closed=false.
