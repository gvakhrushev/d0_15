# A11. Явные полные операторы двух источников и общая граница нормы

Потребитель — незаполненные `H_f,H_q,Lambda_h` в настоящем H.1, а не новый геометрический корень. Фаза — native realization. Предыдущая A10 построила восстановление, но его геометрический вход оставался не развёрнут. Здесь исходное тензорное построение из `A4D_FULL_TWO_BAND_FIXED_TEN_SIGN_CAR_CHOI_SOURCE_2026_10_21.md` (8)–(15) развёрнуто в конечный DAG из **20 402 узлов**, со всеми шестью основанными гранями, настоящим `R2`, обоими CAR-материальными полями и одним inverse-PF множителем.

Новое доказанное утверждение: заданные DAG представляют фиксированные Hermitian операторы на **полном** пространстве независимых входных копий; при нижеследующем конкретном адресном контракте их общая поле-независимая норма не превышает `2^1525`. Поэтому исходные знаковые эффекты положительны на всех входах. Это явная подстановка в ранее не вычисленную нормовую предпосылку, условная на адресный контракт. Ни настоящий native writer, ни READY/factory закон, ни физическая Cost−Info этим не построены. `GR_closed=false`.

## 1. Полный вход и точная нормировка

На одном local stencil используются 4 inverse-coframe адреса, 4 исходящих link-адреса базы и 12 shifted link-адресов. Одинаковый глобальный link при привязке имеет одно имя поля; его разные вхождения не объявляются независимыми геометриями. Точные адреса глобального представления и граница проверяются в B23/B24.

Полный агрегатный Choi bank — исходный

```
Omega=(32 A)^(-1/2) sum_(a,i) |a,i> J_a |i>,
anchor r=|a0,i0,i0>, J_a0=I32.
```

`A` — число активных адресов; дополнение регистра нулями не меняет `A`. При любом queried адресе `a != a0` элементный оператор

```
H_aij=(32 A)/2 (|r><a,i,j|+|a,i,j><r|)
```

имеет **точную** полную норму `16 A` и среднее `J_a[j,i]`. Наши листья `u/r/i` — vacuum-to-grade-one элементы `J(C(u_r))`, то есть эти `H`. Листья `M/location/role/i/j` — **дважды** элементы grade-one блока `J(Lambda(U)/2)`; их полная норма `32 A`, а среднее есть истинный `U_ij`. Оба являются операторами на всём `a,input,output` пространстве, с нулём на остальном и identity на spectator RIGHT; это не оценка только на истинных Julia states.

Внутри каждой материальной копии сохраняется **свой** исходный равномерный `S=256` site/Fourier128 банк. Общий внешний PF SITE является отдельным управляющим фактором (B23). Листья

```
X_(z,A)=(|z,1><z,A|+|z,A><z,1|) tensor I_RIGHT, A=0,15
```

имеют норму 1 и на исходном bank дают `2 sqrt(p) Psi_(z,A)/S`. Полный RIGHT не сбрасывается; все прочие CAR grades остаются. Здесь `p^2+p=1, 0<p<1`. Формула использует диагональное по site извлечение; off-diagonal Fourier overlap не требуется и не теряется.

Указанный ниже общий сертификат действует при `A<=4096`, `S=256`, `h=1/4`, `nu=3/5`, `rho_x>=3712/5473`. Последняя граница — точный минимум B21 `256 N_x/10946` при `N_x>=29`. `4096` — **верхняя граница A**, не подстановка padded-нормировки в anchor. Она покрывает как периодический кандидат `A=2049`, так и геометрический halo-каталог B23 `A=2433`; совместимость материального halo из этого не следует.

### Связь actual B21 raw columns с исходной геометрией

Для `R=diag(1,1,-1,-1)` имеем точно `R^T eta R=eta`, `det R=1`. Если исходная primary coframe `e0=I+H E_(1,0)/2` и link `U0=exp(+Kx N2+Ky N3)`, то B21 выписал

```
e=R e0,   u=R (nu eta e0^-T)=nu eta e^-T,
U=R U0 R^-1=exp(-Kx N2-Ky N3).
```

Именно эта постоянная proper-Lorentz map объясняет положительные spatial columns `+nu` у B21. Её полный exterior lift одновременно переносит creators и links, поэтому исходный CAR16 trace сохраняется. `check_current_frame.py` проверяет точные целочисленные CAR/generator identities и все 256 actual B21 raw columns; максимальная ошибка совпадения `<3.5e-18`. PF-dressing здесь нет.

Выбранный 16-компонентный chart — **additive raw u**, с обратной картой `e=nu eta u^-T`. Это открытые координаты полного coframe при невырожденном u. Именно для `u0+delta u` была выписана B21 bound `nu*(1+H_bound/2)+4s`; её нельзя молча считать оценкой additive e. Все 16 coframe направления сохранены, а boundary-зависимости не меняются от этой локальной обратимой карты.

## 2. Что именно значит операторный DAG

Каждому узлу присвоена пара степеней `(число Choi, число CAR)`. Constant — действительное число `a+b p`, times identity. Moment leaf — один полный Hermitian оператор выше.

* При сложении каждый член дополняется identity справа до максимального числа копий **каждого** типа.
* При умножении дети действуют на **раздельных** копиях; результат — их тензорное произведение, с математической перегруппировкой типов Choi/CAR.
* Повторная ссылка на один узел DAG в разных множителях не означает повторное использование неизвестной квантовой копии: каждое произведение получает свои независимые слоты. Это компактная запись формулы, не бесплатный native reuse.

Индукцией каждый узел Hermitian; сумма действительных Hermitian операторов Hermitian, а тензорное произведение независимых Hermitian факторов Hermitian. На одинаково подготовленных независимых ресурсах его среднее равно ровно scalar-polynomial DAG. Для **произвольных**, в том числе коррелированных/нефизических входов на полном carrier, верны

```
||sum padded T_i|| <= sum ||T_i||,
||tensor T_i|| = product ||T_i||,
||I||=1.
```

Следовательно вычисляемая рациональная граница не предполагает равенство копий или истинность геометрического input. Перегруппировка факторов описывает математику фиксированного оператора; необходимый аппаратный маршрут при компиляции всё равно оплачивается. Не утверждается стационарность каждой independently prepared копии: её source и принадлежащая владельцу paid symmetrization остаются отдельными шагами.

## 3. Полный геометрический оператор

Используется буквальный null metric и CAR order `(0,2,3,1)` с physical-bit masks `1<<i`. Каждый creator строится на всех 16 grades. Для каждого 4×4 link-moment matrix M заданы

```
M^sharp=eta M^T eta,
R2(M)=M[I - (M^sharp M-I)/2 + 3(M^sharp M-I)^2/8].
```

Матрица `Lambda(R2(M))` задана **всеми** её exterior minors, включая vacuum и top grades. Для каждого `r<s` берётся настоящий four-edge порядок

```
L_rs=L_r(base) L_s(plus r) L_r(plus s)^sharp L_s(base)^sharp,
D_rs=C(u_r) H_eta C(u_s)^T H_eta - C(u_s) H_eta C(u_r)^T H_eta,
f_x = -(1/(8 nu² h²)) sum_(r<s) Tr_16[D_rs L_rs].
```

Во вне-Lorentz продолжении inverse slot означает исходный polynomial `sharp`, а не нелинейный matrix inverse. На истинном proper-Lorentz поле они совпадают. `R2` имеет degree 5, его exterior lift degree <=20, поэтому полная степень не больше `2+4*20=82`. Все 6 граней и их 24 link-occurrences в DAG сохранены. Нельзя заменить эту формулу одной face, скалярным class invariant или только grade-one trace.

`H_f_before_inverse_PF` имеет среднее именно `f_x` из §7eh.B(F1). Для conditional sign на site x применяется `H_f,x=H_f_before_inverse_PF/rho_x`. Если у другой исходной конвенции PF уже находится в coframe numerator, сначала нужна её карта; повторно одевать данные и делить на PF нельзя. В этой конкретизации используются **raw** `u=nu eta e^-T` как в F1 и отдельный один inverse-PF, а не кандидатный `sqrt(rho)`-dressed coframe B21.

## 4. Полный материальный оператор

На тех же coframe-moment листьях

```
g^(rs) = u_r^T eta u_s / nu²,
q_x = sum_(A=0,15;r,s) g^(rs) D_r^+Psi_A D_s^+Psi_A.
```

Подставляя `Psi=S<X>/(2 sqrt(p))`, получаем точно

```
H_q_before_inverse_PF = S²/(4 p nu² h²)
  sum_(A,r,s,i,j) eta_ij
     H_(u_r,i) tensor H_(u_s,j)
     tensor (X_(x+r,A)-X_(x,A))
     tensor (X_(x+s,A)-X_(x,A)).
```

Никакой square-root matter gate здесь не предполагается. `1/p=1+p`, поэтому все постоянные DAG лежат в `Q(p)`; степень ровно `(2,2)`. Conditional operator `H_q,x` делится на `rho_x` один раз. Этот оператор задан на полном CAR/RIGHT пространстве, не только четырёх ненулевых подготовленных amplitudes. Отсутствующий halo address нельзя называть этим листом без выбора корректного адресного интерфейса.

## 5. Сертифицированная общая норма

`certify_source_norm.py` независимо проходит сохранённый DAG, заново вычисляет все степени и нормовые majorants. Для констант использован точный рациональный isolating interval `309/500<p<619/1000`, проверенный через `p²+p-1`. Для листьев — `16 A<=65536`, `32 A<=131072`, `||X||=1`. Суммы и произведения выполняются в точной рациональной арифметике, затем применяется настоящий worst-case inverse PF.

Получено

```
max(||H_f,x||, ||H_q,x||) <= 2^1525 = Lambda_h,
epsilon_h = 1/(64 Lambda_h) = 2^-1531.
```

Точные отдельные rational majorants и целое `Lambda_h` сохранены в `SOURCE_NORM_CERTIFICATE.json`; степень 1525 — минимальная степень двойки, перекрывающая **этот majorant**, не вычисленная минимальная норма самих операторов. По Hermiticity и norm bound оба исходных эффекта `(I +/- H/Lambda_h)/2` являются положительными contractions на всех input columns. Выбор консервативен и делает настоящий gain очень малым; его нельзя отменить или заменить удобным числом. B21 reference `g=(1.635...e-23) alpha_h²/Lambda_h²` теперь получает именно этот допустимый `Lambda_h`, но `alpha_h` пока не вычислена.

Два f-sign используют 164 Choi copies; восемь q-sign ещё 16 Choi +16 CAR. Итого исходный bound **180+16** получен из выписанного оператора; семь unspecialized report calls дают **1260+112** slots. Это не число gates/births и не доказательство supply/READY. Identity padding не удаляет реальные ресурсы из clock/cut.

## 6. Проверка формулы и оставшееся применение

`check_source_operator.py` сравнивает DAG с отдельным прямым CAR16 matrix evaluation на общем, в том числе off-Lorentz, входе. Проверены все **282 независимые scalar-moment координаты** (16 coframe, 256 link entries, 10 matter moments) через reverse differentiation DAG и независимый complex-step прямой формулы. Максимальная относительная ошибка производных `<5.3e-15`. Проверены все **160 normal link directions** при настоящих proper links; R2 annihilates их first source с ошибкой `<5.4e-15`. Hostile deletion последней грани обнаружена. Настоящий interior B21 `(0,0,1,1)` даёт оба нулевых центральных moments.

Это численные диагностики алгебраической реализации, не Lean-проверка полного доказательства. Нормовый сертификат отдельно точный и распространяется на весь тензорный carrier. Диагностика 282 moment-coordinates не выдаётся за уже выполненные 2688 geometric-chart equations или независимые внутренние equations всех actual native occurrences.

Для применения остаются: реальная глобальная адресная binding и boundary; фактические source-bank targets всех семи Z_j на SAM vertices; true full processor/READY and prefix marks; конечная native компиляция, её ошибки и clock; полноценное физическое source comparison с original Cost−Info. Здесь нет новой Info, нового физического коэффициента или переопределения цели вывода ОТО.

Воспроизведение из этой директории: `python3 -B -W error source_operator_dag.py`, затем `python3 -B -W error certify_source_norm.py` и `python3 -B -W error check_source_operator.py --b21 <путь к open/round21>`. Последние две команды независимы. Все исходные данные и результаты закрепляются в `RECEIPT.json`.
