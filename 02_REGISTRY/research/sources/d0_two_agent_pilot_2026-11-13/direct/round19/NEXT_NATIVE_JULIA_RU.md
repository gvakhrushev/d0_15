# Следующий parent после A19: реальные coframe/link Julia words

Префикс A19 и B39 не перезапускать. Конкретное следующее обязательство:
полный branch/SAM/address-controlled исходный Julia SELECT с uniform
operator error <=2^-3251, strict branch0 I, неизменяемыми controls,
literal inverse, фактическими ресурсами и без обращения к отдельным
rebit/comparator B39. В этом случае A19+SELECT автоматически даёт
требуемый B39 полный Omega-loader error <2^-3250.

## A: coframe native compiler

1. Вывести outward dyadic names исходных четырёх coframe компонент,
   n, трех alignment rotations и base pair из B25 formulas. Использовать
   исходные k0, pi, rho_x и raw perturbation `2^-30(b-p²)`; Y0 не равно
   all-zero SAM. Типы каталога A19 содержат все 4864 f/q и 1024 reference
   sectors, но 247 float vectors служат только диагностикой повторений.
   Дедупликацию строгих target names делать по исходным формулам/интервалам,
   не по совпадению float64.
2. Подтвердить interval bound выбранного dominant-first порядка и всех
   знаменателей. Нельзя пропускать маленькие ненулевые rotations как zero.
   Для структурного нуля нужен точный аргумент, не численный threshold.
3. `choi_output[:4]` — occupation grades; `choi_output[4]` — Julia flag t.
   Fock plane пары используют parity из `ORDER=(0,2,3,1)`.
   Base two-bit plane действует на `[q0,t]`, пару индексов 1,2.
   При обычном least-different-bit pivot исходный a имеет pivot bit=1:
   native sine должен быть отрицанием желаемого pair sine. Для base
   желаемая sine=−n, следовательно native sine=+n.
4. Удобный общий multiplier `2^20`: не более 20 controls для Fock plane,
   18 для base pair. При меньшем K масштабировать k на `2^(20-K)`,
   сохраняя один и тот же **actual** active rotation. X_t контролируется
   address/SAM/branch (K<=17); его aux phase имеет K+1<=18. Для него
   отдельно сертифицировать целевые pi/2 и pi, не делить старое k на
   неподтверждённую степень двойки.
5. Per-macro delta=2^-3264 уже достаточно: 26 delta <2^-3259, что
   оставляет запас к требуемому 2^-3251. Более высокая точность допустима,
   но не является обязательством исходного parent. Каждый угол имеет
   свой реальный integer k и независимый outward interval certificate.
6. При up to 2^20 Walsh terms на plane нужен конечный lazy emitter,
   точный algebraic inventory и проверка структурных инвариантов.
   Не строить гигантское дерево в RAM. Inverse должен быть буквальным
   обращением реальных leaf calls. Проверить малые полные columns и
   реальные large-k DAG bindings, явно разделяя их роли.
7. Ошибка всей блочно-диагональной sector программы — max активного
   sector error, если controls никогда не пишутся и off-pattern exactly I.
   Оплаченные ресурсы при этом суммируются по всем исполняемым sectors.

## B: proper-link structure

B41 отдельно исследует исходный `C=Λ(U)/2` через полярную/сингулярную
форму Lorentz U, включая zero-boost cases. Возможная общая identity:
если `C=L D R^T`, то
`J(C)=diag(L,R) J(D) diag(R^T,L^T)`.
Дальнейшее разложение должно сохранить исходную ETA, ORDER, все
grade columns, strict defect roots и фактический fixed/SAM source binding.
Float SVD не является native certificate. Не присоединять результат до
проверки знаков/хронологии, точных условий и контрольной namespace.

Полный prepared Choi источник, исходные vacuum/Fourier/SITE ресурсы,
физический допуск complete marked H1, его alpha и original Cost−Info
остаются открытыми. Не менять действие/Info и не начинать geometry scan.
