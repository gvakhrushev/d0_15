# A47: полный first jet, двухбитные CODE controls и конкретный source budget

**Результат.** Для A46 выявлено точное ограничение прежней бинарной карты:
никакой real skew control на всём SAM не превращает её скалярную передачу
координаты в универсальную полную векторную передачу. Потреблён уже имеющийся
в исходном §7ej.MG2 двухбитный lift; для него построены **новые конечные G/CX
control words с 12 сертифицированными положительными степенями**, точными
counts и общим padding. Для конкретного полного восьмибанкового source
target впервые здесь вычислены all-DATA operator bounds
`M1≤1748`, `M2≤3233036`. Они дают полный идеальный jet error `<2^-44`
при выбранном `σ=2^-80`.

Это контрольный модуль и численный контракт следующей подготовки, а не
готовая замена целой истории A46. Новые SOURCE vertices ещё не скомпилированы;
новый полный clock/heat/gain ещё не вычислен. Нет заявления о физической
стационарности, Cost−Info или выводе ОТО. `GR_closed=false`.

## 1. Почему нынешнего одного бита недостаточно

Пусть Φ содержит исходный born bit v=(√p,p) на координате j и любой
нормированный fixed remainder; Π — его единичный проектор. Для любого
real skew X на всём совместном пространстве положим

    H=[Π,X],   z=(I−2Π)Φ.

H симметричен и off-diagonal относительно Π, поэтому `(I−2Π)H` skew и
`<z,HΦ>=0`. Но `||z||=1` и `<z,Φ>=p−p²=p³`. Следовательно

    ||[Π,X]Φ−Φ|| ≥ p³ > 0.

Граница достигается X=u J_j при u=2p√p. Если дополнительно требовать
правильное среднее `<Φ,[Π,X]Φ>=1`, оптимальная граница усиливается до p³/u;
её достигает X=J_j/u. Это точная геометрия Hilbert space, не результат
сканирования отдельных генераторов и не следствие native ограничений.

Утверждение относится к прежнему affine binary decoder и matched
`P† B_s P` lift. Оно само по себе не запрещает другие декодеры или
target-specific компенсации. Независимый B91 предъявляет конкретный
ненулевой source-functional для настоящего fresh Choi компонента A46,
отделяющий координату j=2 от остальных. Его коэффициент K очень мал;
имеющаяся native погрешность перекрывает K. Поэтому доказанное препятствие
идеальной бинарной карты **не выдаётся за нижнюю границу actual compiled jet**.
WORK-only скалярный effect после сжатия на Φ не обнаруживает весь векторный
дефект; нужны полная карта или соответствующий joint CODE/DATA effect.

## 2. Потреблённый двухбитный lift

Используем исходную формулу §7ej, а не новый selector:

    φ=(p,p√p,p√p,p²), π_i=φ_i²,
    h_i=(1−2π_i)^−1, S=Σπ_i h_i,
    V=diag(0,1,2,3)−3p² I,
    H_ii=0, H_ij=φ_iφ_j(h_i+h_j)/(1+S),
    X_ij=H_ij/(i−j), X_ji=−X_ij.

В точном поле Q(a), a⁴+a²−1=0, проверены `φᵀφ=1`, `φᵀVφ=0`,
`[V,X]φ=φ`, `||X||op≤||X||F<1`. Шесть λ_ij=−X_ij положительны,
их сумма L<3/2. Для m независимых пар
`[V_j,X_k]φ^⊗m=δ_jk φ^⊗m`: корреляционный остаток первого порядка исчезает
как вектор, а не только в среднем.

Новый source target имеет vertices

    Y_b=Y0+σ(b_low+2b_high−3p²),  σ=2^-80.

Проверено точное включение каждого из четырёх значений в прежний
**асимметричный** continuous chart interval
`[−p²·2^-30,(1−p²)·2^-30]`. Это разрешает использовать continuous-chart
slacks, но не готовые binary-corner angle tables.

Для каждого из 2688 полей используются прежний physical SAM wire `2+j`
и новый wire `n_A46+j`. Требуются 2688 новых RAW births; число CODE bits
становится 5376. Все старые WORK/helper/source адреса сохранены. Этот
layout реализован для control module; в SOURCE providers ещё не интегрирован.

## 3. Настоящие G/CX control words

Выбран t=2^-1700. Двенадцать plane rotations идут в палиндромном порядке
шести пар (i,j). Для каждой целевой половины Strang-шага tλ_ij/2 используем
алгебраический Cayley angle

    z=±tλ_ij/4,   α=2 atan z.

Это сохраняет явную вычислимость угла. A41/B80 выбирает положительное k,
чтобы kθ приближало **половину** α, то есть atan z. Каждое из 12 значений
k для шести пар и двух знаков отдельно проверено через outward interval
целевого угла, residue `k·pn mod q` и certified error `qγ−pn`.
Получено half-angle error `<2^-20075`.

Двухбитный zero-Walsh `star_blocks(m=2)` исполняет точно plane rotation
на угол 2kθ и identity вне выбранной плоскости. Остальные пары переводятся
через прежние X/CX affine maps; X по A38 приближается положительными G/CX
на той же паре, без нового clean helper. Все четыре колонки сохранены.
Контрольная полная 4×4 матрица проверена для каждой из шести пар.

При δ=2^-20000 один plane word имеет ошибку ≤42δ: два angle blocks и
не более двух X macros по 20δ. На весь 12-plane control приходится ≤504δ.
Cayley добавляет ≤L³t³/48, прежний Strang bound — ≤L³t³/3. Итого

    ||P̂_±−exp(±tX)|| ≤ (17/48)L³t³+504δ <2^-5099.

Оба знака компилируются отдельно. Отрицательное слово не объявляется
точным inverse уже скомпилированного положительного. Центр и оба знака
дополняются до единой длины точными CX identities; для нечётного padding
используется третий существующий CODE wire соседней координаты. Полный
padding тождествен на всех колонках, а его операции оплачены.

Counts всех четырёх независимых control occurrences равны 4L_control,
не 2L_control. Они записаны hex в плане; огромные repeats не развёрнуты.
Здесь нет SourceI, скрытого angle oracle, нового действия или Info коэффициента.

## 4. Область полной source карты

Рассматривается конкретная B̃(Y), составленная из A22 full Choi,
A24 full CAR и B45 SITE targets, включая их фиксированные RAW prefixes.
A22 покрывает все 2^22 DATA columns при 24 private на canonical RAW→0
fibre. A24 покрывает все 2^19 DATA+freshRIGHT columns при трёх private на
canonical RAW→0 fibre. Неизвестные DATA/SITE/SAM/old/reference могут быть
запутаны; общий hybrid сохраняет их. Произвольные dirty source-private
columns этим контрактом не охвачены.

Особая граница: A23 vacuum/Fourier prefix — явно выбранная полная extension.
Её совпадение на всех входных колонках с иным, ранее не предъявленным
original vacuum-prefix не доказано. Поэтому B̃ не называется безусловно
тождественной original B(Y) во всех marked-history смыслах. Это отдельная
обязанность admission, не нулевой error term.

## 5. Явные нормы полного source target

Норма поля — Euclidean norm исходных 2688 raw coframe/Lorentz/matter
координат, без нового нормирования физического поля.

На старом continuous cube B21/B65 дают `||U||<17/16`, coframe/link
contractions имеют `I−CCᵀ,I−CᵀC ≥ (1/16)I`, а material slack L_m>1/3.
Для Lorentz block `Θ=Σ θ_a J_a`, `||J_a||=1`, откуда
`||DΘ[h]||≤√6||h||`, `||Θ||≤6s`, s=2^-30. По Duhamel и
`exp(6s)<16/15`, `||U0||<17/16`:

    ||DU[h]||<3||h||,   ||D²U[h,k]||<7||h||||k||.

Для C=½⊕∧^r U максимумы r≤4 дают C1<8, C2<80. Coframe block имеет
C1≤1, C2=0, поэтому те же верхние bounds покрывают оба вида.

Пусть Q=√(I−CCᵀ). Обратный Sylvester operator имеет норму ≤2, поскольку
Q≥I/4. Дифференцирование Q² даёт

    ||DQ||≤4||DC||,
    ||D²Q||≤4||D²C||+68||DC[h]||||DC[k]||.

Для полного Julia block соответственно J1≤5C1 и J2≤5C2+68C1².
Frobenius norm 32×32 block ≤√32 operator norm <6 operator norm.
Нормировка Choi равна 1/√65568<1/256. Сумма квадратов по непересекающимся
coframe/link addresses, с Cauchy–Schwarz для смешанных направлений, даёт

    ||DΩ|| <30·8/256 <1,
    ||D²Ω|| <6(5·80+68·64)/256 <112.

Anchor c=1/√65568 постоянен на всём chart. Для исходного полного
`O_Ω=I+K+K²/(1+c)` имеем `||K||≤1`, `||DK||≤||DΩ||`, и потому
O1≤3, O2≤3·112+2=338 на **всей DATA матрице**, включая padding.

В CAR `||ψ||²<1/15`, `L_m>1/3` дают m1<11/10, m2<3; anchor √p
постоянен. Поэтому полный material O_m O_m*ᵀ имеет O1<4, O2<12.
Controlled internal SITE — direct sum, unknown RIGHT — identity, поэтому
экспоненциального множителя от их размерности нет.

Переменными являются 540 Choi копий (старые f/q и fresh f) и 32 CAR
(старый q и fresh q); reference banks, SITE и RAW frames фиксированы.
Для полного произведения unitary targets:

    M1 ≤ 540·3+32·4 =1748,
    M2 ≤ M1²−(540·9+32·16)+540·338+32·12
       =3233036 <2^22.

Любой завершённый field-independent processor prefix Dν не увеличивает
эти operator norms. Это применимо к выбранной typed source карте B̃,
без partial trace её остатка и без inverse success probability.

## 6. Полный jet и честный precision gate следующей сборки

Здесь R_v<2√2688<104. Исходные MG6 estimates теперь имеют конкретные числа:

    ||Fν,σ(I)−φ^⊗m⊗Aν(Y0)|| ≤σ R_v M1 <2^-62,
    ||F′ν,σ(0)/σ−φ^⊗m⊗∂_j Aν(Y0)||
       ≤σ R_v² M2 ||X_j|| <2^-44.

Для конечного control comparison нельзя молча использовать exact-inverse
сокращение MG11: два actual G/CX слова здесь лишь приближают взаимно обратные
контроли. Ниже их ошибка, включая постоянную часть source, делится на
действительное σt. Малость этой ошибки не отменяет source approximation.
В плане заданы **ещё не выполненные** обязательства новой SOURCE/corner
компиляции:

    e_B,new <2^-3300,   e_M,new <2^-3298.

Из прежнего g·2^-30>2^-3158 следует только gσ>2^-3208. Поэтому требуемый
новый e_M дал бы e_M/(gσ)<2^-90 (в плане ослаблено до <2^-89).
Прежний A46 e_B<2^-3231 даёт лишь e_B/(gσ)<2^-23 и не заменяет этот gate.
При новом e_B и идеальных взаимно обратных controls его отдельный вклад
в full axis jet `2e_B(L+504δ/t)/σ` был бы `<2^-3218`. Для ACTUAL двух
скомпилированных контролей используем более грубую независимую оценку.
Обозначим ε_P приведённый выше полный error относительно exp(±tX).
Для симметричной разности `(Fhat_+−Fhat_-)/(2σt)` её добавочная ошибка
относительно идеального first jet не больше

    (e_B+2ε_P)/(σt) + (4/3) R_v M1 t² <2^-1519.

Первый член — прямой двухсторонний hybrid двух independently compiled
prefixes; он не предполагает точную native обратимость или бесплатное
сокращение constant target. Второй — остаток центральной разности exp±tX;
здесь constant target коммутирует с идеальным X. Сумма с MG6 по-прежнему
`<2^-44`. Это условный бюджет для указанной ещё не выполненной SOURCE
точности, не утверждение о готовой новой physical history.

Требуется пересобрать SOURCE coordinate predicates/angle catalogues для
четырёх вершин на каждую координату, а также достаточную точность фиксированных
SITE/vacuum/adapter частей, если старые ошибки превышают новый gate.
Старые binary tables, namespace validators и готовые источниковые counts
не считаются подходящими автоматически. Новый полный clock, post target,
gain, четыре независимые price rows и heat нужно вычислить после этого.
Старые A46 численные bounds на эти строки сюда не перенесены.

Тем самым имеется конкретный full-vector repair и его исполнимый модуль
управления; оставшаяся работа — новый SOURCE compiler и original map/admission
binding. Ни необходимость stationarity, ни физический Cost−Info selector,
ни полное D0→ОТО из одного этого модуля не следуют.
