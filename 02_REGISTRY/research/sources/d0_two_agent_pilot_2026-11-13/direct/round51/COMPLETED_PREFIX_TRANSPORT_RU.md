# A51: завершённые marked prefixes той же A49 истории

Для двенадцати конкретных завершённых frontiers после Qf построены native
prefix providers **той же** A49 оплаченной истории. Они сохраняют полный
retained SOURCE/processor/factory выход, включая неготовые ветви. Для
выбранного ideal A17 processor на объявленной canonical RAW fibre получены

    full-prefix value error <2^-62,
    finite full-vector axis-jet error <2^-44,
    finite axis-jet error любого norm-one joint effect <2^-43.

Проверены literal placement и full-effect algebra. Production word не
исполнялся. Это перенос к **явно выбранному** полному target, ещё не
идентификация всех marks произвольного другого исходного descriptor.
`physical_C_closed=false`, `GR_closed=false`.

## 1. Один список frontiers, без перестановки прежних marks

`completed_marked_prefixes.py` перечисляет:

1. SOURCE_after_Qf — полный SOURCE и первый RAW frame, затем реально
   оплаченный Qf†.
2. RAW_frame_return — следующий обратный RAW frame.
3. Восемь отдельных complete REPORT, включая fresh current bank.
4. PORT_ZERO.
5. SC6 — полный forward prefix непосредственно перед central sign.

Это двенадцать frontiers. Каждый REPORT включает все десять walks, их
coherent factories, record/READY/failure, REPORT extraction и retained
work. Ни READY-only effect, ни successful postselection не заменяют его
полную изометрию. Shared SITE и branch-dependent fresh remainder сохраняются.

Исходный SOURCE_before_Qf реализован как **отдельный** prefix с тем же
реальным положением. У него ещё не исполнен компенсирующий frame; A51
не присваивает ему геометрический MG3 jet. Для mark внутри незакрытого
macro или некоммутирующего раннего shared-SITE observable этот список
не доказывает deferral. Их необходимо сопоставлять на настоящем времени.

## 2. Реальные prefixes, равные началам A49

Пусть Bhat — A48 native SOURCE prefix до первого B82 cut. Для выбранного
завершённого processor frontier ν после него:

    Fhat_ν,± = Dhat_ν Phat_∓ Bhat Phat_± i,
    i = Φ_CODE ⊗ J_canonical,
    Φ_CODE = φ^⊗2688.

Контроли взяты из A47/A48 и имеют **те же** дополнительные четыре CX
reserve каждого слота, что A49. Core padding остаётся после полной
обратной ветви, не перемещается к mark. Остальные два controls, fixed
post, probe и retention лежат позже и сохраняют родительскую полную
историю и её цену. Новые записи registry — метаданные, а не gates/births.

Dhat_ν состоит из реальных `stage_blocks` A48, с тем же A29 compiler,
старым helper и physical address map. На исходном Q-cut pending=0;
выбранный завершённый prefix обязан также закрыть transducer. Повторный
запуск transducer с нулевого состояния в этой точке даёт тот же native
stream. Если выбранная граница разбивает SourceI-пару, её нельзя назвать
этим завершённым prefix.

Малый проверяющий расчёт сопоставляет все 13 frontiers (включая pre-Qf)
при signs −,0,+ с буквальными началами полного `A49.family_blocks`:
39 совпадений actual native leaves, с настоящими control/core/post
identity-padding. Это проверка порядка и платы, не запуск гигантского
production источника. Общая prefix-identity следует из совпадающих
providers, последовательности stages и закрытых cut boundaries.

## 3. Target и область входов

Идеальный B̃(Y) — выбранное полное SOURCE-продолжение A22/A24/A48,
включая A23 vacuum/Fourier и RAW frame. Dν — соответствующий полный
retained ideal A17 processor prefix: каждая исходная закрытая макрооперация
заменяется своим владельческим точным target, сохраняя саму finite factory,
все flags и исходную длину логического алгоритма. Его идеальный смысл не
задаётся одной вероятностью Beta или одним эффектом READY.

Домен: все SOURCE DATA и SITE input columns при объявленных canonical
SOURCE-private и processor/factory RAW входах; допускается произвольный
внешний reference и соответствующие old/protected spectators. Выходные
private/factory/failed ветви не удаляются. Это не гарантия для произвольных
dirty private inputs. Материальная identity на неизвестном oldRIGHT
не означает identity вакуумной подготовки на семи **fresh** RIGHT wires.

Двенадцать processor prefixes не адресуют CODE даже как control; A50/B98
проверили их полную affine support grammar. Поэтому Dhat_ν и Dν
коммутируют с exact CODE control. Производные B̃ имеют B91 bounds
M1≤1748, M2≤3233036 на старом B21 cube; fixed processor не добавляет
полевых производных.

## 4. Ошибка процессора не делится на конечный шаг

A17 имеет 162754649904 известных approximate macro occurrences на семь
REPORT. Каждый REPORT использует одну и ту же grammar; на восьми полных
банках достаточно `8·(162754649904/7)` таких occurrences. A14/B31/A17
hybrid применяется на их заявленной canonical processor/factory fibre,
при сохранении arbitrary SOURCE inputs и всех выходов. RAW inverse,
PORT и SC6 точны в SourceI-profile. После A48 replacement можно взять
одну равномерную оценку для всех выбранных frontiers:

    e_D = 8(162754649904/7)2^-4096 + e_W <2^-4058,
    e_W <2^-15800.

Целый budget всех восьми REPORT безопасен также для раннего завершённого
frontier. Он не распространяется автоматически на ошибку внутри одного
ещё не закрытого macro, для которого этот target не является prefix.

Положим Jhat_B=(Fhat_B,+−Fhat_B,−)/(2σt), а J_B — исходный геометрический
axis derivative `Φ⊗∂j B̃(Y₀)`, σ=2^-80, t=2^-1700. A48 уже даёт
`||Jhat_B−J_B||≤e_J,B<2^-44`. Один и тот же Dhat_ν стоит в обоих arms:

    Jhat_ν = Dhat_ν Jhat_B,
    Jhat_ν − Dν J_B
      = Dhat_ν(Jhat_B−J_B) + (Dhat_ν−Dν)J_B,
    ||Jhat_ν−Dν J_B|| ≤ e_J,B + e_D M1 <2^-44.          (1)

Уже нормированная настоящая derivative J_B ограничена M1. Поэтому
`e_D/(σt)` не возникает. Это точное линейное разложение общего fixed
processor, а не пренебрежение его ценой или ошибкой. Цена процессора
полностью остаётся в A49 clock.

При центральном mark `G_ν=Φ⊗Dν B̃(Y₀)` value error ограничен

    E₀ = σ·104·M1 + e_B + e_D <2^-62.

Здесь e_B — actual A48 SOURCE-prefix error. Все значения поля лежат
в прежнем cube; никаких новых полевых targets или reference коэффициентов
не вводится.

## 5. Полный joint-effect jet, включая CODE-корреляции

Для любого полного нормированного effect O, ||O||≤1, на этом фактическом
frontier зададим

    Fbar=(Fhat_++Fhat_-)/2,
    Jhat=(Fhat_+−Fhat_-)/(2σt).

Точное тождество на **всех допустимых input columns**:

    (Fhat_+† O Fhat_+−Fhat_-† O Fhat_-)/(2σt)
      = Fbar† O Jhat + Jhat† O Fbar.                   (2)

Fhat_± — полные isometries, значит ||Fbar||≤1. Для analytic matched curve
двойной коммутатор ограничен 4, поэтому midpoint displacement от центра
≤2t². Добавляя два independently compiled control errors ε_P, получаем

    Ebar = E₀ + 2ε_P + 2t² <2^-62,
    effect-jet error ≤2(e_J,B+e_D M1)+2M1 Ebar <2^-43.  (3)

Это операторная оценка неусловного полного effect, а не scalar marginal.
В неё входят off-diagonal CODE/DATA correlations, failure и retained
reference. Conditioned success statistic с inverse success probability
из (3) не следует. Для нескольких наблюдений с intervening instruments
нужны их actual norms и допустимая композиция; одна оценка не объявляет
автоматически нулевой или безразмерной сумму всех тестов.

## 6. Уточнение исходного descriptor: не ждать несуществующий selector

B99 подтверждает, что §7cz(879) полностью задаёт Choi O_b и (880)
полностью задаёт M_Y, но проверенные параграфы не задают **единственного**
продолжения vacuum/site/Fourier подготовки на ортогональных входных
столбцах. A23 даёт конкретное такое продолжение и его платную историю.
Одна совпадающая vacuum-колонка не доказывает равенство иных maps/marks;
точный B99 counterexample сохраняет эту границу.

Однако из слова «registered» нельзя выводить обязательность внешней
регистрации или универсального выбора одной истории. Более поздний
владелец RO1 в том же основном доказательстве прямо исправляет это
чрезмерное требование: обосновать нужно **использованные** operation,
inputs, clock и variations из retained task data. XF5–XF6 прямо допускает
descriptor как datum T по KAPPA6, без дополнительного физического
program register. Это не разрешение менять чужую уже фиксированную задачу.

Правильное следующее обязательство — предъявить **один полный согласованный
scoped descriptor** с выбранным A23 prefix, фактическими A48/A49 операциями,
canonical inputs, всем требуемым mark list, actual clock/price, свободным
regular field chart и допустимыми independent variations. Для него нужны
владельческие Book01/KAPPA witnesses. Допуск не должен зависеть от Einstein
predicate, от нулевого source или заранее подобранного ответа.

Если вместо этого заявляется transport к иному конкретному исходному
descriptor, потребуются именно его полные B_orig,Dν_orig, marks и price.
A51 их не отождествляет по совпадению одной колонки. Но отсутствие
единственного такого исходного prefix не является поводом ждать новых
материалов пользователя или вводить новый universal scheduler.

## 7. Оставшиеся применения

A51 закрывает fixed-processor transport для явного списка завершённых
target prefixes. Нужны полный scoped descriptor и его admitted mark set,
ранние/незакрытые marks там, где они действительно требуются, исходная
V_h/right-lift norm, all-control и old/input/WORK/scene/record/Info source
на этой же задаче. Ограничения A50 между 2688 выбранными finite axes и
полной dual-нормой сохраняются. Нужны также исходные Cost−Info binding,
реальные constraint reactions и заявленное GR refinement/dynamics.
Новая цена или физическая стационарность не выводятся из одной (1).

Проверка содержит exact symbolic (2), full fixed-D decomposition (1),
отрицательный pre-/post-Q пример и 39 буквальных paid-prefix сравнений.
Root повторил B99 exact boundary checker побайтно без записи в B и
сверил входы и Git blobs. Это не Lean-формализация и не production run.
