# Что действительно выбирает минимум среди всех допустимых порядков

Рассматриваем полностью определённый конечный класс программ для [окна A86 на том же физическом Fourier-возврате](RECORD_WINDOW_RU.md). На входе уже есть копия \(s\) действительного регистра и отдельная нулевая мишень. Обязательны две буквы \(X=\mathrm{CX}(H,s)\) и \(2N\) букв \(Y=\mathrm{CX}(s,\mathrm{target})\), разрешена любая их перестановка, на выходе необходимо тождество на всех столбцах. Начальные, конечные и фабричные расходы вне этого участка одинаковы между порядками на каждом поле. Выбор делается по всем допустимым программам этого класса до сравнения их результатов.

Пусть между X стоят \(m\) букв Y. В двоичной арифметике чистый результат на мишени равен прибавлению \(mH\bmod 2\), а рабочий контроль возвращён. Следовательно, расписание допустимо точно при \(m=2k,\ 0\le k\le N\). Для данного \(k\) таких порядков \(2(N-k)+1\); всего \((N+1)^2\). На очищенной записи в любой базисной ветви мишень до Y имеет определённое значение. Ветки с разным \(s\) сохраняют ортогональную ссылку. Поэтому число Y, выполненных до первого X, может менять отдельные состояния, но не полную стоимость при фиксированном \(k\). Для общей ставки \(\lambda>0\) цена окна равна
\[
 C_k(q)=\lambda[2+2(N-k)g(q)+2k\,g(1-q)],\qquad
 g(q)=\sqrt{2q-q^2}.
\]
Каждый разрешённый порядок имеет тот же полный спектр на данном поле по точному стадийному сопряжению из доказательства окна. Родившиеся ресурсы, копирование и восстановление находятся снаружи и не меняются при выборе \(k\).

**Минимум по программам.** Для исходных опор с полной физической памятью \(q_5>q_6>1/2\). На обеих опорах строго выбирается \(k=N\), то есть X до и после всех букв Y, и минимальная цена самого окна **растёт** при F5→F6. Этого выбора и ссылки на весь алфавит перестановок достаточно, чтобы исключить искусственный выбор одной из двух реализаций внутри данного класса. Если заготовка \(N\) велика относительно диапазона прочих листовых цен, как доказано в A86, та же ориентация сохраняется при добавлении этих цен на поздних листьях. Для абсолютного минимума с ранними отказами нужны условия на терминал из A86. На графе с независимо приготовленным целым Fourier128-состоянием полная спектральная секущая имеет при этом **отрицательный** знак. [Физическая подготовка, предел тепла и знак спектра](../clock/FOURIER_RETURN_RU.md).

**Положительная сумма по всем порядкам.** Если разрешённые исполнения суммируются по одному разу с их реальной ценой окна и одинаковым остальным весом, положим \(r=\varphi^{-2\lambda(g(q)-g(1-q))}\). Тогда
\[
 -\log_\varphi \sum_{\rm orders}\varphi^{-C_{\rm order}(q)}
 =\lambda[2+2Ng(1-q)]-\log_\varphi\sum_{m=0}^N(2m+1)r^m .
\]
Это отдельное предположение о том, какие исполнения в данном сравнении различимы и с какой кратностью они входят. При \(\lambda=1\) и \(N=1,1024,4096,10000\) разности F6−F5 для самого окна равны соответственно \(-4{,}1806\cdot10^{-6}\), \(-0{,}00087579\), \(+0{,}0165241\), \(+0{,}0663154\). Последние цифры вычислены по конечной сумме; взята высокая точность из первичной калибровки. Для любого фиксированного \(\lambda>0\) линейное по \(N\) положительное слагаемое в секущей в итоге преобладает: модуль отрицательной поправки сверху ограничен \(\log_\varphi[(1+r_6)/(1-r_6)^2]\), где \(r_6<1\) вычислено для F6. Для единичной ставки одна эта консервативная оценка достаточна при \(N\ge3\,260\,963\) в указанной калибровке. Таким образом можно отличить минимум от суммы по программам по наблюдаемому знаку на конечном времени даже при одном и том же терминале.

**Если время можно сокращать.** При разрешённом удалении всего тождественного окна и сохранении тех же будущих требований и записей обе версии уступают его пропуску при положительной оплате движения. Для этого достаточно аддитивности положительных стоимостей удалённых стадий, отсутствия новой измеренной информации и допустимости более раннего завершения. При обязательном фиксированном clock, метках внутри участка либо самостоятельной оплате сдвига времени сравнение ведётся с фактической допустимой заменой. Поэтому оптимум по всем порядкам заданного инвентаря не равен автоматически минимуму Book03 по всем допустимым историям. Физический выбор класса и обязательной валюты оплаты остаётся различающим вопросом для ОТО. GR_closed=false.
