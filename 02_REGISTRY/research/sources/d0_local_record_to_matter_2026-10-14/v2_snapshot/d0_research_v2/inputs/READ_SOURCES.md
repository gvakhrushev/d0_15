# Прочитанные первичные источники и границы происхождения

Два файла прочитаны через GitHub connector только на ранее закреплённом SHA `6e1662d4840c58fae118a35c344dfedddea3e3b2`. Ни current-head audit, ни запись, ни CI не запускались.

1. `03_FORMALIZATION/D0/Representation/GoldenCoherentMemory.lean`, Git blob `a3860d148f86bcda52882459468089303cd5be5c`. Прочитаны буквальный fullStep, его ортогональность, blank evolution и GoldenRelativeChannel import. В новом коде проверяется фактическое равенство fullStep=CNOT(G⊗I). Полный исходник здесь не выдаётся за заново импортированный/скомпилированный Lean-модуль.
2. `02_REGISTRY/research/A4D_NATIVE_GOLDEN_PROGRAM_COMPILATION.md`, Git blob `9de7100f8a3a97aa4b3a46fccc02ef95824cc2c5`. Источник явно отделяет матричную addressed G/CNOT-компиляцию, основу XGX=Gᵀ и предоставленный basis-one record от физического допуска операций. Эта граница сохранена. Успешный parity-extractor нового пакета предоставляет реальный basis-one record внутри заявленного heralded опыта.

Попытка получить побайтные raw-копии этих двух публичных файлов в контейнере закончилась DNS-ошибкой; она записана отдельно в `repository_sources.json`. Нельзя считать эти raw-копии включёнными в пакет. Текст определений был доступен в результате connector-read, но автоматического source-import/AST closure из remote здесь не было.

Периодический Hodge-носитель, source-формулы и интервал G₈ взяты из локального v1, который включён в `input_v1/`. Его SHA256 manifest проверен; большая прежняя root-программа в этой сессии заново не запускалась. Новые интервалы оценивают приготовленное состояние и source-погрешность на всём ранее сертифицированном прямоугольнике.

Статус π₀/минимального замыкания и BOOK 07 — сообщённый пользователем input. Это не новая Lean-проверка D0-PI0-001.

Сравнение с внешней литературой: J.-s. Yan, J. Jing, Generic eigenstate preparation via measurement-based purification, arXiv:2307.16496 (2023). Использовано для разграничения заявлений о новизне, не как замена доказательств нового пакета. Абстрактная ancilla-filtering идея не заявлена открытием D0.
