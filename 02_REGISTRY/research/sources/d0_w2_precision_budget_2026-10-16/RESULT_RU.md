# Кандидатный бюджет точности raw-l1

Статус: **candidate**. Это достаточная оценка ошибок одного объявленного интерфейса `unweighted_raw_l1_h_minus_2`. Прохождение бюджета означает, что мажоранта стремится к нулю при заявленных ASSUMED скоростях. Существование native refining solutions этим не доказано. ОТО не выводится. Строка `claims.csv` не заводится. Цена v8 и центрально-терминальная цена AF остаются двумя программами: их границы не складываются.

## Интерфейс

Носитель — невзвешенная решётка `(Z/LZ)^4`, шаг `h = 1/L`. Родительские слоты — 10 упакованных метрических строк. Целевая норма

```text
T(h) = h^{-2} * sum_x sum_{j=1}^{10} |slot_j(x)|.
```

При равномерном поточечном значении это `10 * h^{-6} * pointwise`. Поточечное `O(h^6)` после суммы `h^{-2}` даёт `O(1)`. Десять строк размера `h^6` суммируются в константу `10`. Исторический свидетель (38) на шести слотах даёт ровно `6` при каждом `h = 1/L` и не является родительским носителем. Объёмное чтение того же свидетеля есть `6 h^4` и стремится к нулю. Норма `volume` получает отказ `volume_norm_is_not_raw_l1`.

Фиксированные калибровки v8 сохраняют ограничение unfolding. Эндогенные движущиеся веса узлов остаются именованным условным входом `WRK-A4D-WEIGHTED-SITE-SOURCE-TRANSFER`, путь `02_REGISTRY/research/sources/d0_w2_weighted_source_2026-10-16/`. Этот вход в бюджет не влит. Закон веса `endogenous_moving` получает отказ `n08_endogenous_weight_conditional`.

## Параметрическая оценка

```text
T(h) <= C_W * slots * h^{-6} * (gap_one + tail_one + observer_pointwise + remainder)
      + slots * h^{-6} * (operator_pointwise + quadrature_pointwise)
```

Хвост `G_Q` добавляется только при предикате открытого окна N06 и заданном `gq_to_slot`:

```text
C_W * slots * h^{-6} * gq_to_slot * exact_neumann_tail.
```

Окно: `||Delta - Delta0|| < 1/8`, `|epsilon - epsilon0| < 1/8`, сертифицированный зазор `> 1/2`, сжатие `t < 1/2`. В слот входит точный хвост Неймана модуля N06. Равномерная мажоранта `4 * 2^{-(k+1)}` остаётся сравнением и в сумму не подставляется. Константа `4` не является обратимостью полного field/shell гессиана и не даёт пространственного измельчения. В двух опубликованных бюджетах `include_gq = false`.

Глубина возврата `k` и допуски `eps_H`, `eps_J` выбираются по самому медленному положительному ASSUMED показателю среди оператора, квадратуры, наблюдателя и ненулевого остатка. При показателе с избытком `guide_power` каждая из двух щелей и хвост получают сырой вклад порядка `h^{guide_power}`. Каналы `H` и `J` делят эту долю пополам. `beta`, `alpha`, `z`, `M` остаются входными масштабами. Программа не назначает `beta(h)`, `t(h)`, `alpha(h)` или `lambda(h)`.

Перевод Шаттена на фиксированном слое размерности 16: `||A||_HS <= 4 ||A||_op`, `||A||_1 <= 16 ||A||_op`. Отбрасывание размерности — отказ `hs_bound_independent_of_dimension`. Растущая размерность с показателем `-4` на операторе `h^8` оставляет после raw-суммы `O(1)` и получает отказ `pointwise_h6_after_raw_sum`.

## Шесть слагаемых v8

Общий предикат сложения: программа v8; невзвешенная решётка; 10 строк; фиксированный считающий вес; фиксированные `beta`, `alpha`, `z`, `M`; настоящая правая обратная; карта N05 регулярна и возврат `SO(3)`; окно N06 соблюдено; нижний блок седла `[H_red, T*; T, 0]` не обращается.

| Величина | Область | Норма | Дополнительный предикат |
| --- | --- | --- | --- |
| auxiliary gap `eps_H`, `eps_J` | unfolding: след `sigma` равен 1, `X > 0`, `q >= max(1, ||Y||_op)`, фиксированные `alpha` и `b0 > 0`, `0 <= z < 1` | скаляр `|dS[v] - partial_x L[v]|` из (12)+(13): операторная норма на `dLambda`, HS на сэндвиче `dA` | каналы переведены в один скаляр до raw-суммы |
| return tail `z^{k+1}` | `0 <= z < 1` фиксировано, `X_k = sum_{j=0}^k z^j F^j`, `k` выбран | следовая норма `||dDelta||_1` в обратной связи (15) | операторный хвост (14) в raw-l1 не входит; `z` не заменяется на `t(h)` |
| operator approximation | ASSUMED скорость на восстановленном упакованном источнике, спаривание N07 `real_fourier_pairing_plus_traceless_hermitian_shell` | поточечный sup слота уже после правой обратной | стадия `reconstructed_source`; коэффициент предполагается, а не подгоняется |

`C_W` опубликованных бюджетов — вход `3` или `4`. Это не константа `28/s`. При `s = 1/8` и выполненном шаре Неймана программа принимает `28/s = 224` как отдельный вход и не подставляет его в численные бюджеты.

Численные `beta` и `b0` — рациональная мажоранта и миноранта фиксированных констант v8 при знаменателе `10^6`: `beta <= 763933/1000000`, `b0 >= 236067/1000000`. Это оболочка `beta = 3 - sqrt(5)` и `b0 = sqrt(5) - 2`, а не закон `beta(h)`. `z = 2^{-20} = 1/1048576`, `M = 128`. Длина `ell = 1/8` — калибровка v8. Она не является полем и не равна `log(phi)`.

## Отдельный центральный бюджет

Нормы этой программы: двойственная норма `dQ`, ненормированный address-l1 и липшицево чтение на адресном кубе. В raw-l1 они не переносятся.

ASSUMED: `lambda = 1/10`, `residual_dual = 1/100`, `Lip = 1`, `||f||_inf = 1`, `||db||_inf = 1/10`, допуск чтения `1/1000`. Маршрут формулы `lambda = 4 p^{12} / (B R s^4)` считается при входах `B = R = s = 1` и хранится отдельно.

Вердикт `PASS`. Выбраны `c = 179`, `k = floor(16*179/17) = 168`.

```text
compiler_dual            = 1/4
address_l1               = 359/125000
source_l1                = 1697/2000000
reading                  = 59/62500
lambda_route_alternative = 10062403/5000000
```

`compiler_dual = (5 / (2 lambda)) * ||r||` при ASSUMED `lambda`. Альтернатива `10062403/5000000` — другая подстановка той же компиляторной оценки при формуле для `lambda`. Эти два числа не складываются. Чтение `59/62500` не превосходит допуск `1/1000`.

Подстановка `ell = 1/8` в центральную программу получает отказ `v8_length_ell_is_not_af_log_phi`. Перенос в raw-l1 без доказанной ведущим связи получает `central_to_raw_without_lead_link`. ## Blocker

Достаточный raw-бюджет не доказывает существование native refining solutions. Связь одной программы между ценой v8 и центральной ценой AF ведущим не доказана, поэтому бюджеты остаются раздельными. Движущиеся веса узлов остаются условным входом N08.
