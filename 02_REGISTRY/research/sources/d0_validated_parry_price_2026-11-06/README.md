# C1–C3. Полная цена на хвостово-валидированной записи H.1

**Результат C2.** Уточнение модели цены меняет даже существование полевого отклика. На одном и том же зарегистрированном исходе §7fx средняя двухсимвольная цена кода имеет положительный отклик. ## C2. Сравнение двух полных записей на одном носителе

Положим \(\ell=\log\varphi\), \(0<u<1\), \(p^2<q\le 1/2\). Таблица использует **порядок обоих символов** и фиксированные ограничения валидатора.

| исход | вероятность \(P_i\) | записанная длина \(L_i\) |
|---|---:|---:|
| 00 | \((1-q)(1-u)\) | 2 |
| 01 | \((1-q)u\) | 3 |
| 10 | \(q\) | 3 |

Проверяем конкретную атрибуцию \(S_i=L_i+\log(P_i)/\ell\) для этих двух символов. При \(f(x)=1+x-h(x)/\ell\), где \(h\) — бинарная энтропия в натуральных единицах, из цепного правила для энтропии следует

\[
\overline S=f(q)+(1-q)f(u)+q,\qquad
Z_{\rm pair}=\sum_iP_i\exp(-\ell S_i)=p^2+2p^3=1-p^4.
\]

В каждом слагаемом момента положительная вероятность сокращается с обратной вероятностью. Двухтактовая золотая сумма ранее [доказана в Lean](https://github.com/gvakhrushev/d0_15/blob/191eace4a413f7f886cb65b4d5a79601b13e0ce8/02_REGISTRY/research/certificates/a4d_native_code_price_resolution.lean). Здесь она применяется к трём разрешённым листьям именно валидированной истории. Вывод работает на любом сохраняющем этот носитель конечном сравнении. При исчезновении положительной ветви состав суммы меняется.

На секции \(u=p^2\) имеем \(f(u)=f'(u)=0\). Обе независимые производные по \((q,u)\) дают

\[
 D\overline S=(1+f'(q))Dq,\qquad D[-\log Z_{\rm pair}/\ell]=0.
\]

Полевая компонента среднего строго больше единицы в единицах \(Dq\), поскольку \(f'(p^2)=0\) и \(f''(q)>0\). В контрольной точке исходного H.1 оценка CD11 даёт \(5/4<1+f'(q_0)<4/3\). В частности, на общей ветви восстановления, где текущий отчёт реагирует на поле, нулевой отклик скалярного момента нельзя откалибровать положительным gain. Независимая bright-вариация на секции имеет нулевой отклик у обоих выражений. Условный момент **только дополнительного** символа из §7fx остаётся \(1-p^2q\). Разница получается, когда в тот же экспоненциальный вес входит также ранее оплаченный первый символ.

Для каждой независимой допустимой вариации \(v\) вне координат записи на этой секции применяется цепное правило: подставляются фактические \(Dq[v]\) и \(Du[v]\). В частности, \(Dq=p^3 DQ\) включает свободную прямую подготовку LC9. Для нескольких текущих копий компонентный gain средней цены равен \(\sum_i (1+f'(q_i))g_i\) с действительными коэффициентами источника \(g_i\) владельца. Постоянство момента для одной пары даёт нулевую производную на **всех** таких входах одновременно. Отношение ошибки к собственному gain у постоянного момента неопределено; деление на ноль в C2 исключено. Отдельный положительный gain операторного источника сохраняет своё определение.

Тот же расчёт выделяет конкретные строки для продолжения. Если к листьям в этой **скалярной** интерпретации действительно добавлена физически выведенная цена \(w_i\), при фиксированных длинах и носителе

\[
 D[-\ell^{-1}\log Z]=\sum_i\tau_i D w_i,\qquad
 \tau_i=\frac{p^{L_i}\exp(-\ell w_i)}{\sum_jp^{L_j}\exp(-\ell w_j)}.
\]

Формула сохраняет каждую независимую строку меняющегося тарифа. Источник дополнительной общей внешней работы, если она отдельно оплачена, прибавляется один раз. У памяти упорядоченной истории и у когерентного терминального эффекта могут быть свои производные. Эти операнды нельзя получить выбором \(w_i\) по желаемому полевому уравнению.

## C3. Решение для полного теста

Оператор \(\sum_\omega(C_\omega-I_\omega)K_\omega^*K_\omega+W\) представляет среднюю цену при соответствующем выборе условной оценки и типа \(W\). Для сопоставления со скалярным функционалом нужно указать подготовку, её вариацию, оценку памяти и оплату терминального чтения. Например, дифференцирование \(\operatorname{Tr}(\rho M)\) содержит как \(\operatorname{Tr}(\rho\,dM)\), так и \(\operatorname{Tr}((d\rho)M)\).

Результат §7fu на исходной заявленной области использует \(-\ell D A_{stat}=D B+(\beta-1)D H\) при \(\beta=2p^2\). §7fx переносит на расширенную задачу отдельные источники с их действительными положительными gain в условиях LC12–16. Эти две ступени следует различать. Для физической приёмки на одной и той же оплаченной задаче нужен источник всех рёбер, вершин, памяти и работ либо доказанный перенос взвешенного продолжения и терминального чтения. В варианте CD13 с фактическими коэффициентами конуса окончательное сравнение имеет вид

\[
 R_{phys}=D S_{phys}-(c_BD B+c_PD P_{code,full}),\quad
 \frac{\|R_{phys}\|_*}{\Gamma}\to0,\qquad
 \frac{\|R_h\|\,\|R_{phys}\|_*}{\Gamma}\to0 .
\]

Для меняющихся коэффициентов сохраняются \(B\,D c_B+P_{code,full}\,D c_P\). Норма двойственна максимальной норме на доступных независимых блоках. Ошибка конечных пар делится на действительный шаг и gain с учётом нормы отображения из базисных координат. Оба предела нужны для прямого результата и обратного подъёма. Число для \(\|R_{phys}\|_*\) по имеющимся данным не вычисляется. Следующая подстановка — оценка исходного взвешенного перехода через фактическую запись и валидацию на тех же парах слов со всем прежним состоянием. Нулевой gain исключает лишь указанную скалярную двухсимвольную замену в качестве единственного источника. Физическое условие C открыто, предложение scoped terminal отозвано, `GR_closed=false`.

### Применение в Lean

В [модуле RetainedRecordSurprisal](../../../../03_FORMALIZATION/D0/Analysis/RetainedRecordSurprisal.lean) формально доказаны точная конечная сумма и её полная производная Фреше на окрестности с фиксированным положительным носителем. Массы могут зависеть от всех координат. Для фиксированных тарифов производная нулевая, для движущихся — сохраняются производные тарифов. Для самой цены \(-\log Z/\ell\) теоремы `hasFDerivAt_logPrice` и `hasFDerivAt_logPrice_fixed` доказывают нормированную сумму полных производных тарифов и её нулевой частный случай на непустом носителе. Внешняя [проверка специализации](validated_joint_mass.lean.inc) применяет существующую теорему `golden_two_tick_event_mass` к длинам 2,3,3, сохраняя исходный код ранее принятой капсулы. Аксиомы проверенных теорем — `propext`, `Classical.choice`, `Quot.sound`.

Чтобы воспроизвести специализацию из корня репозитория после сборки модуля:

```sh
joint_check=$(mktemp -d)
{

  cat 02_REGISTRY/research/certificates/a4d_native_code_price_resolution.lean

  cat 02_REGISTRY/research/sources/d0_validated_parry_price_2026-11-06/validated_joint_mass.lean.inc
} > "$joint_check/Joint.lean"
(cd 03_FORMALIZATION && lake env lean "$joint_check/Joint.lean")
```

Генерируемые представления совпали, реестр прошёл проверку с нулём предупреждений. Проверки покрытия claims и отсутствия незавершённых доказательств прошли.
