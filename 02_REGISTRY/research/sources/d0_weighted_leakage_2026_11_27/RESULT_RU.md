# Конечный контроль weighted leakage

На четырёх точках двух периодических направлений возьмём сдвиги
`X=(0 2)(1 3)` и `Y=(0 1)(2 3)`. Для целочисленной функции `f` положим

```text
dx f = f∘X − f,             dy f = f∘Y − f
d0 f = (dx f, dy f),        d1(a,b) = dx b − dy a.
```

Сдвиги коммутируют. Поэтому `d1(d0 f)=0` для любой функции на этих четырёх
точках. Lean проверяет это равенство для всех входов и всех точек.

Пусть множитель `s=(1,1,2,2)` действует поточечно на выход каждой ступени:
`d0_s=s d0`, `d1_s=s d1`. Это положительный корень веса
`w=(1,1,4,4)). Для функции `f=(0,0,1,0)` точное значение равно

```text
d1_s(d0_s f)(0) = −1.
```

Следовательно, конкретная вставка `sqrt(w) d` не обязана сохранять
нильпотентность. Постоянный вес `s=1` возвращает нулевой квадрат. Проверка
на четырёх базисных векторах и весь ненулевой результат приведены в
[check.py](check.py). Файл [Witness.lean](Witness.lean) доказывает
нильпотентность исходной цепочки для произвольной целочисленной функции и
точное значение контрпримера.

Это конечный пример внутри заданной модели. Он не утверждает ненулевой
квадрат для каждого непостоянного веса, не доказывает единственность
альтернативной процедуры и не устанавливает физический перенос к гравитации.
Запись `D0-ARCHIVE-NAIVE-WEIGHTED-CAR-DEGREE-LEAKAGE-NOGO-001` и её
зарегистрированный статус сохранены. Отсутствующая в реестре Lean-ссылка на
общего владельца остаётся предметом [аудита](../../../LEAN_REFERENCE_AUDIT.md).
