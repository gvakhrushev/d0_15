## Утверждение

Фон

```text
N[0,0]=N[0,3]=1/2, N[3,0]=N[3,3]=-1/2,
e=I+H N, H=x^2+1/4, g=e^T eta e, k=(1,0,0,1).
```

На этом фоне `det e=1`, `det g=-1`, скалярная плотность лоренцевой метрики равна 0, `G^{00}=1`. Положительная метрика `e^T e` имеет скаляр `-2 x^2 = -|dH|^2/2`. Квадратичная анголомия `q(T)=8 x^2=2|dH|^2`. Отсюда

```text
L2 = -4 R(e^T e)/3 + q(T) = 8|dH|^2/3 = 32 x^2/3.
```

Это воспроизведение формулы (7) теплового моста, не новая плотность.

Две вариации с пробной функцией `phi(x)`:

1. Профиль `H -> H+eps phi`. Это `delta g = phi k k^T`. Уже опубликовано и здесь только контроль: эйлерова плотность Эйнштейна–Гильберта равна 0, эйлерова плотность `L2` равна `-32/3 = -(16/3)(Hxx+Hyy)`.
2. Подъём (14): `delta e = e g^{-1} (phi E_00)/2`. Тогда `delta g = phi E_00`.

Новое сравнение на вариации 2:

```text
EL(R sqrt(-det g)) = -1 = -G^{00}.
Ток = -x phi - (4 x^2-3) phi_x / 4.
Сырая производная в нуле при постоянной phi равна -2 phi, не -1 phi.
EL(L2) = -(4 x^2-4 x-1)(4 x^2+4 x-1)/6.
EL(L2 det e) = -(48 x^4-48 x^2+1)/6.
Обе тепловые плотности в нуле равны -1/6 и не постоянны.
EL(|det e|) = EL(sqrt(-det g)) = -(4 x^2-3)/8.
В нуле объёмная плотность равна 3/8, не -1.
```

Пусть `C0`, `C2`, `c` — постоянные. На этих двух вариациях система

```text
C2 * EL_profile(L2) = c * EL_profile(EH),
C0 * EL(volume) + C2 * EL(L2) = c * EL(EH)
```

имеет только решение `C0=C2=c=0`. То же для `EL(L2 det e)`. Следовательно ни каналы `A0`, `A2` формулы (11) теплового моста, ни их постоянная линейная комбинация не воспроизводят геометрический covector. Коэффициенты не подбирались.

## Что сюда не входит

`C4 dA4`, `dR` и `dRem` формулы (11) не вычислялись. Полная v8-цена не дифференцировалась. `beta`, `t`, `alpha` не выбираются. Независимое `S_matter` не построено. Равенство (20) остаётся открытым: тепловое чтение `S_native` его не даёт, и недостающий член не назначается разностью до `G`.

## Предусмотренная атака

1. Подставить `G^{00}` вместо производной действия. Проверка считает плотность через символы Кристоффеля и отдельно поднимает Ricci.
2. Перепутать сырое значение `-2` в нуле с эйлеровой плотностью `-1`. Оба числа проверяются отдельно.
3. Сменить знак стягивания Ricci. Контроль сферы: скаляр 2 и `R_theta theta=1`.
4. Объявить пропорциональность по значению `-1/6` в одной точке. Плотность зависит от `x`, а профильная компонента Эйнштейна равна 0 при тепловой `-32/3`.
5. Снять множитель `det e` и получить постоянную. Без множителя плотность тоже непостоянна, калибровка снова только нулевая.
6. Назвать профильную невязку новым результатом. Она уже стоит в тепловом мосте; здесь это контроль.
7. Отождествить `L2` с тензором Эйнштейна. Сертификат записывает несовпадение.

На втором профиле `H=x^2/2` тот же контроль даёт `G^{00}=1/2`, эйлерову плотность Эйнштейна–Гильберта вдоль `E_00` равную `-1/2`, профильную тепловую плотность `-16/3` и профильную геометрическую плотность 0. Непропорциональность не является свойством одного значения `Hxx=2`.

Независимый проход по предусмотренной атаке: SURVIVES. Значение `-1/6` в нуле годится только как отношение двух компонент вдоль `E_00` в одной точке; оно не задаёт постоянную `c`.
