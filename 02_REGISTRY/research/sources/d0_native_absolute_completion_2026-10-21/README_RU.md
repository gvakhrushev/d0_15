# Полная проверка нормировки исходного D0-исполнения

**Дата:** 21 октября 2026. Пакет для существующего #334, а не новая ветка
физической теории. Полное D0→ОТО не доказано.

В этом пакете выполнен сам расчёт, который предыдущие сообщения оставляли
за фразой «нужно получить абсолютный нормировочный якорь». Для уже заданного
полного full128-прибора нормировка не является свободной: полнота Kraus
даёт единичную норму. Для его реально определённой маркировки стоимости
нормировочный объект — вычисляемый положительный **оператор**, а не
произвольно выбираемая константа.

## Результаты

1. Получены нормировочный оператор, его все первые вариации и точная
   конечная полярная/Doob-нормировка. Явно сохранено необходимое изменение
   входного состояния.
2. На исходной подготовке из256 ячеек с неравномерной F/R-плотностью,
   всеми16 CAR-компонентами и128 Fourier-столбцами показано: нормированный
   маркированный результат меняет oldRIGHT. Поэтому это не детерминированное
   LEFT-исполнение из того же полного начального состояния. Знак установлен
   интервально, а не оценкой численного ранга.
3. Вычислен настоящий Book-комплемент нормированного возврата и полный
   HJR-отклик. На прежнем сертифицированном HJR-корне, где oldRIGHT-проблемы
   нет, этот отклик всё равно ненулевой: при t=ln(phi) он находится между
   -0.497238841832 и -0.497238839255 по допустимому масштабному направлению.
4. Построено отдельное конечное Golden-завершение с сохранением всех
   отказов. Его полный выход нормирован, но его комплемент отличается от
   полярно нормированного. Дополнительные вызовы и часы не объявляются
   бесплатными.

Это завершённая проверка данного пути замыкания: он **не** даёт заявленную
подстановку в физическое действие. Результат не опровергает всю D0 и не
подменяет определение Book03 Info. Он исправляет ошибочную рабочую гипотезу,
что после относительных вероятностей осталось выбрать один скалярный якорь.

## Файлы и воспроизведение

`PROOF.md` — полный вывод и точные условия.
`OVERVIEW.md` — подготовленная обзорная запись для research-части репозитория.
`check_absolute_completion.py` — буквальный full128 и аналитические
неперестановочные производные, вся цена и384 исхода Golden-завершения.
`check_native_root_transport.py` — интервалы по всем65536 тепловым модам
исходного L8-корня и независимая высокоточная проверка формулы производной.
`check_primary_reference.py` — исходный full4096×128 вход, точная маршрутизация
F/R и интервальное нарушение условия сохранения RIGHT.
`matrix_result.json`, `root_result.json`, `primary_result.json` — результаты.

Требуются Python3.9+, NumPy, SciPy, mpmath. Запуск:

```sh
OPENBLAS_NUM_THREADS=1 python verify.py
```

Проверяющий скрипт не меняет результаты. Он сверяет целостность, запускает
расчёты обычным Python и с `-O`, сравнивает результаты. Интервальные строки
сравниваются точно; диагностические float-значения — с явно указанными
допусками. Существование прежнего корня потреблено из его владельца, не
доказывается повторно. Разбор другим независимым исследователем не выполнен.

## Передача в Git

`integration/additions.patch` добавляет обзор и пакет в отдельные пути
существующего исследования. Патч не переписывает Book, main/README, старые
сертификаты или параллельные результаты. `integration/STATUS.json` фиксирует
фактическое состояние передачи. В этой сессии удалённая запись пока не
выполнена: подключение GitHub предоставляет чтение, но не операции записи.
Пакет нельзя называть уже опубликованным коммитом или прошедшим GitHub CI.
