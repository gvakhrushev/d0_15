# D0: полный четырёхмерный конечный локальный лист

Новый научный пакет для существующего SOURCE #310, не новая задача/ветка.
Все изменения в additions.patch — добавления файлов; прежние владельцы
и квитанции не переписаны. Научный вход указан в самом доказательстве.

Основной результат — точный искривлённый якорь и интервально доказанная
обратимость ПОЛНОГО 6144-мерного connection-якобиана. Она даёт открытое
семейство точных решений для произвольных четырёхмерных coframe-возмущений
на фиксированной сетке L=4. Предел при измельчении НЕ объявлен доказанным.

Для локального воспроизведения:

    cd repo/02_REGISTRY/research/sources/d0_full_four_dimensional_sheet_2026-10-15
    OPENBLAS_NUM_THREADS=1 python verify.py
    OPENBLAS_NUM_THREADS=1 python -O verify.py
    OPENBLAS_NUM_THREADS=1 python hostile.py
    python invariants.py

Для обычного приёма в существующую рабочую ветку сначала сверить её текущий
head и затем применить additions.patch обычным git apply --check / git apply.
Никаких force-push или автоматического merge пакет не выполняет.

UPSTREAM_INTERVAL_REPAIR.patch внутри пакета — ОТДЕЛЬНАЯ предлагаемая правка
старого интервального конструктора. Она намеренно не применяется additions.patch:
после её применения нужен повторный старый реплей и корректная новая квитанция.
Старый PASS не переписывается задним числом.

Удалённая публикация этой сессией не выполнена: доступные connector-операции
только читают GitHub, терминальный сетевой доступ не разрешил имя хоста.
