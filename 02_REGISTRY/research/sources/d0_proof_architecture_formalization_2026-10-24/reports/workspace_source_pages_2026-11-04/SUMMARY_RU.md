# Проверка рабочих ссылок — 4 ноября 2026

Отдельная ограниченная страница открывает локальные Markdown-ссылки из действительно возвращённого документа. Она сохраняет строку ссылки, digest документа и digest содержимого цели. Исторический Git pin при этом не предполагается.

Совместный набор: 77 тестов, 5 Windows-специфичных пропусков; расширенный набор компактора: 184 теста, 5 пропусков. Проверены контроль содержимого, происхождение, границы страниц, устаревшие файлы, подмена страниц и небезопасные пути. Оба набора завершились успешно на Python 3.9; полные журналы и хеши сохранены. Исходная несовместимость тестовой обёртки с Python 3.9 исправлена и набор повторён.

Это проверка реализации на локальных фикстурах. Контроль исходного AF-запроса на чистом снимке и полный v3 replay остаются отдельными шагами. Платформы без безопасного открывания файлов получают отказ; Windows здесь не проверялась. Физическое допущение и `GR_closed=false` не меняются.
