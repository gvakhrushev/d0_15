## 3. A precise conditional retained-work covariance criterion

Let \(P_0\) be an old active projection on \(H_0\), and append one work
qubit. Suppose an extended projection \(\widetilde P\) obeys

\[
 [\widetilde P,I\otimes X]=[\widetilde P,I\otimes Z]=0,\qquad
 (I\otimes\langle0|)\widetilde P(I\otimes|0\rangle)=P_0.    \tag{2}
\]

Then, uniquely,

\[
                    \widetilde P=P_0\otimes I_2.          \tag{3}
\]

Indeed, commutation with Z removes the two off-diagonal work blocks;
commutation with X makes the two diagonal blocks equal, and the blank
compression identifies that block. Iteration gives \(P_0\otimes I_K\)
for a finite collection of such spectator qubits.

The initialized cut \(P_0\otimes|0\rangle\langle0|\) fails (2).
Thus the published retained-u neutrality on that initialized cut [S5]
cannot be promoted to a spectator-covariant cut by calling u retained.
Conversely (2) has NOT been derived from Book01 alone. A physical
observer may distinguish the workspace values. A proof that these
relabelings leave its active question unchanged is the additional
premise; no free implementation of X or Z is asserted here.

## 4. Full active input frames and selected input states are distinct

Fix an active embedding \(i:H\to E\), \(P=ii^*\), and a complete map
\(V_t:E\to E\), including whatever actual fixed branch-cost marks have
been specified. Suppose the code operations are unitaries \(C_k\)
preserving P, so \(C_ki=i c_k\) with unitary \(c_k\) on H. Put

\[
 W=V_ti,\quad N=W^*W>0,\quad A=i^*W,\quad
 \widehat F=I-N^{-1/2}A^*AN^{-1/2}.                       \tag{4}
\]

The coded map is \(W_k=V_tC_ki=Wc_k\). Therefore

\[
 N_k=c_k^*Nc_k,\quad A_k=Ac_k,\quad
 \widehat F_k=c_k^*\widehat F c_k,\quad
 \Pi_{W_k}=\Pi_W.                                        \tag{5}
\]

For the declared finite reference multiplicity \(r_{\rm ref}\) and
\(0<z<1\),

\[
 J_k=-r_{\rm ref}\log\det(I-z\widehat F_k)=J.              \tag{6}
\]

This includes nonscalar N and any common fixed marked V_t. No scalar
normalizer repair is used. It is the unitary case of [S3, §4], whose
range identity even permits arbitrary invertible right factors.
If a continuous admitted family consists only of these right frames,
all its J derivatives vanish; for finite code words (6) states exact
finite contrasts, not an invented derivative of a rounded code map.

For a fixed prepared density \(\rho\) on H and a report effect E on
the output, however,

\[
 q_k=\operatorname{Tr}\!\left[
       \rho\,c_k^*W^*E Wc_k\right]                       \tag{7}
\]

can vary. In (7) W must be the actual unmarked physical map when q
denotes a Born probability. The trace in (6) runs over ALL active
input columns; (7) evaluates ONE specified preparation. These are
different operations.

The all-column premise matters. A fixed initialized factory
\(S:H_{\rm in}\to E\) gives \(V_tC_kS\), which need not equal one common
map times an invertible input frame. Its outputs need not span an
invariant subspace of C_k. Equal factory probabilities on initialized
inputs alone do not establish (5). If the entire paid prefix, raw
instruction history and every failure record have a proved common
all-column factorization, (5) applies to that full map. Otherwise it
applies only to the block for which the factorization was proved.

## 5. Exact four-qubit Golden/CNOT realization

Use registers \((c,u,b,R)\), with their entire 16-dimensional carrier.
The ready prepared input is \(|1,0,0,0\rangle\). Section 6 supplies it
from the actual paid prefix. Let

\[
 p=\varphi^{-1},\quad a=\sqrt p,\quad
 G=\begin{pmatrix}a&-p\\p&a\end{pmatrix},\quad
 A=\mathrm{CX}(c,u),\quad B=\mathrm{CX}(u,b).
\]

The actual code words, listed in chronological order, are
\(C_0=(B,A)\) and \(C_1=(A,B)\) [S4, §2].
Their output on the ready input is respectively
\(|1,1,0,0\rangle\) and \(|1,1,1,0\rangle\).
They contain the same two addressed CNOTs and retain u permanently.
No reset or complementary controller-column deletion occurs.

Use ONE fixed downstream word, also chronological:

\[
       V=(G_R,\mathrm{CX}(b,R),G_R,
                    \mathrm{CX}(b,R),G_R).              \tag{8}
\]

The exact identity \(XGX=G^{-1}\) gives \(G^3\) on b=0
and G on b=1. Thus its R=1 probabilities on the ready input are

\[
 r_0=(3p^2-p^3)^2=(4-5p)^2=41-65p,\qquad
 r_1=p^2=1-p.                                           \tag{9}
\]

These are distinct strict probabilities. To check the entropy ordering
without floating point, the positive root of \(x^2+x-1=0\) satisfies
\(8/13<p<41/66<5/8\). Consequently
\(1/2<p<r_0<1\), and binary entropy is strictly decreasing on
\((1/2,1)\). In base \(\varphi\),

\[
                h_\varphi(r_0)<h_\varphi(p)
                              =h_\varphi(r_1).           \tag{10}
\]

Now declare the SAME complete report cut at input and output:

\[
 P=I_{c,u,b}\otimes|0\rangle\langle0|_R,\qquad \dim H=8.
\]

Both code maps preserve this P. On H, the uncoded complete complement
\(F_V=i^*V^*(I-P)Vi\) is diagonal, with r0 for each b=0 column
and r1 for each b=1 column. Each appears four times. On EVERY active
column the coded effects are \(F_k=c_k^*F_Vc_k\), so

\[
 \det(I-zF_k)=[(1-zr_0)(1-zr_1)]^4,\qquad
 J_k=-4r_{\rm ref}\log[(1-zr_0)(1-zr_1)].                \tag{11}
\]

Equation (11) is equal for k=0,1 although (9) and (10) differ.
The multiplicity is the actual r_ref of the declared carrier; 128 is
not imported. Any genuine oldRIGHT spectator is acted on identically.

In particular \(-\log(1-zr_k)\), computed from the selected prepared
column, is NOT (11). Replacing the full active domain by that column
while retaining a distinct final-report projection is a two-cut
effect construction. It is not the same-P Book complement without a
separate binding theorem. Even an identical rank-one input/output
blank cut asks a different return question.

This is an exact complete logical block. The raw ordered programme

 q_k=(\,1-\alpha,\ \alpha(1-r_k),\ \alpha r_k\,).          \tag{13}
