## Reproduce

From the repository root:

```sh
python3 -B 02_REGISTRY/research/sources/d0_native_gr_completion_synthesis_2026-10-20/source_selection/run_checks.py
```

Python requires SymPy and NumPy; the history checks require Node.js.
Use `--node /absolute/path/to/node` when Node is not on PATH.
The default run is read-only. `--output /tmp/validation.json` saves a new
run receipt without replacing the preserved receipt.

The finite checks verify exact algebra, original path counts, source
identities and hostile controls. The uniform convergence and all-integer
selection conclusions rest on the accompanying analytical proofs, not
on finite sampling. Original source pins are in `SOURCE_PINS.json`.
The helper `metric/owned_ir_checker.py` and the interval JSON are
unchanged source snapshots; the current checker verifies the pinned
interval hash. No Lean or unchanged geometry suite is rerun.
