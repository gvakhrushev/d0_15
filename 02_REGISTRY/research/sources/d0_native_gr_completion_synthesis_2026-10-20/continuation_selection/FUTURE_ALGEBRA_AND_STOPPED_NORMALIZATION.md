## 2. Minimal sufficient conditional expectation on the original Golden code

Let `p=phi^-1`, `a=sqrt(p)`, and use the original isometry from a blank record:

    V(u,v)=(a u-p v)|00>+(p u+a v)|11>.

Its accessible output support is `C=span{|00>,|11>}`. In this fixed output
code basis the owned observables `Z tensor I`, `X tensor X`, `Y tensor X`
restrict respectively to the ordinary Pauli `Z,X,Y`. They already linearly
span all Hermitian matrices on C together with I. Equivalently, on the input
fibre their pullbacks are

    V* (Z tensor I) V = c Z-s X,
    V* (X tensor X) V = s Z+c X,
    V* (Y tensor X) V = Y,
    c=p-p^2, s=2ap, c^2+s^2=1.

**Theorem.** Let A be a unital complex *-subalgebra of `B(C)` and E_A its
trace-preserving conditional expectation. If replacing every code state rho
by E_A(rho) preserves the three original readouts for every density rho on C,
then `A=B(C)=M2` and `E_A=id`.

**Proof.** A trace-preserving finite-dimensional conditional expectation is
self-adjoint for the trace pairing. Preservation of a readout O for every
density says `Tr rho (E_A(O)-O)=0`; density matrices span Hermitian matrices,
so `E_A(O)=O`. Thus I,X,Y,Z belong to A and span M2. Alternatively, the exact
owned Bloch reconstruction says every state is unchanged. No entropy axiom
or infinite family of tests is used.

More generally, for a declared finite-dimensional future effect family F,
the smallest possible range of such a conditional expectation is the
unital *-algebra generated by F. This is a statement about conditional-
expectation compression, not about arbitrary nonlinear sufficient encodings.
On the Golden support there is no distinction because the displayed tests
are already informationally complete. This result retains the original
conditional admission of the joint readouts; it does not infer their
physical availability from matrix algebra alone.

Concrete control: from input |0>, `rho=|a00+p11><a00+p11|` is pure. Its
pointer dephasing preserves probabilities `(p,p^2)` but changes the owned
XX expectation from `2ap` to zero. Consequently it is not sufficient for
this declared future interface. Evaluating pointer entropy as a scalar
functional of the retained full rho is still possible; it is not the same
claim as physically replacing rho by its dephased version. Thus the theorem
does NOT force `Info=S(rho)`, forbid conditional mutual information, or make
the old coherent/pointer price candidates equivalent.

## 4. The essential normalization correction

The cost weights on these stopped leaves are NOT a probability measure:

    Z_k=sum_n mu_n=p^(B+A_k+1)/(1-p^A_k)<1.

Calling E log(P/mu) ordinary normalized KL would be incorrect. Exactly,

    E log_phi(P/mu)=D_phi(P || mu/Z_k)-log_phi Z_k.

Two different normalizations must be distinguished.

1. With original cost C and absolute Book weight `w=P`, the value is
   H_geom and the missing minimum follows as above.
2. If the candidate is instead `I=log_phi(P/(mu/Z_k))`, while retaining
   the SAME original C, then

       w=Z_k P,
       E(C-I)=H_geom(q_k)-log_phi Z_k
              =H_geom(q_k)+B+A_k+1+log_phi(1-p^A_k).

   This value is coercive as k->infinity when ell_G>0. A finite k minimum
   therefore exists. On each fixed k branch Z_k is field-independent for
   the stated fixed ledger, so the source is exactly the SAME nonzero
   coefficient as in section 3.

Changing the reference AND replacing C by `-log_phi(mu/Z_k)` would instead
change the actual paid ledger and recover H_geom; that is not a harmless
normalization of the same cost.

The second choice is precisely absolute Book normalizer `N=Z_k` in the
already-owned partition-corrected cocycle; the first chooses N=1. Neither
the future-complete record algebra nor the normalized probability P chooses
between them. In particular per-programme normalization is not automatically
the correct global normalization when different programmes are compared.
A single absolute operational scale/cycle/clock binding would have to decide
this. The new consequence is concrete: identical complete normalized tapes,
identical sufficient algebra, and identical fixed-programme field sources
