## 3. Exact scalar Gibbs identity, with its terminal term

On this same finite complete leaf set define

\[
 w_\gamma=e^{-\ell C_\gamma},\qquad
 Z_C=\sum_{\gamma\in\mathcal L_K}w_\gamma,\qquad
 R_C(\gamma)=w_\gamma/Z_C,\qquad
 \tau_C=\bigoplus_\gamma R_C(\gamma)\rho.
 \tag{3}
\]

These are positive reference weights; they are not Born probabilities.
Since \(\rho\) is faithful, the relative entropy below is well defined
even when an actual output block has deficient rank. Directly,

\[
 D(\Gamma\Vert\tau_C)
 =-S(\Gamma)+\ell\,\mathbb E_P C+\log Z_C
                    -\operatorname{Tr}(\rho_T\log\rho).
\]

Consequently the exact full-price identity is

\[
 \boxed{\displaystyle
 \ell\mathscr P_{\rm gain}
 =D(\Gamma\Vert R_C\otimes\rho)-\log Z_C
    +\operatorname{Tr}[(\rho_T-\rho)\log\rho].}
 \tag{4}
\]

The terminal term is zero when the actual terminal DATA state equals
the input. Its first derivative need not be zero for a variation
leaving that constraint. At a finite cap, even a stationary input
generally has a nonzero terminal correction. The return-balance owner
provides its exact capped operator, so it is computable.
The reference \(\rho\) in (3) is the faithful DATA state specified
above; a pure retained joint purification cannot be inserted into
this reference without checking the required support inclusion.

For a fixed leaf language and fixed \(\ell\), moving actual costs obey

\[
 \mathrm d\log Z_C=-\ell\sum_\gamma R_C(\gamma)\,\mathrm dC_\gamma.
 \tag{5}
\]

Thus the normalizer's source is retained even if a field changes an
actual controller or edge price. Differentiating (4), including the
moving reference and \(\log\rho\), reproduces precisely

\[
 \mathrm d\mathscr P_{\rm gain}
 =\sum_\gamma C_\gamma\,\mathrm dP_\gamma
  +\sum_\gamma P_\gamma\,\mathrm dC_\gamma
  -[\mathrm dS(\Gamma)-\mathrm dS(\rho)]/\ell .
 \tag{6}
\]

There is no extra adjustable source hidden in \(Z_C\). The finite-tree
logarithmic source is used on a smooth-support chart, or with the
complete-history owner's amplitude regularization and its error budget.

An actually charged deterministic one-time prefix \(B(y)\) gives
\(C_\gamma=B+\widehat C_\gamma\),
\(Z_C=e^{-\ell B}Z_{\widehat C}\), and
\(R_C=R_{\widehat C}\). Its price and derivative therefore survive
exactly as \(B\) and \(\mathrm dB\). A random preparation/controller

## 4. The native fine-code partition on the declared coarse stop

For homogeneous additive reporting costs \(c_z\), define

\[

 u_a=\sum_{b(z)=a}w_z,\qquad

\]

\[
 \boxed{\displaystyle
 Z_{C,K}=\sum_{a\in\mathcal A}
 \left[u_a^2\sum_{j=0}^{K-1}r_a^j+u_ar_a^K\right].}
 \tag{7}
\]

actually declared for the programme. Grouping the literal singleton labels

\[
 Z_{C,\infty}=\sum_a\frac{u_a^2}{1-r_a}.
 \tag{8}
\]

## 6. Constructive stopped cost-marked operator and full source

The existing fixed-horizon normalization owner extends directly to the
actual coarse stopping tree. For \(t\ge0\) and nonnegative actual

\[
 \mathcal I_{z,t}=e^{-tc_z}\mathcal I_z,\qquad
 \mathcal A_{a,t}=\sum_{b(z)=a}\mathcal I_{z,t},\qquad
 \mathcal T_{a,t}=\sum_{b(z)\ne a}\mathcal I_{z,t}.
\]

Stars denote adjoints for the trace pairing. With \(K\) comparisons
remaining after the anchor, calculate on the original DATA space

\[
 H_{a,0,t}=I,\qquad
 H_{a,k,t}=\mathcal A_{a,t}^{*}(I)
                  +\mathcal T_{a,t}^{*}(H_{a,k-1,t}),\qquad
 N_{K,t}=\sum_a\mathcal A_{a,t}^{*}(H_{a,K,t}).
 \tag{10}
\]

The first term is the next matching leaf; the second retains the
mismatches; \(H_{a,0,t}=I\) keeps the capped abort. Expanding gives

\[
 \boxed{\displaystyle
 N_{K,t}=\sum_a\mathcal A_{a,t}^{*}
 \left[
 \sum_{j=0}^{K-1}(\mathcal T_{a,t}^{*})^j
                         \mathcal A_{a,t}^{*}(I)
       +(\mathcal T_{a,t}^{*})^K I
 \right].}
 \tag{11}
\]

This is exactly the last table row, including the charged anchor.
The computation requires only the coarse classes' DATA matrices,
not enumeration of all fine histories.

Under the already owned killed-map transience, nonnegative marking
preserves convergence. Thus

\[
 \boxed{\displaystyle
 N_{\infty,t}=\sum_a\mathcal A_{a,t}^{*}
       (I-\mathcal T_{a,t}^{*})^{-1}
                         \mathcal A_{a,t}^{*}(I).}
 \tag{12}
\]

All unmarked complete leaves sum to \(I\), so \(0<N_{\infty,t}\le I\)
at each fixed finite-dimensional transient point: any vector in its

leaf, contradicting complete termination. A uniform inverse bound
over a varying chart is a separate quantitative condition.

The initial derivative is \(\mathrm dH_{a,0,t}=0\), and

\[
