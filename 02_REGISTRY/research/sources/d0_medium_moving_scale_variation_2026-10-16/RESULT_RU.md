## 2. Семейство `E4` и почему это не топологическая константа

Класс проверки: `q = diag(1, b(x), c(x), d(x))`, коэффициент `f(x)`. В той же конвенции Римана, где срез единичной сферы даёт `R = 2`, а джет единичного `S^2 × S^2` в точке `(π/2, π/2)` даёт `R = 4`, `E4 = 8`,

```text
sqrt(b c d) E4 = ∂_x K,    K = b' c' d' / sqrt(b c d).
```

Отсюда при постоянном `f` действие на интервале есть разность `f K` на концах, и объёмный метрический оператор Эйлера–Лагранжа равен нулю. Это не новое доказательство `∫ E4 dVol = 32π² χ`. Числа сферы владельца остаются `A4D_RECORD_NORMAL_VOLUME_SOURCE.md:249`: `Vol = (8π²/3) r^4`, `∫ E4 = 64π²`. Джет `E4 = 8` согласован с `χ(S^2×S^2) = 4` и `∫ E4 = 128π²` только как точечная проверка нормировки, не как интегральная теорема.

Поднятые компоненты объёмной метрической плотности, `δS = ∫ E^{ii} δq_{ii} dVol` для компактной вариации:

```text
E^{yy} = [2 c c' d d' f''
          + f' (2 c c' d d'' - c c' (d')^2 + 2 c c'' d d' - (c')^2 d d')]
         / (2 b c^2 d^2),
```

и циклически `E^{zz}`, `E^{ww}`. Слот `yy` не содержит струи `b`. При `b=c=d=b'=c'=d'=1`, `f'=0`, `f''=1` получается `E^{yy} = 1 ≠ 0`. Полевая эйлерова плотность не заменяется топологическим числом.

Скалярное уравнение коэффициента общее, не только на семействе: лагранжиан линейен по `d` и не содержит `∂d`, поэтому источник по `d` есть сама плотность `E4`.

Проверенный отрицательный контроль: на рациональных струях этого семейства `E^{yy}, E^{zz}, E^{ww}` не лежат в постоянной линейной оболочке девяти свёрток ковариантного гессиана `f` с кривизной: `R ∇^μ∇^ν f`, `q^{μν} R □f`, симметризованный `Ric^{μλ} ∇_λ ∇^ν f`, `q^{μν} Ric^{αβ} ∇_α ∇_β f`, `Ric^{μν} □f` и четыре расстановки индексов `R^{····} ∇∇f`. Та же кривизна воспроизводит тензор EH из §1. Эта оболочка поэтому не принимается как метрический член `d E4`.

## 3. Граничный поток кривизны

Для `W^μ = ∇_ν V^{μν} - ∇^μ τ`, `τ = tr_q V` и единичной нормали `n` кандидатный поток

```text
Φ_c[V] dΣ = [ c W^μ n_μ - (∇_μ c) V^{μν} n_ν + τ ∇_n c ] dΣ.
```

Это поток Стокса тождества Палатини владельца (`A4D_RECORD_NORMAL_VOLUME_SOURCE.md:243–247`), не граничное слагаемое Гиббонса–Хокинга–Йорка.

На `q = diag(1,b,c,d)` и вариации одной поперечной компоненты `δq_{yy}` член `(∇_μ f) V^{μν} n_ν` равен нулю, и коэффициент в `∫ dx` совпадает с `√g (f W^x + τ ∂_x f)`. Без `τ` равенство нарушается. Коэффициент при `∂_x δq_{yy}` равен `-f √(bcd) / b`; на срезе `b = c = d = 1` это `-f`. Одного значения `δq_{yy}` для потока недостаточно.

На `q = diag(a,b,1,1)` и вариации `δq_{xx}` та же трёхчленная формула с `n_x = √a`, `n^x = 1/√a` совпадает с граничной формой вариационного исчисления. Выбрасывание `(∇_μ c) V^{μν} n_ν` оставляет ненулевой остаток.

Для `E4` на семействе §2 интегрирование по частям даёт `[f K] - ∫ f' K dx`. Если на конце не обращаются в нуль и вариация метрики, и её первая производная, к потоку добавляется вариация `f K`.

## 4. Цепное правило и конечный срез

`A4D_COHERENT_COMPILATION_COST_DESCENT.md:319–323`:

```text
c = gamma alpha_n t^2 / 2,    gamma = 2 p^6.                         (18)
```

`p + p^2 = 1`, `p > 0`. `A4D_NATIVE_JACOBIAN_CONTROLLED_RECORD_SOURCE.md:216–220` задаёт `alpha_n` на фиксированном срезе; `:248–252` — цена `B_n + (alpha t^2/2) R + Rem` до множителя `gamma`. `:309–312`: если `t` или `alpha` зависят от точки, член `∇^μ∇^ν f - q^{μν} □f` сохраняется; постоянную калибровку нельзя вставлять после дифференцирования полевого коэффициента.

При фиксированном срезе

```text
δc = (gamma t^2 / 2) δα_n + gamma alpha_n t δt,
∇c = (gamma t^2 / 2) ∇alpha_n + gamma alpha_n t ∇t.
```

Подстановка только внутрь `-c G^{μν}` оставляет на плоском `t = x` компоненту `yy` гессиана `κ(∇∇(t^2) - q □(t^2))`, равную `-2κ` при `κ = gamma alpha / 2`. Компонента `xx` того же тензора равна нулю: заморозка видна не на всех слотах.

Шаг среза, при `X_n + Y_n = a_addr` и `1 - p = p^2`:

```text
X_{n+1} = a_addr - p^2 X_n,    Y_{n+1} = p^2 X_n,
Δalpha = alpha_{n+1} - alpha_n = p^2 (f_0' - f_1') (X_{n+1} - X_n).
```

Десятичные `f_0'(p^2)`, `f_1'(p^2)` из мемо не используются как точные. Гладкая производная по вещественному `n` множит геометрический член `(-p^2)^n` на `log(-p^2)`. Отношение конечного шага к этой производной есть `(-p^2 - 1) / log(-p^2)` и не равно 1. Если на фиксированном срезе `alpha_n` не зависит от точки, а `t` зависит, `u(Δ_n c) = gamma (Δalpha) t u(t)` не является нулём при ненулевых `Δalpha`, `t`, `u(t)`.

## 5. Два нормализатора

Они не подменяются друг другом.

**N1, центрированный агрегат.** `A4D_COHERENT_COMPILATION_COST_DESCENT.md:353–356`:

```text
A = sum_i w_i L_i / Z,    Z = sum_i w_i,
dA = sum_i [w_i dL_i + (L_i - A) dw_i] / Z.                          (20)
```

То же самое: `DA = (DM - A DZ) / Z`. Равномерный сдвиг каждой цены на `k` меняет `A` на `k` и не меняет `dA`. Условная геометрическая форма при постоянных `b`, `ell` — `:397–400`, уравнения `(23)–(24)`. `ell` отражённой кривизны есть `-c`, не `+c` (`:422–432`). Полевое `c` в `(22)` как постоянную после дифференцирования не подставляют (`:431–432`).

**N2, локальное разбиение подготовки.** `A4D_NATIVE_PREPARATION_STATIONARY_SOURCE.md:130–132`:

```text
Z(E) = sum_j μ_j Tr exp(-ℓ f_j(E_j)),    A* = 6 - log Z / ℓ.          (5)
```

В синтезе `g0 = log(phi)` не является метрикой, `PREPARATION_SYNTHESIS.md:16–18`, и на верном минимуме `dA_comp* = -d log Z(E) / g0` (`:40`). Ведущий член `:66` содержит `b_* = k + 6 - log Z0 / g0` и `alpha_* = omega f1`. Это не выбранное здесь действие: цепное правило §4 относится только к коэффициенту `c`. Подстановка всей цены `(19e)` вместо независимых `b,c,d` не делается. `t` входит в `Z(E)` через `u_i = t^2 e_i + t^4 det A_i`, поэтому заморозка `t` внутри `Z` при живом `c(t)` вне `Z` есть другой оператор.

Фикстура, не выбор меры: веса `(1,1)`, цены `(0,4)`, `DZ = (1,0)` дают `DA = -1`. При `Z(E) = 2`, `dZ = 1`, `g0 = 1` источник N2 равен `-1/2`. Частное `t^2/(1+t^2)` при `t = 1` имеет полную производную `1/2`, заморозку знаменателя `1` и заморозку числителя `-1/2`.

Наблюдатель не удаляется нормировкой. На двух равных весах цена второй клетки содержит `4 θ u(c)`; производная агрегата по `θ` равна `2 u(c)`. При `u(c) ≠ 0` она не нулевая, в отличие от производной по весам после равномерного `k`.

## 6. Интерфейс нормы ошибки источника

Точное разложение первой вариации, без сборки в одно число:

```text
δS = ∫ E^{μν} V_{μν} dVol + Φ_∂[V, ∇V]
   + ∫ (δb + R δc + E4 δd) dVol
   + δS_observer(J_⊥)
   + δP_N1 + δP_N2 + δP_M06.
```

`E^{μν}` — метрический столбец таблицы §1. Для `E4` вне семейства §2 этот столбец не заполнен. `Φ_∂` зависит от `∇V`: оценки только через `‖V‖_∞` недостаточно. `L_J^T J = 0`, поэтому слот наблюдателя берёт сдвиг `J`, ортогональный линии.

`δP_N1 = (DM - A DZ) / Z` точно для своего `Z`. `δP_N2 = -dZ(E) / (g0 Z(E))` точно на верном минимуме подготовки. Эти равенства требуют каждый своего нормализатора и одного и того же касательного направления. Подстановка одного в другой не является тождеством.

M06, `02_REGISTRY/research/sources/d0_medium_measure_source_transport_2026-10-16/RESULT_RU.md:52` и `:282`, даёт скалярную пару `(E, D_v E)` после отдельно заданной стрелки `π_N(X)`. Коэффициенты `1`, `1/2` и `4` остаются коэффициентами той `ℓ¹`-оценки. В `G_{μν}` они не добавляются. Пока стрелка не задана, слот имеет статус `unevaluated` и не заменяется объёмными весами.

Непрерывность геометрической части: если `‖τ‖_{C^1}` есть максимум норм `V`, `∇V`, `δb`, `δc`, `δd` и ортогонального `δJ`, то модуль геометрического спаривания не превосходит `‖τ‖_{C^1}`, умноженного на сумму `L¹`-норм объёмных и граничных коэффициентов. `‖c‖_1` эту оценку не заменяет: на `[0,1]` функции `x^2` и константа `1/3` имеют один и тот же `L¹`, а `□(x^2) = 2` и `□(1/3) = 0`.
