Восемь шагов вперёд

  1. φ вынуждено, а не постулировано. Матрица совместимости следов башни имеет собственные значения φ и −1/φ. Позитивность на всех уровнях убивает второй корень; золотой профиль — единственная точка проективного предела.
  2. Полоса неоднозначности конечной башни равна φ−2N. Одна и та же скорость управляет и сходимостью следов Фибоначчи к φ, и исчезновением неоднозначности.
  3. Найден мост башня ↔ хронология: |Role|·x2 + x5 = 1, причём x2 = p3 = √5−2 — корень x2 + 4x − 1 = 0.

С1башня

φ вынуждено вторым собственным значением

Рекурсия совместимости следов записывается как действие матрицы на вектор весов. Это и есть настоящий источник золотого профиля — не подстановка собственного вектора Перрона, а спектр переноса.

перенос D = [[1,1],[1,0]],   (xn, yn) = D(xn+1, yn+1),   spec D = {φ, −1/φ}. Характеристическое уравнение 1 = λ + λ² даёт λ = 1/φ = p и λ = −φ. Золотое отношение R = 1 + 1/R есть то же уравнение — вот где оно входит в вывод.

Общее решение рекурсии: xn = A pn + B(−1/p)n. Второй корень растёт по модулю как φ, поэтому неотрицательность на всех уровнях вынуждает B = 0. Нормировка x0 + y0 = 1 даёт A = p, то есть xn = pn+1, yn = pn+2.

Почему это сильнее прежней аргументации

Прежняя формулировка «R = 1 + 1/R» предполагала, что золотое отношение уже задано. Здесь оно не предполагается: оно есть отношение компонент собственного вектора матрицы совместимости. Совместимость следов между всеми уровнями — проверяемое условие; её матрица — целочисленная; её собственные значения — вынужденные.

Проверено точно. Совместимость τn+1(ιn(A,B)) = τn(A,B) на случайных матрицах: максимальная ошибка 4·10−17. Тождество τn(I) = 1 выполняется на уровнях n = 0…59 с точностью 5·10−60.

Две полные массы башни — тоже вынужденные

(1) Σn≥0 xn = p/(1−p) = p/p2 = φ,    Σn≥0 yn = p2/(1−p) = 1.

Использовано тождество 1 − p = p2. Второе равенство существенно: y-сектор башни имеет полную массу ровно 1, то есть является вектором вероятностей. Золотой профиль — единственный, для которого это так. Усечённый дефицит тоже точен: φ − Σn≤N xn = φ−N.

С2конденсация

Конечная башня никогда не даёт единственности

Слой положительных нормированных следов на уровне N — не точка, а отрезок. Его ширина вычисляется точно и убывает с той же скоростью, что и ошибка приближения следов Фибоначчи к φ.

(2) |B|/|A| < p2N = φ−2N   ⟹   limN→∞ (полоса) = 0.

Конденсированная формулировка. Единственность золотого следа — утверждение о проективном пределе башни, а не о каком-либо конечном уровне. На любом конечном уровне существует открытая полоса конкурирующих профилей. Это снимает разрыв между «выведено» и «постулировано»: выведено именно предельное утверждение.

Численная проверка согласуется с предсказанием. Профиль с B = 10−6 теряет позитивность на уровне n = 15, тогда как оценка log|B|/log p2 даёт 14.35. Тот же масштаб для B = 10−9: нарушение на n = 23 против предсказания 21.53.

С3мост

Мост башня ↔ хронология: разбиение единицы

Здесь появляется первое точное тождество, связывающее башню с хронологическим блоком обратной связи. Оно не косметическое: коэффициент 4 в нём вынуждается.

(3) x2 = p3 = √5 − 2 = 0.236067977499789696…,    x5 = p6 = 5 − 8p = 0.055728090000841214…,
(4) |Role|·x2 + x5 = 4p3 + p6 = 1.

Почему коэффициент равен именно 4

Требование, чтобы золотой вес x2 = φ−3 был корнем уравнения x2 + mx − 1 = 0, фиксирует коэффициент однозначно:

(5) m = 1/x2 − x2 = φ3 − φ−3 = 4 = L3,

где Ln — числа Люка, Ln = φn + (−φ)−n. Итак, |Role| = 4 есть третье число Люка, и это не совпадение: последовательность Ln совпадает с последовательностью размерностей башни, 2, 1, 3, 4, 7, 11, 18, 29, … В частности, L5 = 11 — параметр сцены K(9,11,13), а L4 = 7.

Тождества φ − φ−1 = 1 и φ3 − φ−3 = 4 проверены символьно. Это даёт вынужденность числа ролей из золотой башни — то, что раньше было входным параметром сцены.

С5тепло

Мост тепла: дуальный ном встречает золотой вес

Тепловой функционал при объёмосохраняющей кривой сводится к произведению одномерных тэта-сумм. Преобразование Пуассона переводит прямую сумму в дуальную, и в дуальной появляется ном, зависящий только от β.

Точный предел β → 0

При β → 0 веса Гиббса выравниваются, и среднее sin2(πk/L) по решётке равно 1/2 точно. Отсюда замкнутый предел:

(8) Er(0) = 2L2/Qrr,    F(L,0) = 2(E1 − E2) = 4L2(1/Q11 − 1/Q22) = −15L2.

Вдоль тестовой кривой Q11 = 4, Q22 = 1/4, поэтому 1/Q11 − 1/Q22 = 1/4 − 4 = −15/4. Множитель 15 = 16 − 1, где 16 есть число градуированных компонент формы и одновременно 1/Q22. Проверка: при β = 10−6 и L = 4 численно получается −239.98 против точного −240.

С6пределы

Пределы не перестановочны — это физическое утверждение

Здесь находится самое сильное уточнение к исходному тепловому результату. Неперестановочность двух пределов не техническая деталь, а требование к любой формулировке: порядок пределов должен быть частью закона.

Поэтому тепловой отклик при фиксированном β нельзя объявлять «просто дискретизационной ошибкой, исчезающей при измельчении». Он исчезает только если сначала устремить L к бесконечности. Обратный порядок делает его расходящимся. Утверждение «на более мелкой сетке лишний отклик исчезнет» требует указания, что β при этом фиксирован, — и это ограничение теперь точное, а не эвристическое.

Что это даёт Φ. Отображение поле → прибор обязано включать правило упорядочения пределов. Это ровно та «равномерность при уточнении», которая в аудите числилась открытой: теперь у неё есть точная формулировка и точный контрпример к наивному чтению.

С9ошибка

Неустранимая ошибка классического чтения

Классический рид-аут видит только вероятности. Его образ — span{(p2, −p2, 0)}, то есть ковектор τ пробегает однопараметрическое семейство (c, −c, 0). Расстояние от этого семейства до истинного градиента (0, a, 0) минимизируется явно.

(11) minc ‖(c,−c,0) − (0,a,0)‖2 = minc[c2 + (c+a)2] = a2/2.

Ошибка не может быть устранена никаким выбором τ: она равна расстоянию от образа дифференциала рид-аута до истинного ковектора.

Это уточняет исходный результат о когерентной записи. Там было показано, что вероятности не различают состояние. Здесь показано, сколько именно отклика теряется при таком чтении — точная величина, а не просто «не ноль».

С11дальше

Что теперь можно атаковать

Синтез не закрывает проект, но меняет карту. Вместо «нужно вывести Φ» появляются четыре конкретные задачи, каждая с ясным критерием успеха.

  • открыто Вывести β из башни. Если требование r = x2 (или β = 1/(3 ln φ)) можно вывести из самой структуры башни, а не выбрать, тепловой сектор и золотой спектр сольются в один закон. Критерий: тождество, а не численное совпадение 0.065 %.
  • открыто Построить пяти-канальный прибор. Размерностный минимум известен; нужно предъявить пять возвратов, для которых Dπ имеет полный ранг 66, и проверить, что золотой след остаётся решением. Это прямое продолжение требования (R).
  • открыто Доказать равномерность по L с правильным порядком пределов. Контрпример найден: наивный порядок даёт −15L2. Нужно доказать устойчивость в режиме фиксированного β и указать, откуда следует фиксация β.
  • открыто Проверить гипотезу 66 = 2N. Если размерность касательного пространства следует из числа сцены 33, размерностный дефицит интерфейса перестаёт быть совпадением и становится структурным. Критерий: вывод 66 из построения сцены.

Общая линия. Все четыре задачи сводятся к одному: превратить золотой спектр из «найденного» в «вынужденный на всех уровнях». Пока это сделано для башни следов, для числа ролей и для порога хронологического блока. Не сделано для теплового параметра и размерности интерфейса — именно там лежит следующий шаг.
