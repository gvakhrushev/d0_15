## 1. Входы, заданные отдельно

Пусть `q` пробегает открытое выпуклое `U ⊂ R^d`. Индекс `q` — параметр заданных весов и цен. Он не отождествляется с метрикой, с глубиной AF, с гладким `t` и с масштабом `h`.

На фиксированном срезе стоимости `n` заданы:

1. Конечное множество цилиндров `C_n = R_n ⊔ P_n`. `R_n` — ready, состояние 0; `P_n` — pending, состояние 1. Это различие взято из `A4D_NATIVE_GOLDEN_COST_REFINEMENT.md:57–58` и `:64–67`, не из равномерного двоичного деления.
2. Конечная карта `π_n : C_n → I`, `I = {1,…,m}`, `m ≥ 1`. На области производной карта постоянна.
3. Веса цилиндров `μ_c(q)`. На выпуклом компакте `K ⊂ U` нормализатор `Z_μ(q) = Σ_c μ_c(q)` удовлетворяет `Z_μ ≥ z_μ > 0`.
4. Геометрические веса клеток `w_i(q) > 0`. Их сумма `Z_w ≥ z_w > 0`. Принадлежность `w_i` объёмной мере D0 **не** предполагается и **не** получается.
5. Цены цилиндров `λ_c(q)` и цены клеток `L_i(q)`, все класса C¹.

Золотая специализация весов, не новая мера: `A4D_NATIVE_GOLDEN_COST_REFINEMENT.md:76–80`,

```text
a_n p^n + b_n p^{n+1} = 1,
```

`p + p^2 = 1`, `p > 0`. На ready-состоянии вес цилиндра `p^n`, на pending — `p^{n+1}`. Тогда `Z_μ = 1`, и нижняя граница `z_μ = 1` достигается. Это не нижняя граница `Z_w`.

Алгебраическое включение `ι_N` и след `τ_N` остаются скалярным/матричным фактом того же мемо, строки 111 и 127: `τ_{N+1}(ι_N(A,B)) = τ_N(A,B)`. Условное ожидание `C_N` (`:152`) остаётся внутри AF-алгебры. Индекс алгебры `N` и индекс среза `n` связаны у владельца сдвигом `(a_{N+1}, b_{N+1}) = pathCount(N)` (`:64`). Этот сдвиг здесь не стирается: производная ниже не дифференцирует ни `n`, ни `N`.

## 3. Три агрегата

При `Z ≠ 0`

```text
A = M / Z,   M = Σ ω_j ℓ_j,   Z = Σ ω_j.
```

Точная производная, та же форма, что `A4D_COHERENT_COMPILATION_COST_DESCENT.md:355–356`:

```text
D_v A = Σ_j [ω_j D_v ℓ_j + (ℓ_j − A) D_v ω_j] / Z
      = (D_v M − A D_v Z) / Z.
```

Аргумент: `D(M/Z) = (DM)/Z − M (DZ)/Z^2` и `DM − A DZ = Σ ω Dℓ + Σ (ℓ − A) Dω`.

Незаконное удаление нормализатора:

```text
D_v^{bad} A = (D_v M) / Z,
D_v^{bad} A − D_v A = A (D_v Z) / Z.
```

Коэффициент при `A (D_v Z) / Z` равен **1**. Равенство `D^{bad} = D` равносильно `A D_v Z = 0`, а не тождеству.

Три скаляра на одном `q`, при постоянной на этой области карте `π`:

```text
ν_i = Σ_{π(c)=i} μ_c,
A_λ = Σ_c μ_c λ_c / Z_μ,
A_π = Σ_i ν_i L_i / Z_μ,
A_w = Σ_i w_i L_i / Z_w.
```

`A_λ` не зависит от `π`. `A_π` зависит. Ошибка переноса значений

```text
E = A_λ − A_w = (A_λ − A_π) + (A_π − A_w).
```

Пусть `η_c = λ_c − L_{π(c)}`, `δ = A_λ − A_π`, `p_i = ν_i / Z_μ`, `r_i = w_i / Z_w`.

**Слой цены.** `δ = Σ_c (μ_c / Z_μ) η_c`.

**Веса.** Для любого числа `c`

```text
A_π − A_w = Σ_i (p_i − r_i) (L_i − c),
```

потому что `Σ (p_i − r_i) = 0`.

**Движение весов внутри производной**, карта `π` постоянна:

```text
D_v p_i = (Z_μ D_v ν_i − ν_i D_v Z_μ) / Z_μ^2,
D_v r_i = (Z_w D_v w_i − w_i D_v Z_w) / Z_w^2,
D_v ν_i = Σ_{π(c)=i} D_v μ_c.
```

Второе слагаемое есть вклад движения разбиения масс при замороженных метках. Его нет в `D^{bad}`.

## 4. Коммутирование с реальным включением

Родитель `ρ` следующего среза стоимости, по `A4D_NATIVE_GOLDEN_COST_REFINEMENT.md:64–67` и матрице `K` (`:88`):

- ready-цилиндр `c` имеет двух детей: прямой `δ(c)` с множителем `p` и pending-старт `σ(c)` с множителем `p^2`;
- pending-цилиндр `b` имеет одного ребёнка, завершение `κ(b)`, с множителем `1`;
- деление **каждого** листа, включая pending, — другое измельчение (`:66–67`).

Согласованность масс: сумма весов детей равна весу родителя. Для золотых множителей это `p + p^2 = 1` на ready и множитель `1` на pending.

Пара карт **коммутирует** с этим включением, если

```text
π_{n+1} = π_n ∘ ρ.
```

Достаточность. Если карты коммутируют и веса согласованы с `ρ`, то для каждой клетки `ν_{n+1,i} = ν_{n,i}`. Группировка детей по клетке родителя и сохранение массы на слое дают равенство. При тех же `L_i` тогда `A_π` не меняется от `n` к `n+1`. Полная масса `Z` сохраняется и без коммутирования: это след/масса, не клетки.

Необходимость только в таком объёме: если равенство pushforward требуется для **всякой** неотрицательной системы весов, согласованной с `ρ`, то `π_{n+1} = π_n ∘ ρ`. Иначе у ребёнка `c*` клетка `i` не равна клетке `j` родителя; масса 1 на этом родителе и положительная доля на `c*` разделяют `ν_n` и `ν_{n+1}`.

Одного золотого веса мало для необходимости. У двух ready-цилиндров одного среза веса равны, и обмен их равновесных детей между разными клетками может сохранить `ν`, не коммутируя. Универсальная формулировка выше этот обмен исключает; золотая фикстура сама по себе — нет.

Коммутирование с ложным родителем, который делит pending надвое, — другое условие. Контроль в тестах отделяет число детей: у реального `ρ` pending имеет одного ребёнка.

Сохранение `τ_{N+1} ∘ ι_N = τ_N` есть равенство скаляров. Оно не влечёт `π_{n+1} = π_n ∘ ρ`.

## 5. Оценка

На точке, где карта постоянна, веса клеток и цилиндров дают вероятности только если веса неотрицательны. Тождество частного требует лишь `Z ≠ 0`. Оценка колебанием требует `Σ_i (p_i − r_i) = 0`, что верно при `Z_μ ≠ 0` и `Z_w ≠ 0`.

Обозначения в одной точке `q ∈ K`:

```text
ε_λ   = max_c |λ_c − L_{π(c)}|
ε'_λ  = max_c |D_v (λ_c − L_{π(c)})|
η_*   = max_c |η_c − δ|
θ     = ||p − r||_1
θ_1   = ||D_v p − D_v r||_1
osc(L)= max_i L_i − min_i L_i
Λ'_v  = max_i |D_v L_i|
```

**Значения.**

```text
|A_λ − A_w| ≤ ε_λ + (1/2) θ osc(L).
```

Коэффициент при слое цены равен **1**: `|δ| ≤ ε_λ`, если `μ_c ≥ 0` (выпуклая комбинация). Коэффициент **1/2** при весе: пусть `a_i = p_i − r_i`, `Σ a_i = 0`, `osc = max L − min L`. Тогда `Σ a_i L_i = Σ a_i (L_i − min L)` и `0 ≤ L_i − min L ≤ osc`, а `Σ_{a_i>0} a_i = ||a||_1 / 2`. Значит модуль не больше `(1/2) ||a||_1 osc`. Константа 1/2 достигается (§6).

**Первая производная, карта заморожена.**

```text
|D_v E| ≤ ε'_λ + η_* (||D_v μ||_1 + |D_v Z_μ|) / Z_μ
         + (1/2) θ_1 osc(L) + θ Λ'_v.
```

Слагаемые:

- слой: `D_v δ = Σ_c [μ_c D_v η_c + (η_c − δ) D_v μ_c] / Z_μ`, поэтому модуль не больше `ε'_λ` плюс `η_* Σ_c |D_v (μ_c/Z_μ)|`, и `Σ |D(μ/Z)| ≤ (||Dμ||_1 + |DZ|) / Z`;
- веса: `D_v(A_π − A_w) = Σ (D p_i − D r_i) L_i + Σ (p_i − r_i) D L_i`; первое оценивается коэффициентом 1/2, как выше, потому что `Σ (Dp − Dr) = 0`; второе — коэффициентом 1 на `θ Λ'_v`.

Коэффициент 1/2 при `θ_1` достигается (§6). Коэффициент 1 при `A (DZ)/Z` в тождестве удаления — равенство, не верхняя оценка.

**Следствие с одной нижней границей.** Если `μ_c ≥ 0` и `Z_μ ≥ z_μ > 0`, то `|δ| ≤ ε_λ` и `η_* ≤ 2 ε_λ`, а `||Dμ||_1 + |DZ| ≤ 2 ||Dμ||_1`. Подстановка даёт

```text
|D_v (A_λ − A_π)| ≤ ε'_λ + 4 ε_λ ||D_v μ||_1 / z_μ.
```

Коэффициент **4 = 2·2** не объявляется точным. В бюджетной форме его можно держать рядом с точной дробью `(||Dμ||_1 + |DZ|)/Z_μ`, а не вместо неё.

Никаких `O(·)` здесь нет: каждый коэффициент написан числом, каждый дефект — максимумом или `ℓ¹`-нормой заданных входов.

## 6. Движение разбиения

Производная §5 определена на открытом множестве, где конечная карта постоянна. Скачок меток не является частной производной по `q`.

Для двух карт `π` и `π'` на тех же `μ` и `L`

```text
ρ = (1 / Z_μ) Σ_{π(c) ≠ π'(c)} μ_c,
|A_π − A_{π'}| ≤ ρ osc(L).
```

Аргумент: разность равна `Σ_c (μ_c/Z_μ) (L_{π(c)} − L_{π'(c)})`, каждое ненулевое слагаемое по модулю не больше `osc`, а сумма соответствующих `μ_c/Z_μ` равна `ρ`. Коэффициент **1** достигается, когда вся масса переходит с минимальной цены на максимальную.

Полная ошибка значений при смене карты — оценка §5 для новой карты, либо оценка для старой плюс этот член `ρ osc(L)` на разности двух `A_π`. Член `ρ` не прячется внутрь `D_v`.

Глубина `n`, параметр `t` и масштаб `h` не подставляются друг в друга. Конечная разность pushforward при одном шаге `ρ` не равна `∂_t` и не равна `∂_h`.

## 7. Точные фикстуры

Это не `π_N(X)`. Две карты с одной и той же массой обязательны именно затем, чтобы фикстура не выглядела как выбранная физическая карта.

### Рациональные две клетки, достижение 1/2

`μ_0 = 3+q`, `μ_1 = 1+q`, `Z_μ = 4+2q`. В точке `q = 0`: `Z_μ = 4`, `D Z_μ = 2`. Клетки `(i0, i1)`, карта `c0 ↦ i0`, `c1 ↦ i1`. Цены клеток `L = (0, 4)`, геометрические веса `(1, 1)`.

Независимый полином момента при наклонах цен `(5, 7)`:

```text
M(q) = (3+q)·5q + (1+q)·(4+7q) = 4 + 26q + 12q^2.
```

Симметричная разность даёт `M'(0) = 26`, `Z'(0) = 2`, `A_λ(0) = 1`, полная производная `(26 − 1·2)/4 = 6`. Замороженные цены `(0, 4)` дают полную производную `1/2`. Значения цен в нуле совпадают, первые струи источника нет.

Удаление `dZ` даёт `26/4 = 13/2`. Щель `13/2 − 6 = 1/2 = A (DZ)/Z`.

Нормированные веса: `p = (3/4, 1/4)`, `r = (1/2, 1/2)`, `θ = 1/2`, `osc(L) = 4`. Оценка `(1/2)·(1/2)·4 = 1`. Фактическая `|A_π − A_w| = |1 − 2| = 1`.

`D p = (−1/8, 1/8)`, `θ_1 = 1/4`, `D L = 0`. Оценка производной весов `(1/2)·(1/4)·4 = 1/2`. Фактическая `|D(A_π − A_w)| = 1/2`. Закрытая форма `D((3+q)/(4+2q))` в нуле равна `(4−6)/16 = −1/8` и совпадает с первой координатой `Dp`.

Одна цилиндрическая масса `5`, перенос всей массы с цены `0` на цену `4`: `ρ = 1`, оценка `1·4 = 4`, модуль разности средних равен `4`.

### Три клетки, золотой срез `n = 2`

Счёт `(a_2, b_2) = (2, 1)` из рекурсии `(a_0,b_0)=(1,0)`, `(a_{n+1},b_{n+1})=(a_n+b_n, a_n)`. Веса

```text
μ(R1) = μ(R2) = p^2,   μ(P) = p^3,   Z_μ = 1.
```

Фикстурная карта: `R1 ↦ 1`, `R2 ↦ 2`, `P ↦ 3`. Цены `L = (0, 1, 3)`. Геометрические веса `(1,1,1)` — произвольные положительные числа, не объём и не `ν`.

```text
A_π = p^2 + 3 p^3 = −2 + 5p,
A_w = 4/3,
|A_π − A_w| = 10/3 − 5p,
(1/2) θ osc(L) = 4 − 6p.
```

Разность оценки и модуля есть `2/3 − p > 0`, поскольку `4 < 5` влечёт `p < 2/3`. Здесь 1/2 не насыщена; насыщение дано рациональной фикстурой.

Реальное измельчение: прямые дети ready имеют вес `p^3`, pending-старты — `p^4`, завершение `P` — `p^3`. Коммутирующая карта сохраняет `ν = (p^2, p^2, p^3)` и массу `1`. Перенос только ребёнка `σ(R1)` в клетку 3 даёт `ρ = p^4` и `|Δ A_π| = 3 p^4 = ρ · osc(L)`. Масса по-прежнему `1`, клетки уже другие.

Отдельный срез `μ(R)=p`, `μ(P)=p^2`: некоммутирующий увод `σ(R)` меняет массу клетки 1 на `−p^3`. Числа `∂_t (t) = 1` при `t = 2` и `∂_h (h^2) = 4` при `h = 2` этому приращению не равны.

## 8. Контроли, которые отвергают ложный вывод

Они отвергают вывод, а не ломают арифметику. Равенства в `test_transport_bound.py` остаются равенствами; ложный тезис проверяется отдельным булевым значением.

1. Одинаковые значения цен `(0, 4)` при `q = 0` и разные струи: полные производные `1/2` и `6`. Тезис «струя источника определяется значением pushforward» ложен.
