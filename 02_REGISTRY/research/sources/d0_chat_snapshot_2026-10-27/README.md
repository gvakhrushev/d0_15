Все 74 текстовых файла из девяти доступных локальных архивов этого чата: доказательства, исходный код, таблицы целых порогов, исторические результаты обычных и оптимизированных запусков, старые манифесты и ссылки на исходные коммиты. Это архив научной работы, а не автоматическое принятие всех содержащихся в ней утверждений. Последующие ограничения и отрицательные результаты сохранены наравне с положительными. `GR_closed=false`. Исторические receipts не объявляются свежими запусками.

Ранние результаты чата, уже находящиеся в базовой ветке, этим коммитом не заменяются. В частности, сохраняются ранее опубликованные результаты о неподвижном DATA-состоянии, портовой истории, когерентном архиве 256, двухсобственнозначном CAR16 и полном внутреннем clock. Здесь устраняется незавершённость выгрузки локальных продолжений.

## Восстановление

Из корня репозитория, Python 3.10+ со стандартной библиотекой:

```bash
python 02_REGISTRY/research/sources/d0_chat_snapshot_2026-10-27/restore.py
python 02_REGISTRY/research/sources/d0_chat_snapshot_2026-10-27/restore.py --extract /tmp/d0-chat-2026-10-27
```

Вторая команда восстанавливает `packages/D0_.../` под указанным каталогом. Она сначала проверяет все части, полный поток и каждый из 74 исходных файлов по SHA256; не исполняет архивный код и отказывается перезаписывать отличающиеся файлы. Используйте отдельный каталог вне рабочей копии, чтобы не добавить восстановленные дубли в Git случайно.

Файлы `payload/part-*.xz` — последовательные части ОДНОГО XZ-потока, а не независимые архивы. Их нельзя распаковывать по отдельности. [MANIFEST.json](MANIFEST.json) фиксирует порядок, размеры, SHA256 и Git blob. [FILES.md](FILES.md) содержит независимый читаемый список всех оригинальных файлов с контрольными суммами.

## Текущий научный вывод

Нельзя складывать условные результаты в безусловное закрытие простым снятием их предпосылок. Вместе пакеты показывают сильный механизм реализации источников и несколько контролируемых геометрических пределов. Не установлен общий переход от исходных `U_N, P_N, Delta_N`, их реальных вариаций и полной цены к обязательному физическому Einstein-источнику. Уникальность каждого компилятора для этого не требуется; требуется общий доказанный физический источник или контролируемый остаток.

Продолжение должно потреблять исходное действие Book03 §03.25 и всю производную `F=P U* (I-P) U P`, включая движения U и P, тепло и независимые upstream-переменные. Нельзя подставлять желаемый полином в декодер и объявлять такую реализацию выводом выбора самого закона. Общая exact-root recovery и корректный совместный предел остаются отдельными задачами.
