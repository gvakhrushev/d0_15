## 19 ноября. Цена подтверждения исхода

На внутреннем такте CX штатного читателя H.1 при доступе только к уже зарегистрированному биту средняя цена подтверждения в единицах одного когерентного такта равна $1+2q(1-q)$. Для всех внутренних наблюдаемых двух соседних тактов также получена точная формула. В исходном центре после вычитания энтропии записи производная первой цены равна **−0,385033** при единичной калибровке и **+0,907058** при спектральной калибровке $\sqrt{22}$. Правила определяют скорость на графе сцены и нормировку оператора Ходжа. Перевод внутреннего спектрального расстояния в фактическую стоимость исполнения остаётся открытым.
