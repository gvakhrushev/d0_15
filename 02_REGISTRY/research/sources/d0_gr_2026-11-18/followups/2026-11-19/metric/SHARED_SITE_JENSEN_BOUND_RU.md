# Строгая нижняя граница локального Jensen-остатка

**Результат.** Для исходного нелинейного отчёта при \(f=0\) получена равномерная строгая оценка кривизны: на всём разрешённом интервале \(|y|\le1/64\) выполняется \(-\mathcal R''(y)>3z/2\). Поэтому замена одного QND-сохраняемого SITE восемью независимыми SITE-сдвигами может изменить конечную вероятность отчёта не просто ненулевым числом: разность снизу ограничена дисперсией локального материального поля. Реальный полный sign-компилятор, общий clock и физическая цена не построены; граница относится к отдельно указанной локальной ветви и не закрывает ОТО.

## 1. Исходный полный отчёт и допустимая область

Используем точную исходную формулу 2+8-sign-владельца и [исходную композицию SITE/сдвигов](INDEPENDENT_SHIFT_SHARED_SITE_RU.md). Пусть \(p=\varphi^{-1}\), \(z=2^{-20}\), \(L=4p^3\),
\[
 u=p+p^2y,\quad B=4u^2(1-u^2),\quad
 A_y=L+(1-L)B,\quad
 \mathcal R(y)=1-(1-zB)(1-zA_y).\tag{1}
\]
Здесь \(y=\sigma q_x/(64\Lambda)\), \(\sigma=\pm1\), и предполагается реальная граница **локального** знакового операнда \(|q_x|\le\Lambda\) для каждой ячейки. Одна граница нормы другого глобально усреднённого оператора не доказывает это по умолчанию. Тогда \(|y|\le1/64\), \(0.612<u<5/8\), \(0<L<1\), \(0\le B\le1\). Прямое дифференцирование по y даёт
\[
 \mathcal R''(y)=zB''_y\bigl[(2-L)-z(L+2(1-L)B)\bigr]
               -2z^2(1-L)(B'_y)^2,\quad
 B''_y=8p^4(1-6u^2).\tag{2}
\]
Из точных рациональных границ \(309/500<p<619/1000\) следует \(p^2>381/1000\), \(u>153/250\), \(L<119/125\). Поэтому
\[
 -B''_y>8\left(\frac{381}{1000}\right)^2
             \left[6\left(\frac{153}{250}\right)^2-1\right]
 =\frac{5657940297}{3906250000},\quad
 (2-L)-z[L+2(1-L)B]>(2-119/125)(1-z),\tag{3}
\]
а произведение правых частей строго больше \(3/2\). Последний член (2) неположителен. Итак для **каждого** допустимого y
\[
 \boxed{-\mathcal R''(y)>\tfrac32z.}\tag{4}
\]
Проверка использует точную рациональную арифметику; произвольная float-сетка не является доказательством (4).

## 2. Что следует для одного сохранённого SITE

Пусть на физически допустимом фиксированном descriptor-журнале исходные восемь sign-инструментов являются QND по **одному** сохраняемому \(X\), и при каждом зафиксированном \(X=x\) их полные условные signed-эффекты действительно факторизуются с одним и тем же локальным моментом \(q_x/\Lambda\). Это собственный обязательный операторный контракт исходной локальной архитектуры; не следует из отдельных усреднённых эффектов и здесь не доказан для полной геометрической фабрики. Пусть \(\mu_x\) — её фиксированная нормированная SITE-мера. Тогда строгая вогнутость и стандартное тождество второго порядка дают
\[
 \boxed{\mathcal R\!\left(\frac{\sigma\mathbb E_\mu q_X}{64\Lambda}\right)
       -\mathbb E_\mu\mathcal R\!\left(\frac{\sigma q_X}{64\Lambda}\right)
 \ge \frac{3z}{16384\Lambda^2}\operatorname{Var}_\mu(q_X).}\tag{5}
\]
Для вывода применяем сильную вогнутость \(\mathcal R(y)+(3z/4)y^2\), затем берём её среднее: квадрат \(\sigma=\pm1\) равен единице. Условие локальной величины \(|q_x|\le\Lambda\) необходимо для каждого x с \(\mu_x>0\). Эта оценка относится именно к ожидаемым зарегистрированным вероятностям на указанной ветви; оплата и информация сохранённых SITE/shift-флагов не включены.

Для реально выписанной двухкопийной L=4 CAR-ветви \(d=00,e=01\) исходный момент есть \(q_x=2A^2F_x\), \(A=p\sin(712\arcsin p)\), и по полной 256-ячейковой проверке \(F_x=-1,0,1\) с кратностями 64,128,64. Тогда
\[
 \operatorname{Var}(q_X)=2A^4,\qquad
 \boxed{\mathcal R(0)-\mathbb E_X\mathcal R(q_X/(64\Lambda))
 \ge\frac{3zA^4}{8192\Lambda^2}>0.}\tag{6}
\]
Угол \(\arcsin p\) нерационален относительно \(\pi\), как доказано в [NATIVE_SEED_BOOTSTRAP_SECANTS](NATIVE_SEED_BOOTSTRAP_SECANTS_RU.md), поэтому \(A\ne0\). Число \(\Lambda=1\) используется только для воспроизводимого арифметического примера: точный локальный report-разрыв около \(5.6936968622\cdot10^{-18}\), а нижняя граница (6) — около \(5.3653807284\cdot10^{-18}\). Оно **не** устанавливает допустимость \(\Lambda=1\) для полного физического \(H_q\).

## 3. Условия применения к полному источнику

Если точный локальный и независимосдвинутый операнды сравниваются с одним **действительно доказанным** положительным нормировочным gain \(\Gamma\), из (5) следует нижняя граница их различия, делённого на \(\Gamma\). Следовательно, для исчезновения **именно этого отдельного Jensen-разрыва** необходимо контролировать \(\operatorname{Var}(q_X)/(\Lambda^2\Gamma)\); само отличие не является no-go всей физической цены, поскольку другие законные источники и веса могут компенсировать его. При других геометрических полях, начальных SITE-мерах, локальных знаках, коррелированной старой памяти или полевых вариациях нужно отдельно установить их настоящие эффекты и оценки.

Напротив, один общий случайный сдвиг для всех 2+8 знаков, если будет предъявлен соответствующий буквальный прибор и доказана ковариантность всех success/failure исходов, сохраняет локальное усреднение \(\mathbb E_X\mathcal R(q_X/(64\Lambda))\), а не заменяет его на \(\mathcal R(\mathbb E_Xq_X/(64\Lambda))\). Это отдельный маршрут; запись сдвига, steering старой памяти, цена и физический подготовитель остаются в нём самостоятельными строками.
