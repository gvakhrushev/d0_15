# Можно ли выбрать информационный источник по двум штатным записям

У двух действительно реализуемых сравнений каждая отдельная запись имеет один и тот же канонический опорный закон. В центре H.1 отклик цены по вероятности каждой из двух записей равен **+0,013055409845** в первом сравнении и **−0,021350426614** во втором. Различие обнаружимо по частоте двух подряд единиц в опорном опыте. Для опоры, симметрично продолжаемой на сколь угодно длинный архив, нулевая корреляция этой пары однозначно определяет опору всего классического архива. Эти результаты дают проверку того, какое предположение о памяти требуется для переноса цены с одной записи на физическую историю.

## Какие данные входят в источник

Пусть p=1/φ, a=p², b=p, ℓ=ln φ. Рассматриваем восстановленные независимые записи H.1 с символами 0,10, которые далее обозначаем 0,1. Исходные длины равны 1,2. В поле вероятности единиц равны qᵢ. При фиксированном порте и независимых копиях выберем классическое сравнение Yᵢ, для которого H(Bᵢ|Yᵢ)=h₀ постоянно по соответствующим полевым строкам. Примером служит первичное событие до восстановления. Квантовый оптимум при допустимом однократном классическом чтении исходного банка даёт другую доказанную константу. Для оплаты этого сравнения и для переноса его измерения действуют исходные условия. Если выбрана полная относительная информация о блоке при условии Y, относительно заданного классического распределения ν, то для этой части цены

    Sν = ∑ᵢ(1+qᵢ) + m h₀/ℓ + E_q ln ν(B₁,…,Bₘ)/ℓ.

Это разложение определения условного относительного выигрыша. В условной энтропии использовано произведение действительных подготовок и чтений. Само ν допускает память. Любая заданная положительная опора, не зависящая от варьируемого поля, даёт на **отдельной** координате точный коэффициент

    ∂ᵢSν = 1 + E_{q без i} ln[ν(B_{−i},1ᵢ)/ν(B_{−i},0ᵢ)]/ℓ.

Для движущейся опоры добавляется E_q D ln ν/ℓ. Для подвижной условной энтропии добавляется её собственная производная. Суммарная производная одного общего поля получается после подстановки настоящих Dqᵢ. ## Две разные цены из одних и тех же четырёх канонических чтений

В отдельном опорном опыте четыре независимые канонические метки X,Z,C,D прямо получаются чтением свежих золотых указателей, Pr(1)=a для каждого. Первая сообщаемая метка равна X. Вторая равна X, если сработал заданный предикат, иначе Z. Первый предикат требует C=1 и D=0, второй требует только C=1. Оба запроса являются обычными функциями того же оплаченного классического журнала. Никакого обращения к варьируемому полю в выборе индекса нет. Физический вывод нового бита либо реализация запроса отдельным контроллером имеют собственные затраты. В опоре оставляем два результата запроса; включение всей его внутренней памяти в доступную условную информацию меняет эксперимент.

Вероятности выбора X равны η=p³ и η=p² соответственно. Обе строки по отдельности имеют золотой закон (b,a), даже если контроллер переиспользует именно первую запись. Совместное распределение и источник при варьировании q₁ с фиксированным q₂ равны

    ν₀₀=b(b+ηa),   ν₀₁=ν₁₀=ab(1−η),   ν₁₁=a(a+ηb),
    ∂₁Sν=1+[(1−q₂)ln(ν₁₀/ν₀₀)+q₂ ln(ν₁₁/ν₀₁)]/ℓ .

Для производной по q₂ индексы меняются местами. В истинном центре q₁=q₂=0,412469880568… получаются следующие значения.

| Условие выбора X | Избыток Pr(11) над a² в опоре | ∂₁Sν | ∂₁∂₂Sν |
| --- | ---: | ---: | ---: |
| C=1 и D=0 | 0,055728090001 | +0,013055409845 | 2,074447585949 |
| C=1 | 0,090169943749 | −0,021350426614 | 3,440420090413 |
| Всегда выбирать независимую Z | 0 | 0 | 0 |

Смешанная производная равна логарифму отношения шансов ln(ν₀₀ν₁₁/(ν₀₁ν₁₀))/ℓ. Она сохраняется при добавлении отдельных произвольных функций q₁ и q₂. Связанная плата за два события может её изменить. Тем самым зафиксирована наблюдаемая проверка памяти. В сравнении с общей памятью существует физический путь через X. Для сцен без соединяющих путей в Книге 03 действует собственная факторизация. ## Когда контроль пары определяет всю опору

Пусть первые m символов опоры допускают продолжение до L≥max(2,m) символов, совместный закон которых инвариантен при всех перестановках. У каждого символа среднее a. По одной паре обозначим c=Pr(11)−a². Если X — доля единиц в L символах, то

    EX=a,       Var X=ab/L+(1−1/L)c.

При заданном числе единиц длина-m выборка имеет закон извлечения без возвращения. При извлечении с возвращением условная вероятность конкретного слова с k единицами равна f(X)=Xᵏ(1−X)ᵐ⁻ᵏ. Две выборки можно совместить до первого совпадения выбранных индексов. Вероятность совпадения ограничена m(m−1)/(2L). Кроме того |f″|≤m(m−1), поскольку f — произведение m линейных множителей, каждый по модулю не больше единицы на [0,1]. Формула Тейлора в точке a даёт для **каждого слова** ошибку относительно независимой золотой опоры

    |ν(w)−aᵏbᵐ⁻ᵏ| ≤ Eₘ,    Eₘ = m(m−1)(1/L + Var X)/2 .

Если Eₘ<aᵐ, из теоремы о среднем для логарифма следует |∂ᵢSν|≤2Eₘ/[ℓ(aᵐ−Eₘ)] при фиксированном ν и любом действительном наборе qᵢ. У независимой опоры этот коэффициент равен нулю. Например, при m=5, L=1 000 000 и c=0 остаток по каждому qᵢ меньше 0,006329. Неограниченная симметричная продолжаемость и c=0 вынуждают для каждого конечного m точное ν=Ber(a) в произведении. Тогда рассматриваемая чистая кодовая цена в точности m h₀/ℓ. Та же логика применима в каждом поле для опоры с другим измеренным средним; полевая зависимость этого среднего входит в полную производную. Малый остаток на одном поле сам по себе не контролирует движение опоры по полю. [Диаконис и Фридман, конечные перестановочно-инвариантные законы](https://doi.org/10.1214/aop/1176994663)

Одной перестановочной симметрии в пределах измеренной тройки мало. Для закона независимой тройки добавим к массе слова w число δ(−1)^{|w|}, где |w| — число единиц, а 0<δ<min(a,b)³. Сумма добавки по любой выпущенной координате равна нулю. Получена положительная симметричная тройка со всеми верными парами и другим полным законом. Утверждение об определении цены двумя измеряемыми моментами использует возможность произвольно длинного симметричного продолжения.

## Причинная опора, которая обучается на уже напечатанных знаках

Разрешим опоре сравнивать очередной знак с законом по предшествующим i−1 знакам, используя формулу Pr(1|прошлое)=(k+a)/i. Здесь k — целое число единиц. Первое чтение имеет штатный золотой вес a. Умножение условных вероятностей даёт полную массу слова с k единицами (a)ₖ(b)ₘ₋ₖ/m!, где (x)ⱼ=x(x+1)…(x+j−1). Она строго положительна и инвариантна при перестановках. Конструкция относится к семейству последовательных вероятностных оценок. Начальные веса a,b выбраны по каноническому указателю. [Кричевский и Трофимов, универсальное кодирование](https://doi.org/10.1109/TIT.1981.1056331)

Из отношения масс соседних слов при qᵢ=q имеем для каждой независимой координаты

    ∂ᵢSν = 1 + E ln[(K+a)/(m−1−K+b)]/ℓ,   K ∼ Bin(m−1,q).

В исходном центре для m=1 вклад равен нулю. Для m=2,3,4 он отрицателен, а для m=5 равен +0,014893380827. При m→∞ коэффициент стремится к 1+ln[q/(1−q)]/ℓ, в центре +0,26484698. Действительно, на любом компактном внутреннем интервале q отклонение K/(m−1) от q за пределы фиксированной окрестности имеет вероятность O(1/m) по неравенству Чебышёва. Логарифм там ограничен O(log m). На оставшемся интервале он равномерно липшицев по доле единиц и отклонение в среднем есть O(1/√m), с добавкой O(1/m) от начальных весов. Здесь сравнение не получает q как вход. Опора сама имеет ненулевую ковариацию пары ab/2, что согласуется с предыдущей теоремой.

Можно получить положительный коэффициент на каждой из пяти координат и с **конечным** выбором из старых меток. Для позиции i≥2 заготовим i независимых канонических индикаторов и один свежий золотой бит. При ровно одной единице у индикаторов выбираем её индекс: из первых i−1 слотов выдаём соответствующую прошлую метку, из последнего слота выдаём свежий бит. При любом другом исходе выдаём свежий бит. Первую метку готовим сразу из свежего бита. По симметрии индикаторов вероятность успешного выбора sᵢ=i·a·b^(i−1), условно на успехе индекс равномерен, поэтому точный закон есть sᵢ(k+a)/i+(1−sᵢ)a. Все исходы, включая отказы, входят в вероятность; повторов до успеха нет. Для пяти сравнительных результатов достаточно 5 свежих золотых битов и 2+3+4+5=14 золотых индикаторов, а также доступа к уже записанной классической истории и обработки указанных предикатов. Прямой расчёт по всем 32 словам даёт на пяти **независимых** координатах соответственно

    +0,05649246;  +0,05649246;  +0,06193161;  +0,05878374;  +0,04734900.

Для получения полевой строки надо умножить коэффициенты на соответствующие действительные Dqᵢ и сложить. Сравнительные измерения и обработка требуют места и работы; 19 обозначает только число подготовленных независимых битов опорного опыта. Их скрытые исходы нельзя одновременно объявить условием при вычислении того же ν. Этот протокол реализует закон опорных наблюдений и положительный вклад цены на выбранной секции.
