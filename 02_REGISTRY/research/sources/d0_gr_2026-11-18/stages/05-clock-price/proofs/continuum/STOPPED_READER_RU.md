# Шесть настоящих указателей на каждом посещении и полный остановленный источник

Используем прежний прибор full128 с остановкой на первом b=0, сохраняем все 128 точных исходов каждого посещения и ставим после каждого прочитанного исхода шесть canonical CX из §7gd. Направление есть V₀₀−V₀₁ на геометрической кривой при нулевых бустах. При p=1/φ, λ=9/640, q=4p³λ и κ=27p²/25600 получаем точную цену известного адресного считывания

    D C_read,stop = 6p³κ/(1−q) = 81p⁵/[12800(1−q)] = 0.00057828562821482…

Для маргинальной энтропии Шеннона всего остановленного журнала и опубликованного условного DATA-CQ различие первых вариаций положительно на этом же входе

    0.01642720208 < D H(fine-журнал) < 0.01644055757 нат,
    0.00026963716 < D H(fine-журнал) − D I_DATA,stop < 0.00029634813 нат.

Если полный исходный вход DATA+R действительно чист, каждая условная квантовая ветвь исходного эффективного инструмента чиста. Тогда первое число есть также производная совместного CQ со всем R. Для произвольного смешанного входа формула Шеннона относится к маргинальному закону журнала. Новые указатели далее учитываются в соответствующей алгебре явно.

## Почему допустимо сложить посещения

На всей указанной кривой A=N₀ самосопряжён и A²=λ(t)I по CAR. Следовательно, подготовленная ρ=I/16 постоянна. Для j>0 положим L_j=N_j†A/√[λ(1−λ)]. Обе суммы Σ L_j†L_j=Σ L_jL_j†=I следуют из обеих полных Walsh-сумм для N_j и A²=λI. Для настоящего продолжения b=1 имеем

    T₁(X)=t X + r Σ_j L_j X L_j†,      t=qλ,    r=q(1−λ).

Здесь j=0 даёт тождественную ветвь, а остальные 63 карты сохраняются внутри сравнения. Отсюда T₁ⁿ(ρ)=qⁿρ на всей кривой. В центре Dλ=Dq=Dρ=0. Это даёт исходное состояние следующего посещения только после суммирования по реальным старым адресам. Состояния при условии отдельных точных адресов могут различаться.

Пусть C(Y) — одношаговый эффект реально оценённого считывания. Ожидаемая сумма за M посещений с остановкой равна Σ_{n=0}^{M−1} Tr[C(Y)T₁ⁿ(ρ)]. При Dq=0 её производная равна (1−qᴹ)D C_read,one/(1−q). При M→∞ получаем формулу выше. Геометрическая мажоранта равномерна на малой окрестности. Шесть когерентных чистых указателей добавляют нулевую условную энтропию при известном точном адресе. Их действительное считывание в 0/10 добавляет 6h(p²) на посещение. Среднее число посещений 1/(1−q) имеет нулевую производную. Постоянный базовый код 6(1+p²) на посещение также не вносит первой вариации. Тарифы рождения, контроллера и прохода часов остаются отдельными.

## Проверка Шеннона без независимости адресов

Отделим четыре группы одного посещения: (продолжение, j=0) массы t; (продолжение, j>0) массы r; (стоп, j>0) массы p r; и оставшуюся (стоп, j=0). Эти групповые вероятности скалярны для всех состояний, а их производные нулевые. У прежней полной остановленной записи при k≥1 нетривиальных адресах их вес w_k=(1+p)(1−g)gᵏ, где g=r/(1−t). Все точные адреса и время сохранены. Для слова ω=(j₁,…,j_k) положим B_ω=L_{j_k}…L_{j₁}, u_ω=Tr(B_ω†B_ω)/16. Тогда

    D H(fine-журнал) = Σ_{k≥1} w_k [−Σ_ω (D u_ω) log u_ω].

Для k=1,2,3 вычислены все 20, 400 и 8000 слов из ненулевых центральных карт. У остальных слов первый джет вероятности нулевой. В проверке каждая матрица и вероятность вычислена точно, логарифмы заключены между рациональными числами. Для хвоста берём норму одного шага C≤13/10, проверенную на всех 63 картах, включая карты с нулевой центральной амплитудой. Из полноты и униальности произведений Σ‖DB_ω‖²_HS/16≤k²C². Для распределения с ≤20ᵏ положительными словами Pr(−log u_ω>x)≤min(1,20ᵏe⁻ˣ). Неравенство Коши даёт |DH_k|≤2k C(k log20+√2). Сумма после k=3 ограничена сверху 0.00000667774. Для дифференцирования во всей окрестности достаточно 63 карт и локального g<1; нулевые центральные амплитуды дают нулевой первый энтропийный джет. Оценка DATA использует ранее проверенный спектр тех же матричных произведений и тот же способ ограничения хвоста.

## Что должна покрыть полная цена

В единицах исходного кода поля необходимые источники после вычета уже оплаченного считывания равны

    0.03297078486 < D I_DATA,stop/logφ − D C_read,stop < 0.03299853872,
    0.03355886817 < D H(fine-журнал)/logφ − D C_read,stop < 0.03358662203.

Исходный портовый код имеет нулевой источник. Если полный Cost−Info должен быть стационарен в этом направлении, выбранный остаток обязан дать сумму D W_work + D H_thermal + прочих реальных строк в соответствующем интервале. В варианте равенства двум ценам вместо стационарности из этой суммы дополнительно вычитается производная сравниваемого мастера. Тепловой или новый остановленный feedback-источник на этом носителе здесь не положен равным нулю. Интервалы являются тестом независимо определённой полной цены. Выбор Book-Info и перенос full128 на другую H.1-гисторию остаются открыты.
