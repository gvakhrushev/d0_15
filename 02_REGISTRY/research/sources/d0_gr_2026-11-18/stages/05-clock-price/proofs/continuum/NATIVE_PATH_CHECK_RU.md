# Знаковые пути для полного тепла H.1 и положительное событие цены

На фиксированном нативном H.1 буквальное слово определяет классическое ограниченное наблюдение, среднее которого даёт весь тепловой след. Из его независимых копий восстанавливаются сам логарифм цены и положительное событие с вероятностью φ⁻ᴴ. Изменения внешней сцены или стоимости исполнения самого вычислителя требуют отдельной физической привязки. Формулы используют G1–G6 и §7fq.SR3 оригинальной ревизии 076d5d5a7b366c0dd0970f388df7a9e6895498c4.

## Рождение, замыкание и обращённая стрелка

На каждом рабочем бите выбираем базис v=(√p,p), w=(−p,√p). Spin сохраняет исходный координатный базис. Пассивная birth-инъекция дописывает цифру 0. При закрытии R из G3 смотрим на последнюю по времени рождения цифру 1. Финальная метка идёт в стадию вступления этой детали, младший хвост из нулей отбрасывается. Если единиц нет, метка идёт в H₀. Это покоординатная биекция между финальным базисом и объединением базисов H₀ и всех birth-complement.

Для прямого T внутреннее рождение маршрутизирует детерминированно, внутренняя квадратная операция локальна, на финальной стадии T=Rg маршрутизирует каждую строку выхода g. При применении T* к одной координате есть ровно один из двух случаев. После обычной операции или на нулевой цифре последнего рождения работает только предыдущая внутренняя стрелка. На H₀ или на цифре 1 в момент её рождения работает только g*R*: восстанавливаем хвост нулей и применяем g*. Поддержки двух вариантов покоординатно различны, в том числе при рождении непосредственно перед финальным g. При совпадении внутреннего локального пространства с глобальным эта аргументация всё равно действует.

В истинном алфавите G затрагивает один бит, CX — два. Для SourceI на координате Spin возможны только исходный адрес и адрес его образа при L_i, поскольку L_i есть знаковая перестановка. На управляемом порте два новых адреса. Значит, на любом столбце SourceI и его сопряжения в выбранном базисе не более четырёх ненулевых чисел. Из унитарности и неравенства Коши получаем обе оценки col₁(T),col₁(T*)≤2. Для произвольных дополнительных квадратных операций на не более чем трёх битах верна консервативная граница √8. На некомпилированную многобитную матрицу, смену определений рождения или произвольную управляемую измерительную операцию эти оценки автоматически не распространяются.

## Сцена и знак нормировки

В §7fq.SR3 матрица Δ₀=I−M с M=B_s⊗I + C_s⊗(T+T*), B_s=RAR, C_s=R², R=(D_s+2I)⁻¹ᐟ². Преобразование подобия R⁻¹MR по пространственному индексу даёт вес 1/(d_x+2) для каждого соседнего пространственного перехода из x и тот же множитель для обоих временных направлений T,T*. Здесь d_x есть степень пространственной вершины. Минимальная степень K(9,11,13) равна 20. Сумма модулей, даже когда совпадающие стрелки считаются отдельными каналами, не превосходит

    (d_x+4)/(d_x+2) ≤ 12/11 = C     для физических G,CX,SourceI.
    (d_x+2√8)/(d_x+2) < 6/5        для произвольных локальных трёхбитовых унитарных матриц.

Выбираем любую из применимых констант C. Берём случайный начальный адрес равномерно на всех 33D координатах, D=Σ dim H_j. В частности, вероятность стадии j пропорциональна dim H_j. Берём K с пуассоновским законом среднего βC. На каждом шаге выбираем меченую стрелку e с вероятностью |M'ₑ|/C; оставшаяся вероятность ведёт в поглощающее состояние. При возврате в начальную координату выводим произведение знаков, в остальных случаях 0. При K=0 получаем +1. Все числа реальны для указанного буквального алфавита. При комплексных локальных дополнениях знаки заменяются фазами, а действительная часть замкнутого произведения даёт ограниченный вещественный ответ.

Обозначая результат через X и μ=E X, суммирование по длине и всем замкнутым путям даёт

    μ = exp(−βC) Tr exp(βM)/(33D)
      = exp[−β(C−1)] Tr exp(−βΔ₀)/(33D).

Поэтому исходная полная сумма Z=359D+2 Tr exp(−βΔ₀) равна 359D(1+bμ), где b=66 exp[β(C−1)]/359. В подлинном режиме β=2p²<4/5 обе константы C дают 0<b<1. Это математический пробник тепловой трассы полного носителя, не требующий физически прочитать неизвестную плотность oldRIGHT в выбранном координатном базисе. Для его исполнения классически нужны доступ к описанию действительной программы, адресам, её длине, слоям рождения и локальным матрицам.

## Сам исходный логарифм и положительное абсолютное событие

Пусть λ=−log(1−b). Выбираем целое N≥1 с вероятностью bⁿ/(nλ), исполняем N независимых копий X и выводим Y=(−1)ⁿ⁺¹∏X_i. Разложение логарифма абсолютно сходится, откуда

    βH = log(359D)+λ E Y,     |Y|≤1,
    E N = b/[(1−b)λ].

Тем самым фиксированная физическая конечная разность тепловых цен имеет несмещённую ограниченную оценку на каждой стороне; различную D надо учитывать в явной константе. Логарифм среднего не заменяется средним логарифмом.

Можно получить именно положительное событие с вероятностью φ⁻ᴴ. Положим s=log φ/β, c=2b/(1+b). Из одного наблюдения X строим бит, равный 1 с условной вероятностью (1−X)/2, так что его вероятность r=(1−μ)/2. Независимо разыграем N≥0 с вероятностями

    Pr(N=n)=(1−c)ˢ (s)ₙ cⁿ/n!,       (s)ₙ=s(s+1)…(s+n−1).

Промежуточное событие требует единицы во всех N независимых битах; при N=0 оно выполнено. Его вероятность по биномиальному ряду равна

    [(1−c)/(1−cr)]ˢ = [(1−b)/(1+bμ)]ˢ.

Дополнительный независимый бит принимает значение 1 с вычислимой вероятностью [359D(1−b)]⁻ˢ. Она меньше 1 на всём рассматриваемом алфавите. Требуем совпадения двух событий. Получена положительная, точно нормированная вероятность

    [359D(1+bμ)]⁻ˢ = Z⁻ˢ = φ⁻ᴴ.

Среднее число затребованных копий до возможного досрочного отказа не больше sc/(1−c). Случайные длины почти наверное конечны. Если задача требует детерминированного конечного горизонта, отклонение N>n₀ вносит абсолютную ошибку не больше хвоста соответствующего закона, а отсечение пуассоновского пути в каждой из ≤n₀ копий добавляет не более n₀ Pr(Pois(βC)>k₀). Точность выборки из иррациональных вычислимых вероятностей при детерминированном лимите случайных битов также учитывается. Нормированный источник требует деления всех конечных ошибок на реальный шаг сравнения и его gain. Получение кодом того же положительного веса не устанавливает, что Книга 03 оплачивает сам вычислитель и его вспомогательные записи ровно по этому закону.

## Численная проверка ветви последнего SourceI

Файл check_native_heat_path.py строит обычный G5 с R из произведения исходных инъекций и отдельно строит T по последнему w. Реальное слово состоит из рождения порта, G, рождения помощника, CX и завершающего SourceI. Размерности стадий равны 4,8,8,16,16, суммарная D=52. На всех 33 вершинах проверены подобие, единичная норма, вероятностная огибающая и тепловой след. Получено Tr exp(−βΔ₀)/(33D)=0.472396980198700 и E X=0.440703064773413 при C=12/11. Полный log Z=9.917847278200885. Конструкция и неравенства выше доказаны аналитически; файл native_path_result.json содержит численные значения контрольного примера.
