# Обратная спектральная задача для действительного H.1

В исходном растущем графе H.1 конечный спектр полного оператора Ходжа определяет исходную обратную связь J после конечного числа оплаченных пар CX;CX. Достаточно D уровней, лежащих в выделенной низкой полосе оператора степени ноль. Поэтому пара оплаченных историй одинакового типа с полностью совпадающими спектрами и различными J здесь невозможна. Зависимость от одного скалярного значения тепловой суммы при фиксированной температуре слабее. Для него существует отдельная факториальная оценка.

## Исходная цена и класс историй

Первоисточник Book03 §03.25, строки 1127–1137, выбирает B=H+J, где H=β⁻¹ log Tr exp(−βΔ), J=−log det(I−zF). Цилиндр RAW даёт J=−log det[(1−z)I+z C* C] на действительном входе. В H.1 старейшее исходное пространство есть Spin4, возможно с пассивным множителем. Оно целиком является защищённым срезом, хотя представляет собой собственное подпространство конечного носителя с рождениями. Подлинные WORK-операции действуют в вещественной алгебре A⊗I+B⊗Lᵢ. При породных включениях сжатие действительного конца на старейший слой имеет C=xI+yLᵢ, Lᵢ* =−Lᵢ, Lᵢ²=−I, Tr Lᵢ=0. Поэтому C* C=sI, s=x²+y², J=−r log(1−z+zs), r=dim Spin4 с пассивной кратностью. Это верно в каждой нативной точке. Доказательство не охватывает произвольное возмущение матриц за пределами этой алгебры или дополнительный изменяемый вход DATA. ## Два момента действительного растущего времени

Пусть W есть действительный конец в каноническом базисе рождений, T есть полный унитарный шаг на пространстве времени размерности D, а Πⱼ суть ортогональные слои рождений. Владелец доказывает

    det(I−uT)=det(I−W Σⱼ u^{ℓⱼ}Πⱼ).

Старейший возраст N уникален как слой, его ранг равен r. Минимальный возраст L. Каждая оплаченная пара CX;CX между последним рождением и последним настоящим вызовом увеличивает N и L на два, сохраняя N−L и C. Выбираем L>2(N−L). В логарифме правого определителя произведение m множителей имеет степени от mL до mN. При k=1,2 коэффициент степени kN может появиться лишь при m=k, поскольку (k+1)L>kN. При m=k каждый множитель обязан прийти из старейшего слоя. Сравнение коэффициентов двух логарифмов даёт **точно**

    Tr Tᴺ=N Tr C,                 Tr T²ᴺ=N Tr(C²).
    x=Re Tr Tᴺ/(Nr),             s=2x²−Re Tr T²ᴺ/(Nr).

Таким образом, J выражается через два действительных момента исходного T на обоих состояниях сравнения и вдоль исходных вариаций, сохраняющих алгебру Spin4. Нужны весь старейший слой и указанная алгебра сжатия. Для общего сжатия значения Tr C и Tr C² не определяют C* C. ## Количественные пределы

Предположим, отсортированные D низких уровней известны с ошибкой ε. Ограничим восстановленные t интервалом [−2,2], восстановленный x интервалом [−1,1], s интервалом [0,1]. По |Cheb′ₙ|≤n² ошибка Re Tr Tⁿ не превосходит 13Dn²ε. Поскольку обе оценки x лежат в [−1,1], ошибка 2x² не превосходит 4|δx|. Получаем

    |δs|≤104DN ε/r,    |δJ|≤104zDN ε/(1−z).

На каждом блоке |∂ₜ Tr exp(−β A(t))|≤β Tr Cₛ. Всегда Z≥359D, Tr Cₛ≤33/22. Поэтому |δH|≤78ε/359. Итоговая ошибка B не превосходит [78/359+104zDN/(1−z)]ε. Для центральной секущей (B₊−B₋)/(2tΓ) ту же оценку следует поделить на |t|Γ. Обратно, два одинаково размеченных H.1 с заданной разностью J должны отличаться хотя бы на (1−z)|J₊−J₋|/(104zDN) в одном из упорядоченных низких уровней.

Есть более экономный способ выделить J из одного значения **полной** B с априорной погрешностью. При фиксированной сцене положим Z̄=359+2a₀, c=2/55.
