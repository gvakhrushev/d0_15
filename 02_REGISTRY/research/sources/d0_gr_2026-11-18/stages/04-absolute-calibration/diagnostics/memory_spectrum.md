# Спектр повторённого 18-тактового слова B121

Фиксируем физический порт и оба значения одного изменяемого WORK-бита. B121 раскрывает четыре пути слова \(W_1=G;ZGZ\) на каждом таком входе. У двух возвратных путей центральный класс \(1\); у двух переходов в противоположный WORK классы \(1,z=-1\). Обозначим сумму положительных весов возврата через \(A_i\). Если тот же запрещённый выход точно тёмен в штатном Spin, где \(L_z=-I\), ошибочные пути имеют один вес \(d_i>0\). При поднятии к регулярной памяти \(Q_8\) возвратный блок равен \(A_iI\), ошибочный равен \(d_i(I+R_z)\). Предполагается, что физический перенос сохраняет эту таблицу, эти скалярные веса и их композицию при каждом повторении на той же WORK-паре. Здесь нет свежей инициализации между блоками. Базисный класс \(|e\rangle\) регулярной памяти и полный терминал задают оба сектора с весом \(1/2\). [Первичная таблица и условие подъёма](../primary/B121/B121_ORIGINAL_BOOK_WEIGHT_AND_PREPARATION_RU.md#L23) · [Прежний одноблочный расчёт](../primary/B121/B121_ORIGINAL_BOOK_WEIGHT_AND_PREPARATION_RU.md#L59).

**Когерентная история.** На \(P_\pm=(I\pm R_z)/2\) матрицы одного полного блока в базисе WORK равны
\[
 B_+=\begin{pmatrix}A_0&2d_1\\2d_0&A_1\end{pmatrix},
 \qquad B_-=\operatorname{diag}(A_0,A_1).
\]
Отсюда \(\lambda_\pm=\big(A_0+A_1\pm\sqrt{(A_0-A_1)^2+16d_0d_1}\big)/2\), \(\lambda_+>\max_i A_i\). В полном терминале при входе \(|i,e\rangle\) абсолютная сырая масса
\[
 Z_n=\tfrac12\|B_+^ne_i\|^2+\tfrac12 A_i^{2n}.
\]
Для любого положительного левого собственного вектора \(\ell^TB_+=\lambda_+\ell^T\) неравенство Коши даёт \(\|B_+^ne_i\|\ge\lambda_+^n\ell_i/\|\ell\|\). Доля нечётного сектора в полной массе не превышает \((\|\ell\|/\ell_i)^2(A_i/\lambda_+)^{2n}\). Чётный вклад равен точно \(Z_n-A_i^{2n}/2\).

**С сохранённым WORK после каждого блока.** Различные промежуточные строки WORK ортогональны в архиве. В каждом секторе складываются вероятности путей, а два класса внутри одного блока ещё складываются в амплитуде. Матрицы масс \(T_+=B_+\circ B_+\), \(T_-=\operatorname{diag}(A_0^2,A_1^2)\), где \(\circ\) означает поэлементное умножение. Терминальная масса равна
\[
 Z_n^{\rm rec}=\tfrac12\left({\bf1}^T T_+^n e_i+A_i^{2n}\right),\qquad
 \rho(T_+)=\tfrac12\left(A_0^2+A_1^2+
 \sqrt{(A_0^2-A_1^2)^2+64 d_0^2d_1^2}\right)>\max_i A_i^2 .
\]
Таким образом, даже после разбиения по WORK остаётся строгий отрыв. Запись самих центральных классов или обеих внутриблочных Golden-развилок дала бы другую матрицу.

**Буквальная двоичная подстановка.** При \(p=(\sqrt5-1)/2\), \(A=p^2+p^4,\ d=p^3\) имеем \(A+2d=1,\ A-2d=p^6\). Для любого из двух начальных WORK-битов получаем
\[
 Z_n=(1+p^{12n})/4+A^{2n}/2,\qquad
 Z_n^{\rm rec}=\tfrac12\left[\left(\tfrac{1+p^{12}}2\right)^n+A^{2n}\right].
\]
В частности, обе массы совпадают при \(n=1\), но первая стремится к \(1/4\), а вторая к нулю. Эти величины характеризуют указанную сырую модель. Её одноблочный выбор локальных весов уже расходится с независимым штатным G-чтением на том же входе. [Проверка буквальной модели в B121](../primary/B121/B121_ORIGINAL_BOOK_WEIGHT_AND_PREPARATION_RU.md#L49).

**Чётный вклад доступен по смене WORK.** Нечётный сектор никогда не меняет WORK, поэтому весь сырой сигнал противоположного WORK происходит из \(P_+\). При одном блоке и верном \(|i,e\rangle\) абсолютные массы равны \(M_{\rm return}=A_i^2,\ M_{\rm flip}=2d_i^2\). Измерив обе колонки \(i=0,1\) в одной действительной шкале, восстанавливаем четыре положительных числа и прогноз для каждого \(n\). Есть тест на одном входе. Обозначим \(m_n\) массу противоположного WORK после \(n\) блоков. Формула Кэли–Гамильтона даёт в когерентном режиме
\[
 m_n=2d_i^2\left(\frac{\lambda_+^n-\lambda_-^n}{\lambda_+-\lambda_-}\right)^2.
\]
Значит, \(\operatorname{tr} B_+=\sqrt{m_2/m_1}\), \(\det B_+=(\operatorname{tr}B_+)^2-\sqrt{m_3/m_1}\). При промежуточных WORK-записях те же две формулы для \(T_+\) используют \(m_2/m_1,\ m_3/m_1\) без квадратных корней. В обоих вариантах три измерения в общем сыром масштабе находят спектр чётного переноса без самостоятельного датчика \(P_+\). Разные неизвестные нормировщики трёх горизонтов уничтожают эту идентификацию.

Штатный Spin принадлежит целиком нечётному сектору. Его тёмная строка обосновывает равенство двух ошибочных весов внутри условного подъёма. Чтобы наблюдать чётный вклад, нужны регулярная память с фактической положительной чётной долей и чувствительный к ней терминал. Неизменность произвольного терминального эффекта сама по себе недостаточна: он может отбрасывать \(P_+\); внедиагональный по центральным секторам эффект может давать перекрёстное слагаемое. Приведённые точные формулы используют полный терминал. Новый WORK-архив физически оплачивается; при сравнении с неизмеряемым прибором необходимо проверить его влияние на веса. Если цена зависит от накопленной предыстории, если меняется приготовитель или меняется экономическая шкала, степенная матрица одного блока больше не описывает эксперимент.
