# Два полных золотых таймера для диагностического логарифма

На трёх настоящих восьмимерных словах \((1,1),(3,1),(1,3)\) и входном срезе \(j=[0,2]\) задаём \(F=j^\dagger U^\dagger(I-jj^\dagger)Uj\) и марку \(\Pr(\mathrm{mark})=(15/16)\sum_{\ell=1}^6 z^{\ell-1}\operatorname{Tr}F^\ell/(4r\ell)\), \(z=2^{-20},\ r=2\). Два независимых таймера с пределом \(L=48\) кодируют дополнение этой марки: успешный тик \(i<L\) имеет сырую массу \(p^4(p^2)^i\); тайм-аут имеет массу \((p^2)^L\) и означает «ложь». Все \(49^2\) пары исходов остаются в расчёте. При \(M=p^3+(1-p^3)(p^2)^L,\ \rho=p^2+p^4\), из действительной массы \(Z=M^2[\rho+(1-\rho)Q]\) восстанавливается \(J_{\rm calc}=4rz(1-Q)/(15/16)\). Пороги проверены в точном поле \(\mathbb Q(\sqrt5)\). Для заданных трёх марок это три зафиксированных программы сравнения. Их сборка использует известные значения марок; самостоятельный универсальный способ кодировать неизвестную марку по одному физическому выстрелу здесь не получен. [Проверка](check_query_clocks.py).

Перепады \(J_{\rm calc}\) относительно первого слова равны \(-1.98799240320934996095\cdot10^{-8}\) и \(-3.76610608429156280565\cdot10^{-7}\). Их ошибки относительно прямого \(-\log\det(I-zF)\) составляют \(1.262\cdot10^{-27}\) и \(2.272\cdot10^{-27}\) по верхнему округлению. Для всякого \(0\le F\le I\) общая граница ошибки перепада равна \( (4rz/(15/16))[1-(1-(p^2)^L/M)^2]+r z^7/[7(1-z)]<5.967\cdot10^{-25}\). Проверяется отклик указанного таймера; полная физическая цена истории остаётся открытой. [Числа, цифровые пороги и формулы](query_clocks_result.json).
