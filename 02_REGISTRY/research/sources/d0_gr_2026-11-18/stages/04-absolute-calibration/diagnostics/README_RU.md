# Как повторить проверки

Для запуска нужны Python 3.10 или новее с NumPy, SciPy, SymPy и mpmath. Для проверки исходной модели с 143484 исходами нужен Node.js. В каталоге пакета выполните следующую команду.

```sh
python3 diagnostics/replay.py --node "$(command -v node)" --output /tmp/d0-calibration-tests.json
```

Сценарий сверяет SHA-256 всех 23 первичных файлов и выполняет 19 проверок во временной копии без Git. Параметр `--output` выбирает место для новой квитанции. Исходный результат сохранён в [TESTS.json](TESTS.json). Версии интерпретатора и библиотек, результат каждой команды, критерий численного сравнения и пределы проверки приведены в квитанции.

[Перечень первичных источников](../primary/SOURCES.json) указывает закреплённые ревизии, пути и Git-объекты. Текст [§§7ga–7gb](../primary/current_7ga_gb.md) и [вложенные первичные проверки](../primary/checkpoint/checkpoint_manifest.json) скопированы побайтно. Для B121 локальный адаптер связывает исходный расчёт с приложенными Книгами I и II, Книгой 03 и операторным исполнителем. Он независимо вычисляет Git-хеши двух исторических книг. Неадаптированный проверочный файл также сохранён. [B121](../primary/B121/B121_ORIGINAL_BOOK_WEIGHT_AND_PREPARATION_RU.md)

Диагностические квитанции и символьные контрольные результаты воспроизведены. В двух исторических численных квитанциях последние двоичные разряды зависели от версии математических библиотек. Максимальное отличие при повторе равно (3.34\cdot10^{-16}) по верхнему округлению. Для полного остановленного CQ-источника знак и границы проверяются рациональными неравенствами и точными матричными тождествами.
