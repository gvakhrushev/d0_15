# От исходного регистратора D0 к физическому источнику Эйнштейна

18 ноября 2026. Исходная ревизия D0 — `15f5b786ed912a0e91d660e337bf60a7c15c7cfa`. На самой регулярной семье H.1 удалось исключить один предполагаемый источник расхождения и локализовать другой вплоть до одного квантового регистра на одном такте. Старая пассивная квантовая память выпадает из прироста информации штатного бинарного отчёта. Работу, чувствительную к фазе на управляющем проводе до записи, по одной лишь цене часов восстановить нельзя. Для полного вывода ОТО остаётся необходимым фактическое правило, по которому исходная история оплачивает такую работу и остальные операции.

## Что теперь доказано на самом H.1

**Старая память и повторения.** Фиксируем одну исходную Spin4, любую её связь с пассивным референсом и произвольное число повторений отчёта. Если сохраняются все рабочие выходы каждой прочитанной ветви, оценки прироста энтропии с референсом и без него совпадают в точности. Обе дают энтропию зарегистрированного бинарного журнала за весь опыт. Поэтому равны и их вариации, в том числе при изменении старой подготовки. Для независимых последовательных блоков это сумма \(h(q_i)\). При более грубом чтении, которое исключает часть рабочей памяти, но сохраняет исходный Spin и его нативную алгебру, разность за весь опыт ограничена \(\ln2\); приведён пример, достигающий предела. [Доказательство и условия нормировки](OLD_REFERENCE_RU.md)

**Оплата настоящего читателя.** Если фиксированная работа на целевой указке и хвосте имеет условные средние \(w_0,w_1\), её вариация равна \((w_1-w_0)Dq/p^3\). Нового полевого направления она не добавляет. В исходной проверенной точке любая такая работа с размахом собственных значений до \(1/4\) сохраняет положительный знак составного источника. Несколько реально заданных локальных работ можно проверять по их суммарному наклону. Для спектральных тарифов самих четырёх действительных вентилей при общей для трёх CX разности тарифов δ их полный наклон составляет 0,5739946897…·δ. Если δ≥0, положительная ориентация сохраняется. Для работы, включающей также управляющий провод, появляется ещё одна наблюдаемая величина — его внедиагональный элемент \(\gamma\). [Условия точного переноса](H1_SOURCE_RU.md) · [Прямой расчёт работ](reader/READER_WORK_RU.md)

**Независимая внутренняя вариация.** Построены нативные реализации одного читателя с одинаковым оператором между внешними метками, одинаковой обратной связью и совпадающими спектрами всех часов. В них все заявленные выходы после общего среза совпадают. Однако непосредственно перед тем же CX локальная фазовая наблюдаемая может меняться при неизменном зарегистрированном событии. Числа операций, их настоящая маршрутизация и целевой такт проверены явно. Новое измерение внутренней фазы имеет собственную цену. Его возможность устанавливает различимость состояний; она сама не назначает этому показанию физический вес исходной истории. Для всё более близких значений внутренней координаты u конечная секущая наблюдаемой X по u в точности равна удвоенной исходной вещественной когерентности. У того же компаратора она ненулевая. Для трёх проверенных шагов достаточно 925, 1425 и 4641 оплаченной стадии. Нулевая разность часов сохраняется в каждой паре при общей длине. [Точная пара](coherence/COHERENCE_RU.md) · [Семейство независимых сравнений](fibre/DENSE_FIBRE_RU.md)

Из этих трёх результатов следует более узкая физическая задача на исходном приборе. Для фактической цены, оценивающей только новые указки, достаточно двух условных оплат и оценки их знака. Для стоимости, которая видит квантовое управление или предыдущую программу, нужно также определить её чувствительность к когерентности либо доказать компенсацию на тех же стадиях. На общих независимых вариациях остаются первоначальные требования к усилению и подъёму. [Первичный критерий CD13](frozen/7fq_cd13.md)

## Что показывает полный 128-канальный прибор

Это отдельная исходная реализация Книги. Её нельзя механически подставить вместо H.1. Она позволяет проверить возможные законы полной оплаты на явно известных матрицах.

1. Построена конечная кривая кофреймов с точно постоянной матрицей возврата \((9/640)I\). Любое полное портовое слово имеет одну и ту же вероятность вдоль всей кривой. При этом вероятность уже записываемого адреса 9 в двух точках отличается на 0,0004541052…; строго — более чем на \(1/5200\). Даже бесконечный набор точных вероятностей портовых слов не восстанавливает этот адрес. [Доказательство и полная таблица](REFERENCE_RU.md)
2. Можно получить обе ранее известные предельные информационные производные уже с классической коррелированной памятью. Кроме того, найдены два базиса старого регистра, для которых в центре совпадает вся совместная таблица исходов. Их производные различаются ровно в четырёх адресных ячейках после суммирования по порту. Разность источников полной информации равна \((9p^2/50000)\ln(4/3)\). Для её измерения достаточно одной производной вероятности совпадения двух битов и отношения шансов этих четырёх *исходных* ячеек. Локальные платежи на двух сторонах по отдельности такого сигнала не дают. [Вывод из условных вероятностей](REFERENCE_RU.md)
3. Реальный экспоненциальный момент двух штатных указок даёт корреляционный источник нужного знака — 1,02277% требуемой разности. При 15 посещениях с каждой стороны доля лежит между 96,75% и 96,77%, при 16 — между 103,25% и 103,27%. Получена калибровка смешанного опыта по центральной таблице для **одного** корреляционного контраста. Она предполагает доступные удалённые метки и не определяет цену подготовки и управления в исходной программе. [Проверенные числа](reference_result.json)
4. Для истинного портового и шестибитного счётчиков при повторных посещениях с фиксированным горизонтом производная логарифма однопериодного замкнутого следа положительна; производная предельного давления строго отрицательна. Их разность лежит в \((0.0001581886,0.0001591807)\). Поэтому эту вариацию нельзя убрать общей перенормировкой посещения либо переносом начального и конечного весов. Замкнутый след как измерение требует собственной допустимой подготовки, например действительного соединения входа с выходом через пару Белла. Для всех целых тарифов разброса до 128 вычислена и ближайшая возможная ошибка. Предельные оценки, другие информационные правила и прочие физические расходы требуют отдельного анализа. ## Статус вывода

Присланная теорема проективной жёсткости классифицирует естественный метрический источник при её сформулированных предпосылках. В исходной регулярной области H.1 уже существует математический перенос стационарности статистического функционала на уравнения Эйнштейна с двумя компонентами материи. Настоящие результаты сохраняют эти области и дают новые физические тесты конкретных слагаемых.

Для замыкания по-прежнему необходимо получить из исходной суммы по историям **полную** вариацию Cost−Info, включая необработанную рабочую память, часы и признанные оплаты всех стадий, или доказать требуемую малость её остатка во всех независимых направлениях. Равенство для одного регистра и калибровка отдельного измерения этому условию не эквивалентны. Научный статус: физическое замыкание ОТО остаётся открытым.
