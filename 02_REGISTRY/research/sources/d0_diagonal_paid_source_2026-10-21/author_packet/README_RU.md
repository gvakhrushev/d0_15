# D0 — оплаченная диагональная реконструкция полного источника

В пакете строго разделены два вопроса:

1. Прежняя точная первичная Choi-подготовка недостижима конечными исходными Golden/Boolean-словами в указанной палитре (известный запрет, не переоткрывается).
2. Её **приближения** из конечных рационально-ортогональных оплаченных программ позволяют восстанавливать первые и вторые вариации уже определённой полной **CQ** цены. Выведена оценка без нижнего порога вероятностей всех исходов: ошибка значения `omega_h(epsilon)=O_h(epsilon |log epsilon|)`. При точности `epsilon=delta^5` полные первые/вторые разностные источники сходятся к действительным источникам исходного CQ-интерфейса как `O_h(delta²)`.

Сохраняется строгая типизация: фиксированный ресурсный процессор имеет **собственный** доказанный коэффициент `g_h=a_pi gamma_F s0>0`, а коэффициент `gamma_1=-12.444...` относится к другому одноэтапному CQ-детектору. Их нельзя объединять без одного исполнения. Параллельный **fixed ten-sign** полный двухполосный детектор теперь даёт ещё один отдельный CQ-потребитель с собственным `gamma_10,h≠0`, 1024 реальными логическими исходами и не более 180 Choi+16 материальных ресурсных копий на отчёт. Оплаченный writer даёт готовность `eta>=1/2`, следовательно `|eta g_h|>=|g_h|/2` для собственного коэффициента выбранного процессора — но не из `gamma_1`. Сеточно-равномерная нижняя граница не заявлена. Для каждого конечного шага сетки можно алгоритмически выбрать конечную кодовую точность так, чтобы ошибка после истинных коэффициентов и заданной нормы стала `o(h²)`. Доказательства физически равномерной цены/сложности и общего исходного контроллера **нет**.

Проверены исходные 124 author checks рационального writer с побайтовым повторным результатом. Новый конечный проверщик и sample-diagonal budget запускаются из `check_diagonal_source.py`. Эти проверки не являются новым full42, HJR или Lean replay.

**Главное ограничение:** конечные разности цен нескольких раздельно выбранных программ не являются Эйлеровой производной ОДНОЙ программы. У фиксированного конечного слова без настоящего поля в начальном состоянии и без полевого query её внешняя производная строго равна нулю.

**Физическое закрытие D0→ОТО не заявлено.** Остаётся необходимость вывести из G0 один действительно обязательный источник поля и кодового селектора, полную Book03 Info/Cost память и её clock/work/observer операторы; совпадения CQ при условно предоставленных кодах для этого недостаточно. `GR_closed=false`.
