# Плоская сдвиговая проба: общий источник не склеен

Статус: **кандидат, DRAFT**. Это не утверждение об общей относительности и не выбор полного действия. Физический допуск подготовки остаётся открытым. Результат отрицательный в узком смысле: на одной пробе нет допустимого дополнительного источника. Это не общий NO-GO.

Пин источника, только чтение: `dfaf7c8df509d5abd83fa60a185ad530feadc9b5`. Квитанция с 2899 проверками не переигрывается. Её поля читаются как уже принадлежащий результат.

Потребитель: любой следующий кандидат полного действия, прежде чем ведущий синтез его примет, обязан пройти эту пробу. Сейчас он её не проходит, потому что не задана стрелка `iota_V_shear_to_common_preparation`.

## Потреблённая проба

Ортонормированный касательный вектор уже зафиксирован:

```text
V = diag(2,-2,0,0).
```

Цитата: `A4D_NATIVE_PREPARATION_FACTOR_SHEAR.md:10` на указанном pin. Та же квитанция даёт три входа, которые здесь не пересчитываются:

- compiled/preparation source = `0`;
- heat source = `2*(E1-E2)>1/10000` при `beta=log(2)`, для всякого `L>=2`;
- fixed-gate remainder = `0`;
- плоский Einstein covector = `0` во всех десяти слотах.

Квитанция: `02_REGISTRY/research/certificates/a4d_native_preparation_factor_shear_results.json`, поля `optimized_AF_source`, `positive_heat_factor_source`, `fixed_golden_two_tick_remainder`, `flat_Einstein_covector`, `metric_tangent_in_whitened_chart`, `exact_checks = 2899`. Вывод квитанции: эта preparation price не даёт напряжения, способного снять heat. Носитель пути — формулы (10) и (12) в `A4D_NATIVE_FACTOR_IMBALANCE_REMAINDER.md:208` и `:284`.

На `t=0`:

```text
q(0) = diag(4, -1/4, -1, -1),   V_q = diag(8, 1/2, 0, 0),
Q(0) = diag(4,  1/4,  1,  1),   V_Q = diag(8, -1/2, 0, 0).
```

`q(0)^{-1} V_q = diag(2,-2,0,0) = V`, след равен нулю. В положительной карте `S = diag(2,1/2,1,1)` и `S^{-1} V_Q S^{-1} = V`. Путь пространственно постоянен, поэтому координатные символы Кристоффеля нулевые; это та же причина, по которой плоский Einstein covector на пути равен нулю. Объём сохраняется: `tr(q^{-1} V_q) = 0`.

Подготовка пробы — blank effect `E = p^2 I`, fixed-gate frame, `D = I`, `b = 0`, `m_x = 0`. Удержанная запись `(a,0,0,p)` не отождествлена с `m = 0` (`A4D_NATIVE_FACTOR_IMBALANCE_REMAINDER.md:255`).

## Четыре строки на этой же пробе

Сложение производных разных прогонов запрещено. Строка даёт дополнительный source только если совпадают carrier, preparation, tangent, action и map, и значение не подменено.

| Строка | Carrier | Preparation | Tangent | Action | Map на пробу |
|---|---|---|---|---|---|
| prepared-source, формула (7) | count-event прибор v3 | `rho0, Phi_b, Delta`, архив | `H_r` не является образом `V` | цена `R_A` | **unbound** |
| canonical active record | `A10 = M144 ⊕ M89` на `H7` | канонический след и кривая (2) | `dm` на масках `0,1,14,15` | `A_old`, `A_gain`, `Cost` | **unbound** |
| observer/reflection | отражение положительной метрики | фиксированный observer либо поперечное `m(s)` | постоянный путь либо `partial_y` | перепись `c R_h`, не действие пробы | геометрический нуль; допуск в действие **unbound** |
| chronology | локальная цена `J` на 16 амплитудах | первая ступень с `k > 0` | конформный `2q`, либо frame lift | `S = H+J+R` | **domain mismatch**, на пробе `k = 0` |

Ни одна строка не есть связанный ненулевой extra source на `V`.

### Prepared-source

Формула (7) в `A4D_NATIVE_RECORD_SOURCE_JOINT_CONTINUATION.md:164` дифференцирует `rho0`, `Phi_b` и `Delta`. Этих полей нет на пробе. Уравнение (8) там же, строка 194, не разрешает выбирать `H_r[V]` по нужному источнику. Стрелка `V ↦ (drho0, dPhi_b, dDelta, d archive)` не задана.

### Canonical active record

Кривая (2) в `A4D_NATIVE_CANONICAL_TRACE_RECORD_SOURCE.md:175` — материальная, с нулевой радиальной частью: коэффициент при `a p^3` в `m0·dm` равен `-2+1+1 = 0`. Это не `V`.

Повтор диагональной грубой струи из принадлежащего `interval_witness`, без матрицы 1597×1597:

```text
0.43415444592488 < dA_old,4 < 0.43415444592489,
-0.65076653214095 < dA_gain,4 < -0.65076653214094,
dCost4 = -8 a p^7.
```

Полный первый операторный спектр на той же кривой постоянен (`:189`), поэтому его старая производная равна 0. Архивная производная на (2) равна `-dA_old,4` (`:267`). Второй активный record переносит грубый ненулевой интервал вдоль той же кривой (`:292`), не на `V`. Грубый источник нельзя переименовать в полный первый операторный (`:252`).

Нуль preparation на `V` и нуль полного первого оператора на `dm` — разные нули. Их равенство чисел не есть отождествление касательных.

### Observer / reflection

На пространственно постоянном пути `theta = K = Omega = 0`, поэтому наблюдательный интегранд в (6) равен нулю. Он не снимает положительный heat и не является членом действия пробы: общее действие ещё не выбрано, а допуск той же программы не доказан (`A4D_NATIVE_LORENTZ_REFLECTION_SOURCE.md:465`).

Поперечный свидетель — другой support, `partial_y`. При `s = 1`:

```text
chi_y = -4/5,  K^2 = Omega^2 = 8/25,  R_h = -32/25,  R_g = 0.
```

Тождество (5) на этом свидетеле даёт `R_g = 0` заново: `-R_h + 2(0 - 8/25 - 8/25) = 0`. Наклон тока `d/ds (J_1/J_0)` при `s = 1` равен `-4/9`. На пробе записанный observer от `t` не зависит, так что его производная вдоль `V` равна нулю. Перенос `-4/9` или `K^2 = 8/25` на `V` — другая касательная.

### Chronology

Реальный владелец, разрешённый source memo (`A4D_NATIVE_RECORD_SOURCE_JOINT_CONTINUATION.md:42`), — `A4D_NATIVE_CHRONOLOGICAL_JOINT_REDUCTION.md`. Диагностический return-product того же memo, строка 434, не есть chronological `J`.

Область `J` требует `k = v^T q^{-1} v > 0` (`:24`). На пробе `m_x = 0`, поэтому `k = 0` и тождество (4) не имеет входа. Конформный путь (19), `q(t) = e^{2t} q`, на базе пробы имеет касательную `2q(0) = diag(8,-1/2,-2,-2)`. Её бесследовая часть равна нулю, а спаривание `tr((q^{-1} V_q)(q^{-1} 2q)) = 0`. Это объёмное направление. Объёмный член уже имеет нулевое сжатие на (11); он не снимает shape-heat. Уравнение `dR[(19)] = -2 E_beta` (`:301`) — тест другого пути, не определение источника на `V`.

## Недостающая стрелка

Единственная недостающая стрелка, одна и та же для всех четырёх строк:

```text
iota_V : ShearProbe -> CommonPreparation.
```

`ShearProbe` — путь (10)–(12), blank `E = p^2 I`, fixed gate, касательная `V = diag(2,-2,0,0)`, пространственно постоянный support.

`CommonPreparation` — одна подготовка, на которой одновременно заданы данные (7), шестнадцатикомпонентный `m` с `k > 0` и полный архив, а производная берётся вдоль образа того же `V`. `H_r[V]` из этого образа не выбирается так, чтобы источник стал равен минус heat.

Пока `iota_V` нет, дополнительный source на пробе не определён. Это и есть следующий тест: кандидат полного действия предъявляет `iota_V` и свою производную на этом образе, либо явно остаётся без источника на `V`.

## Что проверяющий отвергает

Подмена считается принятой только если она выглядит как bound extra source на той же пробе. Код отвергает её по происхождению:

1. переименовать coarse source в complete source;
2. перенести current derivative (`-4/9` поперечного тока) на metric shear;
3. отбросить archive compensation (`-dA_old,4` на кривой (2));
4. положить fitted source равным минус heat;
5. сложить производные разных прогонов.

Если снять замок происхождения, та же подмена становится extra source, и проверка падает. Так отрицательный контроль бьёт по заключению, а не по соседней опечатке.
