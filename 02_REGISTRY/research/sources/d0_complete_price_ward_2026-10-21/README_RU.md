Результат записан в существующий PR #334 репозитория gvakhrushev/d0_15.
Контрольная точка: bd2005bb5f2ec6dfe4d1738941ff7ab36cde072e.

## Новое утверждение

Для уже заданной непрерывной цены с фиксированной мерой и независимой
лоренцевской связностью совместные уравнения дают

    x F_x - y F_y = 0,
    d(F - x F_x) = 0.

Якобиан этой пары при нулевых плотностях равен F_x(0) F_y(0) != 0.
Поэтому обе плотности постоянны на каждом связанном регулярном решении.
Для исходного Golden-детектора существующие точные оценки обеспечивают
эту регулярность на общей ветви при всех фиксированных конечных cap.
Получено равенство ВСЕХ локальных регулярных полевых стационарных множеств,
а не только нескольких космологических примеров. Равенство распространяется
на локальные ядра связанных линеаризованных уравнений, но не на весь
гессиан, его знак или задачу глобальной устойчивости.

В тимеподобном секторе с одним внутренним направлением материи это
уравнения Эйнштейна с безвихревой пылью и определённой связью плотности
с фиксированной мерой. Проверено пространственно-неоднородное решение
с произвольной гладкой функцией b(s), ненулевыми Риччи и Вейлем,
всеми 16 coframe + 24 torsion + 2 scalar уравнениями.

## Что не изменено

Не доказаны обязательный выбор полной Book03 Info/цены, физическая
реализация подвижного запроса, независимые upstream-уравнения и перенос
этого нового класса на исходную конечную решётку. Это не замена меры,
не добавление пылевой среды и не объявление full-HJR функцией только
двух плотностей. GR_closed=false.

## Файлы и запуск

PROOF.md — полный вывод и точные границы.
check_complete_price_ward.py — реально выполненный проверочный код.
RESULT.json — детерминированный результат его работы.
run.log / run.optimized.log — совпадающие обычный и python -O прогоны.
AUTHOR_RECEIPT.json — проверяемые хеши, исходные Git blobs и границы.
PUBLICATION.json — точная привязка публикации.

Требуются Python 3.9+ (проверено на 3.13.5), SymPy 1.14 и mpmath 1.3:

    OPENBLAS_NUM_THREADS=1 python check_complete_price_ward.py

Проверка может перезаписать RESULT.json идентичными байтами в указанной
среде. Выборки параметров при 85 знаках — диагностика, не доказательство
утверждения для всех cap. Общее утверждение использует аналитическую
оценку из закреплённого исходного владельца. Независимая рецензия,
Lean-формализация и новый удалённый CI не заявлены.
