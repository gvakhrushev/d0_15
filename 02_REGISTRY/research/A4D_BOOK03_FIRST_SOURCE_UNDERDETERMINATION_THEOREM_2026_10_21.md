  V=\sum_\omega\sqrt{q_\omega},|\omega\rangle u_\omega,

  Q_B=\sum_\omega\varphi^{-C_\omega+I_\omega}

## 2. Two already present scalar actions have different first sources

There are at least two scalar quantities naturally generated by the same
data (1):

1. the complete mean path price

[
  \overline S(y)=\sum_\omega q_\omega(y)S_\omega(y),
\tag{2}
]

which is the literal mean `Cost-Info` used by several complete-CQ owners;

2. the absolute amplitude pressure of the same Book vector,

[
  P_B(y)=-\log_\varphi\|Q_B(y)\|.
\tag{3}
]

Because (\sum q_\omega=1), (1) gives the exact identities

[
  \boxed{
  \overline S=\tfrac12 H_\varphi(q)-J,\qquad
  P_B=-J,
  }\tag{4}
]

where
[
  H_\varphi(q)=-\sum_\omega q_\omega\log_\varphi q_\omega.
]

Hence, for every admitted tangent,

[
  \boxed{
  D\overline S-DP_B=\tfrac12,D H_\varphi(q).
  }\tag{5}
]

The common amplitude mode (J) cancels from this difference. Therefore
fixing the absolute common mode does not repair the ambiguity.

Equation (5) is not the familiar distinction between a value and an
arbitrarily chosen estimator. Both sides are scalar functionals of the
same complete amplitude-bound history family. A theorem selecting one as
the physical Euler functional is an additional required bridge.

The same calculation also distinguishes the two derivative operations
which already appear in the literature:

[
  \sum_\omega q_\omega,D S_\omega=-DJ,\qquad
  D\sum_\omega q_\omega S_\omega
  =\tfrac12 DH_\varphi-DJ.
\tag{6}
]

Thus even after (1), `expected differential of path action` and
`differential of expected path action` are not interchangeable.

## 3. Exact original Golden witness: the gap is nonzero at first order

Take the actual full128 nonblank port pair from
`BOOK_SOURCE_BINDING.md`:

[
  q_0=p^2,\qquad q_1=p,\qquad
  (C_0,C_1)=(1,2),\qquad p=\varphi^{-1},\quad p+p^2=1.
\tag{7}

Use the normalized probability tangent

[
  Dq_0=-1,\qquad Dq_1=+1.
\tag{8}
]

The Golden identities give

[
  \log_\varphi q_0=-2,\qquad
  \log_\varphi q_1=-1,

and therefore

[
  D H_\varphi(q)
  =\log_\varphi(q_0/q_1)
  =\log_\varphi p

\tag{9}
]

Substituting into (5),

[
  \boxed{
  D\overline S-DP_B=-\tfrac12 .
  }\tag{10}
]

This is an exact native first-source separation, not a second-order or
off-shell asymptotic effect.

At the convenient common anchor (J=0), the corresponding branch gains

  I_0=0,\qquad I_1=\tfrac32,
\tag{11}

The branch prices are (S_0=1), (S_1=1/2).

## 5. Closure theorem for the present specification

### Theorem

Under the explicit Book03 equations currently present in the repository,
plus the strongest same-record amplitude binding (1), the native first
Euler covector of the complete execution is not uniquely determined.

### Proof

The same complete native history family, branch vectors, Born probabilities,
actual charges and amplitude-bound gains (1) define both scalar functionals

first derivatives differ by (5), and on the literal original Golden pair by

This theorem does **not** say that Book03 cannot be completed. It says that
a proof of D0->GR from the current files cannot honestly promote one of these
sources without an additional native theorem/definition.
