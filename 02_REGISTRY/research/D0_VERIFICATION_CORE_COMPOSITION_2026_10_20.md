## 1. The missing substitution

The existing necessity theorem concerns a correct verification protocol. The
existing empirical theorem concerns a quotient by supplied tests. The existing
future-memory theorem concerns every finite continuation generated by supplied
actions. Their conclusions must hold on the same represented states before the
generic transfer theorem can consume them together.

This result constructs the maps connecting those three objects, and proves
that their records, comparisons and actions commute. The outcome is one
conditional verification kernel with exact native future semantics.

The input is a `FutureExecution F` and a
`TheoryVerification F.futureEmpiricalTheory`, denoted `E`. The latter supplies
the existing verification protocol `P`, its correctness contract, and an
equivalence

\[
e:P.\mathrm{State}\simeq
  \mathrm{EmpiricalState}(F.\mathrm{futureEmpiricalTheory}).
\]

Every test of this empirical theory is a pair `(w,q)` consisting of a finite
word in the original action alphabet and an original observation. Its
catalogue is `Unit`. Thus the test family is fixed by `F`; the construction
does not add an independently chosen family of observations or discard a
future distinction.

The `TheoryVerification` premise retains its original scope. It is an
operational verification representation of this exact empirical theory. It
does not establish physical realizability of every supplied action or causal
independence of two concrete apparatuses. The protocol's existing independent
line labels and catalogue-uniform correctness are preserved unchanged.

This is the exact map consumed by the inter-system transfer construction.

## 4. Book Sigma uses explicit finite-code witnesses

The source tuple is Book 01, sections 01.1.2 and 01.1.4:

\[
\Sigma=(C,C^*,D_{\min},\Delta,R,O).
\]

The generic quotient construction places no cardinality or computability
restriction on `F.State`. Finite strings and effective algorithms are
therefore exposed as additional representation inputs, as required by
`verification-core-v1`.

`CodePresentation C A` supplies an encoder and partial decoder, with

\[
\operatorname{decode}(\operatorname{encode}(a))=\operatorname{some}(a).
\]

Injectivity of the encoder is derived from this round trip. A separate
`shortlex_minimal` field requires the encoded representative to be minimal,
by length then the declared alphabet order, among all valid codes decoding to
the same object. The theorem does not infer that premise from injectivity.

Canonicalization decodes a valid code and returns its encoded representative.
It is proved idempotent. Valid canonical codes preserve their decoded object
and satisfy the supplied shortlex condition. Invalid strings remain syntax;
they do not acquire a new physical interpretation through this construction.

The shared object type is

\[
A=P.\mathrm{State}\;\sqcup\;
  (P.\mathrm{State}\times P.\mathrm{Line}).
\]

The sum tag is internal type information. State facts and registered
state-plus-line facts use one code space, and the round trip prevents them
from being accidentally identified. A `SigmaWitness E` supplies:

- a fixed finite ordered alphabet `C` with its primitive coding;
- a `CodePresentation C A`;
- a genuine Mathlib `Computable` proof for canonicalization;
- a genuine `Computable₂` proof for the resulting binary comparison.

These algorithmic proof fields are explicit premises. A bare Lean function,
classical decidability or quotient representative is not reported as an
effective implementation.

The witness conditions are also inhabited in every supplied finite protocol
presentation. `finiteSigmaWitness` encodes each tagged object as one symbol
in `Fin(card A)` and accepts exactly singleton words as valid object codes.
Every object then has one valid code, which is shortlex minimal. Canonization
is the identity on all words, and binary code comparison is primitive
recursive. This is a finite consistency construction, not physical selection
of that alphabet. The generic finite enumeration is noncomputable; no
algorithm encoding arbitrary raw states or decoding their full infinite
future profiles is claimed. The supplied coded interface and its effective
operations remain distinct from such a physical realization.

| Book role | Constructed interpretation and its boundary |

The original archive list remains available; representing a frame as the set

It retains both empirical content and registered-line provenance. This
