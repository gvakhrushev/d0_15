Все номера теорем совпадают с номерами в `00_RESULT.md`, `02_OWNER_AND_DEPENDENCY_MAP.md`,

## 0. Обозначения

`V, E, F` — конечномерные вещественные пространства; `d:V→E`, `G:V→End(F)` линейны;
`X = im d`, `H = ker d`; `j:X→V` — линейная правая обратная (`d∘j = id_X`);
`ξ = j(dξ) + c_ξ`, `c_ξ ∈ H`. Все матричные объекты — в базисе, где это указано;
`R` = `ℚ` (все тождества полиномиальны с целыми/рациональными коэффициентами, поэтому
переносятся на `ℝ` по линейности).

## T1. Точное разложение группоидного произведения

**Утверждение.** Для `R_m(s,t)=I+sG+st·D_g+½s²K`, `R_b(t)=I+tG+½t²K`,
`R_Σ(s,t)=I+(s+t)G+½(s+t)²K` и
`X=G²+D_g−K`, `A=½GK+D_gG`, `E=½D_gK`, `B=½KG`, `C=¼K²` выполняется
тождество (точное равенство полиномов от `s,t` со значениями в матрицах)

    R_m(s,t)R_b(t) − R_Σ(s,t) = st·X + st²·A + st³·E + s²t·B + s²t²·C.     (1)

**Доказательство.** `R_Σ = R_m + t(G+tK) + (t²−t²)K/2 …` — проще: раскрываем произведение.
Каждое слагаемое `R_mR_b` имеет суммарную степень по `(s,t)` не выше 4, а `R_Σ` — не выше 2,
поэтому разность — полином вида `Σ_{p+q≤4} s^p t^q M_{pq}`. Прямое раскрытие даёт

    R_mR_b = I + (s+t)G + ½(s+t)²K + st(G²+D_g−K) + st²(½GK+D_gG)
             + st³(½D_gK) + s²t(½KG) + s²t²(¼K²),

что и есть (1) после вычитания `R_Σ`. Тождество проверено символьно при произвольных
`G,D_g,K` (`[T1]`, C1). ∎

**Замечание.** `C = ¼K²` входит при `s²t²`; при `K=0` все коэффициенты, кроме `X`, обнуляются.

## T2. Полная классификация точной полиномиальной композиции

**Утверждение.** Для любых вещественных матриц `G,D_g,K`

    hcomp  ⟺  X = A = E = B = C = 0,                                       (2)

где `hcomp` — точное равенство `R_m(s,t)R_b(t) = R_Σ(s,t)` для всех `s,t`.

**Доказательство.**
*Достаточность* немедленна из (1).
*Необходимость*: если `hcomp` выполнено, то правая часть (1) — нулевой полином.
Коэффициент при `st` в точке `(s,t)=(a,b)` равен `ab`; рассмотрим 5 линейных функционалов
`ℓ_{pq}(M) =` коэффициент при `s^p t^q`. Из (1) следует, что
`0 = ℓ_{11}(X)·ab + ℓ_{12}(A)·ab² + ℓ_{13}(E)·ab³ + ℓ_{21}(B)·a²b + ℓ_{22}(C)·a²b²`
при всех `a,b`. Взяв 5 точек `(a,b) ∈ {(1,1),(−1,1),(1,−1),(−1,−1),(1,2)}`, получаем
линейную систему с матрицей `C_m`, `det C_m = −96 ≠ 0` (`[T2]`, C2a). Значит `X=A=E=B=C=0`
покомпонентно. ∎

*Явная изолирующая комбинация для `X`*: `w = C_m^{−T} e_1 = (¾, −¼, −1/12, ¼, −1/6)`
(`[T2]`, C2b); т.е. `X` извлекается линейно из 5 значений без предположений о структуре.

**Замечание о честности.** Это утверждение — про **полиномиальное** равенство. Оно не
является условием существования струи второго порядка или потока. Ниже это
используется, чтобы отделить (2) от T6.

## T3. Специализация `D_g = 0`

**Утверждение.** При `D_g=0`

    hcomp  ⟺  K = G²  и  G³ = 0.                                            (3)

**Доказательство.** При `D_g=0`: `X = G²−K`, `A = ½GK`, `E=0`, `B=½KG`, `C=¼K²`.
Если `hcomp`, то по T2 `K=G²`, откуда `A = ½G·G² = ½G³ = 0`, значит `G³=0`.
Обратно, если `K=G²` и `G³=0`, то `X=0`, `A=½G³=0`, `E=B=0`, `C=¼G⁴=¼G·G³=0`; по T2 `hcomp`. ∎

**Смысл.** Кубическое условие `G³=0` — дополнительное требование **точной композиции
квадратичных полиномов**; оно не является условием существования однопараметрического потока.
Поток `U(t)=exp(tG)` удовлетворяет `U(s+t)=U(s)U(t)`, `U'(0)=G`, `U''(0)=G²` при любом `G`
(это контроль, не выбранная динамика D0).

## T4. Нативный контрпример владельца — для всех `n ≥ 3`, с точной замкнутой формой

**Постановка.** Скалярный владелец: `dξ = n(ξ(i+1)−ξ(i))` (периодически), т.е. `d = n(U−I)`,
где `U` — циклический сдвиг; `G = scalarCycleG = (n/2)(U − U^T)`. Постоянное поле `ξ = 1`
лежит в `ker d` (изотропия), а вдоль направления изотропии `D_g = 0`.

**Утверждение.** Для всех `n ≥ 3` имеется `G³ ≠ 0`; точнее

    (G³)[0,1] = −3n³/8  при n ≥ 3, n ≠ 4;   (G³)[0,1] = −n³/2  при n = 4.   (4)

**Доказательство.** `C := U − U^T = P − P^{−1}` (`P` — сдвиг). Тогда
`C³ = P³ − 3P + 3P^{−1} − P^{−3}`, а `G³ = (n³/8)C³`. Матрица `P^j` имеет
`(P^j)[0,1] = 1 ⟺ j ≡ 1 (mod n)` для `0 ≤ j < n`. Вклад слагаемых:
`P³` даёт 1 лишь при `n | 2`; `−3P` даёт `−3` всегда; `3P^{−1}` — лишь при `n | 2`;
`−P^{−3}` даёт `−1` лишь при `n | 4`. При `n ≥ 3` единственное выживающее вычитание —
`−1` при `n = 4`. Отсюда (4). ∎

**Следствие (для G0).** Ни при каком `K` точное `hcomp` не выполнено при `D_g=0`:
по T3 требуется `G³=0`, а `G³ ≠ 0` при всех `n ≥ 3`. При `n=4` значение `−32`
совпадает с заявленным в `A4D_NATIVE_DYNAMICAL_OWNERSHIP.md`.

**Точный контроль.** `[T4]` (C5) воспроизводит (4) при `3 ≤ n ≤ 100`; все значения
ненулевые; `(G³)[0,1]=−32` при `n=4`. Это **расширение** значения владельца с `L=4`
на общий носитель, а не новое утверждение о физике.

## T5. Исключение при `D_g ≠ 0` (нельзя молча положить `D_g = 0`)

**Утверждение.** Существует четвёрка `(G,D_g,K)` с `G³ ≠ 0`, `D_g ≠ 0`, `K ≠ 0`,
для которой `hcomp` выполнено, а именно `G = J` (верхний нильпотентный жорданов блок 4×4,
`J³ ≠ 0`), `K = 2E_{1,3}`, `D_g = K − J²`.

**Доказательство.** Прямая подстановка: `X = J²+D_g−K = 0`; `A = ½JK+D_gJ = ½JK+(K−J²)J = ½JK+KJ−J³`.
Для жорданова `J` и `K=2E_{1,3}`: `JK = 2E_{1,4} = 0` (4×4, столбца 4 нет), `KJ = 0`, `J³=0`,
значит `A=0`. Аналогично `E = ½D_gK = ½(K−J²)K = ½(K²−J²K) = 0` (`K²=0`, `J²K=2J²E_{1,3}` имеет
единственный ненулевой элемент в позиции `(2,3)`… проверка прямая), `B=½KJ=0`, `C=¼K²=0`.
Проверено символьно (`[T5]`, C6). ∎

**Следствие.** Условие `D_g = 0` в T3/T4 существенно: без него точная композиция допускает
`G³ ≠ 0`. Поэтому «положить `D_g=0`» требует **доказанного** нулевого фонового направления.

## T6. Ремонт второго порядка и непустота волокна

**Утверждение.** Пусть `H(s,t) = st²A + st³E + s²tB + s²t²C` (остаток из (1) после `stX`).
Тогда

    R_m(s,t)R_b(t) − H(s,t) = R_Σ(s,t)  для всех s,t   ⟺   K = G² + D_g.   (5)

**Доказательство.** По (1) левая часть равна `st·X = st(G²+D_g−K)`, что как полином
нуль тогда и только тогда, когда `G²+D_g−K=0`. ∎

**Следствие 1 (непустота).** Для **любой** пары `(G,D_g)` волокно второго порядка
непусто: `K = G²+D_g`. Никакой совместности не требуется (`[T6]`, C7b).

**Следствие 2 (порядок остатка).** Все мономы `H` имеют суммарную степень 3 или 4.
В любой фиксированной конечномерной норме при `ρ=|s|+|t| ≤ 1`

    ‖H(s,t)‖ ≤ (‖A‖+‖B‖+‖C‖+‖E‖)·ρ³.

Это элементарная аналитическая оценка Тейлоровского смысла; она даёт законный
порядок-2 (не точный, а с явным остатком).

**Отрицательный контроль.** `K = G²+D_g+I` отвергается (`[T6]`, C7b-neg): условие (5)
действительно связывает `K`, а не выполняется тривиально.

**Остающийся разрыв.** (5) по-прежнему не строит `D_g = (D_e g)[h]`, не интегрирует
фоново-зависимое группоидное действие и не связывает свои эйлеровы уравнения с физическим
откликом. Это фиксируется как незакрытое (см. `04_OPEN_OBLIGATIONS.md`, O2).

## T7. Полная нормальная форма группоида переносов (включая изотропию)

**Утверждение.** Пусть `H, K` — группы, `X` — множество, `b ∈ X`. Тогда

    {T: X×X×H→K : T(x,y,h)T(y,z,k)=T(x,z,hk), T(x,x,1)=1}
      ≃  {U: X→K : U(b)=1} × Hom(H,K),

    T(x,y,h) = U(x) ρ(h) U(y)^{−1},   U(x)=T(x,b,1),  ρ(h)=T(b,b,h).        (6)

**Доказательство.**
*Полнота.* Для произвольных `x,y,h` склеиваем три стрелки:
`T(x,y,h) = T(x,b,1)·T(b,b,h)·T(b,y,1)` (закон композиции, с учётом `T(b,b,1)=1`).
Далее `T(b,y,1) = T(y,b,1)^{−1}` (положить `x=z=b`), т.е. `=U(y)^{−1}`. Обратно,
правая часть (6) удовлетворяет закону и нормировке тождественно.
*Инъективность* очевидна: `(U,ρ)` восстанавливаются из `T`.
*Ограничение `ρ`*: из закона следует аддитивность `ρ(hk)=ρ(h)ρ(k)`, т.е. `ρ ∈ Hom(H,K)`. ∎

**Исчерпывающий конечный сертификат.** При `X={0,1}`, `H=ℤ/2`, `K=S₃` полный перебор
всех `6^6 = 46656` кандидатов даёт **ровно 24** допустимых `T`, и
`24 = |{U:U(0)=1}|·|Hom(ℤ/2,S₃)| = 6·4` (`[T7]`, C8a). Каждый найденный `T`
восстанавливается как `U(x)ρ(h)U(y)^{−1}` (C8b), отображение `(U,ρ)↦T` инъективно
(C8c). Отрицательные контроли: мутация одного свободного значения ломает закон
(C8-neg1); **18 = 6·3** транспортов имеют нетривиальное `ρ`, и стирание `ρ` (замена
на `ρ=1`) отвергается на них (C8-neg2); снятие нормировки `U(b)=e` дало бы `6·6·4=144 ≠ 24`
(C8-neg3).

**Следствие.** `ker d` **нельзя** выбросить: действие-группоид плоской орбиты есть
`Pair(X) × H`, а не `Pair(X)`.

## T8. Производная переноса по фону

**Постановка.** `U(e) = I + A(e) + ½{A(e)² + S(e,e)} + o(‖e‖²)`, где `S: X×X→End(F)`
симметрична билинейно. `R(e,ξ)=U(e+dξ)ρ(c_ξ)U(e)^{−1}`, `g_ζ(e)=∂_t R(e,tζ)|₀`.

**Утверждение.**

    (D_e g_ζ)₀[h] = S(h,dζ) + ½[A(h),A(dζ)] + [A(h),C(c_ζ)].                (7)

**Доказательство.** Из (6) при `ρ`-фиксированном: `g_ζ(e) = D_e[U(e+dζ)]·U(e)^{−1} − U(e+dζ)·U(e)^{−1}·D_e U(e)·U(e)^{−1}`.
В нуле `U(0)=I`, `DU_0[h] = A(h)`, `D_e[U(e+dζ)]|₀[h] = D_eU|_{dζ}[h] = A(h) + D²U(dζ,h)`.
Симметричная часть `D²U` равна `½(A(dζ)A(h)+A(h)A(dζ)) + S(h,dζ)`. Учёт изотропии:
`ρ(c_ζ)` даёт член `[A(h),C(c_ζ)]` через `D_eρ(c_{e+·})`. Собирая, получаем (7). ∎
Проверено символьно при произвольных `A(h),A(dζ),C(c_ζ),S` (`[T8]`, C9a).

## T9. Диагональная вторая струя

**Утверждение.**

    K_ξ := (D²_e R(e,ξ))₀[dξ,dξ]
         = A(dξ)² + 2A(dξ)C(c_ξ) + C(c_ξ)² + S(dξ,dξ)
         = G(ξ)² + (D_e g_ξ)₀[dξ],                                          (8)

где `G(ξ) = A(dξ) + C(c_ξ)`.

**Доказательство.** По правилу произведения для `R(e,ξ)=U(e+dξ)ρ(c_ξ)U(e)^{−1}` вторая
производная по `e` в нуле есть `A(dξ)² + 2A(dξ)C(c_ξ) + C(c_ξ)² + S(dξ,dξ)` (слагаемые
`ρ`-части дают `C²` и перекрёстный член, симметричная часть `U` даёт `S`). Правая
часть (8) следует из (7) при `ζ=ξ`, `h=dξ` и `G(ξ)²=(A(dξ)+C(c_ξ))²`. ∎
Проверено символьно (`[T9]`, C9b).

**Следствие T9' (наблюдаемость `S`).**

    K'_ξ − K_ξ = (S' − S)(dξ, dξ).                                        (9)

Это точное линейное соотношение: вторая струя переноса **измеряет** разность симметричных
билинейных форм на `(dξ,dξ)`.

## T10. Критерий интегрируемости и смешанный остаток

**Утверждение.** Заданный плоский генератор `G` интегрируем (т.е. существует
`C²`-семейство переносов с производной `G`) тогда и только тогда, когда

    [G(c),G(c')] = 0   для всех c,c' ∈ ker d.                              (10)

**Доказательство.**
*Необходимость.* Изотропные трансляции `c ↦ c+c'` коммутируют; дифференцируя закон
композиции, получаем `[G(c),G(c')]=0`.
*Достаточность.* Положим `A(e)=G(je)`, `C(c)=G(c)`, `R(e,ξ)=U(e+dξ)exp(C(c_ξ))U(e)^{−1}`.
Сокращение `U` в середине и (10) дают точное `R(e+dξ',ξ)R(e,ξ')=R(e,ξ+ξ')`. Для гладкого
аддитивного представления изотропии с производной `C` функция `ρ(tc)` решает `ρ'=C(c)ρ`,
`ρ(0)=I`; дифференцируя `exp(−tC(c))ρ(tc)`, видим, что оно постоянно, значит `ρ(c)=exp(C(c))`.
Вместе с (6) это даёт полноту. ∎

**Смешанный остаток.** Для `B(ζ,h) := (D_e g_ζ)₀[h] − S(h,dζ)`

    B(ζ,dξ) − B(ξ,dζ) + [G(ζ),G(ξ)] = [C(c_ζ),C(c_ξ)].                    (11)

**Доказательство.** Прямая подстановка (7) в левую часть с учётом `G=A+C`:
несимметричные части `S` сокращаются, а перекрёстные коммутаторы `A` дают `[C(c_ζ),C(c_ξ)]`. ∎
Проверено символьно (`[T10]`, C9c). **Отрицательный контроль** (C9-neg): если допустить
антисимметричную добавку к `S`, остаток уже не равен `[C(c_ζ),C(c_ξ)]` — значит `S`
обязана быть симметричной, а (10) — необходимым.

## T11. Полная классификация волокна смешанного коцикла

**Утверждение.** Пусть `B: V×V→End(F)` билинейно. Все билинейные решения смешанного
уравнения `B(ζ,dξ) = B(ξ,dζ)` (т.е. (11) с нулевым коммутатором) суть

    B(ζ,h) = B_adv(ζ,h) + Q(dζ,h),   Q: X×X→End(F) симметрична билинейно,     (12)

где `B_adv` — конкретный владельцем заданный коцикл (`advectiveBackgroundDerivative`).

**Доказательство.** Разность `T = B − B_adv` двух решений удовлетворяет `T(ζ,dξ)=T(ξ,dζ)`.
При `c ∈ ker d` (т.е. `d c = 0`) это даёт `T(c,h) = 0` для всех `h ∈ X`, значит `T`
единственным образом факторизуется через `d` в первом аргументе: `T(ζ,h) = Q(dζ,h)`.
Оставшееся уравнение — в точности симметрия `Q`. Обратно, любая симметричная `Q`
удовлетворяет уравнению. ∎

**Контроль.** `[T11]` (C10a) проверяет эквивалентность `B(z,dξ)=B(ξ,dz) ⟺ B=Q(dz,·)` с
симметричной `Q` на 400 случайных билинейных формах; C10b — что `B(c,h)=0` при `c∈ker d`;
C10c — `dim ker d = dim V − dim X` и `d|_{ker d}=0`; C10-neg — антисимметричная `Q`
нарушает условие (отвергнута).

**Граница.** Значения `B` на трансверсальных направлениях кофрейма вне `X` из (12) не следуют.

**Смысл и граница.** Это **различие переходных цен**, а не эйнштейновский метрический отклик.
Физическое отображение считывания не построено, поэтому вывод о выживании этих параметров
после физического quotient не делается. Это ровно статус опубликованного G0.

## T13. Полное волокно инвариантных фоновых скаляров

**Утверждение (воспроизведение).** Для отношения эквивалентности `r` на `B`

    {F: B→ℝ : x r y ⇒ F(x)=F(y)} ≃ (B/r → ℝ).

**Независимый контроль.** `[T13]` (C12d): на `B=ℝ²` с симметрией `σ:(x,y)↦(x,−y)` скаляры
`0` и `x²−1` инвариантны и совпадают в `x=1`, но их производные по `x` там равны `0` и `2`.

**Смысл.** Производная инвариантного действия не определена без дополнительного
отношения/владельца; это свидетеля **входа** фонового действия, а не нативного решения.

## T14. Интертвинер и сохранение семени

**Утверждение.** Для одной и той же `ρ` два выбора `U₁,U₂` связаны `J(e)=U₂(e)U₁(e)^{−1}`, и

    J(x)T_{U₁}(x,y,h) = T_{U₂}(x,y,h)J(y).                                 (13)

Более того, при действии `GL(F)` на `Y` переносимый срез `U(e)·v` ковариантен тогда и
только тогда, когда базовое значение `v` неподвижно относительно **всех** `ρ(H)`;
в частности инвариантное квадратичное семя `W₀` даёт `W_e(ψ,φ)=W₀(U(e)^{−1}ψ,U(e)^{−1}φ)`, и

    W'_e(Jψ,Jφ) = W_e(ψ,φ).                                               (14)

**Доказательство.** (13) — прямое следствие (6) и определения `J`. Для (14):
`W'_e = J^{−T}W_eJ^{−1}`, что проверяется прямой подстановкой `W_e = U^{−T}W₀U^{−1}`
и `J = U₂U₁^{−1}`. ∎ Проверено символьно (`[T14]`, C11a) и для второго порядка (C11b):
`J(0)=I`, `J'(0)=0`, `J''(0)=S₂−S₁`.

**Граница.** (13) — абстрактный изоморфизм расслоений. Он не обязан быть **собственной**
физической gauge-эквивалентностью: он может менять локальность, предписанное считывание
кофрейма/линка/материи или карты уточнения. Это фиксируется как обязательство O1.

## T15. Решающая теорема: неидентифицируемость физического отклика на полном плоском interface-е

**Определение (класс `𝓛`).** `𝓛` — множество всех `C²`-переносов
`R(e,ξ)=U(e+dξ)ρ(c_ξ)U(e)^{−1}` с `U(0)=I`, `ρ ∈ Hom(H,GL(F))` и
`U(e)=I+A(e)+½{A(e)²+S(e,e)}+o(‖e‖²)`, `S:X×X→End(F)` симметрична билинейно.
Это в точности собственное определение владельца (`A4D_NATIVE_DYNAMICAL_OWNERSHIP.md §6.2`);
никаких новых полей или действий не вводится.

**Утверждение T15.** `𝓛` непусто и полностью описано; и

    (i)  K'_ξ − K_ξ = (S'−S)(dξ,dξ)  для всех S,S' ∈ Sym²(X,End F);        (15)
    (ii) при dξ ≠ 0 отображение ΔS ↦ ΔS(dξ,dξ) сюръективно на End(F):
         ядро тривиально в направлении наблюдения, и для любого ΔS ≠ 0
         существует S' = S + ΔS с K'_ξ ≠ K_ξ;
    (iii) при dξ = 0 (направление ker d) K_ξ = G(ξ)² не зависит от S.

**Доказательство.**
(i) — это (9) из T9'.
(ii) Достаточно предъявить для любого `M ∈ End(F)` симметричную билинейную `ΔS` с
`ΔS(dξ,dξ)=M` при `dξ ≠ 0`: фиксируем линейный функционал `λ` с `λ(dξ)=1` и положим
`ΔS(u,v) = ½(λ(u)Mλ(v) + λ(v)Mλ(u))`; это симметричная билинейная форма с
`ΔS(dξ,dξ) = M`. Значит `ΔS ↦ ΔS(dξ,dξ)` сюръективно, и `K_ξ` различает любые два
заполнения, различающиеся на таком `ΔS`.
(iii) При `dξ=0` имеем `A(dξ)=0`, `c_ξ=ξ`, и `K_ξ = C(ξ)² = G(ξ)²`; `S` входит с
аргументом `(dξ,dξ)=0` и обращается в нуль. ∎
Проверено символьно: `[T9]` (C9b, C9d), `[T15]` (C12f-1).

**Физическая значимость (свидетель).** Различие `S` наблюдаемо на **нековариантном**
считывании. Явный свидетель: `F=ℝ²`, `A = [[0,1],[−1,0]]`, `S₁ = diag(1,−1)`,
`S₂ = S₁ + [[0,1],[1,0]]`, `W₀ = [[2,1],[1,3]]`, `v = (1,1)^T`. Тогда

* ковариантное считывание (поле увлекается вместе с `U`) даёт одинаковый ответ `7 = 7` (C12f-2);
* считывание на **фиксированной** тривиализации даёт разность с коэффициентом при `e²`,
  равным `−v^T W₀(S₂−S₁)v = −7 ≠ 0` (C12f-3).

Следовательно, **если** собственный native readout не ковариантен относительно `ρ(H)`,
различие `S` физически значимо, и отклик неединственен на одном и том же interface-е.

**Честная граница.** T15 доказывает неидентифицируемость **условно**: она неидентифицируема
при отсутствии `ρ(H)`-ковариантности собственного readout. Существующее владение эту
ковариантность **не доказывает** (T14 — абстрактный изоморфизм, а не собственный gauge).
Поэтому T15 — точная граница вывода (п. 3 раздела 1 задания), а не утверждение, что D0
неидентифицируем.

## T16. Дихотомия: остаток G0 сводится к одному типизированному вопросу

**Утверждение.** Пусть `P_h` — собственное readout-отображение на том же носителе.
Рассмотрим свойство

    (Cov)  P_h(ρ(h)·x) = ρ(h)·P_h(x)  для всех h ∈ H  и всех собственных x.

Тогда:

* **если (Cov) выполняется** для всех собственных readout-карт, то `U` и `S` —
  чистая gauge-свобода на плоской орбите, и все допустимые заполнения `𝓛` дают **один и
  тот же** физический отклик (универсальность отклика; п. 2 раздела 1 задания);
* **если (Cov) нарушается хотя бы на одной собственной readout-карте**, то T15 даёт два
  допустимых заполнения одного interface-а с различным физическим выводом
  (неидентифицируемость; п. 3 раздела 1 задания).

**Доказательство.** Если (Cov) выполняется, то по (13)–(14) `J` сохраняет все собственные
readout-значения, значит все элементы `𝓛` попадают в один физический класс и отклик
универсален. Если (Cov) нарушается на `P_h` и некотором `x`, то `P_h(Jx) ≠ J P_h(x)`; беря
`S' ≠ S` как в T15(ii), получаем два заполнения с разными `P_h`-значениями. Обе ветви
исчерпывающие: третьей возможности нет. ∎

**Смысл.** Это не «ещё один свободный параметр», а **исчерпывающая дихотомия**:
оставшееся обязательство G0 эквивалентно **одной** типизированной лемме о ковариантности
собственного readout. Каждая ветвь даёт готовую форму результата.

## T17. Независимая проверка опубликованного препятствия (`A4D_NATIVE_REALIZATION_CLOSURE.md §2`)

**Утверждение (воспроизведение).** При `m=n+2 ≥ 3`, `J_{ij}=1_{j=i mod m}`,
`D = L_f J − J L_c`:

    D_{0,*} = −e₀^T + e_{m−1}^T,  D_{m,*} = −e₀^T + e₁^T,  D_{i,*}=0 (0<i<m);
    ‖D‖² = 4;   −2⟨D, JδL⟩ = 6  для  δL=(e₀−e₁)(e₀−e₁)^T;
    G = −2J^TD:  G_{00}=4, G_{01}=G_{0,m−1}=−2, G_{10}=0,  G ≠ G^T,  row sums = 0.

**Доказательство.** Прямое вычисление строк. Для внутренних строк оба переноса имеют
одних и тех же соседей и степень 2, поэтому разность нулевая; на двух концевых строках
разность даёт указанные векторы; при `m=3` два ненулевых столбца остаются различными.
Первая вариация: `−2⟨D,JδL⟩ = −2(D_{0,0}(−1) + D_{m,0}(−1)·… )`, что даёт `−2(−1−2)=6`.
Матрица `G` имеет единственную ненулевую строку, но `G_{10}=0 ≠ G_{01}=−2`, значит
несимметрична. ∎

**Контроль.** `[T17]` (C13) воспроизводит всё при `m=3..11` на независимом коде, без
использования аргумента документа. Это **не** новый результат и **не** закрытие #310:
это независимая проверка уже опубликованного препятствия.

## T18. Связывание с нативными владельцами

**Утверждение 18a (скалярный цикл).** Для `d = n(U−I)`, `n ≥ 3`: `ker d` = константы;
`d(1)=0`; центрирование по среднему сохраняет `dξ`, и прообраз с нулевым средним единствен.
Обратная `j` — на `X=im d`, `c_ξ = mean ξ`.

**Доказательство.** `dξ=0 ⟺ ξ(i+1)=ξ(i)` для всех `i` (периодически) ⟺ `ξ` постоянно.
Для `h` с `Σh=0` положим `v_i = n^{−1}Σ_{k<i}h_k` и вычтем среднее; периодичность
последнего ребра следует из `Σh=0`. ∎ Проверено (`[T18]`, C14a) при `n=3..12`.

**Утверждение 18b (буквальный четырёхролевой Fock-владелец).** На
`(ℤ/(N+2))^{Role}` с `d = forwardGaugeCoframe`, `G = a4dCartanGenerator`:
`ker d` состоит ровно из четырёх постоянных компонент; для постоянных `c`

    G_c ψ = Σ_r c^r C_r ψ,   [G_c, G_b] = 0,                               (16)

где `C_r` — собственные центрированные разности (centeredDifference), действующие
одинаково на каждой Fock-метке.

**Доказательство.** `dξ=0` означает, что каждая компонента `ξ` инвариантна относительно
каждого единичного сдвига роли; эти сдвиги порождают весь конечный тор, значит `ξ` постоянна
покомпонентно. `[C_r,C_s]=0` — потому что `C_r` действует только на `r`-ю координату тора,
а разные координаты независимы. ∎ Проверено (`[T18]`, C14b) на `(ℤ/4)^4` (256-мерный носитель).

**Следствие.** T7–T15 применимы к полному плоскому четырёхролевому коцикл-interface-у
для каждого конечного `N`, включая `N+2 ∈ 4ℕ`. Это конструкция **совместимых математических
заполнений** на плоской орбите, а не доказательство их физической допустимости.
