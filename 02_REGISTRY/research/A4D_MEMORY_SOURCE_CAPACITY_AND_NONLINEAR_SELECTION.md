## 1. Три источника образуют один точно вычислимый квадратичный CAR-оператор

Пишем положительный однородный creator-frame

    F=(A-B)I+B11^T, A>B>0, u_r=F_r^T,

Чтобы не смешивать пространственный Dirac с вспомогательными обозначениями, используем `gamma(v)=c(v)+b(v)` и `k(v)=c(v)-b(v)` только для полных exterior creators/annihilators.

Определим

    a1=(0,0,-1,1), a2=(0,1,0,-1), a3=(0,-1,1,0),
    B_r=gamma(a_r) k(u_r), r=1,2,3.

Предыдущая буквальная source-формула даёт `J_r=kappa0 B_r` и J0=0. Поэтому ниже нормированный вектор y означает физический источник `kappa0 y`. Это фиксированная смена единиц при данном root, не поле-зависимая перенормировка action.

Для любой вещественной link-пробы t=(t1,t2,t3) положим

    C(t)=sum_r t_r a_r u_r^T,
    B(t)=sum_r t_r B_r=sum_ij C_ij gamma(e_i) k(e_j).          (1)

Нулевая time-row C и нулевая сумма трёх spatial rows следуют из a_r·(1,1,1)=0. Следовательно rank C<=2 для ВСЕХ t. Если s1,s2 — его ненулевые singular values (с нулевым дополнением при меньшем ранге), то полный16 спектр B(t):

    +(s1+s2), +(s1-s2), -(s1-s2), -(s1+s2),
    каждый с кратностью4.                                     (2)

Доказательство не перебирает t. Реальные независимые ортогональные преобразования двух наборов Majorana-операторов приводят C к SVD. Четыре commuting Hermitian инволюции gamma'_i k'_i имеют все16 комбинаций знаков: trace каждого непустого произведения равен нулю в полном CAR-представлении. Два нулевых singular values оставляют кратность4. Никакого eigenvector-каталога прибору не предоставляется.

Можно проверить (2) без извлечения собственных векторов. При

    T=Tr(C C^T), D2=((Tr C C^T)²-Tr((C C^T)²))/2>=0

имеем точное операторное тождество

    B(t)^4-2T B(t)^2+(T²-4D2)I16=0,
    ||B(t)||op=sqrt(T+2sqrt(D2))=||C(t)||_*.                    (3)

Следовательно весь образ положительных внутренне нормированных подготовок

имеет известную support function. Полный критерий принадлежности:

    y in K <=> |t·y|<=sqrt(T(t)+2sqrt(D2(t))) for every real t.   (4)

Достаточность — separation компактного выпуклого образа density space; проверяется одна трёхмерная homogeneous support function, а не отдельная догадка о stress. Этот точный предел запрещает приписывать подготовке произвольный источник.

Для любого допустимого y есть вещественная density rank<=2 с теми же тремя ожиданиями. Доказательство: можно заменить sigma на её вещественную часть, поскольку B_r вещественны; полученная матрица остаётся PSD. ## 5. Что действительно требуется для второго шага искривлённой ветви

При x(t)=x0+t v+t²a/2+..., epsilon(t)=epsilon0+t epsilon1+t²epsilon2/2 и C(t)=C0+t C1+t² C2/2 в исходном Feshbach chart E(0)=0:

    E1=P X_v P-epsilon1 P,
    E2=P(X_a+Y_vv-2 X_v R_Q X_v)P-epsilon2 P.                 (19)

Все матрицы определены прежним полным action/operator. Второй eigen-equation не равен E2=0, а равен

    E1 C0=0,
    E2 C0+2E1 C1=0.                                         (20)

Производные G=J*J также сохраняются. В исходной точке G'=0, G''=2P X_v R_Q² X_v P, так что нормировка даёт

    2 ReTr(C0* C2)+2||C1||²_HS
           +2Tr(C0* P X_v R_Q² X_v P C0)=0.                   (21)

Радиальная часть C2 решает (21) после задания C1 и полевой скорости; E(0)=0 не даёт ей искусственного источника в (20). Если Fourier q лежит вне Omega-Omega, имеем E1=0 и epsilon1=0, поэтому C1 НЕ может исправить второе условие: требуется именно E2 C0=0. Понижение ранга уменьшает этот тест до занятого support, но не отменяет его.

Для полной constrained C3-цены S в реальном local chart обозначим Hessian через H. Если xi — предполагаемая скорость ветви всех полей/амплитуд, то

    H xi=0,
    H eta + D³S[xi,xi,.]=0.                                  (22)

В конечной размерности второе уравнение разрешимо по eta **ровно когда**

    <zeta,D³S[xi,xi,.]>=0  для всех zeta in ker H.             (23)

Это необходимое и достаточное условие существования second-order stationary jet, не теорема о сходимости ряда или точной нелинейной ветви. Для последнего нужны последующие compatibility и/или quantitative existence theorem. Симметрийные directions проверяются по actual native orbits. Выбор coordinates не устраняет (23).

## 6. Новый сильный тест от САМОГО слоя памяти

на внутренних16 координатах. При комплексном Fourier представлении берётся соответствующая real q/−q bilinear combination, не один неэрмитов блок. Именно этот N_v уже присутствует в (17); новый третий native operator derivative ради теста не нужен.

Здесь рассматривается чистая q/−q field-скорость с её предписанной off-shell matter response; для смешанных скоростей сохраняются все дополнительные bilinear terms.     <zeta_delta_sigma,D³S[xi,xi,.]>=Tr(delta sigma M_v).        (25)

Производные field-dependent reconstruction не заморожены: differentiating reduced Hessian равно differentiating полной формы на kernel, поскольку дополнительные члены содержат H xi=0. Это стандартный envelope/Schur факт, здесь с конкретным уже решённым matter block.

### Faithful internal preparation

Внутри sigma>0 любой Hermitian S с `Tr S=0`, `Tr(S B_r)=0` является допустимой касательной стационарной фибры. Следовательно из (23) необходимо

    M_v in span_R{I16,B1,B2,B3}.                              (26)

Не требуется перебрать все252 вариации вручную. Если G_B,rs=Tr(B_rB_s), то полный тест — один остаток

    M_perp=M_v-Tr(M_v)I16/16
             -sum_r B_r [G_B^-1 (Tr(B_s M_v))_s]_r = 0.      (27)

G_B невырождена по первоначальному source-owner. Это квадратичное условие на полевую скорость v. Оно намного сильнее единственного равенства H_rho(v,v)=0 и дополняет, а не заменяет, H_rho(v,w)=0 для всех w. Условие необходимо даже если размерность/число отрицательных eigenvalues полевого блока изменилось при вариации подготовки.

### Собственный pure-memory конец

На rank8-конце internal sigma=|chi><chi|. Поскольку Gamma>0, три source constraints имеют независимые реальные градиенты в pure-state space около chi. Тогда stationarity по pure stationary memory fibre даёт необходимое условие

    M_v chi=lambda chi+sum_r beta_r B_r chi,
    lambda,beta_r in R.                                     (28)

Проекция должна быть на **вещественный** tangent/cotangent space. Комплексная линейная оболочка без проверки реальности коэффициентов может пропустить условие.

Различие (26) и (28) существенное. Оператор `M=|chi><chi|-I/16` нарушает (26) (его спаривание с тем же trace/source-neutral S равно15/16), но удовлетворяет (28). Значит, понижение ранга действительно может снять конкретный nonlinear obstruction; оно не только уменьшает число неизвестных. Это algebraic control различия условий, не заявление, что именно такой M_v уже реализован native field velocity.

Простой полный counterexample опасной логики: `S(t,a)=t a²/2+a⁴/4`. Всё a=0 — стационарная фибра, а transverse Hessian t меняет знак. Но полноценное t-уравнение есть a²/2=0, поэтому никакой ветви a!=0 нет. Treating t как внешний параметр потеряло бы именно source-equation памяти. (26)–(28) предотвращают аналогичную ошибку в нашей программе.

## 7. Выполненная численная разведка: кандидат найден, но не принят за решение

Отдельный диагностический код расширяет старую full-q матрицу на произвольную internal sigma, сохраняя все4096 thermal modes и actual matter second jet. У q=(3,3,0,0) на пути `sigma(t)=(1-t)I16/16+t|chi><chi|` найдена плавающая кандидатная crossing около t=0.430362535. Её slope вдоль этой же stationary fibre около -0.90348. Остаток (27) имеет HS-norm около7.40958 при ||M_v||HS около29.0063.

Эти числа — **floating diagnostic**, не interval certificate и не вычисленное точное ядро при настоящем сертифицированном root. Они показывают, где новый тест должен применяться до заявления «найдена curved branch». Нельзя объявить ни её существование, ни строгое отсутствие на основании этих чисел. Без (25) можно было бы ошибочно назвать почти нулевое собственное значение завершением nonlinear задачи.

Предыдущий scout исполнен на midpoint d,o, а не на точном interval root. Его входной код, новый matrix coefficient, field tangent и diagnostic JSON сохранены отдельно от доказательного checker. Они не используются ни для (1)–(28), ни для изменения scientific flags.

## 8. Интеграционный итог и граница ОТО

Завершённая связка этой итерации:

    actual memory -> exact source cone and pure inverse
      -> full rank-aware joint field/matter operator
      -> exact second stationary jet equations
      -> nonlinear selection imposed by the stationary memory itself.
