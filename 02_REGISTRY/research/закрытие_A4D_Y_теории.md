# A4D-Y: сводка закрытия на выжившем листе `z=1`

Задача: `EXP-A4D-JOINT-RESPONSE-DECOUPLING-MICROSTRUCTURE`, PR #310  
Ветка: `exp/a4d-joint-response-resolvent`  
Статус PR: Draft / `IN_PROGRESS`

Этот документ консолидирует точные результаты для нормированного выжившего Y-листа при `z=1`. Он не заменяет сертификаты-владельцы и не закрывает глобальный терминал PR. Источником для сверки послужила предоставленная сводка SHA-256 `a05297a6fa3d959e1532606088c8ddc044d59b559bb43e7bdc1b423b676c72a0`; её формулировки ниже уточнены там, где они шире проверенного scope.

## Что доказано на листе `z=1`

1. Точный нормальный jet оставляет одну совместимую кривизну `-Y tensor Y`, где `Y=(1,-1,1)`. Ранги плоской и кривой связностных карт равны соответственно 80 и 94; плоский центр имеет размерность 16, кривый — 2.

2. Полный первый-медленный joint-символ имеет пятистолбцовый минор
   `det T = -975737200/35590023`, а
   `||T^-1||_F^2 < 64`. Поэтому `||M v||_2 >= ||v||_2/8`. При гипотезах владельческого first-slow reduction это исключает ненулевой ведущий Y-градиент на регулярной гладко-источниковой ветви.

3. В редуцированном нормальном jet степени 2 ранг возрастает `20 -> 21`. Свидетель сосредоточен на `xi3^2`; точные спаривания равны `-22209` в редуцированном коядре и `-166034484` в примитивном целочисленном свидетеле по 136 строкам. Форсировка степени 4 тождественно равна нулю, а система степени 3 разрешима с рангом `35/35`.

4. Однородность по амплитуде кривизны даёт для `R=kappa R_Y`
   `-22209*kappa^2` и `-166034484*kappa^2`. Следовательно, при `z=1` гладкого формального второго normal-jet продолжения на этом направлении нет для любого фиксированного `kappa != 0`. Это утверждение о конечном jet, не о каждой точной конечнорешёточной ветви.

   Точный смысл несовместимости — невозможность **фазово-общего метрического источника именно в порядке `h^4`** при заданном normal jet. Для ограниченной кривизны этот порядок после нормировки задачи `h^-2` стремится к нулю; без контроля полного остатка он не даёт ненулевого нормированного разрыва отклика.

5. Для периодических ветвей с равномерным разложением по целым степеням `h` до `h^4`, ограниченными `C^4` коэффициентами и остатком `O(h^5)` две точные средние коядра дают

   ```text
   (351402359/2108160) * mean(kappa^2) = 0
   (21506403637/154949760) * mean(kappa^2) = 0.
   ```

   Коэффициенты положительны, поэтому для фиксированного периодического фона этого класса `kappa(x) == 0`. Это закрывает регулярный класс на данном листе, но не является task-level no-go PR.

   Проверочный скрипт воспроизводит локальные коэффициенты и тождество суммы периодических сдвигов; сам переход ко всей глобальной решёточной системе порядка `h^4` изложен как аналитическая редукция в основном мемо. Если фон зависит от шага, например `kappa_h=h*kappa_1`, уравнение порядка `h^4` ограничивает ведущий коэффициент, а не вынуждает `kappa_h` быть точно нулём.

6. Точная чисто-Y транспортная проверка усилила прежнее ограничение на амплитуду. На каждом из 12 фазово-ролевых рёбер два boost-уравнения используют одну пару амплитуд `a,b`. Первое равно, с точностью до ориентации,

   ```text
   8*(a-b)*(a+b) / ((4+3*a^2)*(4+3*b^2)).
   ```

   Оно требует `a^2=b^2`. Второе при `b=-a` равно `±4*a*(3*a^2+4)/(4+3*a^2)^2`, ненулевому при любом вещественном `a != 0`; при `a=0` первое уравнение сразу даёт `b=0`. Значит, пара уравнений требует `a=b` без условия фиксированного знака. Шесть транспортных сдвигов порождают связную чётную подрешётку индекса 2, поэтому любая точно стационарная амплитуда внутри чистого Y-ансатца на периодическом `L=4m` носителе постоянна. Поперечные и не-Y поправки этим не исключены.

7. На плоском фоне точный кубический vertex проверяет низкочастотную волну центра: проекции `YY` и `DD` на постоянное dual-коядро равны нулю для всех 10 пар сдвигов; смешанная `YD` компонента может быть ненулевой. Dual-квадратичный источник кривизны остаётся положительным `351402359/2108160`. Это устраняет один плоский низкочастотный канал компенсации, но не curved vertices, резонансные/alias-сектора или высшие взаимодействия.

8. В product-plane seed независимое варьирование boost-dual `B` внутри лица даёт точно `+/-B` даже при четырёх независимых Cayley-параметрах на Y-связях. Поэтому строка `E_(K0,B)(x)=3 f(x)^2-sum_i f(x-h e_i)^2` не зависит от sitewise `z(x)`. На связной периодической области она исключает неконстантный `f` во всём commuting Y-seed классе, включая sitewise retuning центра. Это не исключает поправки вне commuting Y-подпространства.

## Какой вывод можно делать о непривычных зависимостях от `h`

В PR-задаче фон `Q_h` — выборка одного фиксированного гладкого фона. Поэтому `kappa` здесь — его фиксированная кривизна, а не последовательность `kappa(h)`. Для фиксированного фона нормальный jet и периодическое среднее исключают соответственно заданный конечный jet и регулярную ветвь описанного класса.

Остающаяся компенсация относится к h-зависимым центровым и поперечным поправкам, которые не удовлетворяют равномерным предположениям regular-branch сертификата. Если отдельно рассматривать семейство меняющихся фонов с `kappa(h) -> 0`, это другая постановка, требующая явного определения семейства и общей нормы.

Чтобы закрыть именно этот `z=1` лист для нерегулярных ветвей, нужен либо строгий анализ полной конечнорешёточной reduced map с uniform по `h` контролем её коядра, либо точная нерегулярная joint-critical ветвь. Один конечный нормальный jet и один плоский vertex такого контроля не дают.

## Граница с глобальной задачей PR #310

Для `z=1` Y-листа первый открытый математический шаг — исключить либо построить сингулярные/nonuniform центр-поперечные продолжения над фиксированным кривым фоном. Но глобальную задачу нельзя свести только к этому шагу: её контракт требует результата для объявленного класса joint-critical последовательностей, включающего #232 microstructure. Параметрические значения `z` вне `z=1`, другие допустимые фоны, near-resonant/Bloch sectors и topology/source conventions должны быть покрыты, если их не исключают дополнительные условия задачи.

Для подсемейства с `||log K_h||_infinity=O(h)` основной меморандум теперь
выводит subsequential закон отклика через положительную матричную
frequency-defect measure: конечные уравнения контролируют её поддержку в
`ker H_g(z) intersect ker C_g(z)`, а нормированный слабый отклик выражается
через `1/2 tr(D_Q H_g dmu)`. Это фиксирует точный объект для задачи о
реализуемости резонансных корреляций. Результат условный: требует weak-zero
остатка относительно #216-сравнения, даёт только распределительный предел
и не покрывает большие логарифмы, все нелинейные меры или owner sum norm.

В частности, generic-`z` вывод пока означает только: некоторый соответствующий рациональный минор не тождественно нулевой, поскольку он ненулевой при `z=1`; возможные исключительные значения лежат в конечном алгебраическом множестве на данном pivot chart. Явный числитель `P(z)` и само исключительное множество не вычислены.

Глобальные терминалы остаются открытыми:

- `A4D-JOINT-PALATINI-RESPONSE-DECOUPLING-CLOSED` требует доказать заявленную нормированную сходимость в topology/source convention PR.
- `A4D-JOINT-MICROSTRUCTURE-METRIC-RESPONSE-NOGO` требует точную smooth-background joint-critical последовательность с ненулевым нормированным response gap.

Даже равномерная нижняя оценка, исключающая все ненулевые `kappa_h` в конкретном классе, сама по себе не установит второй терминал: она исключит ветви, а не построит требуемую последовательность с response gap. Для исчезающей `kappa_h` остаток должен оцениваться относительно `kappa_h^2 h^4`; одной оценки `o(h^4)` недостаточно. Для фиксированного фона задача остаётся контролем нерегулярных поправок к связности, а не автоматическим поиском семейства фонов `kappa(h)`.
