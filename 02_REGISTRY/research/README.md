## How to use and maintain this map

1. Find the result's canonical claim or exact research source, then read its
   assumptions and current application before starting a repeated derivation.
2. Read the relevant book chapter for the connecting argument. Follow its
   immutable source link for research that has not entered this tree.
3. When a result changes a composed step, update that existing claim/application
   or ledger disposition and its book explanation together. Update this map
   for a major new reading route.
4. Keep earlier exact certificates and source pins unchanged. The
   [historical-book replay contract](sources/d0_book_editorial_inputs_2026-10-28/README.md)
   explains why an old receipt may intentionally use an earlier book snapshot.
5. Regenerate existing work, Lean and assembly views as required. These views
   index their authorities; they do not synthesize the book narrative.

The existing proof-architecture search also resolves exact IDs, declared
applications, source sections and book-heading candidates. Retrieval does not
supply semantic acceptance or a complete mathematical coverage percentage.
