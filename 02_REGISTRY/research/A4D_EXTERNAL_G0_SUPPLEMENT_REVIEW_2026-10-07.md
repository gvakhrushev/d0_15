## 2. Принятая формула для coframe-сектора

Здесь R — **линейный** `coframeMetricReadout`, d — `forwardGaugeCoframe`
из `D0/Geometry/A4DCoframeParentConstraint.lean`, L=N+2≥2, M=L^4.
Владелец доказывает R d=K, где K=`symmetricRoleGradient`.

Уже опубликованные результаты дают:

```text
rank d = 4(M−1),
rank K = 4(M−gcd(L,2)^4),
dim ker R = 6L^4+4L^3+6L^2  при чётном L,
dim ker R = 6L^4             при нечётном L.
```

Для ограничения R на im d теорема о ранге и ядре даёт

```text
dim(ker R ∩ im d) = rank d − rank(R d)
                  = 4(gcd(L,2)^4−1)
                  = 60 для чётного L, 0 для нечётного L.
```

Следовательно, корректно типизированный quotient имеет размерность

```text
dim [ker R / (ker R ∩ im d)]
  = 6L^4+4L^3+6L^2−60   для чётного L,
  = 6L^4                 для нечётного L.
```

При L=4 это **1828**. Это точное следствие прежних полных rank-теорем,
а не экстраполяция плотной проверки L=2. Обозначение `ker R \\ im d`
в присланном коде следует заменить указанным quotient: разность множеств
не является векторным пространством. Для чётного L=2 весь im d действительно
лежит в ker R, но при L≥4 это неверно — rank(R d)>0.

Источники: [метрический readout](A4D_NATIVE_CENTERED_METRIC_LIFT.md#3-full-metric-range-kernel-and-all-ten-packed-components)
и [полный образ трансляций](A4D_NATIVE_DYNAMICAL_OWNERSHIP.md#65-complete-metric-image-and-what-the-translation-ward-identity-says).
Их аналитические all-size доказательства и ранее скомпилированные символы
сохраняют свои статусы. Новый сертификат не превращает Fourier-теорему
автоматически в скомпилированное утверждение.

Явный свидетель при L=4,

```text
e(x,r,c) = 1[(r,c)=(0,1)] (−1)^(x0+x1),
```

имеет R(e)=0, поскольку его единственная ненулевая строка уничтожается
своим backwardAverage. Для принятой в коде ориентации
`C_{s,r,c}=D_s e_{r,c}−D_r e_{s,c}` получаем
`C_{0,1,1}(0)=+8`, не −8. Коммутативность forward-разностей даёт C(d xi)=0
для любого xi; следовательно, свидетель не принадлежит im d.

Это доказывает **непринадлежность образу forward-переносов**. Ни полная
физическая gauge freedom, ни физическая кривизна, ни совместный on-shell
gate отсюда не определены. Более того, общее равенство R(e)=0 не означает
неизменности нелинейной Gram-метрики: постоянная кососимметричная поправка
может иметь ненулевой квадратичный Gram-член. У конкретного свидетеля выше
сильнее условие: весь центрированный coframe равен нулю. Эти два случая
нельзя отождествлять.

## 3. Истории: 685 и 686 относятся к разным операциям

В S6 верны матричные тождества C1 Jt=I, проекция Jt C1 и C1 Js=T.
На буквальной сцене ранг C1 равен 33, её ядро на рёбрах имеет размерность
685. Присланный код проверяет матричные тождества на другом, пятивершинном
графе; для сцены он подставляет числа. Новая локальная проверка использует
все 718 рёбер фактической K(9,11,13).

Аддитивный функционал на всех допустимых путях действительно однозначно
задаётся 718 ценами рёбер. Это теперь независимо доказано общей Lean-
эквивалентностью в [исследовании историй](A4D_NATIVE_HISTORY_ACTION_BOUNDARY.md).
Однако его quotient по граничным потенциалам имеет размерность 686,
а не 685: градиенты потенциалов составляют 32-мерное пространство.
Размерность 685 в S6 относится к ядру усреднения C1.

Связь полная: `R^718 = ker C1 ⊕ im(Jt−Js) ⊕ R·1`, размеры 685+32+1.
Доказаны точный оператор C1(Jt−Js)=I−T, описание range и единственность
разложения. Существуют положительные, инвариантные по автоморфизмам цены
с одинаковым C1-readout, но разными значениями на путях одинаковой длины
с одинаковыми концами. Явный свидетель и доказательство приведены в
разделе 3.1 того исследования. Приписывать физическую различимость этим
скалярным ценам без полевой карты по-прежнему нельзя.

Сама запись `F=delta_gamma0` требует уточнения: индикатор ровно одного
полного пути обычно не аддитивен. Аддитивным является **число вхождений
выбранного ребра**. При склейке `[u,v]` с `[v,u]` индикатор пути `[u,v]`
уже нарушает аддитивность. Новый контроль различает эти объекты.

## 4. Сохранившиеся дефекты сертификата

* **S1d всегда PASS.** Его первый операнд содержит
  `all(... if False else True for nn in [3])`, равный True. Последующий
  правильный список значений после `or` не влияет на результат. Это
  опровергает заявление в заголовке, что безусловных успешных проверок нет.
  Общая кубическая теорема остаётся принятой по прежнему независимому Lean.
* **S4a–S4c** проверяют равенство единиц, различие символа J от 1 и
  производную константы. Они не проверяют все предпосылки двух
  контрмоделей. Исправление T16 подтверждается нашим предыдущим доказательством.
* **S5d–S5f** в основном проверяют положительность записанной формулы и
  арифметику 15·4=60. Всеобщая размерность принята по приведённому выше
  выводу из фактических операторов, а не по этим строкам кода.
* **S6i** проверяет только 718−33=685. **S6j** сравнивает два разных
  символа. Это не доказательство отсутствия функционала во всём ядре
  и не проверка двух полных моделей native-физики.
* 25 случайных curl-тестов не заменяют общую коммутативность разностей.
  Ненулевой curl свидетеля проверен отдельно с точным знаком.

## 5. Отдельные входы patch_s5.py и extra_dim.json

Оба текстовых маркера, по которым patch_s5 ищет секции S5/S6, отсутствуют
в присланном актуальном скрипте: он использует hdr(...). Поэтому такой
patch не применим к этой версии. Он также содержит старую подпись −8,
хотя его условие проверяет только ненулевость. Применять его поверх
исправленного сертификата не требуется; вход сохранён как происхождение.

В extra_dim.json размеры равны 16L, 10L и 4L, тогда как четырёхмерный
носитель имеет 16L^4, 10L^4 и 4L^4. Числа согласуются с одномерной
диагональной проверкой, но её генератор и определение операторов не
предоставлены. Поле rankR_on_imD везде null. Этот файл не доказывает ни
четырёхмерные размерности, ни размер пересечения; такая подмена отвергается.
