# Золотая асимметрия и относительный отклик

Проверка: `lake build D0.Representation.GoldenRelativeChannel` — PASS.
Модуль собран отдельно, без включения в `D0.All`.

Подсказка пользователя связывает ранее построенный золотой детектор с
`δ₀=(√5−2)/2`. При `p=φ⁻¹`, `p+p²=1` получаем:

`a₀=p`, `b₀=p²`, `2δ₀=p−p²=p³=φ⁻³`.

Поэтому указанная лестница записывается `Q(D)=φ^(D−4)` для целых D.
Это точная нормированная геометрическая последовательность. Физическое значение
индекса D требует соответствующего отображения в геометрию; одно преобразование
формулы его не устанавливает.

## Связь с уже существующим прибором

В `GoldenOrderInterferometer` ранее вычислен отклик когерентного сравнения порядка:

- тривиальный замкнутый знак: вероятности `(1,0)`;
- отрицательный знак: `(p⁶,4p³)`.

Теперь второй результат выражен через δ без нового параметра:

`(4δ₀²,8δ₀)`, причём `4δ₀²+8δ₀=1`.

Новый Lean-модуль `D0.Representation.GoldenRelativeChannel` доказывает эту связь.
Таким образом, δ из исходного расщепления уже определяет отклик построенного
детектора порядка. Это не дополнительная настройка его вероятностей.

## Сохраняемая сумма и перенос различия

Квадраты элементов существующего золотого затвора дают матрицу

```
T = [ p    p² ]
    [ p²   p  ].
```

Для диагональных входных весов `(x,y)` доказано:

`x′+y′=x+y`,

`x′−y′=2δ₀(x−y)`.

Следовательно, сумма и различие имеют разные точные законы переноса. На этом
уровне δ задаёт половину коэффициента переноса контраста. Матрица получена из
существующего затвора, а не подобрана независимо.

Граница: T переносит только диагональные веса. Когерентная эволюция переносит
также перекрёстные члены. Поэтому последовательное применение T предполагает
устранение когерентности между этапами; оно не заменяет автоматически эволюцию
полного внутреннего аппарата. При таком применении контраст умножается на
`(2δ₀)^n`, что отличается от приведённой пользователем рекурсии половины
разности `δ₀^(n+1)`: это разные операции.

Связь с относительной памятью пока имеет статус конкретного интерфейса:
сначала фиксируются проверяемые относительные альтернативы и их подготовка,
затем к их весам применяется этот уже заданный канал. Его универсальная
необходимость для всех допустимых экспериментов здесь не доказана.
